# Task-local evidence packet (example template)

**Optional Web discovery packet:** for substantive science, include actual search date/tool coverage, foundational/current and contradictory mechanism families, original equations/code/spec references, backward/forward citation threads, closest prior implementation, and *how evidence changed the explanation*. See [Web Research Discovery](../core/WEB_RESEARCH_DISCOVERY.md). An offline agent notes unavailable online coverage while continuing useful source and mathematical reasoning.


This is a *retrieval and handoff template*, not a required user-visible form or a fixed word quota.

**Research question:** What observed phenomenon or new mechanism should the next decision explain?

**Current decision:** Inspect actual implementation / derive a theorem / choose competing mechanisms / register an experiment / analyze a completed run / reformulate the problem.

**Pinned object:** repo@commit; model/checkpoint; actual config; execution mode; focal source graph with shape semantics.

**Observation:** one precise statistic or qualitative contrast, comparator, dataset/seed, source/artifact locator, and evidence level (not inferred from a queued job).

**Established results:** source-verified equations, relevant theorems, falsified predictions with narrow action/data/budget scope; references to full evidence.

**Open alternatives:** 1–3 *decision-relevant* mechanisms with different predicted observations. Ideation can branch wider, but the next expensive test portfolio should be compact.

**Execution context:** decision-time accessible signals; permission and resource budget; full costs of selection/kernel/measurement; terminal evaluator where registered.

**Useful next output:** scientific insight or operator first, then one decisive test/proof and how each outcome changes the decision.

## Example — illustrative only

- North star: Preserve dense video generation quality while reducing FFN execution work.
- Observation: a fixed sparse mask preserves subject identity but changes background lighting in some outputs (hypothetical case; not a measured new run).
- Two mechanisms: (A) errors project onto persistent low-frequency modes; (B) discontinuous mask switching creates step-to-step drift.
- Discriminator: compare equally sized local perturbations with controlled spatial-frequency modes and mask-switch events using existing traces first.
- Caveat that matters: complete hidden activation can define a W2-only oracle, not a claimed pre-W1 saving.
- New freedom: trade token/channel decisions for output-operator geometry or temporal-policy reuse; actual kernel savings require separate measurement.

Archive full experimental details by locator. The packet is only the smallest sufficient context for the next decision.
