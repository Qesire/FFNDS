**四、关闭的精确边界与仍未解决的问题**

关闭的是登记的两位置、16组预选池、q≤2、固定h匹配读出及其具体选择程序。没做的是全部216组的全域原生穷举、其他位置、完整M条件oracle和新机制；这些未知**不构成待执行清单**。此前≤4组的理论设想也不能自动承接q≤2失败成为下一轮调参。

从先前结果尚不能证明“冻结Wan在50%预算下不存在有效稀疏实现”。但本次也没有足够新证据指定另一个方法为可行首选。保持这个空缺，比把backlog或换名旧方法写成突破更准确。

若提出新分支，应使用[机制差异记录](../research/NEW_BRANCH_TEMPLATE.md)：指出最近失败配方、实际计算变化、旧阻碍为何不再适用、与旧方案和简单对照不同的预测、最小判别检验、成本与数据暴露。仅换名/扩大参数不满足这些内容。该记录不增加一套无条件人工审批流程，也不替代用户授权；它用于阻止把“未知”写成“准入”。

**五、防回退如何生效及其限制**

根目录[AGENTS.md](../AGENTS.md)要求后续研究先读当前决定与最新证据。运行：

```bash
python tools/check_research_routes.py
python tools/check_research_routes.py --method-id R4E1
python tools/check_research_routes.py --method-id R4E2
```

第一条检查当前记录一致性；后两条应返回非零并说明该路线关闭或下游未触发。检查器不加载模型，不连接worker，不初始化CUDA，不修改实验状态。它检查关闭状态、原生摘要门槛、下游依赖、当前入口与明确的准入列表，并为历史ID/阶段别名提供统一查找。

**它不是自然语言新颖性判定器，也没有拦截所有可能的shell/GPU入口。** 故意虚报机制、绕过AGENTS或直接启动历史脚本仍不可能仅靠这个小工具彻底阻止；语义对照与原有执行约束仍须遵守。不能把检查通过说成科学有效、GPU授权或最终验收。

本次没有修改原实验脚本、原协议、原始结果或质量阈值，也没有安排新模型作业。新增的测试仅验证拒绝状态不会因陈旧条目、别名或缺失依赖而被误判为可继续。
