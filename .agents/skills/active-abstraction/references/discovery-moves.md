# 从关系到构造

用已有的部分关系产生能够继续推演的候选。构造可以帮助发现关系，也可以暴露新的知识缺口；结合当前对象调整动作。

## 将关系推进成具体候选

先指出原方法哪些操作实际承担了目标作用，哪些实现要求可以放开。把开放的自由度用于改变所求对象、表示、状态或过程，写出一个可计算、可推导或可观察的后果。

对求解或生成路线，可以用接口

\[
\widehat y=D\bigl(x,S(E(x))\bigr)
\]

说明构造：\(x\) 包含当前任务所需输入与条件，\(E\) 建立新问题，\(S\) 是实际求解、生成或更新过程，\(D\) 结合所需上下文读取结果。声明对象类型与各环节可用的信息，将运算展开到足以检查其作用。新旧解的对应方向见 [数学判据](mathematical-tests.md)。

让候选在一个有代表性的输入或简单实例上运行、手算或推导。若某个环节只能写成“找到正确表示”“执行理想求解”，进一步研究怎样得到它：可调用哪些操作、需要估计什么、是否存在更容易实现的表示。

对理论路线，定义新对象、假设与待研究关系，推导特殊情形、推论或反例。对机制解释，明确竞争解释在哪些条件下产生不同结果。按研究对象发展构造，不必把理论与解释都改写成求解接口。

## 通过改变对象产生构造

下面是可组合的生成动作，具体对象还可引出其他动作。

| 改变的部分 | 怎样产生候选 | 可以继续推演什么 |
|---|---|---|
| 所求对象 | 把完整中间量改写为下游实际读取的作用、观测、差分或决策，推导直接求取关系 | 哪些计算随之省去，哪些后续查询仍得到支持 |
| 编码、坐标或度量 | 构造输入编码与结果读出，或按真实输入变化、输出敏感度重新组织逼近目标 | 非线性与约束怎样变换，新的误差如何连接到任务 |
| 中间状态或过程 | 加入辅助变量、记忆、轨迹或解族，使原目标成为新状态的读出 | 状态怎样更新，合法过程能否产生所需结果 |
| 分解与求值次序 | 沿依赖关系改写运算顺序、原始与对偶求解、分块或可复用状态 | 等式何时成立，数据移动、求解条件与摊销成本怎样变化 |
| 保证范围 | 研究真实输入、特定查询、局部区域或条件分布下的版本 | 哪些要求被保留或调整，剩余误差怎样传播 |
| 知识或能力来源 | 将原领域的构造、自然配对、模型能力接入目标问题，设计输入条件与读出 | 对应依赖哪些条件，哪些结果可达，缺少什么接口 |

例如，“低秩”可以服务于存储、去噪、函数族约束或特定方向响应。先确定当前构造使用的是哪种作用，再寻找实现；工具名称只提供继续理解的入口。

## 接续来自不同来源的知识

恢复来源中的对象角色、关系方向、条件与结论，建立当前所需的局部对应。利用关系相似提出候选，再研究各角色在目标任务中由什么承担；保留差异给出的新问题。

多个来源可以分别贡献表示、更新、求解或读出。组合时检查共享变量、信息时点与成立条件能否同时满足，并研究前一环节误差怎样影响后一环节。候选差异应来自信息、机制、假设或成本的变化。

说明三个不同方面：构造改变了什么，目标中保留了什么，当前依据支持到哪里。坐标变化或状态扩张描述构造动作；精确关系或误差界描述保留程度；原始证明、实测或经验能力提供不同依据。这些方面可以同时存在。

## 用构造结果继续发现

围绕当前主张寻找能改变判断的推导或观察。例如，方向作用的解释应产生输入方向变化的后果；跨状态关系的解释应涉及合法配对；状态复用的解释应涉及更新跨度；数据移动的解释应连接实际读写。

根据结果定位后续工作：

- 同一表示下需要不同答案，寻找被合并的区别并调整表示。
- 当前读出足够、后续更新失效，研究必要状态与记忆。
- 某个操作无法从现有信息得到，寻找可估计替代或改写接口。
- 候选已实现所需关系、目标仍退化，重新检查关系与目标的连接及适用条件。
- 数学收益未转化为实际收益，沿构建、调用与读出定位代价。

在构造、学习、误差分析与执行之间往返。根据已有进展决定继续实现、收窄主张，或形成解释边界与新的研究问题。
