# 数学知识地图与理论联系

## 知识条目保留什么

一个概念或定理应当足以支持理解、推理与进一步查证。根据内容需要保留下列信息，不要求每条知识填满同一张表。

| 内容 | 要保留的区别 |
| --- | --- |
| 原始问题与动机 | 它在原领域解释什么，为什么采用这个对象或结构 |
| 定义与类型 | 空间、映射、作用域、配对、概率条件、等价关系及坐标约定 |
| 核心关系与推导 | 公式如何产生，哪个步骤使用了哪项假设，证明中可复用的思路 |
| 定理与算法 | 数学结论、构造方法和数值实现分别保证什么 |
| 适用范围与反例 | 局部／全局、有限／无限维、精确／近似；缺失前提具体破坏哪一步 |
| 相邻知识 | 特例、推广、对偶、等价、不同表示、近似、极限或尚未建立的联系 |
| 来源与证据 | 原文位置与阅读范围；本文推导、外部定理、实测结果和假说分别标明 |
| 迁移线索 | 可以映射的结构、必须新增的选择、当前缺口与可提出的问题 |

已知数学结果可以与尚未确定的 AI 用途并存。反例也有知识价值：保留反例排除的具体结论，以及仍可探索的条件、结构与变体。

## 用有类型的关系连接理论

给联系注明性质，才能沿它继续推理。下面的关系可以并存，也可以只在明确范围内成立。

| 关系 | 需要说明什么 | 常见误推 |
| --- | --- | --- |
| 定义依赖 | B 使用 A 中的哪个结构 | 知道名称就视为满足定义 |
| 特例与推广 | 对象、假设、结论如何变化 | 放宽假设后沿用原强结论 |
| 等价与表示变化 | 可逆映射、重构或双向蕴含 | 仅有单向投影就宣称保留全部信息 |
| 对偶与伴随 | 所用配对、源与目标、实／复域与度量 | 把所有对偶都简化为同一种转置 |
| 结构保持映射 | 哪个组合、作用或不变量被保持 | 一项性质被保持就视为完整同构 |
| 拉回、推前与商 | 什么被搬运，什么被识别或丢失 | 将退化拉回当成正定度量；将商代表当成唯一对象 |
| 近似、松弛与模型选择 | 工作域、误差、偏差、可行集和目标变化 | 把近似改写成恒等式，或把新增结构说成已观测事实 |
| 离散化与极限 | 嵌入、尺度、边界、收敛方式和有限规模误差 | 用极限结论直接保证任意有限模型 |
| 类比与待验证联系 | 共享结构、尚缺桥梁、可检验的后果 | 由相同公式外形推出定理可迁移 |

例如“自然梯度使用 Fisher”“Fisher 是模型分布下的 score 二阶矩”“正则条件下 Fisher 等于期望负对数似然 Hessian”是不同关系，后两者的分布与正则条件必须保留。实际任务 Hessian、经验 Fisher 和广义 Gauss–Newton 也应分别定义；见[近似与优化](approximation-and-optimization.md) A5–A6。

## 跨领域反复出现的结构

以下连接提供继续学习与推导的方向；相关参考给出各自完整条件。它们的用途不限于表中已有例子。

### 配对与反向传播

对线性映射 $A:V\to W$，代数对偶拉回 $A^*:W^*\to V^*$ 由

$$
\langle A^*\lambda,v\rangle=\langle\lambda,Av\rangle
$$

定义。反向微分通过复合映射的对偶传递协向量；伴随状态方法也沿目标配对反传作用。概率核则在函数与测度的积分配对下建立双侧作用。共享的是配对关系；对象空间、连续性与可积性、复数约定和表示仍需分别定义。引入内积后才可通过 Riesz 识别写成相应度量伴随。

继续读[算子理论](operator-theory-and-functional-analysis.md) O3、[张量微积分](tensor-calculus-and-autodiff.md)、[学习与概率](learning-dynamics-and-probabilistic-models.md) LK04。

### 拉回与可见方向

若 $F:M\to N$ 可微，$g$ 是 $N$ 上的双线性形式，则

$$
(F^*g)_x(u,v)=g_{F(x)}(DF_xu,DF_xv).
$$

在实坐标中矩阵为 $J^\top GJ$。当 $G$ 正定时，拉回正定需要 $J$ 单射；否则 $\ker J$ 中的方向不可由这个形式区分。这一构造连接观测误差、几何度量、统计模型与优化中的若干二次近似，但形式相同不保证目标与意义相同。

继续读[流形建模](manifold-modeling-and-computation.md) GM01、GM06，[近似与优化](approximation-and-optimization.md) A1–A6；详细区别见[知识迁移](knowledge-transfer-and-discovery.md)。

### 对称、冗余与商

若群作用满足 $F(g\cdot\theta)=F(\theta)$，则同一轨道上的参数给出相同观测；在作用与映射光滑时，轨道的切方向被 $DF$ 消去。反过来，$\ker DF$ 中的方向还可能来自其他退化，不能据此认定全部不可辨识性都由已知群描述。构造光滑商还需相应作用的正则条件。

这条联系把因子的缩放／基变换、模型参数冗余、可辨识性与商几何连接起来。继续读[张量代数](tensor-algebra-and-symmetry.md) TA08–TA10、[微分流形与丛](smooth-manifolds-and-bundles.md) MF14–MF17、[流形建模](manifold-modeling-and-computation.md) GM01–GM04。

### 分解、潜在结构与可计算表示

分解把复杂对象表示为可复合的因子；共享的代数结构可以出现在多线性张量、统计矩或计算图中。因子能否辨识、截断误差如何、怎样收缩、是否降低资源消耗是独立问题。保持原对象不变的因子变换，还与上一节的冗余和商相连。

继续读[张量分解](tensor-decompositions.md)、[张量网络与统计](tensor-networks-and-statistics.md)、[张量编译](tensor-compilers-and-layouts.md)。同一个分解表达可以连接统计解释与硬件实现，但须分别建立证据。

### 投影、粗粒化与闭合

给定离散动力学 $x_{k+1}=F(x_k)$ 和表示 $z=\Phi(x)$，若存在 $F_r$ 满足

$$
\Phi\circ F=F_r\circ\Phi,
$$

则 $z_{k+1}=F_r(z_k)$ 在该表示中精确闭合。这只说明所保留变量的演化；非单射 $\Phi$ 通常丢失原状态的信息。若等式不成立，差值（在差值有定义的空间中）可以作为闭合缺陷研究，也可以增加状态、引入记忆或改为条件概率模型。哪种方式有效由目标与证据决定。

这条关系连接降阶、可观测量、压缩表示与充分状态。继续读[近似与优化](approximation-and-optimization.md) A11–A12、[学习与概率](learning-dynamics-and-probabilistic-models.md) LK02、LK04、LK09。核对原动力学、表示与约化动力学，而不是把拟合成功自动视为闭合定理。

### 复合次序、路径与局部到全局

复合的非交换性、局部信息能否拼接、沿不同路径得到的结果是否一致，是多个领域都会提出的问题。矩阵交换子、向量场 Lie 括号、联络曲率和全局拓扑分别作用于不同对象；它们之间需要具体构造才能建立联系。一个顺序敏感的网络并不因此自带指定的几何曲率。

继续读[数值线性代数](numerical-linear-algebra.md) N6、[微分流形与丛](smooth-manifolds-and-bundles.md) MF13、MF17、[微分几何](differential-geometry.md)、[全局与辛几何](global-and-symplectic-geometry.md) GS01、GS04、GS08。

## 由知识提出问题并扩充知识库

从一条已理解的知识出发，可以询问：去掉一个前提后哪一步失效？改变配对、观测、群作用或尺度会得到什么？原领域的反例在模型中对应什么机制？两个理论是否描述了同一对象的不同表示？数值或硬件限制能否反过来促成一种新的数学表示？

沿这些问题形成候选联系，再按需要查原始来源、推导映射、构造反例或验证预测。探索允许暂时没有直接应用，允许结论是“这条联系在该条件下失败”；失败的范围应具体，不能泛化为整个领域不可迁移。

扩充时把知识放到其自然概念位置，建立指向已有材料的关系，并记录原文定位。新来源的阅读范围、数学正确性、迁移的证明程度、实际收益和学术新颖性分别核查。不要把仅有题名、摘要或二手介绍的条目写成已完整收录。

本页承担概念导航与关系组织；具体定理、算法、来源及既有核查记录由所链接的参考保留。需要全面覆盖某批论文时，再使用[来源覆盖表](source-coverage.md)核对。
