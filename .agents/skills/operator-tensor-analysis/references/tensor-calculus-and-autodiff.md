## C1 命名轴与表达代数

**对象与用途。** 对数组计算，用轴名区分相同大小但不同身份的维度；对几何对象另保留向量空间与对偶类型。令 shape 为轴集合 S，数组是从索引记录集合 rec(S) 到标量域的函数。共享轴必须具有相同取值域；缺失的轴按声明广播。命名轴不是内存 stride。[CS03]

统一乘法定义为

\[
C[s_3]=\sum_{(s_1\cup s_2)\setminus s_3} A[s_1]B[s_2].
\]

这同时表达内积、外积和逐元素乘。输出标签决定保留轴，不能只凭“重复两次”猜归约。[CS02]

该式要求 \(s_3\subseteq s_1\cup s_2\)，且各轴在本操作数内已是不同的槽；新输出轴须先显式广播，同一操作数内的重复标签须先解释为取对角等操作。这里的无共轭乘积是双线性收缩，复数 Hermitian 内积还须对指定操作数取共轭。

| 操作 | 轴关系 | 拉回的对应操作 |
| --- | --- | --- |
| reshape / 可逆轴合并 | 保存双射及输出槽次序 | 逆双射 |
| rename / transpose | 身份改名或排列；禁止无意轴合并 | 逆改名或逆排列 |
| broadcast | 沿新增轴复制 | 沿所有复制轴求和 |
| sum reduction | 消去指定轴 | 沿这些轴广播 |
| mean reduction | 求和后除以轴大小 | 广播后除以同一大小 |
| gather | 按索引读入，可重复读取 | scatter-add，重复索引须累加 |
| mask | 固定 mask 逐元素选择 | 对已选分支分配 cotangent |

例如 `Y[b,i]=X[i]+B[b,i]`，则 `barX[i]=sum_b barY[b,i]`。大小偶然相同不意味着 b 与 i 可互换。求导时将输入轴复制并改名为新槽，如 `J[out_i,in_i]`；否则同名轴可能错误形成对角或收缩。Named Tensor 的广播、部分索引、收缩、归约和轴改名提供此流程的正式依据。[CS03]

## C2 微分、JVP 与 VJP

**目标。** 对 F:V→W，先确定需要 DF(x)、DF(x)u、DF(x)*v，还是一个标量目标的梯度。实有限维空间中

\[
J^a{}_i=\partial_iF^a,\qquad
(Ju)^a=\sum_iJ^a{}_iu^i,\qquad
(J^*\lambda)_i=\sum_a\lambda_aJ^a{}_i.
\]

VJP 是对偶拉回，不必先定义欧氏梯度。若实坐标中的内积由正定矩阵 M_V、M_W 给出，伴随为 `J†=M_V^{-1} Jᵀ M_W`。复线性映射在线性对偶基中的拉回仍用 Jᵀ；经 Hermitian 内积识别后的伴随用 `M_V^{-1} Jᴴ M_W`。一般实可微复映射使用 C8 的两分支规则。

**图算法。** 对结点 `v=f(a,b)`，前向累积 `dotv=D_a f[dota]+D_b f[dotb]`；反向从种子 cotangent 出发，对每条使用边累加 `bara += D_a f* [barv]`。共享子表达式的贡献必须相加；分支不能覆盖已有 cotangent。高阶求导可把所得表达继续微分。[CS01, CS02]

**代价。** 只需一个 JVP 或 VJP 时，传播方向种子而非单位阵。求整个 m×n Jacobian 的朴素方法分别需要 n 个前向方向或 m 个反向种子；批处理、稀疏和结构压缩可能改变常数与策略。用 `n<m` 选择前向只是起点，仍应检查中间张量和复用。

## C3 基本算子的微分字典

以下采用实 Frobenius 配对 `〈A,B〉=tr(AᵀB)`，bar 表示由下游传来的 cotangent。复数情形转到 C8。对光滑嵌入子流形及其诱导度量，环境梯度正交投影到切空间才得到 Riemannian 梯度；参数化变量须按参数化拉回，一般不等式约束也不能一律当作切空间投影。规则可由 `〈barY,dY〉=〈barX,dX〉` 逐项推导。[CS04]

| 算子 | 前向微分 | 反向拉回 / 条件 |
| --- | --- | --- |
| Y=AB | dY=dA B+A dB | barA=barY Bᵀ，barB=Aᵀ barY |
| y=φ(x) | dy=φ′(x)⊙dx | barx=φ′(x)⊙bary；共享广播按 C1 还原 |
| Y=A⁻¹ | dY=−Y dA Y | barA=−Yᵀ barY Yᵀ；A 可逆 |
| y=A⁻¹b | A dy=db−dA y | 解 Aᵀλ=bary；barb=λ，barA=−λyᵀ |
| s=log det A | ds=tr(A⁻¹dA) | barA=bars A⁻ᵀ；实 log 要 det A>0，SPD 时常用 Cholesky |
| s=det A | ds=〈cof(A),dA〉 | 奇异点仍用余子式；`det(A)A⁻ᵀ` 只适用于可逆 A |
| s=‖A‖²_F/2 | ds=〈A,dA〉 | barA=bars A |

**softmax 与 log-sum-exp。** 令 p=softmax(x) 在指定轴归一化，则

\[
Dp[u]=p\odot\left(u-\mathbf1\sum_jp_ju_j\right),\qquad
D\operatorname{LSE}(x)[u]=\sum_jp_ju_j.
\]

不物化 `diag(p)−ppᵀ`，即可在 O(n) 工作与 O(n) 中间量内计算 JVP/VJP。相同推导适用于每个命名轴切片；mask 全空时须先定义函数值。

**LayerNorm / RMSNorm。** 在长度 n 的归一化轴上令 `P=I−11ᵀ/n`、`c=Px`、`σ²=cᵀc/n+ε`。固定 γ、β 时

\[
D\operatorname{LN}(x)[u]
=\gamma\odot\left(\frac{Pu}{\sigma}
-\frac{c\,c^\top u}{n\sigma^3}\right).
\]

RMSNorm 将 c 换成 x、P 换成 I。ε>0 提供正分母；γ、β 或统计量也变化时加入对应导数。训练态 BatchNorm 的统计轴会耦合样本，不能沿用逐样本块对角结论。

**分解的微分。** Cholesky 的 A=LLᵀ（A SPD）给出

\[
E=L^{-1}(dA)L^{-\top},\qquad
D L[dA]=L\Phi(E),
\]

其中 Φ 保留下三角、将对角减半。通过三角解实现，避免形成逆。对实对称 A 的简单特征对 `(λ_i,q_i)`，

\[
d\lambda_i=q_i^\top(dA)q_i,\qquad
dq_i=\sum_{j\ne i}q_j\frac{q_j^\top(dA)q_i}{\lambda_i-\lambda_j},
\]

采用 `q_iᵀdq_i=0` 的规范。简单正奇异值满足 `dσ_i=u_iᵀ(dA)v_i`；奇异向量微分包含 `σ_i²−σ_j²` 的分母。重根附近改研究不变子空间或投影，不能通过添加任意 ε 来宣称精确导数。[CS04]

## C4 高阶导数与直接方向作用

**HVP。** 对 C² 标量 f，

\[
H(x)u=D(\nabla f)(x)[u].
\]

对梯度程序做前向方向微分即可计算 HVP；也可对 `〈∇f,u〉` 反向求导，但 u 必须作为固定方向。工作量通常为梯度求值的常数倍，仍受原计算图大小控制；不是对任意稠密 n 参数问题无条件 O(n)。这是 Pearlmutter 的 R 算子思想。[CS05]

**多方向与 Taylor jets。** 若沿路径 `x(t)=x₀+t u`，可传播系数 `x^{[k]}=(1/k!)d^kx/dt^k`；乘法遵循卷积 `c^{[k]}=Σ_{j=0}^k a^{[j]}b^{[k−j]}`。这计算一条路径上的高阶信息，不等于完整 n^k 个混合分量。多变量 jets 的系数数目为 `binom(n+k,k)`，仍存在组合增长。

**高阶链式法则。** 在光滑条件下，用集合划分组织 Faà di Bruno 公式：

\[
D^k(g\circ f)[u_1,\ldots,u_k]
=\sum_{\pi\in\mathcal P_k}
D^{|\pi|}g(f)
\left[ D^{|B|}f[u_i:i\in B] : B\in\pi\right].
\]

每个输入方向恰好出现在一个块中。k=2 时恢复链式法则的两项；k=3 时出现一个三阶外函数项、三个二阶交叉项和一个三阶内函数项。用分区计数检查漏项；实际计算优先共享中间方向作用。

## C5 求导图的化简、重排与压缩

**化简流程。** 给新导数槽使用新指标；消去 Kronecker δ 的复制槽；合并相同子表达式；将重复使用的缩放/投影提取到共同结点；最后选择收缩路径。δ 是恒等映射，不能把带两个同变槽的度量随意当作它。逐元素非线性也不具有任意换基协变性。[CS01]

**cross-country。** 在把每条输入到输出路径切断一次的计算图切面 S 上，链式累积可写为

\[
D_xy=\sum_{v\in S}D_vy\circ D_xv.
\]

允许混合前向和反向，并优化局部乘法序。对逐元素 g、h 的 `B g(h(Ax))`，先算 `g′⊙h′`，再缩放 A 或 B，避免构造两个稠密对角矩阵。任意 DAG 的最优顺序并无通用廉价解；以实际维数、稀疏性、峰值中间量和调用次数选择。[CS02]

**精确结构压缩。** 若 `f(U)=‖T−UVᵀ‖²_F` 且 V 固定，令 K=VᵀV：

\[
H_{ia,jb}=2\delta_{ij}K_{ab},\qquad H[\Delta U]=2\Delta U K.
\]

存 K 只需 O(k²)，作用需 O(nk²)，无需存 `(nk)×(nk)` 数组。Newton 方程可对小 K 分解一次、对 n 个右端求解；代价还含右端构造与 O(nk²) 的求解，不只是 O(k³)。K 奇异时须使用相容解、阻尼或最小范数约定。此压缩保留完整算子，而把 H 近似成低秩是另一项决定。[CS02]

## C6 稀疏导数与图着色

**对象。** 已知一个可靠的结构非零模式 P。构建列相交图：两个输入列在某一输出行可能同时非零时连边。对图正确着色，种子矩阵 `S[j,c]=1{color(j)=c}`，前向求 `B=JS`。因为同一颜色各列的非零行互不重叠，可用 P 从 B 无歧义恢复 J。[CS06]

**代价与条件。** 若需 c 色，使用 c 个方向而非 n 个方向，再加着色与解码成本。当前点上的偶然数值零不能证明结构零；错误模式会把多个分量混加。反向可对行着色；Hessian 的对称性允许 star/acyclic coloring 及相应恢复规则，不能直接套普通邻接图着色。已知三对角 Jacobian 时，输入列按 j mod 3 分色即可三方向恢复；不同边界模式先核查冲突。

**Hessian 的两种恢复。** 对对称 H，以其结构图的每个顶点代表一个变量，非对角可能非零项代表边，先用 HVP 计算 B=HS。star coloring 要求正常着色且任意两色诱导子图都是星形森林；每条边至少在一个端点的对应颜色组中唯一，可直接读出并用对称性填另一半。acyclic coloring 只要求两色诱导子图是森林，允许更少颜色：在每棵两色树上找叶子 i，其唯一邻居 j 的 H_ij 可由该行压缩和读出；从邻居的压缩和中减去已知项、删边，继续叶子消元。对角元由自身颜色列直接恢复。该流程依赖正确的结构模式与对称性，浮点减法会引入恢复误差。[CS06]

## C7 隐函数、平衡层和优化层

**对象。** 通过 `R(z,θ)=0` 定义解 z*(θ)。R 为 C¹ 且 `A=∂_zR` 在该解处可逆时，隐函数定理给出

\[
A\,\dot z=-B\,\dot\theta,\quad B=\partial_\theta R;
\qquad
A^\top\lambda=\bar z,\quad \bar\theta=-B^\top\lambda.
\]

用 JVP/VJP 与线性求解实现，无需显式 A、B 或 A⁻¹。对于 `z=T(z,θ)`，选 `R=z−T`；若 `‖D_zT‖<1`，逆可用 Neumann 级数或固定点迭代。若只知道谱半径小于 1，虽有有限维渐近收敛，非正规性仍可能造成长暂态。[CS07]

**选残差。** 无约束光滑优化用 `R=∇_zf`；等式约束可对原始—对偶 KKT 系统求导；不等式约束须说明活跃集及正则性。prox / projected fixed-point 只有在相应映射可微或选定广义导数时才能采用同样的线性系统。近似根与近似线性解都会影响梯度，应分别报告残差，不能以求解器“已停止”代替误差依据。

**可核验实例。** 岭回归 `A(λ)=XᵀX+λI`、`z=A⁻¹Xᵀy`，则 `dz/dλ=−A⁻¹z`。λ>0 保证 A SPD。展开有限步迭代所得的是该有限程序的导数；隐式方法目标是所选根的导数，二者须在收敛及稳定条件下比较。[CS07]

## C8 复数微分

对 `z=x+iy` 的实可微 f，定义

\[
\partial_z=\tfrac12(\partial_x-i\partial_y),\qquad
\partial_{\bar z}=\tfrac12(\partial_x+i\partial_y),\qquad
df=f_zdz+f_{\bar z}d\bar z.
\]

实值非恒定损失通常不全纯。若把梯度 g 定义为 `df=Re(gᴴdz)`，则 `g=2∂f/∂barz`；某些文献和框架使用不同二倍因子约定，先固定配对。例 `f(z)=|z|²` 给 `∂f/∂barz=z`、g=2z。共轭变换是实线性而非复线性；不能对含共轭或绝对值的函数只传播复解析导数。[CS08]

对 \(F:\mathbb C^n\to\mathbb C^m\) 的一般实可微映射，令 \(A=\partial F/\partial z\)、\(B=\partial F/\partial\bar z\)，则其 JVP 与上述实配对下的拉回为

\[
DF(z)[u]=Au+B\bar u,\qquad
DF(z)^{\dagger_{\mathbb R}}[g]=A^Hg+B^T\bar g.
\]

第二式由 \(\operatorname{Re}(g^HDF[u])=\operatorname{Re}((DF^{\dagger_{\mathbb R}}[g])^Hu)\) 直接推出；\(F(z)=\bar z\) 时两种传播都是取共轭。\(B=0\) 才退化为复线性微分和 Hermitian 伴随。高阶导数若仅假定实光滑，应把 \(\mathbb C^n\) 看成 \(\mathbb R^{2n}\)，或保留 \(z,\bar z\) 的混合槽，不能声称它属于复多线性 \(\operatorname{Sym}^k((\mathbb C^n)^*)\)。[CS08；两分支拉回由配对独立推导]

## C9 状态、非光滑与 checkpoint

**状态。** 对迭代 `s_{t+1}=F(s_t,θ_t)`，先决定终端目标是否通过全部历史依赖求导。反向依赖前向状态；有随机数、mask、控制分支时，重算必须恢复同一计算语义。detaching 缓存、截断 BPTT 和改变求导边界都会改变导数对象。

**非光滑。** ReLU 拐点、max 并列、排序次序改变处通常没有经典导数。AD 对执行分支采用的导数约定不自动构成所有方向的正确导数，也不自动等于 Clarke 次微分的任意合法选择。局部 Lipschitz 且满足条件时才使用广义 Jacobian；若算法依赖该性质，需要额外核对链式规则。

**重算换内存。** 长度 T 的同等规模串联图，存每 K 步的 checkpoint，反向时重算一个区段并暂存其 K 个状态，峰值状态数为 O(T/K+K)。取 K≈√T 获 O(√T) 状态与 O(T) 额外前向工作。这是简单可推导方案；Revolve 研究给定 checkpoint 预算、可重放时间步等模型中的更优调度，其“最优”不涵盖任意异质 DAG、通信和随机副作用。[CS09]

## C10 数值验证与调用选择

| 要回答的问题 | 首选形式 | 具体核验 |
| --- | --- | --- |
| 局部输出响应 | JVP | 多尺度中心差分，避开不光滑点 |
| 标量损失梯度 | VJP | 检查随机方向 `〈λ,Ju〉=〈J*λ,u〉` |
| 曲率作用或 Newton-CG | HVP | 比较梯度方向差分，检查光滑标量 Hessian 的对称性 |
| 全部稀疏 Jacobian | 着色压缩 | 结构模式与种子解码相容性 |
| 高阶张量结构 | 保留槽位的符号微分 | 对称输入槽、δ 化简、方向作用交叉核验 |
| 根或最优解对参数的响应 | 隐式 JVP/VJP | 原问题残差、伴随残差及分支条件 |

中心差分的截断误差通常为 O(h²)，舍入误差随 1/h 放大；单一极小 h 的不吻合不足以否定推导。数值相符支持实现一致性，不能证明全域恒等式。当前 AD 库的 API、算子覆盖和性能必须检查对应版本；不把 2018/2020 年论文的框架比较当作今天的能力边界。
