# Web Research Discovery — WARD

**Activate by default** for substantive scientific exploration, literature review, current/novel research directions, novelty audits and independent reviews whenever web tools are available. For a simple static fact check, use the narrow source required. For open science, use the web to discover additional mechanisms **before selecting one operator**.

1. **FRAME:** anchor to the user's original question and identify the observed phenomenon. Generate complementary conceptual, mathematical, implementation and failure-mode search formulations.
2. **BROAD SEARCH:** find foundational + current work, neighboring domains and mutually competing explanations; include negative evidence and independently named similar mechanisms.
3. **DEEP READ:** inspect primary method equations, experiments/ablations, original source code/config or official specifications relevant to the actual claim.
4. **CHASE CITATIONS:** backward/forward references, related versions and new vocabulary from important seeds; refine the research question based on genuine new information.
5. **COMPARE:** establish the closest mechanism-level competitor and exact difference in source, chronology, computation, assumptions or predicted consequence.
6. **SYNTHESIZE:** return a new scientific insight or revised hypothesis, strongest contradictory explanation, decisive next observation, and actual source/provenance.
7. **TRACE:** note when and where searching occurred, material personally read and remaining gaps. If web browsing is unavailable, use accessible local evidence and clearly mark online search as pending.

Apply [web research protocol](../../../core/WEB_RESEARCH_DISCOVERY.md) together with mechanism-research, research-expansion and problem-reformulation as appropriate. This skill generates information and hypotheses; model experiments and external writes retain independent authorization.
