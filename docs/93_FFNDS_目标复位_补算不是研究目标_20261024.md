# FFNDS 目标复位：停止将 dense 补算作为默认研究对象（2026-10-24）

## 首要结论
**核心任务：降低 Wan 四步蒸馏 I2V 中 FFN 实际执行成本，在相同冻结模型/调度/精度/来源条件下保持完整视频质量。** 可以通过动态或静态、无补算或带补算、无补偿或带补偿、改进原权重/激活/组构造或改变执行单位实现。**补算、R256、UB1 支持、行级 dense exception 均不属于目标函数，也不是算法成立的必要条件。** 研究目标包含真实 FFN latency、完整 generation wall、部署开销与质量的 Pareto 改进。

错误不是某个秩下界的局部数学适用范围（另见历史 Issue #7 早期记录），而是 **从现有 dense/UB1 标签和完成路径倒推候选设计，把最容易观察的“哪些行应恢复 full FFN”提升为方法选择默认前提**。有效研究应先寻找不同的低成本完整算子，再针对其各自的误差与下游传播选择恰当机制，绝不要求用 R256 修复后才被视为合法候选。

## 对原始研究行为的具体纠正

| 旧隐含前提 | 新的行为 |
| --- | --- |
| 首先固定 UB1，再决定给哪些行补 dense | 先寻找可执行且便宜的 FFN 算子族；direct narrow/select/merge/group/conditional independent operators 无补算即合法 |
| 完整 compensated 64-channel 动作是新方法标签唯一来源 | 标签必须是**候选的真实完整输出/传播**；无补偿直接算子就测直接算子，不凭空施加 correction |
| 通道动作都与 Dense−UB1 residual 有关 | Dense D-Q 是同条件质量参考，不自动成为计算图的父节点；只有恢复型动作才定义“恢复值” |
| 首先验证补算的条件收益 | 先验证被选择的算子能否在真实数据上降低所需计算并保持下游视频质量；补算的额外收益/成本在专门比较时测量 |
| 只有主 W1 前可判定的 dynamic route 才能探索 | 可以无路由（静态算子），也可以在部分已付费计算后路由；只要求其信息在真实决策时可得且总成本确实更低。若论文声称 pre-W1，仍按其合同验证 |

**候选集合不设默认路径：** A 直接选择/裁剪/重组原生通道或组（无补算，无 R256）；B 把冗余折入较窄 FFN（合并、条件重参数、共享计算），原生不执行被删除的路径；C 按输入/步/层/区域选择不同的低成本算子或连续组合，允许无恢复分支；D 如果独立证据支持，可增加低秩补偿、有限的 dense 补算或少量后训练，但它们仅是**有计费的可选对照/候选**。这些分类用于发散而非互斥或固定名额；E/T/R AutoResearcher 的表示变换可产生新的类别。

## 真实比较准则

一项候选合法性不依赖是否来自 UB1、能否重用旧 teacher/dense 标签、是否存在补算接口、是否选择 64 通道组或是否有 R256。每个候选分别说明：
1. **实际算子**：原输入到输出计算图、GELU/Q1/Q2/alpha/bias/residual/gate、形状和能裁撤的真实工作；允许改变算子时应正确定义新的量化边界。保留旧模型并不自动要求保留旧 UB1 的 alpha/b2/R256。
2. **实际省算**：W1/W2 MAC、激活/量化/算子准备、selector、权重、布局、Kernel/壁钟。一个路径减少 MAC 但新增另一路大计算，不得直接计为加速。
3. **质量**：首先同前缀数值/块输出，关键候选需要自由四步完整配对视频，尽量避免新方案的背景/小物体/光照抖动，最终按独立来源官方 I2V 多指标和真实延时的 Pareto 判断。
4. **控制**：Dense D-Q 精度和视频参考、最佳适配的**同实际执行代价静态方案**、现有强基线（UB1、若适用）和近邻论文实现。补偿/补算的消融仅在相同候选定义下能独立开关且成本可匹配时才要求。
5. **先例与归因**：积极借鉴/重组方法，只避免把完整等价方法冒称原创；历史 R4/R8/R9/R12/C1/C2 只关闭实际执行过的实例。特别是 R12 的“无补偿”对照同时改变 alpha、folded b2 和 R256，不能单独证明任一项不可缺。

**机制评估和算法选择不是一回事。** 已有保存的 Dense/UB1/C1 行恢复标签能研究该动作族的条件收益，但不能证明全体 FFN 稀疏算子的 Pareto 上界。负结果应标记为 `action_family + exact_operator + compensation + compute_budget + data + metric` 的局部结论，不能归因于“必须恢复 dense”。

## 暂停状态及执行边界

依据 [研究暂停凭证](../research/20261024/EXPERIMENT_PAUSE.json)，所有 CPU/GPU/模型实验与自动后续任务仍暂停；本文件只校正目标、已有证据解读与未来方法选择，不授权运行试验。C2N2 因隔离问题停止于 **0 native forward / 0 video**。历史已登记协议、真实结果和资源账目不可重写；只调整今后的研究优先级与 Agent 指引。若未来明确恢复，先从宽方法空间提出数个机制不同的可执行算子，对同来源、同预算的质量—速度基线进行针对性检验，而不是默认恢复旧 C2 路线。

## 在新研究任务中的优先级

`OPTIMIZE_TRUE_COST_SUBJECT_TO_VIDEO_QUALITY` > `GENERATE_OPERATOR_CHOICES` > `COMPARE_MATCHED_COST` > `CHOOSE_WHETHER_TO_RESTORE`。

这个优先序是一条**目标防偏规则**：不是规定“必须无补算”，而是禁止“必须有补算”或“先研究补算”。改变补算假设时，应当先尝试**直接不补算**的可执行对照，是否使用任何补偿由独立证据决定。
