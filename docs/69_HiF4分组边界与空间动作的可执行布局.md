# HiF4 分组边界与空间动作的可执行布局

**新增结构认识：完整 64 通道组与行切分可以保留当前 HiF4 的量化边界；任意重排单通道不可以。** 这给空间 FFN 动作提供一个可实现的接口，但尚未证明新 tile 的原生 GEMM 数值、动态收益或速度。

## 原生计算与实际 CPU 判别

已检查当前 `QType.py`、`QTensor.py`、`QFuncs/hifx.py` 和 `hifxg_quant_cuda.cu`：[实际记录](../research/20261022/R12_HiF4_group_separability.json)。`hifx4` 使用 64 个通道及其内部 4/8/64 层级，outer block=1；CUDA inner 每个线程只读取、处理、写回自身连续 64 个元素。尺度不依赖整幅 token、整行所有 hidden 或其它64组。所有当前输入/hidden 宽度均整除64。

若 P 选择或重新排列完整输入行，S 选择且保持各组内部次序的完整64组，在相同保留输入值和分组边界下，有

`Q(P X[:,S]) = P Q(X)[:,S]`。

这是对分组算子的结构推导。实际 CPU 检查执行了原作者**未经改动的 Python reference 函数体**：8份已保存 OP2 的真实 post-Q1 张量（各256行）上，整组重排、整组选择、行分段、行重排共32项逐位通过；另外4个使用已冻结108/162支持的合成 hidden 检查通过。反过来，在每个64组内交换第0/4通道后逆置换，有 **401 个 BF16 元素不一致**。这反驳任意通道重排均可交换的假设，未把 CPU reference 冒充已运行 CUDA 对照。

仍需验证的边界是**实际 GEMM**：改变 M/N/K、布局与写回可能改变 BF16 累加/算法；只凭 Q 的可分性，不能把整幅输出裁成 tile 当作已执行的新动作。D0 的原生对照和任何将来的 tile 登记保持独立。

## 来自真实 token 几何的成本约束

原 flow `[16,21,58,104]` 对应 patch `(1,2,2)`，所以 FFN 网格是 `[21,29,52]`、M=31668。[整数布局验算](../research/20261022/R12_native_tile_layouts.json)给出：

| 等行数两区的定义 | 每区行数 | 每区连续片段 | 意义 |
|---|---:|---:|---|
| 每帧左/右26列 | 15834 | 609段，每段26行 | 空间半区真实等预算，但直接拼成大矩阵需要搬运或带 stride 的执行 |
| 每帧 row-major 前/后754行 | 15834 | 21段 | 相同主MAC，几何与访存不同 |
| 完整序列前/后半 | 15834 | 1段 | 可用连续视图，但不是左右空间半区 |

复制式实现若完整 gather 输入、scatter 输出，各读写一次，每个 FFN 额外流量约 **1.30GB**。这是具体实现的流量账，不是所有 fused/strided kernel 的下界；共享 Q1、直接输出到分区或融合可以改变它。相同组数并不意味着相同时延。

21 个 latent frame 无法按整帧均分。10/11帧直接分配216/108组，两个方向的全局主MAC分别为 **49.99256% / 50.00744%**；后一项已超过原50%门槛。不能用“两个半区”这个名称掩盖真实行数不同。14帧216组、7帧54组只是一条等预算算术例子，属于另一动作，**不在 D0 中执行**。

## 对后续方法构造的影响

目前开放三种有不同预测的构造，均未登记为新模型任务：

1. **保持原64组的规整空间宽度动作**：改变不同区域实际执行的两侧 GEMM，量化边界不变。与最优固定空间布局比较；若真实传播后无条件收益，停止给该动作族加 router。与 FIS-DiT 的完整帧稀疏计算/插值区别需用原生结果体现。
2. **利用原有低秩投影作决策与恢复的共享信息**：现有 R256 在 W1 前已经计算 `h=BF16Linear(Q1, first, bias_first)`。未来可考虑共享该前置基底，预测新动作的 signed value，再使用对应读出；这比追加一套全输入扫描更有成本潜力。但动作专属 first 会造成选择循环，必须先固定共享基底，并计入统计、路由和写回费用。HP/NF 的 C-score/局部输出失败不等于这种新标签可预测，也没有证明其可预测。
3. **改变功能坐标**：只重命名完整64组不会产生新函数类；跨原组混合单通道又会改变量化。任何新功能基须正面比较这项数值变化和已有 R4/R9 失败，不能把重排假设当等价证明。

这些是为质量—真实加速目标寻找可执行动作，不增加并列模型作业。已批准 D0 仍只检验原三个 raw 动作；空间动作、共享补偿与自由视频均需要各自的冻结实验。

## 最新先例的原文复查

[FIS-DiT v2](https://arxiv.org/html/2605.11869v2)第3.3节对完整 latent frame 选 anchor、插值恢复并按 block 交错；主 Wan 评测是四步 **T2V Lightning LoRA**，不是当前 I2V HiF4。其固定校准的空间/深度策略必须作为相关静态先例，输出拼接5.089%仍不能作为新 tile 的收益界。[PARE](https://arxiv.org/html/2605.27336v1)的内容/时步 block 路由、[E-DiT](https://proceedings.mlr.press/v306/wang26dd.html)的样本条件 MLP 宽度以及 [Dynamic-in-Few-Step](https://arxiv.org/html/2607.06631v1)的联合蒸馏/step结构模型，进一步说明“动态宽度＋router”本身不是贡献。本轮尚未形成新的原生动态方法或质量/速度结果。
