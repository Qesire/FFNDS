# 复用残差隐藏量的输出修正 NF2

NF2在实际UB1状态上检验已有rank256隐藏量是否足以提供廉价非线性输出修正。原主分支和残差完全冻结；两臂共享仅由训练来源估计的均值/标准差，将BF16隐藏量标准化后，候选再做BF16 GELU tanh，控制直接使用标准化线性量。两臂均按固定FP64 lambda1岭回归拟合教师减去实际StudentY的输出，只增加一次256→5120 BF16输出GEMM与原生BF16相加。

这与HP1/HP2的C-score预测、NF1新增遗漏通道投影不同。若完整部署，主计算仍为50%，辅助GEMM比例从原始完整FFN的1.852%升至2.778%；归一化、GELU、相加也应计时，目前没有新增完整FFN速度结论。

事前固定四步block20、两折全部8项，要求非线性误差同时≤冻结UB1的0.90和匹配线性头的0.95。实际结果全部拒绝：

候选相对冻结基线改善约0.31%–3.81%，全部逊于同成本线性头，未执行全160拟合或视频。该结论只约束已登记的隐藏量标准化/GELU配方，不证明所有非线性修正无效。

全部96个位置的原残差拆分与BaseY+R逐位控制通过；输出头在完整原始M/stride上推理，BF16相加后使用原始BF16 gate和FP64 SSE。保存后的BF16权重/bias和FP32训练矩均通过无损SHA复核。三个新测试覆盖常量训练通道、验证批次不能改变训练矩或同一行特征，以及错误精度/无效矩拒绝；全部98项CPU测试通过，未初始化CUDA。
