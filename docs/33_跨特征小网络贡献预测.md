# HP2：跨特征小网络贡献预测

HP1逐维二次特征四折均输给线性对照，HP2另登记一次跨特征非线性控制：复用相同h256，固定FP32的256→128/ReLU→216网络，20轮240次AdamW更新，预测216倍的归一化C-profile。没有扫描网络、训练轮数或学习率。48个隐藏量SHA与HP1全部相同，冻结线性头在完整M重算后的保留C也与HP1精确一致。

四折训练均完成，但均未达到捕获50%及比线性高0.2个百分点的门槛。停止此配方，不继续增大网络或扫描epoch。训练MSE下降本身不能代替验证收益，本结果也不能证明所有MLP都无效。

主结果来自折叠训练mean/std后的FP32权重、原完整M上的推断。与未折叠、采样批次推断比较，约0.26–0.49%的行支持顺序/选择存在差异；没有用次要实现更好的数字替换主结果或宣称逐位等价。BF16残差隐藏量本身与HP1逐位一致。

程序内部6.077秒，不是部署速度。输入特征参数早已见过全部24来源，CV只约束新头；C-score不是FFN风险，逐行topk也不是已实现的稀疏kernel。UB1视频和静态支持均未修改。
