## 1. 最重要的任务不是增加机制种类，而是发现有效方法

研究以冻结的 LightX2V/Wan2.2 I2V 四步蒸馏 D-Q 为基线；要发明有真实输入/状态条件、能够从 FFN 主乘法中省算、只需离线后处理或轻量训练、**实际完整视频质量和时延**都成立的动态稀疏策略。历史登记协议以 MAC≤50%、完整 FFN≥1.5×、真正新来源 aesthetic/imaging/motion 各下降≤2%为固定工程验收；**今后新研究以可比最新工作和最佳静态/动态方法的质量—速度 Pareto 位置为评价目标，而不是受旧阈值束缚。**此前 UB1 已展示局部工程可行性，但其补充20 imaging 下降3.166%，也没有输入动态性。

AdaLN 调制、Attention 后 residual、FFN 功能组、跨 block/step 的传播、区域差异、时间风险和 kernel fusion 都是候选**信息或动作**。它们不分别构成必须完成的论文课题。V3的单个跨层二选一和V4的 GBA/STB 只是备选构造，任何新观察都可以引出信息时序、量化坐标、算子形式、计算粒度或训练目标不同的算法。

## 3. 演绎一次最重要的动态收益

对**同一个输入分布和评价尺度**下两种等成本原生动作 A/B，定义 `D(x)=L_B(x)-L_A(x)`。最佳固定动作误差与知道每个输入真实动作结果后的后验 oracle 差值为

`V_oracle=(E|D|-|E D|)/2 ≥0`.

若政策只能读到动作之前现存的信息 `Z`，其贝叶斯最优相对固定收益为

`V_Z=(E|E[D|Z]|-|E D|)/2`, 且 `0 ≤ V_Z ≤ V_oracle`.

这两个量分别问**动作集合有没有条件差异**与**真实可得信息能预测其中多少**。它们是数学性质；真实 Wan 的损失、任务作用和空间动作仍需原生计算/自由视频获取。若在线执行成本不同，应把它纳入动作损失或单独建立带预算的决策问题；不能把固定两臂的公式直接当 160 步顺序决策的充分算法。

对相同 native 流目标，基线残差 `e=F_0−F_D`、干预差 `δ=F_a−F_0` 的严格误差收益是 `-2<e,δ>-||δ||²`。此恒等式不意味着 flow SSE 和视频感知分数完全同序。顺序动作要评估当前历史、剩余额度、真实后续策略以及错误累积；可使用完整四步 fork/rollout 构建对照，而不是拼接互不兼容的模型状态。

## 4. 自由但有辨别力的算法搜寻

从实际结果提出新算法的几个互不等价切入点（**示例而非上限**）：

- **改信息**：利用已经完成的前层 Attention/residual、modulated input 或低成本状态摘要。先核对信号产生的时序与预测性，避免把同 step 常量 AdaLN gate 误当内容特征。
- **改动作**：在真正可执行的常规 packed 两侧 GEMM、整幅/整层宽度、空间规则 tile 或功能上不同的通道组之间分配计算。跨 block 交互、同层分块和跨去噪步都是合法候选，但不由旧后验输出拼接保证收益。
- **改表示**：测试补偿可合并的功能子空间、不同激活近似、非线性重构或共享低成本计算主干。比较新动作实际成本，而非重复失败的 q/rank/search。
- **改训练/目标**：对动作的实际下游 signed value、完整真实轨迹及视频质量作小型监督；保留强静态目标与 matched local/flow 对照。
- **改执行**：预打包与 QDQ/layout/GELU/gate 的正确融合，可以将逻辑省算变成性能；fusion 本身不能被冒称是未有先例的科学发明。

这些入口可能组合、竞争、被结果替代。研发工作以一个实证方法收敛；非必要机制不成为实验开销义务。

## 5. 从实验小样转向全生成效果

每种新动作先有严格的数值与等价测试，然后在包含不同 step、不同深度和区域的少量作用域做**同输入原生反事实**，并由同种子继续执行真实下游及四步生成。新方法是否有条件价值，须比较 **最强相同费用固定动作**、离线 oracle 和实际提前信息政策；形成自有自由轨迹后再补齐完整 FFN/端到端耗时以及未见来源三轴质量。

这不是规定所有候选必须先完成 block30/31 的 R12，也不是强制在科学上只探索 V4 的整 M 或 tile。若一个机制无法在便宜诊断上得到收益，寻找导致缺口的结构并转向改变动作/信息/表示；若有收益但 video 不改善，则直接研究真实轨迹/时序损伤；若数值与视频均改善但 GPU 没加速，则修改执行粒度或 kernel 路径。

## 6. 最相近先例与研究边界

[PARE](https://arxiv.org/abs/2605.27336) 已做视频 content/timestep 条件 block routing；[E-DiT](https://proceedings.mlr.press/v306/wang26dd.html) 已做按样本 block skip/MLP width；[FIS-DiT](https://arxiv.org/abs/2605.11869) 已在 Wan2.2 上研究 frame-interleaved sparsity；[Dynamic-in-Few-Step](https://arxiv.org/abs/2607.06631) 已结合少步蒸馏和结构稀疏。因此直接把“动态宽度”“按帧跳算”“轻量路由器”或“融合算子”命名为论文贡献并不足够。科学贡献需来自不同而实际可测的计算构造、解释力以及新的质量—真实加速结果；最新学术/实现需要随研究继续检查。
