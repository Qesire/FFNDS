## 冻结门槛结果

| 判据 | task0 Fit | task6 Validation |

| A dynamic 同时优于 random/static | 4/4，通过 | 2/4，未通过 |

主判据是 native CPU BF16、每策略独立的 task0 对侧 seed gain。

这些都是局部投影的归一化 SSE 比值，不是视频质量或 CUDA 倍速。

在相近得分排序下，完整策略的局部风险仍有可测差异，值得继续检查如何低成本预测。
各 gain 的控制、匹配 FP32 结果、CPU/GPU dense 漂移和八个独立 scope 的详细值保留在表内。

## PR1：前 FFN0 核回归代理，阴性

`PR1_PRE_FFN0_V1_KERNEL_C_PROXY_20261020` 只把实际 Q1 后、FFN0 前的 V1 交给预测器。
静态/线性/二次核与 ridge 参数由 task0 donor 内的 latent-time 四折选择；test V2/Delta 不进入预测。
每策略的 gain 也仅由该 donor 的预测支持拟合，bias 排除一次、候选 bias 保留一次。

两来源均为 **0/4**。代理/真实 C 风险比约 1.219–1.496，未满足保留 C 优势的冻结门槛，
不修改门槛、不把训练 CV 的改善写成独立来源的成功。
数据、参数 CV、负面结果分别保存在 `proxy_pr1/` 和 `pr1_*.json/csv`。
拟合/推理是 FP64 CPU 诊断；尚未给它记在线 CUDA 成本或稀疏速度。

## 真实输入的 QDQ/FFN2 packing 检查

使用新 D-Q task0/seed20261001 的 block20 steps0/2、各 512 行、冻结 random mask0。
原生 Q2 对采样输入的回放逐位等于捕获的 V2；按原 64 通道整组保留 108 组后，
packed Q2 逐位等于完整 Q2 的对应子集。
FP64 packed 投影与 mask 后完整投影一致；本次两个 scope 的 native BF16 投影也完全相同，bias 保留一次。

隔通道重排的对照改变了约 52.0%–52.3% 的 QDQ 值，不能推广成任意通道重排可交换。
证据为 `group_packing_probe.json`。这里只验证 FFN2 的实际 50% GEMM 尺寸与数值关系，
没有减少/测量 FFN0，不能升级为完整 FFN 加速。
