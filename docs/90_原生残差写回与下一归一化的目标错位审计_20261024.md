# 原生残差写回与下一归一化的目标错位审计

在既有 C1 的72个同前缀原生 FFN 位置上，两种误差目标的行排序并不等价。残差写回 SSE 与下一层 norm1 SSE 的平均 Spearman 为0.875635；各选误差最大的7,917/31,668行，平均重合78.2976%。六个已暴露来源的重合范围为75.5579%—80.9408%。这把 PRD 的合成目标反例推进到实际有限误差标签，但没有测量后续完整 block/step 的动作价值。

本次只读取 C1 已保存的每行标量误差及原始绑定，不载入模型、权重、h256或选择器，不增加 GPU、FFN、norm、selector、训练或分解调用。[分析计划](../research/20261024/C1_boundary_target_audit_plan.json)先于读取结果冻结；[原生捕获实现](../tools/c1_native_probe.py)中，`post_UB1`是完整补偿 FFN 经 BF16 残差写回后的状态误差，`nextnorm_UB1`是同一状态经下一 block 的 norm1 后的误差，尚未进入调制、attention或后续FFN。

| 以既有标量标签排序并取前25%行 | 捕获残差写回总SSE | 捕获下一norm总SSE |
|---|---:|---:|
| 残差写回误差排序 | 35.6498% | 35.1327% |
| 下一norm误差排序 | 34.0291% | 36.7113% |

表中先对各位置选行，再累加72位置的标量误差；重合率及相关系数为位置均值。六个来源才是独立来源簇，行数和位置数不能替代样本量。两列具有不同单位，仅可分别比较同列。按下一norm排序损失部分残差状态保真，反向也如此；这是离线已知标签的目标取舍，并非可执行pre-W1路由、完整tile动作、总体oracle上界或视频质量。

按step0/1/2/3，前25%重合分别为73.9246%/78.3967%/80.2261%/80.6429%。目标错位在早步更明显，而既有 C2 尺度能量的15个负位置有12个在后两步，因而不能仅凭“归一化丢失残差方向”便解释 C2 的晚步负值。保存的标量SSE没有误差向量，也不能识别径向分量或推断完整下游传播。

下一步仍是已获独立授权的 C2N1 固定六视频：算法、数据、对照和预算不变。其结果检验冻结尺度规则是否改善实际自由轨迹；后继 PRD 研究应另行获得完整 block/step 因果标签，而不是在这72处继续调尺度评分。
