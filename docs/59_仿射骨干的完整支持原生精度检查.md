# 仿射骨干的完整支持原生精度检查（R8F1）

本轮探索既有R2仿射骨干旁的固定0.5斜率/额外HiF4变体。这不是原R2学习型BF16算子的完整检验，也不重启已拒绝的“只保留GELU线性一半”配方。本轮保留完整非线性余项、完整13824通道，只检查理想折叠经过真实HiF4/BF16边界后的误差来源，尚不压缩或拟合。范围更正及原设计SHA见[R9校对](../research/20261021/R9_scope_reconciliation.json)；以下事前协议、控制和负结果全部保留。

## 计算与前提

输入为OP2实际UB1状态的原生post-Q1 BF16 V1。令原始有效HiF4权重为W0/W2，原始偏置为b0/b2，第二层Smooth向量为s2。FP64推导的仿射矩阵为`A=.5*W2*diag(1/s2)*W0`，偏置为`biasA=.5*W2*diag(1/s2)*b0`。余项从**原生完整Q2值**减去`.5*z_BF16/s2`，保留原始激活量化误差，不把量化器当线性算子。b2在余项GEMM中仅出现一次。

先通过两位置全部24来源的冻结UB1主输出/R256逐位回放，以及八个固定样本的完整教师逐位重建；所有控制通过后才测量改变的表示。保持原始全M和stride，在原采样坐标上核对256个真实行。其余行仅恢复独立FFN的原始GEMM几何，不冒称已知完整激活总体。

## 固定八项检查

[协议](../research/20261021/R8F1_native_affine_protocol.json)固定step2/3、block20，OP2来源00/06/12/18；均已开发暴露。每项比较三个完整支持表示：BF16仿射矩阵与BF16余项、HiF4仿射矩阵与BF16余项、HiF4仿射矩阵与HiF4余项。前两个用于区分矩阵折叠/新增权重量化的误差；只有第三个同时遵循新主线性算子的HiF4精度边界。

门槛在结果前固定：八项BF16折叠gated SSE各不超过对应冻结UB1误差的1%，八项完整HiF4折叠各不超过10%。这里用UB1误差作尺度来检查压缩前的表示误差是否足够小，并非比较同预算候选。任一拒绝都停止这个固定表示的压缩后续，不改阈值或挑支持。它不排除所有仿射或量化感知恢复方法。

完整支持目前主MAC为原dense的`1+40/216=1.185185`。R2原先推导的余项组数14/68/68/122，加仿射40组等价计算，才会在理想矩阵MAC上匹配25/50/50/75%步间预算。新增QDQ、相减、相加、辅助项、访存都要计入未来完整FFN时间；此处既不运行这些压缩宽度，也不继承原1.546×或官方质量结论。

只有全部精度门槛通过，才考虑另行登记余项可压缩性检验。本轮无训练、无新视频、无候选质量验收；折叠矩阵与大张量留HF缓存。原始目标仍为50%主MAC、完整FFN≥1.5×、全新冻结来源的三项官方质量分别下降≤2%。

当前状态：135项CPU检查通过，48项UB1与8项完整教师逐位控制通过，全部八项三臂比较完成；BF16门槛通过，完整HiF4门槛均未通过。最近完成的[R7D2](58_局部与下游目标的双参数原生对照.md)已按开发留出结果关闭，不由其小幅训练误差改善升级候选。

## 实测归因与闭合

[完整原生结果](../research/20261021/R8F1_native_affine_results.json)保留所有源/矩阵SHA与逐项数值。BF16折叠误差/UB1误差：step2为0.000813–0.000883，step3为0.001786–0.002051。仅量化折叠矩阵、余项仍BF16时，step2为0.06974–0.08429，step3为0.14321–0.19944；完整HiF4时分别为0.10143–0.11643和0.22249–0.26847。误差项有交叉项，不能把三臂差值当独立可加方差。

完整HiF4的八项均超过既定0.1门槛，故关闭这个固定RTN表示，不运行剪枝/余项拟合。理想代数与原生BF16数值并非主要障碍，新增量化带来可测差距。后续[R8F2](60_HiF4仿射矩阵的分组Hessian量化修复.md)单独登记已知Hessian补偿的离线权重编码，保持当前层/验证源/门槛，不是放宽精度或重跑有利来源。
