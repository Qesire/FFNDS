本文件支撑 [学术指标族与执行协议](77_FFNDS学术指标族与评测协议_20261023.md)。目标是用合适的指标区分计算表示、选择器、泛化、视频质量和系统收益。复算采用 `aebd37f749b484f0caaf6224c0a1e507e327cf3f` 的保存数据，脚本为 [audit_r15_metric_evidence.py](../tools/audit_r15_metric_evidence.py)，结果为 [JSON](../research/20261023/metric_evidence_recalculation_R15.json)。

## 1. 同一误差总量可以来自不同机制

对四 token stripe，定义 \(z_i=F(x_i)-Ax_i\)，共享响应 \(c\)、相同门控对角矩阵 \(G\)。在精确实数运算及共享 gate 条件下，

\[
\sum_i\|G(c-z_i)\|^2
=n\|G(c-\bar z)\|^2+\sum_i\|G(z_i-\bar z)\|^2.
\]

第一项测平均响应误差，第二项测被共享表示留下的组内差异。原生量化/写回的舍入另记录差值；实际 gate 随 token 改变时改用加权最优中心。标量 SSE 相同的 `[1,1,1,1]` 与 `[1,-1,1,-1]`，其共享偏移与组内变化完全不同。今后在对应张量上保存组均值和去均值误差，可直接判别该优先改善共享响应还是细粒度计算。

这也是 F8 指标存在的理由：局部统计解释计算误差；F1–F7 负责终端视频与感知表现。

## 2. R14N0：分开测动作族与选择器

保存数据的开发来源为 0/10，每来源 64 个四 token stripe、5120 通道；固定动作只使用训练来源 1/11 选定。复算总量：

| 方法/参考 | 开发 SSE | 相对 UB1 |
|---|---:|---:|
| UB1 | 8183.322744 | 1.000000 |
| 训练集最优共同固定掩码 | 10206.335383 | 1.247212 |
| 当前范数动态掩码 | 10733.587573 | 1.311642 |
| 逐输入标签 oracle | 9747.502792 | 1.191142 |
| 开发集事后共同掩码参考 | 9827.802850 | 1.200955 |

在这个固定、可加的采样动作集合中：

\[
L_{dyn}-L_{UB1}=(L_{oracle}-L_{UB1})+(L_{dyn}-L_{oracle})
=1564.180048+986.084781.
\]

动作族剩余差距占 **61.3340%**，选择器 regret 占 **38.6660%**。这是相对 UB1 的 SSE 差距分解。共享均值是潜在原因的判断另由已保存 teacher-mean CPU 参考支持；61.33% 本身并不完成均值误差的因果归因。

另一个分解是：

\[
L_{train-fixed}-L_{oracle}
=(L_{train-fixed}-L_{dev-common})+(L_{dev-common}-L_{oracle})
=378.532533+80.300058.
\]

前一部分占 **82.4991%**。开发集内一个事后共同动作已解释大部分固定→oracle 差距；逐输入变化的附加空间需对这个强共同参照单独量化。事后共同掩码由公开标量重组，尚无该掩码的独立原生运行。其数据暴露属性为描述性参考。

据此，动作评价至少同时报告：对 UB1 的差距、对同计算预算固定策略的收益、selector regret、对同来源最优共同动作的条件收益。后者在开发集上用于诊断，在新来源上用预冻结策略评价泛化。

## 3. 归一化、尾部与样本单位

每来源 MSE 的分母为 `64 × 4 × 5120`。复算还保存 stripe-SSE 的 p50/p95/max。动态方法来源 0/10 的 p95 分别为 130.60/161.25，UB1 为 82.09/87.13；平均数与尾部一并构成该局部观测。

当前公开标量没有教师张量能量，因此 post-NMSE 保持空值。需要 NMSE 时直接保存相应张量能量，并区分 FFN-only、gated-update 和 post-writeback。

合并 SSE 的比值为 1.3116417，逐来源比值的等权均值为 1.3119899，两种汇总在本数据接近。反例 `baseline=[1,100]`、`candidate=[2,90]` 则分别得到 0.91089 与 1.45，方向相反。因此每项结果明确总体权重和聚合公式。

原实验重复差值 \(\eta=0\) 描述固定输入执行的一致性。来源总体不确定性由独立来源数量决定；两个开发来源的 128 个 stripe 保留在各自来源簇内。当前结果报告逐来源值和描述统计，后续正式质量研究按来源簇估计不确定性。

## 4. 从局部到完整视频的指标映射

| 既有结果 | 对应指标族 | 作用于今后评测的启示 |
|---|---|---|
| R11：局部目标与 native flow 改善方向不同 | F8 局部/传播诊断 | 保留 flow/latent 轨迹与自由视频，两端联合解释 |
| D0：固定动作 oracle 对 best fixed 的收益很小，且高于 UB1 | F8 条件价值与动作集价值 | 分离“选择信息有用”与“动作本身有用” |
| R14N0：上述三段差距 | F8 表示/选择/来源分解 | 下一次动作诊断同时测强共同参照和均值/对比误差 |
| 用户关注背景小物体与静态光照 | F4、F7 | 全时长视频、稳定区域诊断、人工具名异常率 |
| UB1 既有 aesthetic/imaging/motion | F2、F4 的历史子集 | 正式新方法扩展到九维 I2V 及成对人评 |

冻结实验的原始判定原样保存。本次采用新指标族安排后续研究，而具体原生方法由其新的算子、信息与可执行性证据进入相应评测。

## 5. 实测效率：记录真实比较对象

R14 同次合成 A100 backend：dense 53.8966 ms，UB1 32.2916 ms，融合固定 27.9487 ms，融合动态 28.1745 ms。动态相对 dense 为约 1.913×，相对 UB1 为 **1.1461×**；动态相对同族固定增加 **0.8078%** 时延。

这组数据属于 F9 合成 backend；原生完整 FFN 和整视频的时延独立测量。该构造主 projection MAC 为 45.1381%，UB1 为 50%，因此 UB1 是工程参照，同族固定才提供相同动作数量的对照。每条质量—成本记录绑定同一部署，分别保留 selector/layout、QDQ、投影和恢复开销。

## 6. 离线记录工具修正

原检查器在五组合成元数据反例中均接受了错误声明：合成时延标成 native speed、完成值 false 且审阅 COLLAPSE 却报 smoke、NaN SSE、开发集宣称独立质量、缺少完整视频/质量维度却报 Pareto。[修复前回执](../research/20261023/metric_guard_before_R15.json)。

修正内容：

- 按 metric ID 校验数值类型、有限值和执行模式；NMSE 指定分母；JEDi 区分有偏/无偏 MMD 估计器，后者允许有限样本负估计。
- 成功视频声明绑定已有候选 rollout 记录和实际完成/审阅结果。
- 完整独立质量/Pareto 声明要求九维、独立来源标识、维度来源 hash、官方版本及配对基线；Pareto 额外链接质量取舍和不确定性审阅。
- 计时写入同一部署身份、基线时延、重复数和边界；`native_speedup` 对应实际更短时延。
- 增加部分官方维度、失败 rollout、原生计时、合成 backend 的诊断记录类型，支持逐来源/逐工作点观测。

这些检查校验记录的语义与证据链接。视频判断、来源独立性和科学结论通过链接的原始数据与审阅复核。实际 R14N0 局部数据及 R14 backend 数据已录入 [records](../research/metric_system/records)，作为有效粒度的实例。

新一轮研究以 [十类指标的核心组合](77_FFNDS学术指标族与评测协议_20261023.md#10-ffnds-的三个评测组合) 为评价入口，优先形成完整、可比较的质量与成本测量。
