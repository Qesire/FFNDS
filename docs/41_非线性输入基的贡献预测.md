# NP1：扩展输入基对C贡献预测的检验

NF1的遗漏非线性特征仅带来有限输出误差改善，没有通过其原生SSE门槛。NP1独立检验相同特征对通道贡献C预测的作用；它没有继续拟合NF1输出修正，也不改变已经拒绝的任何质量结果。

在NP1拟合和评分前固定[协议](../reports/worker_20261020/NP1_registered_protocol.json)和[源码](../reports/worker_20261020/NP1_before_fit_source_freeze.json)。仍用相同24个C24学生来源、step2/3 block20、12/12两折，原本已见过全24的主FFN/残差继续冻结。4组输入投影完全复用各折NF1由训练C选出的组，W0、rawb0、Smooth2哈希逐一复现，全部48份已有h256与HP1逐位相同。

两头都读取512维特征、使用相同lambda1标准化ridge。线性对照输入为已有h256与实际新W0投影的GELU前z256；候选为同一个h256与GELU/Smooth2/HiF4 QDQ后的新hN256。这样两者增加相同输入投影，候选仍额外支付GELU/QDQ成本；不会把增加输入信息的收益误记为非线性收益。最后在原始完整M上运行实际FP32读出和稳定topk，评分对象仍只是C保留比例。

| step/折 | 匹配线性512保留C | 非线性512保留C | 非线性捕获oracle改善 | 非线性−匹配线性 |
|---|---:|---:|---:|---:|
| 2 / 0 | 0.563444 | 0.562934 | 26.946% | −0.000510 |
| 2 / 1 | 0.561765 | 0.560603 | 26.462% | −0.001163 |
| 3 / 0 | 0.791767 | 0.791263 | 26.929% | −0.000504 |
| 3 / 1 | 0.790443 | 0.789798 | 25.852% | −0.000645 |

4项都未达到预设捕获50%oracle改善且比匹配线性多0.002绝对C比例的门槛；非线性反而略低于同等输入投影的线性对照。原HP1的静态/oracle参考全部精确复现，因此没有因换参考而制造改善。
