# 三方向融合：同一合成链路 1.913×，下一步检验真实条件价值

> 后续原生检查已完成：[R14N0 结果与失败分解](74_完整空间邻域的原生值与固定双点构造拒绝.md)。本文保留后端完成时的测量与待测状态，当前交接见 [R14N0](../research/20261022/HANDOFF_R14N0.md)。

R14 把 R13 的三方向仿射表示实现为融合算子。在一张 A100 80GB PCIe 上，完整随机张量链路从稠密版 **53.897 ms** 降到动态版 **28.174 ms（1.913×）**，主投影 MAC 为 **45.1381%**。相同三方向算法的未融合动态版需要 **46.987 ms**。因此本轮支持的是“表示改写与辅助执行融合共同产生实际后端收益”；降低 MAC 本身并没有使未融合版本变快。

这是已执行的随机驻留张量后端比较。真实 Wan 操作数误差、条件分配价值、完整 160 个 FFN 和自由生成视频均未测。新研究按[同前提质量—速度竞争准则](72_与同前提方法竞争的质量速度评价准则_20261022.md)推进；R13 直接实现的旧判定和 D0 的原生拒绝保持原样。

## 1. 从四个输出改成三个对比方向

四行当前 post-Q1 输入记作 \(x_0,x_1,x_2,x_3\)，均值为 \(\mu\)，冻结仿射骨干为 \(L(x)=Ax+b\)。由于

\[
L(x_i)-\overline L=A(x_i-\mu),\qquad\sum_i(x_i-\mu)=0,
\]

不必计算四个完整仿射输出再求均值。取

\[
h_1=(x_0+x_1-x_2-x_3)/2,\quad
h_2=(x_0-x_1+x_2-x_3)/2,\quad
h_3=(x_0-x_1-x_2+x_3)/2.
\]

三个 \(Ah_j\) 经半倍带符号求和即可重建四个中心化仿射响应。仿射偏置消失，非线性平均响应仍包含原 FFN 偏置。R13 已验证实数恒等式和保存输入上的 CPU 舍入差异；本轮为三方向算法单独声明 BF16 截断顺序，再验证融合与该参考顺序一致。**并未声明它与旧四投影算法逐位相同。**

非线性支路沿用同一构造：每组生成均值和共享符号对比 \(c=\frac12\sum_i\epsilon_i(x_i-\mu)\)。单点组在 \(\mu\) 计算；双点组在 \(\mu\pm c\) 计算原 W1、tanh-GELU、Smooth 和 group64 Q2，平均 **post-Q2** 激活后只做一次 W2。最终将该组响应加到各行自己的仿射对比，再执行 gate 与 residual 写回。原始全行 Q1 不省略。

固定形状 \(M=31668,D=5120,H=13824,G=M/4=7917,K=3958\)，主投影成本为

\[
\frac{(3M/4)D^2+(G+K)DH+GDH}{2MDH}
=0.45138099448444274.
\]

计入了额外双点 W1，未将点数或仿射投影免费化。它只是 MAC 账本，速度由下面的完整实测链路决定。

## 2. 一次固定设计，七臂成对计时

[预先冻结的协议](../research/20261022/R14_three_direction_backend_protocol.json)固定随机种子、形状、双点数、4 warps/1024 特征块、3 次预热与每臂 7 次交错/反向顺序测量；没有自动调参或设计扫点。使用 PyTorch 2.10.0+cu128、Triton 3.6.0。所有臂计入共同 LayerNorm/AdaLN 代用品、Smooth、原 HiF4 Q1/Q2、GEMM、辅助布局、选择、gate 和 residual；JIT 与离线随机权重构建均不计入。

| 同次运行的臂 | 中位 CUDA 时间 / ms | MAD / ms | 相对同次稠密版 |
|---|---:|---:|---:|
| 稠密随机 FFN | 53.8966 | 0.3646 | 1.000× |
| 半 hidden＋随机 R256 代理 | 32.2916 | 0.5622 | 1.669× |
| R13 直接动态实现 | 39.5560 | 0.4322 | 1.363× |
| 三方向、未融合、固定位置 | 44.1988 | 0.2141 | 1.219× |
| 三方向、未融合、动态位置 | 46.9870 | 0.1316 | 1.147× |
| 三方向、融合、固定位置 | 27.9487 | 0.3353 | 1.928× |
| 三方向、融合、动态位置 | **28.1745** | **0.1769** | **1.913×** |

融合动态版比同算法未融合版少 **18.8125 ms（40.04%）**，超过预定噪声幅度 `max(0.5 ms, 3×最大臂MAD)=1.6865 ms`，通过此次后端工程判据。它也比同次半 hidden＋R256 **随机代理**少 12.75% 时间；后者不是冻结 UB1 真实权重、完整模型或视频结果，不能据此声称已胜过 UB1。

固定臂省去评分、top-k 和动态映射，只处理前 K 组所需的对比。动态臂使用 **W1 前的当前 post-Q1 对比范数**，计入全组评分、top-k、排序、补集与位置映射。两融合臂相差 0.2258 ms；其中包含布局差异，且幅度小于本次测量波动，**不能将该差值独立解释为精确选择器耗时**。前 K 组仅是高效的后端放置对照，不是质量最优的固定策略。

峰值分配 **8.0797 GiB**、峰值保留 **15.3008 GiB**，低于预先规定的 32 GiB 分配上限。一张空闲 GPU、标准独占锁；零模型权重、零训练、零新视频、零新张量文件。首次固定后端运行成功退出，未按结果修改布局重跑。

## 3. 数值证据与能解释的机制

[原始结果](../research/20261022/R14_three_direction_backend_results.json)保存所有 49 次 CUDA 和 host 样本、16 项融合控制及 14 项原 QDQ 控制。

- 固定/动态的三个对比、均值、共享对比、点打包、平均 post-Q2、逆变换和 gate/residual，以及完整链路输出，均与各自未融合三方向参考数值一致；所有 BF16 控制的位差均为 0。
- 范数并行规约最大相对差为 `1.93477e-7`，低于预定 `5e-6`；最终选中的 3958 组完全相同。
- 全部 14 个实际调用的 Q1/Q2 边界与原 `force_fp32=True` 参考逐位一致，包含稠密 hidden、半 hidden 和 11875 点行的不同形状。
- 新三方向与旧 R13 直接版随机输出相对 L2 差为 `0.00145082`。这不是 Wan 精度或质量检查，不能用融合自身的逐位一致掩盖表示改变带来的差异。

四个融合边界依次合并输入对比/均值/草图/部分范数、直接点打包、post-Q2 平均、逆变换与最终写回。它们减少了中间张量物化和分散操作。计时证明整体融合方案有效；没有运行硬件性能分析器，**尚不能把收益单独归因于显存带宽、启动次数或某一个 kernel**。常规融合是已有工程手段，可参考 [Triton 官方融合示例](https://triton-lang.org/main/getting-started/tutorials/02-fused-softmax.html)；本轮没有凭此宣称算法原创性。

## 4. 下一条真正需要区分的科学问题

速度障碍已有正面证据，价值障碍仍开放。至少存在三种不同解释：

1. 原非线性响应的局部平均与输入对比能量相关，双点预算有来源相关收益，简单 W1 前范数能胜过最强固定放置。
2. 局部平均本身有用，但增量价值受 W2 方向、gate 或量化组边界影响，范数不预测收益；oracle 可好而当前动态规则不好。
3. 单个共享草图在原 GELU/Q2 下的偏差或方差过大，双点动作本身没有价值；更好的排序也不能修复这个固定算子。

缺少完整邻域的数据使现有 96 份 OP2 不能区分这些解释。已准备[固定原生值草案](../research/20261022/R14_native_value_DRAFT.json)：只在 step2/block20、原暴露来源 0/1/10/11，每来源相同 64 个真实水平四 token 邻域；最多 4 次**原冻结 UB1**四步观察采集和 32 次独立原生 FFN 前向。没有新模型拟合、候选自由视频、位置/符号/点数搜索。

与旧 R13 坐标草案相比，共享同一批空间组是必要修正：可仅用来源 1/11 的真实原生损失选出精确最优的固定 32/64 双点位置，并冻结后在 0/10 比较。动态和标签 oracle 也各选 32 组。必须实际执行最终三类动作并检查逐组组合关系，不能用输出拼接冒充已执行策略。主损失读取原始 residual、gate 及 sensitive dtype 后的真实写回误差，另报旧 gated-Y 误差；均不是 flow 或自由视频质量。

[分析工具](../tools/analyze_stripe_native_values.py)已实现训练来源独立的最优固定掩码与同数量对照，测试覆盖评估标签不能改变固定策略。[CPU 资产准备检查](../research/20261022/R14_native_draft_CPU_readiness.json)确认原 12 份模型、80 个量化分片和组合缓存的存在/大小，重验四份旧操作数/图像/视频及冻结仿射 SHA。完整 93 资产 SHA 使用先前镜像收据，**本次没有重新哈希全部 181 GB**。

真实模型尚未运行、没有新资格登记。根 [AGENTS.md](../AGENTS.md)明确要求 `Any model execution still requires a separate explicit registration and user authority.`；本草案只有在执行代码、源/资产绑定与单独用户授权全部落实后才可启动。原 D0、R4、R9、R11 拒绝和旧协议门槛保留。若原生值结果支持，后续仍需独立的新来源自由视频、完整 160 FFN/端到端计时，以及 ToMe/ToMA 类合并表示等可信同前提对照，才能判断真实质量—速度 Pareto。
