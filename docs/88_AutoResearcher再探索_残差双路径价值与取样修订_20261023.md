## 3. PRD E：归一化看见的是方向，残差路径仍携带原误差

对下一norm的输入 `w`，定义 `P=I−11ᵀ/D`、`u=Pw`、`v=||u||²/D`、`σ=√(v+ε)`。无仿射参数的实数 LayerNorm 为 `n(w)=u/σ`。两个输入的有限差分具有恒等式：

```
||n(w_a)−n(w_b)||²
 = D [ v_a/(v_a+ε) + v_b/(v_b+ε)
       − 2 cov(Pw_a,Pw_b)/sqrt((v_a+ε)(v_b+ε)) ].
```

它把输入均值、径向尺度和方向变化分开。ε=0、非零方差时，这是半径√D球面上的弦距；ε>0时径向缩放仅近似不变。其局部 Jacobian 为：

```
J_n = (P − uuᵀ/(Dσ²))/σ.
```

均值方向被完全消去；与u正交的中心化方向乘1/σ；径向方向乘ε/σ³。单个rstd²仅保留尺度，丢掉方向投影。这一几何属于已知 LayerNorm 理论，参考 [Gupta等](https://arxiv.org/abs/2409.12951)。原生 HiF4/BF16、有仿射权重的情况需分别保留其运算顺序与度量；本式不是逐位等价替换指令。

**更关键的自由度是残差直通。** 对固定调制、可微的一个 pre-norm 残差子层 `T(w)=w+B(n(w))`，局部误差为

```
δT ≈ [I + J_B J_n] δw,
Q_T = [I+J_B J_n]ᵀ M [I+J_B J_n].
```

`Q_T`包含直通项、归一化分支项和带符号交叉项。即使 `J_n δw≈0`，直通的 `δw` 仍然存在。下一norm误差很小，不能推出下一残差子层或最终轨迹误差很小。完整 Wan block 包含更多子层，实际标签应执行其完整有限映射，不能把上述局部线性式直接当作完整量化模型。

本次 CPU 反例使用 `w=[1,−1,1,−1]`，候选扰动为径向 `w_r=2w` 与切向 `w_t=w+0.1[1,1,−1,−1]`，ε=1e−6。下一norm损失分别为 **5.62e−13 / 0.03970**；经过合成残差块 `T(w)=w+n(w)` 后，损失为 **4.000003 / 0.159305**，排序反转。40组有限距离恒等式与 Jacobian 差分检查也通过。这个反例说明应增加哪一种观测，实际 Wan 效应由下一项有限响应实验判别。

源码中的 C1 确实只调用下一 block 的 `norm1.apply`，然后丢弃反事实状态，主视频继续 UB1：见 [c1_native_probe.py](../tools/c1_native_probe.py)。C1 的归一化标签有明确作用；“残差双路径是否重排动作价值”仍是新问题。现有公开NPZ字段保存特征与逐行损失，没有保存反事实完整输出向量和后继block输出；这些汇总不能恢复方向交叉项。

## 4. 可行方向集与潜力排序

### A. 最接近执行：C2 尺度修正的配对视频判别

保留已准备的6视频固定草案与对照。C2 改变了决策信息，原物理行分派可直接复用；数学简洁、额外评分便宜，机制贡献预期适中。它最有价值的结果是回答：上述小幅单边界收益能否在全部160处自由运行时保留内容和运动。C2 的原动态臂是历史R16对照，不是恢复旧研究路线。

C2当前数据只比较每处相同25%采样行，不能选择实际最优dense比例。无需据15处下降即改成“只在好位置启用”：那会引入一次看过结果后的策略选择。新的位置策略应单独建候选并用独立来源检验。

### B. 主研究方向：残差双路径的条件有限动作价值

固定可执行的完整动作及其真实补偿，令 `Φ_h` 为下一完整block或余下当前step的真实有限映射。目标为：

```
A_h(a|z) = E[ L(Φ_h(w_U), Φ_h(w_D))
              −L(Φ_h(w_a), Φ_h(w_D)) | z_preW1 ].
```

从 `h256、当前残差/注意力摘要、gate、norm统计、step/block` 中读取少量前置特征，直接预测动作收益或配对动作差。完整参考输出与下一norm投影用于离线标签；在线不读取尚未执行的下一block状态。优先沿用成熟 dense/UB1 物理分支检验表示问题，通道动作扩展需要单独构造有收益且不同于已闭合交换的动作。

上面的归一化几何逐token成立；进入attention后，完整状态的 `J_n` 是分块对角，而 `J_B` 可以混合token。因此完整后继损失一般不能拆成独立行价值之和。首个判别用少数**完整可执行掩码/连续tile干预**，等成本配对地实际运行后继；逐行量只作解释，不用输出拼接代替策略。基线前缀提供第一批可比较标签；选定候选后再检验其自身自由轨迹上的状态迁移。

**区别性预测：** 在匹配局部误差与当前rstd后，方向/残差特征仍能解释完整block的动作收益；仅下一norm评分与完整block评分会在部分状态分歧。若收益只由固定step/block解释，最佳位置静态策略就足够；若跨来源状态信息进一步改善配对决策遗憾，动态方法才获得自己的贡献。

最小下一检查选用来源隔离的少量完整物理干预，同时记录写回、下一norm、下一完整block、当前step末端四个边界。测 `A_h` 的收益方向、相对最佳固定的决策遗憾、跨边界排名翻转、正负交叉项解释度；训练用fit，选择用validation，最终视频用独立test。选择器拟合和完整后继调用分别计费。R7旧证据用于设计对照，避免重做其两层完整teacher恢复；R11同R256改损失训练与本方向的**前置决策+完整动作+双路径标签**分别记载。

这一方向的数学结构比单一rstd权重更完整，贡献候选在“可观测前置信息—完整物理动作—真实残差传播”的结合。归一化几何、条件期望与传播加权各自已有文献，不凭公式或命名宣布原创。

### C. 后续扩展：状态条件的跨位置预算分配

现有R16/C2每位置固定25%dense；改为从少数合法批量比例 `q_i` 选择，并维护剩余实测成本预算 `b_i`：

```
q_i = π(z_i, step_i, block_i, b_i),
b_(i+1) = b_i − c_i(q_i),  b_i ≥ remaining_minimum_cost.
```

可用的动作改变为“在哪里、投入多少计算”，同时保持原native分支及补偿。对照应包含训练选定的最佳位置固定预算、统一25%和状态条件策略；仅跨层平均敏感度不同会支持静态调度，不能证明动态必要性。

CPU等成本可加示例中，两状态交换两个位置的边际收益 `[10,9]` 与 `[1,0.5]`，两单位预算下最佳固定平均收益11，条件分配19。真实模型的多位置干预存在交互，`c_i(q)`也受批量、调度和内存影响，采用实测分段成本与完整轨迹验证。仓库V4/GBA已有跨位置预算种子，[FastForward](https://arxiv.org/abs/2602.00397)也已有层间调度；此路线是继承后精化，优先级低于B的收益标签判别。

## 6. 取样与指标范围的修订

**先分开三个统计目标。** C1/C2已暴露数据用于发现；候选完整配对视频用于集成与质量烟雾；独立来源测试用于质量—速度结论。来源选择、动作/特征选择和最终评估分离；同图不同prompt、seed、帧、层都属于相关观测。按图像哈希和父场景/素材系列双重分组，内容近重复需人工或固定相似度规则复核。模型选择偏差的依据见 [Cawley–Talbot](https://jmlr.org/papers/v11/cawley10a.html)。

**来源及覆盖试点。** 建议24个新开发来源槽位：主体/背景/镜头各8，6 fit+2 validation；fit内各4用于12来源覆盖试点，每来源2个预先抽取并记录的seed。四step全覆盖；将40层分四个深度带，每来源每step轮换一个带，各格覆盖3来源×2seed，共96个干预上下文。带内位置在结果暴露前随机化并轮换；现有代码给出可验证模板，实际身份与映射需写manifest。12、24是覆盖预算，不是显著性所需样本量。一次上下文的基线捕获、每个反事实后继调用、完整视频与评分单独计数。

**空间与潜变量时间。** 原336行是每个21时间bin取16行，时间覆盖充分，但固定位置不能估计未取空间区域的选择质量。新试点在bin内对完整可执行连续tile进行概率取样，记录空间位置、前景/背景/运动标签及抽样概率；分别报告t0与later20，再用正确面积/概率权重汇总。336行内top84的经验oracle只属于这336行，不能当31668行策略上界。21个latent bin与81个解码帧分别记录。

**镜头与图像交叉。** R17每指令一图无法分离指令与图像作用。另设14图×每图3指令的平衡不完全区组：7种指令各出现在6图，每指令对共现2图；2seed时每臂84条视频，独立图像簇仍为14。它是可单独选择的机制诊断设计，官方I2V保持原元数据与评分定义。

**独立最终评测。** 从尚未用于方法或模型选择的场景簇取样，预先固定主要质量维度和最小有意义差异。以来源级配对差 `D_j` 的试点标准差估计精度/功效所需N：

```
N ≳ max{ [(z_(1−α/(2J))+z_power) s_D / δ]²,
          [z_(1−α/(2J)) s_D / w]² }.
```

这里J为预先指定共同主要比较数，w为置信区间半宽；这是正态近似的规划式，最终用t迭代或来源簇模拟并考虑试点方差不确定性。[NIST](https://www.itl.nist.gov/div898/handbook/prc/section2/prc222.htm)提供均值精度/功效的基本公式。没有从6个已暴露来源宣布最终N=6或23。均衡抽样与真实使用分布是两个估计目标，预注册权重并同时给各层结果。

官方I2V完整协议按[官方说明](https://github.com/Vchitect/VBench/blob/master/vbench2_beta_i2v/README.md)对每个image/prompt生成5条视频、随机并记录seed，分别按维度对应子集计算；少量seed的试点明确标为自定义子集。评估器及元数据固定到版本。质量主指标沿用仓库学术指标族；PSNR/LPIPS是dense保真，nextnorm SSE是机制诊断，VBench条件/运动/视觉质量、完整视频盲评与实际wall分别报告。

**测速与顺序。** 以不同来源的配对wall差为统计单位，技术重复估计计时噪声；覆盖试点可用12来源×3重复，最终精度按实测方差决定。固定部署几何后再单列外部几何；包含路由、补偿、统计读取、QDQ、压行、复原与完整生成。按来源完整配对、跨主体/背景/镜头轮转顺序执行，使中断前缀保持覆盖；报告配对完成率与缺失原因。
