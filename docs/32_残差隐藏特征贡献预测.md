# HP1：复用残差隐藏特征的贡献预测

RB2四种固定支持的oracle空间不足，因此HP1改测逐行逐组预测能否捕获更大的动态空间。它复用UB1已计算的rank256残差首层BF16隐藏量h，以线性h作对照，候选使用FP32的[h,h²]。216维归一化教师C-score、固定lambda1 ridge、12/12来源拆分、step2/3 block20和108/162组预算在运行前登记。标准化仅拟合训练来源，折叠入FP32投影；原完整M/布局上的BF16残差首层保持不变。

48个原C24学生输出逐位重放通过；UB1残差拆成首层/次层后也与完整几何重放逐位一致。step3特征使用UB1的75%支持对应残差，未误用旧C24残差。全部参数与教师profile沿用已验证的HF缓存。

| 位置/折 | 静态C | 逐行oracle C | 线性h C | 二次特征C | 二次捕获oracle改善 |
|---|---:|---:|---:|---:|---:|
| step2 / 0 | 0.536167 | 0.635501 | 0.561636 | 0.559266 | 23.254% |
| step2 / 1 | 0.533496 | 0.635934 | 0.559220 | 0.557088 | 23.031% |
| step3 / 0 | 0.774526 | 0.836679 | 0.790815 | 0.789116 | 23.473% |
| step3 / 1 | 0.773783 | 0.835732 | 0.789091 | 0.787589 | 22.287% |

四折二次头均未捕获50%改善，而且均比线性对照略差，未达到额外0.2个百分点门槛。因此停止本配方，未进行native FFN拟合、稀疏kernel或视频。逐行教师oracle有6.19–10.24个百分点空间只属于C-score；不表示存在同等native FFN误差或质量改善。

程序内部4.456秒。24来源已用于C24和冻结残差参数，所以来源拆分只限制新头训练，不是整条管线的未见泛化。每行支持不同还需要实际分组、padding和稀疏矩阵乘，现有头预测没有证明部署速度。
