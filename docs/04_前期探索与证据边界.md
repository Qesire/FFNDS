# 前期探索：已经知道什么，还没有证明什么

## 研究目标与当前判断

研究对象是 Wan2.2 I2V 及其四步蒸馏模型的 FFN。历史验收目标：完整40 blocks×4 steps 的 FFN 总时间比至少1.5×，主 FFN 计算约50%稀疏，并在正式 subject10+background10、seed42 上，三项 VBench 逐项相对下降≤2%。在线 proxy、路由、QDQ、索引、packing、搬运、修正和写回全部计时。

**现有证据没有同时满足这些目标。** 已完成的工作分为：历史仿真质量与多种失败探索；V5 D-Q/D-BF16 的有效边界采集和描述分析；AR1 随机支持下增益补偿的局部诊断。AR2 未完成；原版 O 的固定输入对照尚未完成。

## V5：边界与采样比直接加新方法更先闭合

已收集 D-Q 与 D-BF16，各3来源（task0 Fit、task6 Validation、task10 Development）×2种子×4steps×blocks[0,10,20,38]，共192 scopes、98,112保存行。两个 arm 都是蒸馏 D。独立来源数为3，不是192或98,112。

D-Q 采集 P/C、实际R、U/V1/H/V2/Y、gate、X_next 与 Delta，及匹配量化权重。BF16 使用原生 callable；head、cast、residual 的边界审计已有专项证据。部分 D-Q manifest 是事后恢复，坐标带恢复标记，不声称运行时观察到同一坐标。

最终 signed 汇总使用 `analysis/R1/signed_full_clean/`；旧 `signed_fit_task0` 加权曾把π误用为1/π，旧设计加权列作废。`sample_unweighted` 与 `design_weighted` 分开，分位数按加权逆CDF，不能用普通中位数替代。

### 描述结果一：必须同时看方向与量级

- D-Q 在 block20、step2/3 的12个来源×种子×step scopes 中，`cos(C,Delta)` 加权中位数均为负，约−.551至−.343；与 BF16 的差别存在反例，不构成统一量化因果效应。
- 全192 scopes 的 Delta/R 加权能量比为.0181–.3114；相同局部相对误差在不同层/步可能有不同传播影响。
- `kappa=||C+Delta||²/(||C||²+||Delta||²)` 接近1，可能只是 C 与 Delta 量级悬殊，不能解释成没有相互作用。

来源：`evidence/recent_outputs/V5_20261013/analysis/R1/ANALYSIS_FINDINGS_R1.md` 与紧凑 A 表。

### 描述结果二：D-Q / D-BF16 自然轨迹会分离

96组模型配对均对齐。step0/block0 的 FFN Delta 余弦中位数为.99890–.99916；step3/block38为.561–.760，相对L2为.671–.928。变化不是逐层逐步单调，逐来源/种子表已保留。

这是各 arm 自然轨迹上的比较；后段输入、gate、前序状态已经不同。不能直接称作同输入量化算子误差，更不能称作蒸馏与原版的差别。

### 描述结果三：平均排名稳定不排除动态支持

同expert的96组跨步通道比较中，设计加权平均绝对投影排名相关约.9561，hidden幅值对下一步贡献排名相关约.2464。hidden幅值更接近单通道能量，而不等于对最终dense方向的贡献。

这些是跨行聚合后的通道排名；没有评估逐token支持的输出误差。前期“因此复杂动态路由不值得研究”的判断后来收窄：**平均排名稳定不能否定动态支持选择**。需要在同预算、同增益补偿后，直接比较静态与动态支持。

定义 `c_j=a_j(W_j⊙g)`；单通道删除误差与 `||c_j||²` 有关，而集合删除误差为 `||sum_deleted c_j||²`，包含交叉项。负投影比例不是可安全删除的通道比例；依赖当前dense Delta 的 oracle评分不能直接作为廉价在线特征。

## AR1：可迁移标量增益有效，但仍是局部诊断

2026-10-20 的 AR1 报告记录两轮CPU实验已完成（105037、105047），没有新增GPU。第一轮有16 scopes、8,176行；主判据为其中8个D-Q scopes、同一Fit来源两种子、steps0/2与blocks0/20、连续64通道组、50%随机支持。

- 对侧种子拟合固定增益，使解析期望风险下降47.426%–92.610%，8/8通过。
- 连续分组/随机分组平均的能量比.993240–1.000409，没有达到1.10凝聚阈值；不支持立即投入该重排实现，不等于任意分组都一样。
- 行oracle较scope oracle的额外改善只有.496%–4.438%；只限制“随机支持下标量补偿”的空间，不否定动态选择支持。
- 第二轮按四个预先固定mask做 CPU BF16 post-Q2 回放，SSE下降47.249%–92.474%，8/8 scopes与32个scope-mask均通过。
- block0补偿后SSE/T约.0192–.0230；block20仍为.1209–.1563，增益没有消除所有误差。

回放干预是 `((V2.float()*mask)*alpha).to(V2.dtype)` 后走指定linear/bias/gate/cast。未测试 Q2 前mask后的重量化、原始CUDA kernel位级行为、完整block传播、视频或真实稀疏加速；O也未测。增益补偿属于已有基线，不宣称新算法。

证据：`discovery/AR1_20261019/AR1_FINDINGS.md`、`group_probe/`、`native_postq2_cpu/` 下汇总表与run_meta；路径相对近期V5证据目录。

## 科研叙事必须保留的边界

局部重构改善 ≠ CUDA加速 ≠ 闭环视频质量；影子执行 ≠ 写入模型；D-BF16 ≠ 原版O；同expert ≠ 每层都稳定；视频帧 ≠ 去噪步；逻辑mask50% ≠ 主GEMM实际少50%；counterexample修正与阴性结果都应保留。
