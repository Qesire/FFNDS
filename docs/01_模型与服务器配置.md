## FFN 数值顺序

SA 残差 → CA 残差 → norm2 / timestep 调制 → FFN0 → `gelu(approximate="tanh")` → FFN2 → gate 与残差写回。D-Q 的两次线性输入还涉及各自 smooth scale 和 native QDQ；q64/q8/q4 分层及 cast 顺序都影响结果。

- 量化之前 mask，与量化之后 mask 不是同一干预：一般有 `Q(MH) != M Q(H)`。
- bias 只加一次；增益不应无意中缩放 bias。
- 实际导出的 D-BF16 W2 MMWeight 为 `[13824,5120]`，用 `H @ W2`；checkpoint 的存储布局 `[5120,13824]` 与此不同。
- D-Q 用实际 V2 与匹配的有效 W2；不能混用原始 checkpoint W2。
- 比较 ungated Y、gated Delta、完整 residual 状态或最终视频时，必须明确所处边界。

`v4.9.2 config/site.env + cluster.env` → `wan_hif4_prox_dit_v1/config/cluster.local.env` → formal suite `scripts/common.sh` → 实验 kit 的 `canonical_env.sh / common_runtime_env.sh` → fresh Python 的 `sitecustomize` → runner / family runtime / QDQ wrapper。

`PROX_MODEL_PATH` 指向基础模型目录是兼容行为；实际 D 的 high/low checkpoint 由独立变量绑定。只看 `model_path` 会误认模型身份。源文件、配置副本和 provenance 均在内层服务器归档；近期模型头与 O/D key/shape 对比也见 `evidence/recent_outputs/V5_20261013/evidence/`。
