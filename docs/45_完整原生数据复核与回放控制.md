# 完整原生数据复核与回放控制

OP2采集完成后，先补齐整批完整性与原生回放证据，再登记新的拟合小试。以下入口均已按冻结条件完成：整批完整性、24来源状态描述、192位置原生回放全部通过。当前仍没有新候选质量或速度验收。

## OP2A：整批数据完整性

`tools/audit_ub1_native_dataset.py`在两份24来源UB1分片全部完成后运行，复核24个独立来源、每来源160位置、共3840个不同张量路径。核对全部原始视频、四步no-op记录、采样坐标、输入图像与种子，以及每个张量文件的字节数和完整SHA256。

每个safetensors文件还独立检查六个字段、BF16类型、四个256×5120主张量、5120值bias/gate及无重叠、无缺口的精确存储范围。有限值证据来自原始生产器保存前的检查，完整字节SHA与生产器绑定保护其身份；此处不宣称重新解码全部数值。仅四个CPU读线程，不初始化CUDA、不复制张量。任一失败保留现场并停止，不修复或跳过数据。

新增五项测试分别检查有效原生载荷、内容字节损坏、有效SHA下的错误形状/精度，以及错绑来源目录。连同原有测试共95项通过。见[协议](../reports/worker_20261020/OP2A_registered_protocol.json)、[源冻结](../reports/worker_20261020/OP2A_before_complete_payload_audit_source_freeze.json)和[95项测试](../reports/worker_20261020/OP2A_preflight_95_tests.txt)。完整路径与坐标留在原始HF输入记录，公开证据采用紧凑来源索引与全清单SHA。

## OP2D：配对状态描述

`tools/compare_ub1_native_states.py`已完成完整24来源描述。全部来源step0 block0的V1/完整TeacherY及gate/raw bias前缀控制逐位通过，随后报告固定四步block20的实际V1、完整教师输出差异；数据见[完整结果](../reports/worker_20261020/OP2D_native_state_description_RUN.json)。旧C24与新UB1各自状态上的学生误差属于描述量，不能当成相同输入的策略优劣或视频指标。两批配对坐标与原训练行复用，原生控制不因此成为独立空间总体的无偏估计。

`tools/plot_ub1_native_states.py`仅渲染已经完成的全24来源描述，展示每个来源与等权均值，输出独立PNG/PDF；不会绘制局部来源或改变统计规则。该图已生成并完成目视检查，见[PNG](../reports/worker_20261020/OP2D_native_state_differences.png)及[PDF](../reports/worker_20261020/OP2D_native_state_differences.pdf)。图中统计仅来自各位置的256个保存行。

## OP2R：四步原生回放控制

`tools/verify_ub1_native_replay.py`在OP2D完整成功后使用一张空闲工作卡执行。对固定block20、全部24来源和四步，在完整原始M/stride上重建UB1主分支与rank256残差，96个新状态位置的BaseY、StudentY必须逐位等于实际采集值。

同时先逐位复现旧C24全部96个位置，再在这些旧状态上重算UB1。step1/2未改变的算子必须仍逐位等于旧采集；step0/3输出明确属于局部反事实计算，没有被称为真实UB1轨迹。旧状态step2/3的四个来源折还需复现NF1中冻结UB1的原生SSE；登记相对容差1e-12、绝对1e-9，并额外报告浮点数是否完全相等。

回放器只读取冻结系数，不拟合参数；原UB1策略SHA、支持、gain/bias、原始权重、平滑/QDQ/cast、两次BF16辅助线性及BF16相加都保留。系数绑定已在工作节点CPU上核验，CUDA未初始化。准备时曾因本地不存在节点HF索引而停止；另一次元数据检查误把选择依据注记当作字典额外字段拒绝，已改为显式检查rank/lambda，未改变任何数值门槛。原失败记录保留。[协议](../reports/worker_20261020/OP2R_registered_protocol.json)、[冻结来源](../reports/worker_20261020/OP2R_before_native_replay_source_freeze.json)及[绑定准备检查](../reports/worker_20261020/OP2R_coefficient_binding_readiness.json)均已保存。

新的拟合小试必须等采集、状态诊断、数据完整性和原生回放全部完成后另行登记；不会用准备完成替代这些实际结果。
