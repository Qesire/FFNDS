# UB1真实状态的原生教师采集 OP2

此前HP/NF/LR等局部检验大多复用OP1采到的旧C24学生状态。较强基线UB1的四步宽度已变为3456/6912/6912/10368；状态分布可能不同。OP2只检验能否在真实UB1状态可靠采集原生完整教师目标，尚不代表分布差异解释了质量失败，也不训练新候选。

原观察器的半宽形状检查固定为6912，不能直接用于UB1。版本化观察器仅扩展四步形状检查、增加完整M/stride元数据；原始TeacherRecords、bias、逐位比较和数值observe主体通过AST控制。教师仍走原始HiF4完整两次GEMM、GELU tanh、Smooth/QDQ/cast及原始bias顺序。

隐私迁移后，旧量化生产脚本与协议的字符串身份改变。新入口同时核对私有原始SHA与公开源码在仅替换标识后的AST/JSON等价性；不存在通用忽略哈希选项。UB1仅另存一个协议路径指向私有原始字节的执行别名，其政策SHA另行记录，参数和原始协议SHA保留。必须实际复现旧输出，不能据元数据认定等价。

控制输入在运行前固定为原正式0/10、seed42。D-Q与UB1各自先plain再observed，每次重置scheduler.generator。四步潜变量和视频须逐位复现对应旧冻结输出，plain与observed也须逐位一致；所有160位置必须齐全。D-Q额外要求教师Q1/Q2/Y全部逐位等于实际完整算子；UB1要求教师Q1及实际BaseY+R等于StudentY。控制中的正式来源张量仅作诊断，不用于拟合。

两臂控制在两张空闲工作卡分别执行。只有两臂全部通过，条件控制器才启动原24校准来源在真实UB1状态上的采集：按来源奇偶分片，每来源独立重置seed42+i，所有160位置各256个原均匀坐标，保存V1/BaseY/TeacherY/StudentY/bias/gate及几何身份。plain/observed两视频必须相同。新张量和视频进入共享home的HF derived缓存，工作节点保留80GiB余量，共享home保留200GiB余量。

两臂两个固定输入的原生控制现已全部通过：32次逐步潜变量、8条重复视频与旧参考逐位一致；四次observed执行覆盖640个原生位置。两张控制图仍只有两个独立来源。见[完整控制摘要](../reports/worker_20261020/OP2_native_control_summary.json)、[D-Q证据](../reports/worker_20261020/OP2_DQ_native_controls_RUN.json)和[UB1证据](../reports/worker_20261020/OP2_UB1_native_controls_RUN.json)。条件控制器随后启动24校准来源采集；当前尚无新拟合、完整视频质量或速度结论。见[协议](../reports/worker_20261020/OP2_registered_protocol.json)、[源冻结](../reports/worker_20261020/OP2_before_native_control_source_freeze.json)、[90项测试](../reports/worker_20261020/OP2_preflight_90_tests.txt)、[教师数值AST控制](../reports/worker_20261020/OP2_complete_hook_AST_control.json)及[条件控制器启动记录](../reports/worker_20261020/OP2_conditional_controller_dispatch.json)。
