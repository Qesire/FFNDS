# FFNDS / AutoResearcher 新探索：门控残差商空间与可观测 FFN 计算（2026-10-24）

**新构造。** 将“被省略通道的 FFN 输出误差”分解为沿残差流每 token 全通道平移的不可观测分量，以及实际影响归一化分支的中心化分量。对于标准 pre-LayerNorm Wan 主干，后者比原始输出 SSE 更接近真实计算必要性。这是一条 **Q3 算子优先 ↔ Q1 信息 ↔ Q2 净决策价值** 的新探索支路；没有预设 dense 补算、R256、router 或大规模再训练。

**证据等级：** LayerNorm 平移恒等式及条件传播是数学推导；原代码/配置是结构证据；实际 D-Q/HiF4 上可节省的组数、BF16 等价、质量与时延均尚未测量。2026-10-24 的实验暂停仍生效，本文只使用源码、历史文件和推导。

## 2. 精确恒等式：pre-LN 残差的逐 token 平移自由度

令 `d=5120`，`1` 为 d 维全1向量，
[

对任意实数 `c`，**严格**
[

]
成立；这不依赖 `epsilon 	o 0`，也不依赖 `c` 很小。区别于正比例缩放，在非零 epsilon 下正缩放只近似保归一化。

若后续每个主干子层为 `xmapsto x+U(N(x),mathrm{context})`，其中条件/attention 读取的 residual 仅经过 LayerNorm，且最终头亦首先做 LayerNorm，则逐 token 差 `x'_i=x_i+c_i1` 对后续所有子层的归一化输入严格不可见：每个 `U` 一致，残差平移被逐层保留，最终 head 输出一致。归纳对任意下游层数成立；各 token 的 `c_i` 可以不同。该证明属于理想实数算子/标准主干条件定理，而非 native BF16 位级不变量。

Wan FFN 写回前有按维的 gate `g`：
[
r^+=r+mathrm{diag}(g)y,qquad y=F(q).
]
因此两种 FFN 算子若满足
[
mathrm{diag}(g)(F_a(q)-F_b(q))=c(q)1,
]
则根据上述条件定理，它们在此后的最终主干输出相同。若所有 `g_j
e0`，FFN 输出误差的精确零作用方向是
[
operatorname{span}{mathrm{diag}(g)^{-1}1},
]
而**不是**未门控 FFN 的全1方向。若部分 gate 元素为0，零作用核要按 `Pmathrm{diag}(g)` 直接求；不要对0求逆。

本地 QDQ、GELU、BF16 加法的舍入及额外残差消费支路，都要求另做 native 等价检验。数学证明只断言在被核对的理想结构条件下成立。

## 3. 将新自由度变成不预设补算的 FFN 操作

定义归一化可见的残差更新差：
[
eta_a=P,mathrm{diag}(g),[F_a(q)-F_D(q)] .
]
任意大但纯均值方向的误差有 `eta_a=0`；`||F_a-F_D||` 和旧写回 SSE 并不具有这个性质。

若在定输入和原生完整64组 Q2 可分的实数近似下
[
F_D(q)=b_2+sum_{k=1}^{216}v_k(q),
]
并采用**直接省略部分组、无任何补算**的 `F_S(q)=b_2+sum_{kin S}v_k(q)`，则
[
eta_S=-sum_{k
otin S}u_k,quad
u_k=P,mathrm{diag}(g)v_k(q),
quad
|eta_S|^2=sum_{k,h
otin S}langle u_k,u_hangle.
]
这暴露了与独立神经元幅度排序完全不同的自由度：**组之间可在可见商空间内相消**；不需要恢复整行 dense。它也保留完整64通道物理分组，并让固定组选择、tile共享选择和条件选择都成为同一算子族的不同实例。实际 HiF4/BF16 改变宽度/累加顺序时需重新量化和检验数值等价，不能把这个实数分解冒充 bitwise identity。

可构造三类算子：
1. **固定投影组算子（最强零 router 对照）**：每 expert/step/block 使用固定64组集合；从离线数据或 weight-only `Pdiag(g)W2_g` 提出候选并保留 matched-budget 最优直接裁剪控制。其推理只有真实保留组的 W1、GELU、Q2、W2，无恢复支路。
2. **低带宽区域条件算子**：一个 latent tile 共享组选择；只有当已有信息能预测商空间内的联合误差并在净成本上优于固定组集合，才引入 router。无需默认逐 token 重排。
3. **商空间可观测模式算子**：如果实测 `u_k` 还集中到少量非均值方向，寻找能与实际 QDQ/GEMM 融合的固定或少数模式表示；新的近似模式是需验证的假说，不是 LayerNorm 的精确核。

**关键物理计算账：** `P` 不应作为逐 token 的新增投影 GEMM。固定 gate 下 `Pdiag(g)W2_g` 可离线统计；在线直接用保留原组的 W2。动态组的权重选择、activation QDQ、gather/scatter、policy、tile 分段与 cache 都必须扣费。商空间目标是 *设计和评估表示*，不意味着在线显式计算 full dense difference。

此结论甚至允许任意固定非零的逐维 gate 方差比例，因为迹之比抵消。**如果真实 FFN 输出与组间组合近各向同性，精确平移核通常远不足以产生实用加速。** 本研究的新科学问题正是蒸馏 D-Q 的组贡献和跨组相消是否显著偏离这个零假设。

可在获得允许的原生组贡献后检查：
- `rho_g=||(I-P)diag(g)W2_g||_F² / ||diag(g)W2_g||_F²`（weight-only 候选先验；不是输入/视频作用）。
- `rho_act=||(I-P)Σ_drop diag(g)v_g||² / ||Σ_drop diag(g)v_g||²`（具体已冻结动作/来源的后验标签）。
- `visible_error=||Pdiag(g)(F_a-F_D)||²` 与 post/writeback SSE、nextnorm SSE、有限后续 block/step、四步自由视频排名的关系。
- 在相同物理预算下，固定投影组 vs 固定未投影组 vs 动态投影组；再对照最强静态 D-Q/UB1 以及已知无恢复方法。

上述统计不能从旧 3840 个 OP2 文件头或 C1 的已存 **标量** 误差凭空恢复；原始文件没有成组 `v_g` 和成对门控向量。下一步零实验权限内，先只核对静态 W2/gate 是否在可访问的已存数据和绑定中存在，之后再决定是否值得有权限的 native trace。

## 5. Q1/Q2/Q3 的竞争机制与明确判别

| 机制 | 互斥性较强的预测 | 最低成本的判别 |
|---|---|---|
| G1：主要误差落在不可观测 gauge | `rho_act` 明显高于 1/d，同预算商空间组集合大幅改善真实 nextnorm 排名 | 数学和源码已完成；下一步只读可用 group/gate 资产；之后如获权限做 native 捕获 |
| G2：重要的是多个可见组的有符号相消 | 单组投影范数不突出，但联合 Gram 出现强正/负交叉项；独立组排序失败而 joint set 有效 | 现有 R7 仅是不同恢复动作的有限传播交互，不能当 `u_k` 标签；需真实分组贡献 |
| G3：门控随 step/专家变化使可见性结构变化 | 同一 W2 在不同 gate 下的 group order 改变；step-aware 静态集合先于昂贵输入级 router 获益 | 先只读源码/配置 gate 生成路径；没有真实 gate 值不得声称发生翻转 |
| G4：真实贡献近各向同性 | `rho_act` 近 1/d，商空间目标对组省算影响微弱 | 以 1/5120 为零假设，及时转向其他更高维的低响应机制 |

## 6. 与现有 FFNDS 证据如何相互更新

- C0 的 pre-norm 残差尺度反例强调：**当前归一化不保留决定未来动作价值的全部信息**；本次引入其正交一面：**某些写回误差在全部后续主干也不可见**。前者是状态充分性问题，后者是算子等价类问题。
- C1 72 native scopes 中 post SSE 与 nextnorm SSE 平均 Spearman 约0.875635、top25%重合约78.30%；说明评价目标不同，却**不能**证明该差异由均值方向造成。旧记录缺少归一化前后的完整误差向量。
- R16V0 的单来源 160-site 完整生成发现局部 SSE 改善约6.13%，但 pooled RGB MSE 比最佳固定模式差约8.23%；因此 `visible_error` 首先是比 post SSE 更贴近结构的候选指标，**仍不能等同最终感知质量**。
- R7D1 的两个有限动作大交叉项相消提醒：即使 `Σu_k` 在一处小，也需检查完整后续非线性与自由四步轨迹。若真的严格纯 gauge 且结构条件成立，才可以从局部恒等式直接证明全后续不变；任意近似小误差不能这样推。
- 历史仿射骨干、R256和 dense completion 对照保持有效，但此探索不把它们作为必需结构或标签。

## 7. 现有学术先例：可以借用的事实与真实增量

- [Algebraic Dead Directions in LayerNorm Transformers (2606.19491)](https://arxiv.org/abs/2606.19491)：已研究 LayerNorm 产生的精确不可观测/零协方差方向，故不能把“LayerNorm 有一个零方向”包装为原创。该文讨论的归一化后激活协方差核（仿射 gamma 的逆尺度方向）与这里 **门控 FFN 更新经残差传播的动作等价类** 相关但不是同一个对象。
- [Complete Characterization of Gauge Symmetries in Transformer Architectures (PMLR 2026)](https://proceedings.mlr.press/v282/wang26a.html)：参数再参数化与注意力/FFN 对称群先例；不能将现有对称性概念作为新的数学发现。
- [QuantSparse (ICLR 2026)](https://proceedings.iclr.cc/paper_files/paper/2026/hash/94359ca6e248af69b8b6854668ae9782-Abstract-Conference.html)：视频 DiT 量化和注意力稀疏耦合研究先例，但不是 Wan D-Q FFN gate 商空间的同一物理动作或结果。
- FFNDS 历史 `docs/61`、`docs/69`、`docs/95`：已覆盖仿射/分组/Hessian/信息价值/K 下游几何。此次可探索的差异是 **精确残差等价核 → 64组的净可见贡献 → 无补算执行单位和真实 NetVOI**；原创性最终还需针对完整方法与更近邻研究查重。
