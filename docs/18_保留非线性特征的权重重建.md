# WR1保留非线性特征的权重重建协议

RR1在前FFN0线性输入上预测残差，完整视频明显改善但仍有模糊。
另一条标准强基线使用已经计算出的保留post-Q2激活作为特征，在calibration12上重建FFN2。
这不是候选理论创新，也不使用缺失的旧缓存或新验证输入作为训练数据。

协议`config/weight_reconstruction_wr1.json`在任何此类ridge拟合或CV前登记。
支持固定为同一C-static108个原64组，FFN0量化权重不变。
用native baseY与captured denseY构造gated残差，FP64中心化/全局RMS/dual Cholesky ridge，
校准图像奇偶6/6二折，只选lambda0.01/0.1/1/10。
全秩修正与原增益离线折入FFN2，拦截均值折入原centered b2一次。
重新BF16转换后必须调用原生native_hif4_weight_qdq(force_fp32=True)，
不能用未重新量化的BF16重建权重冒充原生HiF4候选。

CV只使用实际重新量化后的native风险，要求两个step×两个fold全部≤0.50同一base，
通过时以最低平均风险选lambda，固定后才测试task0/task6；独立测试每来源仍要求至少3/4≤0.50。
base预先见过12校准图像，因此这里仅是修正器的来源分折，不是整套管线的独立CV。
若通过，再拟合同一lambda到全部160位置，随后完整视频/计时/正式20三指标分别检验。

该形式没有额外在线GEMM：仍为两次实际半尺寸主GEMM及原GELU/QDQ/gate。
重建参数和原始风险均留HF派生缓存，BF16按uint16原始位保存，以免FP32编码使磁盘占用翻倍；
任何全位置拟合都须保持节点80GiB磁盘余量。
独立primal/dual ridge与gate逆变换对照、全部65536种BF16位模式的无损存储测试通过。
pilot已完整完成16个native重新量化CV拟合，没有lambda同时通过四scope的≤0.50门槛。
较好的lambda1在high两个fold为0.7345/0.7377，low为0.5599/0.5550；没有选出候选。
重新量化前的BF16风险比high为0.7253/0.7286、low为0.5486/0.5441，仍未达门槛，
因此主要不足已经存在于重建映射，而非仅由再次HiF4量化引入。
保留全部CV参数/量化权重与阴性报告，不做独立task0/task6测试或全160拟合，也不放宽门槛。
完整报告为`wr1_native_requantization_CV_RUN.json`，节点HF缓存由identity指向。
这条基线停止；继续冻结RR1正式质量与常驻验证。
