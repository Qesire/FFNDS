# 公开元数据与私有执行配置

公开目录、文件名、SSH入口、协议说明和历史报告均统一使用worker等中性标签。真实地址与预期主机名保存在仓库外的私有配置，不提交Git。历史原始文件已另外保留在仅用户可访问的私有快照中；模型、张量和运行目录没有重新计算或改写。

连接配置默认使用`~/.config/ffnds/ssh_config`，入口为`Host ffnds-worker`；运行主机配置使用同目录`worker.json`的`expected_hostname`字段。可以通过`FFNDS_SSH_CONFIG`、`FFNDS_WORKER_CONFIG`覆盖路径。真实字段由操作者在私有文件中填写。`tools/run_on_worker.py`使用中性别名，CPU、GPU、评估与编译入口均通过私有配置校验实际主机。两卡限制、互斥锁、已有进程检查和HF缓存规则保留。

历史报告中的SHA256和身份指纹继续表示当时的原始字节；脱敏改变的是公开副本的字符串与路径，不能将原始哈希冒充为公开副本的当前哈希。`reports/worker_20261020/public_redaction_manifest.json`分别保存原始与公开SHA，记录数值字段不变检查。旧冻结脚本因隐私迁移形成新源码身份，不能直接以新源码续写原身份的检查点；后续实验须使用新身份，并明确验证所复用的原始私有资产。

`tools/check_public_metadata.py`从私有配置读取需要禁止公开的标识，扫描可提交文件的路径和内容；`--staged`检查Git暂存区，包括未修改但仍被跟踪的文件。扫描日志只输出不可逆路径ID及匹配数量，不回显敏感名称。当前执行环境已安装对应的本地pre-commit检查；全新克隆如需同样保护，应在配置私有连接后安装本地提交检查。
