# 归一化前信息与完整净动作：C0离线检验

本轮已执行源码核对、3,840份原生文件头审计、五个已暴露主体来源的实际路由分析及确定性CPU反例。主要结论是：**残差尺度可以在当前归一化输入相同的情况下改变后续动作排序；完整动作的传播不能仅凭总收益接近相加就当作线性。** 这给出了具体的下一次观测对象，尚未建立新视频方法或质量优势。

结果及复现：[完整数值](../research/20261023/C0_coupling_offline_results.json)、[分析程序](../tools/analyze_coupling_pivot.py)、[积极先例表](../research/20261023/C0_positive_prior_art.json)、[下一步判别](../research/20261023/C0_next_discriminator.json)。本轮新模型调用、训练、GPU作业均为0。R17保持57条生成/0次官方评分的原始停止状态，质量结论仍为UNKNOWN。

## 1. 当前归一化输入没有决定所有后续动作价值

核查与R17冻结字节一致的Wan实现：`infer_ffn`先将交叉注意力更新加回残差，随后执行norm2、调制、Q1和两侧FFN投影；`post_process`再把门控FFN输出加回**原来的残差**。下一block重新执行归一化和注意力。相关字节绑定保存在结果的`native_source_bindings`。

令归一化前残差为`x=mu*1+sigma*u`，`u`中心化且方差为1。当前FFN主要看到归一化、调制和Q1后的表示；后续残差仍含`sigma*u`。若门控FFN更新为`f(u)`，下一归一化的中心方向取决于：

```text
y = sigma*u + f(u)
J_LN(y) = (I - 11^T/d)/s_y - y_c*y_c^T/(d*s_y^3)
Q_next = J_LN(y)^T J_LN(y)
```

`s_y=sqrt(mean(y_c^2)+eps)`。固定更新不与`u`共线时，改变sigma会同时改变尺度和下一归一化的方向。路由特征里缺少的变量因此可能影响不同动作的相对价值。

已执行四维有限反例：`u=[1,-1,1,-1]`，`v=[1,1,-1,-1]`；Dense门控更新为`v`，两个动作更新分别为`u+v`和`1.5v`。当前norm使用`eps=1e-6`，两种状态的**BF16归一化输入逐位相同**，所以固定调制/平滑下的确定性Q1和R256也看不到差别。

| 归一化前尺度 | 下一归一化后A的SSE | 下一归一化后B的SSE | 最佳动作 |
|---:|---:|---:|---|
| 1 | 0.41053347 | 0.15535453 | B |
| 4 | 0.00905490 | 0.05173862 | A |

这是合成反例，不是Wan中的收益测量，也未证明scale能在真实来源上预测增益。反例中的门控输出是固定构造，未运行神经网络或声称等MAC动作已在原生内核实现。

**反向控制也已执行：** 若改变的只是所有动作共享的`1/sigma^2`损失系数，同一token内部的等成本动作排序不变。不能从“归一化丢失尺度”直接推出“加一个norm特征就会提高通道选择”。需要测量固定残差更新后的方向变化，或跨token的预算配置收益。

这与[Sparse Inter-Layer Dependencies](https://arxiv.org/html/2607.11990v1)保留归一化分母的残差归因相接；可借用其上游信息分解，同时将预测目标改为真实补偿后有限动作的下游损失差。这里提出的是可证伪适配，未声称独立原创性。

## 2. 区分三种耦合：原生加法、补偿与下游损失

在固定输入、固定alpha/bias、完整对齐64通道组和固定共享量化边界下，GELU逐坐标计算，实数FFN输出按隐藏组相加。原HiF4的QType为64通道内组、外组大小1；重排完整组保留该结构。BF16求和、不同GEMM宽度、alpha编码和folded bias仍要在实际动作实现时做数值控制；本轮没有重新运行原生QDQ或FFN。

补偿依赖集合也不必然引入非加性。对**固定特征、固定训练权重的精确OLS**投影P：

```text
R_S = P(T - D_S)
Y_S = D_S + R_S = PT + (I-P)D_S
Y_11 - Y_10 - Y_01 + Y_00 = 0
```

该恒等式对应现有`FixedDesign.fit/residual`的线性结构。已执行合成四臂计算，输出混合差为0，但平方损失交互为−4，恰等于`-2<d_A,d_B>`。另一个明确加入非线性集合补偿的正控制得到非零混合差。改变特征、alpha、bias或编码之后，固定投影定理不再直接适用。

符号应与实现保持一致：原生`Y=main+R`，新增组的净增量是`D_g+R_new-R_old`。TACR原文使用从UB1中**移除的补偿**C，因此`C=R_old-R_new`，相应写成`D_g-delta(C)`。两个约定不能混用。

## 3. R7标量重算：小交互收益掩盖了大传播非加性

复算[R7原始公开数值](../research/20261021/R7D1_results.json)，保留四个旧来源、step3/block30与31、完整teacher恢复及step间Dense重置的原范围。记`e=Y0-target`、`a=YA-Y0`、`b=YB-Y0`、`c=YAB-YA-YB+Y0`：

```text
Gain(AB)-Gain(A)-Gain(B)
  = -2<a,b> - 2<e+a+b,c> - ||c||^2
```

| 四来源池化量 | 数值 |
|---|---:|
| Gain(A)+Gain(B) | 5708.054379 |
| Gain(AB) | 5505.611396 |
| 净交互收益 | −202.442983 |
| 方向交叉项 | −11859.538352 |
| 有限非线性传播项 | +11657.095369 |
| `sum||c||² / sum||a+b||²` | 0.53756158 |

净交互相对单臂收益和只有−3.5466%，但两大项抵消程度为99.1391%。因此“小的标量交互”不支持“把有限动作向量线性相加”。这提示先直接测少量**完整动作**，再判断是否值得拟合单组线性响应。

本次在两处登记的HF根目录未找到R7原始24份流张量，因此做的是公开原生标量的重新组合与恒等式核查，未冒称重新读取原始流或做新的向量传播实验。已有原结果和原始哈希未改。此处的c也是大幅完整恢复的有限非加性，不能解释成小扰动Jacobian曲率，更不能推定所有64通道动作都同样非线性。

[PulseQuant](https://arxiv.org/html/2609.33384v2)提供可借用的同前缀有限干预设计；[Output-aware Residual Stream Pruning](https://arxiv.org/html/2609.35579v1)提供方向敏感度与共享度量对照。新问题是廉价状态是否能预测**原生完整补偿动作**的条件价值，而不是再确认局部幅度与最终质量不同。

## 4. 真实路由在五个主体来源上的重用

读取R17已完成的五份dynamic实际bitset，各覆盖4step×40block×31668行；请求与bitset哈希逐项核对，所有位置都恰好7917条Dense行。来源0..4全部属于已暴露的主体图像，背景和相机族未测。

| 来源 | 条件首latent bin的Dense比例 | 其余20bin均值 | 相邻bin翻转比例 |
|---:|---:|---:|---:|
| 0 | 87.4909% | 21.8755% | 24.8439% |
| 1 | 83.7695% | 22.0615% | 26.2454% |
| 2 | 75.6105% | 22.4695% | 25.7059% |
| 3 | 79.0376% | 22.2981% | 27.8005% |
| 4 | 74.3344% | 22.5333% | 26.3376% |

五来源首bin均值80.0486%，高于旧校准源的66.9674%。两两来源的被选行替换比例为50.19%–59.26%，均值56.87%；Jaccard为0.2558–0.3316，高于匹配每位置/每bin边际密度的独立选择参照0.1949–0.2184。

这些数字同时表明条件bin结构和来源变化都影响了选择。它们没有测量选择是否有益，不能归因于主体/背景，也不能从mask变化直接推断视频闪烁。索引比较在相同latent坐标上进行，没有跨图语义对齐。21个latent bin与81帧视频继续分开记录。

## 5. 已有资产与下一次最小判别

逐份核查24个旧来源的输入凭证哈希，读取全部3840个原生文件头。唯一模式为`V1/BaseY/TeacherY/StudentY/b2/gate`，全部BF16；大张量本体没有重新全量hash。没有原始pre-norm残差、attention increment，也没有新64组完整补偿动作的同前缀续跑标签。**真实E1条件价值目前未知，不能从V1反推出丢失的残差尺度。**

### 已实现的统计读取原语

Wan的norm2由`LN_WEIGHT_REGISTER["torch"]`创建。核查[PyTorch2.10实现](https://github.com/pytorch/pytorch/blob/v2.10.0/aten/src/ATen/native/layer_norm.cpp)：`layer_norm_symint`调用`native_layer_norm_symint`并仅返回其第一个结果。新增[统计读取原语](../tools/prew1_norm_statistics.py)取同一native调用的`output/mean/rstd`，复刻原Wan的敏感精度转换分支；没有请求另一次方差归约，也没有改动当前模型或原生源码。

已在现有Torch2.10.0+cu128环境、CUDA隐藏的CPU上运行[数值检查](../tools/check_prew1_norm_statistics_cpu.py)：BF16同精度、BF16输入/FP32敏感路径、FP32同精度三种设置，1/32/256行×5120维，含/不含仿射，输入尺度1/4，共36组输出逐位相同，输入未修改。另两次CPU BF16归一化调用得到相同输出、不同rstd=1与0.25。原始记录见[CPU凭证](../research/20261023/C0_norm_statistics_CPU_readiness.json)。

该原语没有接入真实模型，未测GPU一致性、完整轨迹观察恒等或延迟。保留mean/rstd会延长张量生命周期，统计读出、后续选择和内存成本仍须计入；CPU位控不能代替这些检查。无需为了取得尺度而预设必须新增一次全维归约或重算R256。

下一步优先准备“固定完整动作的直接有限价值＋归一化前尺度”判别：

1. 冻结少量完整64组动作的alpha、bias、R256、舍入顺序与物理布局，按真实时延匹配最佳固定、幅度路由和UB1；不重复R4的局部q≤2筛选。
2. 在原生FFN入口记录`x_before_cross_update`、attention increment及`x_after_cross_update`的廉价尺度/对齐摘要，与相同token的post-Q1、现有R256特征及**完整动作**有限续跑损失差配对。实际前置信号只许读决策时可用量；Dense/未来状态只用于离线标签。
3. 先比较位置/latent时间区、当前输入、再加尺度/attention的特征阶梯；使用来源簇留出和位置/时间区内shuffle控制。报告同物理预算下的决策regret与新增开销；损失和秒数若合成一个标量，必须预先给出换算系数。
4. 若只有层位置解释收益，就保留强固定控制；若只预测激活而不减少真实动作regret，就淘汰该信息实例；若尺度带来净条件收益，推进低开销原生读取；若有限动作c很大，直接预测整个动作，避免无限扩展组组合。

[Prox](https://arxiv.org/html/2607.27591v1)的廉价选择/精算保留通道可作为执行原语；[SVG-EAR](https://arxiv.org/abs/2603.08982v2)的补偿误差定价可作为目标对照。它们的原始算子与硬件条件不同，引用的跨模型速度不作为FFNDS比较结果。八项先例的已读范围、原设置和改造成本见[提取表](../research/20261023/C0_positive_prior_art.json)，未声称本轮检查过其代码仓库。
