# LA1：折叠低秩量化适配小试

本小试在OP1校准CV或正式评估结果产生前登记，条件为OP1校准CV或正式质量被拒绝。修正版GPU原主重放、原生量化控制及四项CV已完成，均未达到CV门槛。若OP1质量通过，不启动本分支。

OP1仅改变线性残差。LA1检验改变保留FFN主权重是否能恢复它未覆盖的局部非线性误差；这是标准局部量化感知低秩适配控制，不是新的动态选择方法。仍使用OP1已冻结的24个来源及局部原生dense D-Q标签，不使用正式/研究目标。

保留C24支持、smooth、原始b0、folded b2、gain及其cast位置、旧rank256残差与其他网络模块。W0/W2各加入rank32低秩更新；前向权重调用原native HiF4 QDQ，激活同样使用原QDQ，梯度用straight-through。训练固定8 epochs、batch128、AdamW lr0.002、clip1，无超参搜索或早停。完整协议在`config/folded_adapter_la1.json`。

优化使用128行小批次，最终CV风险恢复原始完整序列形状计算；训练小批次本身不宣称与部署完整序列逐位等价。`tools/continue_folded_adapter_pilot.py`已等待登记条件，等待登记条件后，实际小试已在GPU1完成。

每项拟合前，必须以完整原生序列形状/stride及采样坐标重放原主分支BaseY和旧残差之和，并与实际BaseY/StudentY逐位一致。两个晚期位置、全部24来源的控制都完成，才允许任何训练。零更新再次量化可能改变原缓存权重，因此额外报告requantized parent，不把它称为恒等基线。straight-through前向须逐位等于原量化函数。

先做step2/3 block20四项开发校准CV，要求LA1原生风险全部≤原捕获C24 StudentY的80%。这些来源和CV划分已在前序试验复用，且base用过全部24，所以不称全管线留出泛化验证。任一失败即停止，不跑全160位置和正式视频。

CPU测试已检查straight-through的精确前向位模式/梯度，以及原始权重与零更新重新量化的区别。实际GPU主分支重放、原生量化梯度执行和四项CV已验证；全160与完整部署未运行。若小试通过，再实现/验证全部160位置的离线折叠部署；折叠后的主权重才进入同一正式质量及完整FFN测速，不能将低秩训练过程的计算量算作推理收益。

两个CV尚未启动时的源码/协议SHA和采集完成数快照保存为`reports/worker_20261020/LA1_before_CV_source_freeze.json`，更早的OP1首两个输入描述结果也明确保留。44项CPU控制/既有测试全部通过，见`LA1_preflight_44_tests.txt`。
