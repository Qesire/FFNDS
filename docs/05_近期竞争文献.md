# 近期竞争文献与机制边界

检索/核验日：2026-10-20。优先核对已有V5/AR2关注的论文，并补检9–10月公开工作。以下依据原论文、会议官网或作者仓库；不是完备文献计量检索。本项目尚未完整复现这些竞争方法，不能据局部CPU回放宣称胜过它们。

## 直接关系最强的七篇

| 文献与一手来源 | 原方法的关键机制 | 对当前工作的约束/必要对照 |
|---|---|---|
| [Dynamic-in-Few-Step](https://arxiv.org/html/2607.06631)，2026-07，§3.2/§4/附录A | 将少步蒸馏与step-specific block/head/FFN门控联合优化，导出MoM；FFN先按权重L2重排，再按C=8分组 | “按步FFN裁剪+蒸馏”已有先例。我们的冻结D-Q、原始连续64组、CPU支持诊断不是其训练/推理复现；须报告重排、训练与执行约束差别。 |
| [RT-Lynx](https://proceedings.mlr.press/v306/cong26a.html)，ICML 2026；[原文§4](https://arxiv.org/html/2605.26632v2) | 激活2:4 TopK、输入范数补偿、LoRA适配，并融合稀疏化/压缩/稀疏GEMM | “动态激活选择+增益补偿”不能作为原创点。AR1的跨种子输出目标标量不同于输入范数比；同数值边界下应加入该补偿基线，并计选择及kernel成本。 |
| [E-DiT / Elastic Diffusion Transformer](https://proceedings.mlr.press/v306/wang26dd.html)，ICML 2026 | 轻量router按输入latent预测block跳过与MLP宽度，推理还用预测驱动block feature cache | 样本相关width已存在。要证明token支持价值，须优于step/layer静态基线，区分sample级宽度与token级通道身份，并计router成本。 |
| [TAPE](https://arxiv.org/html/2605.17837v2)，2026-05，§4 | 在相邻视频帧之间平滑token重要性，选定层重选token，去噪后段减弱剪枝 | 视频帧轴不同于去噪步轴。“平滑mask减少闪烁”已有先例；不能由局部SSE或同expert复用推出视频一致性。 |
| [SODA](https://arxiv.org/html/2603.07057v4)，2026-03，§3 | 离线建立step/layer/module敏感度，动态规划cache intervals，并按敏感度调整剪枝时机和比例 | 敏感度预算表是强基线。“按层/步分配稀疏率”不新；比较预测器时必须控制同一全局计算预算。 |
| [STEP-OPD](https://arxiv.org/html/2608.04887v1)，2026-08，式9–14 | 输出端外推teacher/base速度差；内部直接匹配相邻block更新的归一化方向与log RMS幅值 | “邻接层差分/方向与幅值对齐”已有先例。本项目FFN/gate几何诊断不是它的on-policy训练复现，未来须分离SA/CA/FFN贡献。 |
| [SVD-Cache](https://arxiv.org/abs/2601.07396)，2026-01；[CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Chen_Forecast_the_Principal_Stabilize_the_Residual_Subspace-Aware_Feature_Caching_for_CVPR_2026_paper.html) | SVD分解principal/residual子空间，对主低秩部分EMA预测、复用残差 | 低秩稳定子空间已研究。跨步feature caching不同于当前步FFN稀疏误差修正；oracle低秩系数可拟合，不代表在线能廉价预测。 |

论文报告的模型、硬件、稀疏粒度和速度边界不同，不直接做“谁的倍速更高”的横向表。Dynamic-in-Few-Step 在四步蒸馏之上报告的额外墙钟收益，与相对50步teacher的总收益是两个分母；RT-Lynx线性层加速也不同于完整视频加速。

## 当前真正需要回答的判别问题（本项目判断）

1. **固定增益之后，动态支持还比静态支持好多少？** 同样50%保留、同一gate/QDQ/cast边界、相同策略专属gain，比较A/E/C各自static/dynamic；赢random或未补偿基线不足。
2. **几何收益能否部署？** C为 `||sum_group c_j||²`，是标准块Gram二次型；它保留组内交叉项但忽略组间项，不保证最优支持。逐组投影可能已接近dense W2成本，必须另设廉价近似/执行门槛。
3. **量化与蒸馏谁改变了可压缩性？** O、D-BF16、D-Q需在相同输入条件下分别调用；自然轨迹差异不能替代函数对照，D-Q/BF16比较不能识别蒸馏效应。
4. **局部目标何时失效？** 对同等局部误差的干预，追踪完整残差、后续去噪和视频；邻接差分、时序平滑与终端对齐都已有先例，创新须体现本对象上新的可检验机制或系统收益。

本项目目前最稳妥定位是：**已有方法与强基线在四步蒸馏Wan、native HiF4边界下的机制诊断；完整实证创新仍未闭合。** 不把有符号投影、交叉项恒等式、标量增益或连续分组包装成独立新理论。
