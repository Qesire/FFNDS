# 固定UB2的多类别前瞻确认集

原始20和来源分离补充20都已参与UB1/LR2/UB2开发。UB2策略、拟合参数、原生身份与末步流控制固定后，在任何UB2官方质量结果和新确认推理之前，登记额外一次前瞻确认；它只有在两批观察过的开发来源都通过质量门槛、并且独立工程检查结束后才启用，不与隔离测速重叠。

第一版试图继续使用animal10/architecture10，按元数据排除已有正式/校准/补充来源后，architecture只余8个，未达到预先要求。程序在图像提取和模型执行前停止，没有自行替换；[停止证据](../reports/worker_20261020/UB2_confirmation20_original_strata_selection_failed.json)与[原注册配置](../config/ub2_confirmation20.json)保留。这不是一次模型质量失败。

随后在仍未得到任何UB2官方质量结果时，独立登记第二版多类别确认。它与前两批的类别构成不同，结果必须单独报告：

| 分层 | 固定类别与数量 |
|---|---|
| i2v_subject，10来源 | animal2、transportation2、food2、single-human2、multiple-human2 |
| i2v_background，10来源 | abstract2、architecture2、indoor3、scenery3 |

每类取固定metadata顺序中的最早可用来源。排除已知原始20、calibration24和补充20的sourceID/图名/prompt，并在提取时检查其实际图像SHA与这些集合、旧calibration12和research0/6无重合；遇到重复或不足立即停止，不替换。20个图像全部使用固定16:9 crop、seed42；输入图像和视频均放HF缓存。复核见[输入与哈希](../reports/worker_20261020/UB2_diverse_confirmation20_recovery_report.json)、[冻结输入表](../reports/worker_20261020/UB2_diverse_confirmation20_canonical.json)及[新协议](../config/ub2_diverse_confirmation20.json)。没有证明所有交接前历史实验从未见过这些源图。

新评分入口只放开旧同类别索引中的image_type限制，保留各图实际类别，以及原subject/background三项metric的dimension列表。原始20历史索引仍能精确重建，[控制证据](../reports/worker_20261020/UB2_diverse_confirmation_historical_index_control.json)已保存；官方worker、模型、逐视频算法和2%门槛不变。每项评分前必须覆盖20来源的100个副本文件名，5个副本仍只代表一条生成视频。[76项CPU检查](../reports/worker_20261020/UB2_confirmation_preflight_76_tests.json)全部通过，CUDA未初始化。

如果当前两批质量通过，则先完成两批全20主动驻留等价和串行独立测速；随后D-Q与同一冻结UB2在新20各生成一次，使用相同官方worker配对评分，三项分别要求相对下降≤2%。不使用确认结果重新拟合参数、改变支持/预算或挑选候选。[推理前源码冻结](../reports/worker_20261020/UB2_diverse_confirmation_before_inference_source_freeze.json)和条件控制器保留执行次序。若开发质量失败，新确认图保持未执行，不能写成已检验泛化。

UB2两批观察过的开发来源最终因imaging失败，条件控制器已按协议停止，[记录](../reports/worker_20261020/UB2_unexecuted_confirmation_RUN.json)为`NOT_RUN_OBSERVED_UB2_QUALITY_REJECTED`。确认集只完成输入、索引与源码冻结，没有生成任何视频或质量分数。
