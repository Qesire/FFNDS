# R12 D0 等预算原生动作检验

E0 揭示了一个实际缺口：历史 R7 的完整教师恢复没有扣除另一层的计算，不能识别等预算 216/108、108/216 的真实动作价值。本轮在用户明确批准后登记并实现固定 D0，以实际原生传播补上这个缺口。

令冻结 UB1 与 DQ 的完整 step3 flow 差为 e，新动作相对 UB1 的变化为 δ，则动作收益精确为 `−2〈e,δ〉−||δ||²`。第一项识别方向是否抵消既有误差，第二项计入改变本身的代价。不同来源若选择不同最优动作且有足够收益，才支持继续研究条件选择；一个统一更好的固定动作不等于动态机制。

本轮不学习支持或补偿。两层总计 324 组，三动作共享原始偏置与零补偿容量；其余 158 个位置保持冻结 UB1。另测带原补偿的完整 UB1，避免只胜过弱化的 N0 就宣告有用。全部是已暴露四来源、固定完整步骤输入的诊断，既非独立质量，也非完整 FFN 测速。

详细冻结范围、24 次上限、数值与资源控制见 [协议](../research/20261022/R12_D0_registered_protocol.json)、[用户授权记录](../research/20261022/R12_D0_authorization.json)、[当前交接](../research/20261022/HANDOFF_R12_D0.md)。原 [E0 数据与结构结论](66_R12等预算动作的操作数与条件粒度审计.md) 和所有旧实验原始结果保留。

准备结果：原始两层三种 CPU pack 的实际权重/Smooth 哈希均匹配 E0；三动作全局主 MAC 同为 358628091494400；CPU 准备未初始化 CUDA、没有新模型生成。原生测量等待两张被其他任务占用的卡空闲，执行器不抢占任务。
