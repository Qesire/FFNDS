# 保留特征与低秩残差联合重建 JR1

这是已完成校准交叉验证、未通过预设门槛的后备控制实验，使用原12输入来隔离C24校准分布变化和VM1矩匹配。协议为`config/joint_reconstruction_jr1.json`，系数拟合前冻结；不将标准重建技术称为新动态选择方法。

RR1从V1预测遗漏残差，WR1从保留的非线性激活做重建，二者都留下了误差。JR1检验两类特征是否互补：固定原108个64组支持、原alpha及其BF16激活cast位置，从原RR1出发，先对其剩余残差做一次锚定W2岭回归，再用原生HiF4重新量化W2，随后重新拟合并替换rank256的V1残差。原bias及中心化截距均只计一次，不叠加第二套辅助网络。

lambdaW=lambdaR=1、rank256、一次W更新/一次R重估，均固定，不扫参数或迭代轮数。主GEMM尺寸仍各50%，辅助仍为原来的两个rank256 BF16线性层。与旧WR1不同，alpha继续放在激活端，避免把BF16 gain/cast与权重量化交换位置。

先在block20的step0/2，重现原RR1的两个校准parity fold风险，并设置同gain位置的WR-only控制。只有四个step/fold全部满足`JR1/RR1<=0.80`且`JR1/WR-only<=0.90`才拟合全12的先导参数，随后做既有task0/task6的固定八scope检查。baseC用过全部12，因此这只是correction-only CV，不能声称全管线留出验证。既有研究来源不参与拟合，亦不称新的最终测试集。

独立已知解的CPU代数测试通过，覆盖互补特征、原bias和负gate。随后在主流程官方指标结束后空出的GPU0上完成四个CV位置，总计22.6秒；原RR1的四个native风险全部重现。

联合重建有少量改善，但全部未达到`<=0.80 RR1`且`<=0.90 WR-only`。重量化前的BF16控制仍未越过门槛，匹配FP32控制接近原生；这些控制不支持将主要差距归于舍入环节。
因此停止此路，**没有拟合全12先导/全160，也没有执行研究来源留出或正式视频**。原CV参数保留在HF派生缓存，原始报告及身份在`joint_reconstruction_jr1_*`归档中。预留评估工具未执行；不根据失败结果放宽门槛。
