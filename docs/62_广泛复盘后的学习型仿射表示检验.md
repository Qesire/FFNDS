# 广泛复盘后的学习型仿射表示检验（R9A1）

本项是在[R10全路线复盘](61_全路线失败归因与组合方案复盘_R10.md)之后，从不同表示方案中选择的固定原生可行性检验；不是继续调R8阻尼、R4支持交换或R7D2增益。原R2已明确学习每通道斜率/截距、BF16骨干、原生Q2目标并取消R256，[原文SHA与范围校对](../research/20261021/R9_scope_reconciliation.json)保留。

## 选择依据：先实际比较完整执行成本

[固定合成协议](../config/representation_cost_preflight_R10.json)在同一张A100、相同M31668/D5120/H13824、相同QDQ路径比较三种完整FFN链，所有Smooth、cast、QDQ、GELU、bias、余项相减/相加、gate均在forward内。三个warmup、七次轮转/反序测量，公开全部样本；权重预处理在离线阶段。原生BF16入口与原forceFP32入口的24项逐位检查全部通过后才计时。派生矩阵和因子明确为BF16混合精度，没有额外R256。

|---|---|---:|---:|
| dense | 51.52 / 50.14 / 50.60 / 51.26 | 203.52 | 1.000× |
| 仿射+余项K896/4352/4352/7808 | 15.99 / 31.69 / 31.74 / 46.84 | 126.26 | **1.612×** |

[结果](../research/20261021/representation_cost_preflight_R10.json)只有合成执行证据，不含学习、模型参数或来源画质。四步计时对应四个完整forward，不是独立组件中位数相加。仿射臂正好50%主MAC；对齐后的因子臂略低于50%。原生模型的非单位Smooth、权重尺度、其他层、访存和驻留仍需另测，不继承原UB1的完整160位置速度。这个成本比较只支持优先研究仿射表示，不能称为新候选达到1.5×。

## 固定原生检验

[协议](../research/20261021/R9A1_learned_affine_protocol.json)固定block20四步，训练仅OP2奇数12来源；验证仍00/06/12/18四个已开发暴露来源。每个专家两步共享一组系数和BF16矩阵，不加R256，不再次量化骨干或余项。

计算为：原post-Q1 V1进入完整线性骨干；所选64通道组通过原始有效W0、原GELU/Smooth/cast/HiF4Q2，减去学习的线性部分形成BF16余项，再通过原W2相加。原b2和学习截距仅计入一次。三个主GEMM的MAC按`d²+2dK`全部计入，保持25/50/50/75%步间预算。

先检查96项旧UB1主输出/R和96项完整教师逐位重建。两个专家共16项完整支持数值检验都必须≤对应UB1误差的1%，两个工作卡通过全局屏障后才允许压缩。若任一项失败，两卡都不选支持。

之后只按训练来源的完整有符号216组Gram，执行一次预定组数14/68/68/122的贪心选择；不给读出增秩、重拟合或交换搜索。检查实际打包W0/W2宽度的原生误差，全部16项都需≤.98UB1。任一失败关闭这个固定表示/选择实例，不扩大组数、折数或位置，不加回R256。完整支持代数正确也不能替代这些检验。

大矩阵与支持载荷仅存HF缓存，最多两卡各一专家，现有环境与精确依赖source view不变，保留80GiB节点余量。无新管线生成、候选视频或最终质量评估。即使全部局部门槛通过，下一阶段仍需单独固定原生窗口恢复目标、真实完整160位置速度和真正新来源质量方案。

当前：**固定原生检验全部完成，该OLS＋贪心余项实例被拒绝。** 141项CPU检查、96项旧UB1与96项完整教师逐位控制通过，16项完整支持数值门槛全部通过；最大折叠误差/UB1仅0.000811，即0.0811%。没有新增量化误差阻断原设计。

## 固定压缩结果

[完整结果](../research/20261021/R9A1_native_affine_results.json)校验两个工作卡的协议/源码/资产一致性、HF矩阵与支持文件SHA、原生控制、全部来源/位置、主MAC和门槛算术。保持每项相同冻结UB1误差分母，不将不同步的比例当质量分数相加。

| 步 | 四来源候选/UB1原生gated SSE | 四来源合计SSE之比 | ≤.98UB1通过数 |
|---|---|---:|---:|
| 0 | .97467 / .98345 / .96158 / .95255 | .96842 | 3/4 |
| 1 | 1.13264 / 1.10836 / 1.21952 / 1.20650 | 1.16237 | 0/4 |
| 2 | .75771 / .68190 / .76819 / .79584 | .74984 | 4/4 |
| 3 | 1.07640 / 1.00730 / 1.24240 / 1.28735 | 1.15444 | 0/4 |

共7/16通过，未满足预定全部门槛，所以固定配方关闭，不运行全160拟合或候选视频。step2确有约25%的误差降低，step1/3却分别增加16.2%/15.4%；不能挑出有利位置与旧候选拼接后宣布通过。

两个专家的第二个去噪步均变差，值得纳入后续假设；但UB1分母和预算也随步改变，这没有隔离共享系数、选择规则或分布变化的因果作用。不会据此事后拆分系数、加组或恢复R256。已确定数值折叠与合成执行可行，尚未解决的是固定预算下的恢复精度。

该结果关闭原R2学习型表示的这一个OLS＋固定贪心实例，不是所有仿射分解的否定。与R7D1/D2、R8F2一起看，下一阶段优先审计真正原生窗口/学生轨迹恢复的操作数、梯度和两卡成本，而不继续局部超参搜索。原质量/速度验收和真正新来源评估要求不变。
