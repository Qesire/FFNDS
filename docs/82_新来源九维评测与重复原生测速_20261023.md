# 固定当前算法，检验新来源质量与真正系统速度

R16V0已经完成全部160处动态FFN的真实生成，并得到人工完整视频无明显崩坏结论。仍未解决的核心问题是：四个dense状态上的局部写回误差改善，并没有给该自由视频带来更好的整体像素轨迹保真；运动也明显不同。下一轮不修改算法、支持、R256、25%完整行比例、seed或checkpoint，而是直接检验新来源官方质量和正确预热后的系统速度。

## 数值控制与计时边界

5条预热视频的初始噪声和四步自由latent必须与已保存R16V0同臂逐位一致；25条正式测速重复必须与各自预热轨迹逐位一致。所有视频均检查完整160处FFN、原始1600逻辑linear/QDQ边界、零cache miss/weight transfer/placeholder fallback及同来源同噪声。新的输入分辨率以该来源先行dense的真实grid为准，其他臂必须相同；这只确定布局，不读取质量作策略选择。

系统时钟覆盖真正生成、解码与写视频，期间不执行独立局部FFN、不做CPU tensor哈希，观测器不逐块同步GPU。冻结动态算子的CUDA布尔索引`ids[keep]`仍可能内部同步；此开销照常计费，不声称整个算法没有同步。完整FFN的norm/AdaLN应用至原始gate/writeback用非阻塞CUDA events单独记录，共享modulation准备另记。四步GPU latent clone仍实际计费，CPU拷贝/哈希与路由图bitpack在计时后进行。保留实际全部重复、顺序、分位数、时钟/功率与显存，不再把R16包含164次局部检查的dense wall当加速分母。

## 预先固定的解释方式

报告九维每个官方子集上的原始同源差值、相对DQ变化、对两个固定行方案分别的差值，以及来源簇配对不确定度。相机/动态程度可能为0，分母为0时相对变化记为不可定义，不能制造Infinity或以加epsilon掩盖。帧数、seed重复和计时重复不增加独立来源数。任何“优于最佳固定”结论需包含对两个固定方案的比较，不能事后逐来源拼oracle。

[逐行源码审计](../research/20261023/R17_metric_aggregation_source_audit.json)确认：官方MUSIQ逐视频明细采用原始分数，总分再除100；主体/背景一致性先按实际帧对数加权，不必然等于逐视频均值。保留官方原始输出，同时另列等来源统计；下游分析须先复算官方聚合、核对单位和解码帧数。I2V主体/背景原公式为`0.4×max(条件图相似度)+0.3×mean(相邻帧相似度)+0.3×min(相邻帧相似度)`，不擅自改成最小条件图相似度。静止可能提高一致性，必须结合动态程度和相机指令查看。

配对统计代码预先固定为同一来源共同重采样、10,000次、seed20261023的百分位区间；相对变化采用等来源均值之比。任何重采样分母为零时，相对区间不报告，保留零分母次数。所有区间是逐项描述，不宣称已校正多重比较或自动质量通过。5个数学测试覆盖100倍单位差、帧对加权、配对身份、零分母和均值比/比值均值区别；这些是合成输入测试，并非新视频评分。

这一轮是冻结算法的验证，预设输出所有来源/指标及失败，既不按局部SSE决定要不要生成，也不依据某个有利聚合选算法。只有真实重复速度和新来源质量共同支持、且强固定/公开方法比较足够，才可进一步讨论实际Pareto/论文结论。历史50%/1.5×/2%数字仍只约束其原冻结试验；不以此追溯修改R4、D0或其他拒绝。

## 保留的机制问题

局部误差与全片排序不同至少有三种解释：自由状态分布偏移；路由几何变化引入时空误差变化；RGB轨迹不同而感知/指令质量并未变差。前两者与第三者应由新来源九维、自由视频和实际路由图区分。仅就数学而言，恒定误差序列e=(δ,δ)和交替误差e=(δ,−δ)有相同总SSE，但相邻误差差分别为0和2δ；较小的局部SSE不控制时序扰动。这个反例不证明当前路由造成了闪烁。新入口在计时后保存动态路由bitset，供后续低成本分析；本轮不据此训练或改变路由器。

执行中的旧source0预热路由图已做一次纯CPU复算：160处平均首个latent时间片的完整行比例为66.9674%，其余20片平均22.9016%，总量仍严格25%。首片消耗全部完整行预算的12.7557%，均匀分配时为4.7619%；128/160处首片超过25%，并非每处都偏向首片。四步首片均值依次51.4241%、58.2394%、82.9924%、75.2139%。见[实际掩码](../research/20261023/R17E0_oldsource_routing_geometry.json)和[条件输入/布局源码复核](../research/20261023/R17E0_time_allocation_readout.json)。I2V条件mask把首图标为已知、其余输入帧置零，pre-infer再按`t,h,w`展平；因此首时间片确有结构差异。21个latent时间片不能当作81个解码视频帧。

这个观察区分了“所有时间片都相同”与实际分配，但尚不能区分“条件图诱导的RR分数尺度偏置”与“首片确实有更高边际价值”。动态相邻时间片掩码翻转均值27.1809%，stride为0，当前LCG hash为18.5146%；这不是闪烁分数或因果运动损伤证据。没有新增模型forward，未改本轮算法、配额或参数，也不据此自动触发分时配额、分数归一化或新实验。

数值/身份/资源/隔离控制失败则保存已扣预算并停止该固定尝试，不自动重试、换图、调比例或扩大模型范围。新数据中的坏视频和长尾原样保留。145生成＋45评分范围之外没有自动后续授权。
