# NF1：遗漏非线性特征的残差读出小试

NF1检验一个独立于UB2结果的小问题：冻结UB1的剩余FFN输出误差，能否由少量被裁掉通道的实际非线性激活更好地修正。HP1/HP2测的是从已有线性残差特征预测C-score；NF1直接测原生门控输出误差，新增特征也确实需要在线计算。它是常规小型非线性辅助基的可行性检查，不能称输入动态路由或方法创新。

[协议](../reports/worker_20261020/NF1_registered_protocol.json)在提取新特征、拟合和任何NF1 CV之前固定，此时UB2主动视频仍在生成、尚无官方质量分数。为避免占用验收资源，程序等待UB2质量、主动等价、独立测速以及条件多类别确认流程全部结束后，才在GPU0执行。

仅使用已有OP1的24个C24学生输入，固定step2/3、block20、12/12奇偶来源两折。先复现48个原C24完整main+R输出，再证明拆分UB1残差所得256维隐藏量与HP1已保存特征逐位一致；step3的UB1三分之四宽度主输出按原生完整M重新计算，不能称在UB1自身轨迹上观测。

每折只按训练来源的平均归一化教师C，选出UB1主支持之外最高的4个原始64通道组，平局按groupID。新增256维特征执行实际完整M的原始有效W0/b0、tanh GELU、原Smooth2和HiF4激活QDQ；不会把缓存教师激活未经检查地视作新执行体输出。输出读出使用固定lambda1、训练专属逐维标准化的FP64 ridge，折叠后明确转BF16，在完整原始M几何上运行F.linear，并以原生BF16加到冻结UB1输出、再经原D gate评估SSE。

控制头读取原已有残差隐藏量h256，拟合同一个剩余误差，输出维度与新头相同。这个控制只额外需要一个输出GEMM，新非线性基需要两个GEMM以及GELU/QDQ，不声称两者在线成本相同。rank、lambda、组数和训练轮数均不扫描。

预先要求4项全部满足：新非线性修正后原生门控SSE≤冻结UB1的0.90，并且≤新线性读出控制的0.95。任一失败即停止该配方，不拟合全160、不生成候选视频、不测速。即使通过，也仍需另外验证完整实现、真实辅助成本和视频质量；不能使用局部SSE替代这些门槛。

NF1已在UB2完整质量拒绝、工程检查与新确认流程停止后完成全部4项原生CV。48个旧C24控制、全部48份HP1隐藏量逐位复现；原始完整M上的结果如下。


| step/折 | 新非线性SSE / 冻结UB1 | 新非线性SSE / 新线性控制 | ≤0.90且≤0.95 |
|---|---:|---:|---|
| 2 / 0 | 0.934893 | 0.977765 | 否 |
| 2 / 1 | 0.942587 | 0.980414 | 否 |
| 3 / 0 | 0.927154 | 0.970327 | 否 |
| 3 / 1 | 0.930439 | 0.969963 | 否 |

新非线性基在这些固定作用域确实减少了约5.7–7.3%的原生误差，且比新线性读出少约2.0–3.0%，但四项都未达到已登记的双门槛。因此停止该配方，没有拟合全量参数、运行新视频或测速，不将“小幅改善”升级为通过。
