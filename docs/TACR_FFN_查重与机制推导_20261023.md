# TACR-FFN：查重、机制推导与下一阶段取舍

**结论：值得列为下一阶段优先探索方向。建议把核心收敛为“补偿后通道净修复的条件轨迹价值”，优先验证其可预测性，再建设动态通道执行。** 原稿的问题选择很好，组合新颖性中等；修正下面的作用量与统计目标后，数学结构更简洁，也更有机会形成独立贡献。

“Fancy”的研究价值来自一个可解释的新现象：**一个通道的平均修复方向接近零，实际补算仍能稳定降低误差；决定价值的可能是补偿残差与轨迹偏差的条件相关结构。** 它能同时解释为何幅度排序失败、为何更准确的向量均值预测也可能失败，以及何时动态计算真正优于固定计算。

本轮使用 mechanism-research、research-expansion 和仓库 ffnds-paper-discovery，完成实际代码核查、原始论文对照、10项合成代数检查及1项历史数值复算。分析基于仓库提交 **27f86cd3f8821b2771f1be633baf32d4cc79ebb0**，检索截至2026-10-23。附件哈希与来源范围见[来源清单](../research/20261023/TACR_source_manifest.json)。以下“推导”是明确前提下的数学结果，“假设”是待检验的 Wan 机制。

## 3. 计算图核查：补算和补偿必须在同一个边界定义

已核查 [ub1_row_dispatch.py](../tools/ub1_row_dispatch.py)、[trained_packed_runtime.py](../tools/trained_packed_runtime.py)、[reduced_rank_residual.py](../tools/reduced_rank_residual.py)：

- FFN输入经过原生 Smooth1、BF16转换与 HiF4 Q1；R256在这个 **post-Q1、pre-W1** 输入上计算。
- 当前实现调用完整 predict_y，并未向 router 单独暴露 h256。复用 h256 需要拆开两次线性计算、保持原生转换顺序，并把临时张量与新增读出计入成本。
- 当前四步基础支持分别为 **54、108、108、162组**，每组64通道。平均108组对应50%主投影MAC，逐步预算并不相同。
- Q2后先乘 alpha 并转BF16，再执行含 folded b2 的 W2，随后加 R256。它与在实数域简单写成 alpha 乘整个输出有舍入差异。
- R256拟合的是整体残差；代码没有给出“第g组对应哪一部分R256”的分解。
- 完整64通道组的QDQ重排等价已有证据；新的GEMM宽度、求和顺序和跨区域拼接仍应按实际执行值记录。

### 推导一：必须给净动作定价

原稿定义：

\[
F_S=F_U+\sum_{g\in S}D_g-C(z,S).
\]

因此新增一组的实际增量是：

\[
\boxed{d_g(S)=D_g-\big[C(z,S\cup\{g\})-C(z,S)\big].}
\]

传播量应围绕 \(d_g(S)\) 定义。原稿的 \(PJG D_g\) 只包含补算，遗漏了同时执行的补偿变化。

反例：基线误差 \(e=1\)，补算 \(D_g=1\)，补偿增量为2。按原稿预计误差变0；实际净动作是−1，误差变2，平方损失由1变4。[CPU检查 net_action_sign](../research/20261023/TACR_cpu_deductions.json)

若 \(C\) 可加，净组作用可以预先固定；若 \(C\) 是任意集合函数，边际作用依赖已选集合，单一的 \(\hat v_g(z)\) 表示不完整。应先选择“可加补偿＋可检验的传播近似”，或直接评价小型完整动作库。

### 推导二：空集合恒等不足以定义“替换”

\(C(z,\varnothing)=0\) 只保证回到 UB1。它既不保证逐组分解唯一，也不保证全部补算时得到 Dense。

用暂时忽略浮点求和差异的分组表示：

\[
F_U=F_B^{U}+b_U+R(z),\qquad
F_D=F_B^{D}+b_D+\sum_{g\notin B}D_g.
\]

若要求全部补算时恢复Dense，就需要：

\[
C(z,B^c)=F_B^{U}-F_B^{D}+(b_U-b_D)+R(z).
\]

右侧包括基础通道缩放与偏置差异。把 R256 任意分给省略通道，无法自动满足这个条件。首版需要固定动作的完整数值定义，包括主分支系数、bias只加一次、补偿输出及写回顺序。

## 4. 最有价值的修正：从预测方向转为条件动作价值

设下游观测为 \(y=\phi(\text{续跑结果})\)，基线误差 \(e=y_D-y_U\)，动作产生有限响应 \(v=y_a-y_U\)。固定半正定 \(Q\)，损失下降恰好为：

\[
A(a)=\|e\|_Q^2-\|e-v\|_Q^2
=2e^\top Qv-v^\top Qv.
\]

这里 **v 可以直接由完整原生动作的有限响应定义**，该恒等式不要求网络可微，也不要求动作之间可加。对W1前实际可得状态 \(z\)，需要预测的是：

此处 \(z\) 指路由器实际读取的廉价压缩特征，如区域h256摘要与位置；条件期望在来源/状态分布上定义。剩余不确定性来自这些特征未保留的信息。如果给定完整且足以决定后续计算的状态，条件方差为零，公式退化为确定性动作价值。

\[
\boxed{A(a\mid z)=
\mathbb E[\,2e^\top Qv-v^\top Qv\mid z\,].}
\]

若进一步假设多个净动作在所选观测中可加，写 \(v=Vb\)，则：

\[
\boxed{
\mathcal R(b\mid z)
=\mathrm{const}-2a(z)^\top b+b^\top H(z)b,
\quad
a(z)=\mathbb E[V^\top Qe\mid z],\quad
H(z)=\mathbb E[V^\top QV\mid z].
}
\]

只用 \(\hat e=\mathbb E[e\mid z]\)、\(\hat V=\mathbb E[V\mid z]\) 代入原稿，会漏掉：

\[
a_g=\mu_g^\top Q\mu_e+
\operatorname{tr}\!\big(Q\,\operatorname{Cov}(e,v_g\mid z)\big),
\]

以及 \(H\) 中的条件协方差项。因此，“有符号均值预测得准”与“计算价值预测得准”是不同任务。

**最小反例：** 固定同一 \(z\)，令 \(e=v\) 等概率为+1或−1。两者条件均值都是0；均值模型预测收益0；实际补算把每个样本的误差都消掉，期望收益为1。再让两种 \(z\) 分别对应两个有效动作，可构造所有条件方向均值仍为0、最佳固定损失0.5、条件选择损失0的例子。本轮已执行这两个反例。

### 与补偿残差的联系

在一个理想化但清楚的模型中，组补偿是 \(\mu_g(z)=\mathbb E[D_g\mid z]\)，精算替换的对象为创新量：

\[
\xi_g=D_g-\mu_g(z),\qquad \mathbb E[\xi_g\mid z]=0.
\]

若下游传播算子 \(L(z)\) 在该条件下固定、可作线性近似，则
\(v_g=L(z)\xi_g\) 同样具有零条件均值；其二阶相关性仍可决定修复价值。**零均值不代表没有计算价值。**

这是本轮最值得保留的机制假设。当前R256是整体残差拟合，这个理想组分解尚未在代码中成立。研究可以先直接采集完整净动作的 \(A(a)\)，再判断是否有必要实现逐组创新模型。

### 一个更小、更优雅的首版

预定义有限个规整64通道集合及其完整补偿算子 \(a\in\mathcal A\)，每个预算档内给固定控制相同的补偿学习机会。离线记录有限响应；在线用已有低成本状态直接预测 \(\widehat A(a\mid z)\)，选择：

\[
\boxed{
a^*(z)=\arg\max_{a\in\mathcal A}
\{\widehat A(a\mid z)-\lambda\,c(a,z)\}.
}
\]

只有当跨动作组合确有额外价值时，再学习 \(a(z),H(z)\)。这样首版无需同时预测216个方向、一个轨迹残差、集合补偿和额外时空项。

对同一有限动作集，若实际净效用预测一致满足误差上界 \(\varepsilon\)，选中动作相对条件最优动作的损失至多 \(2\varepsilon\)：将最优动作与选中动作的两项预测误差相加即可。这是一个可解释的误差—决策连接；统一误差界需要由独立数据支持。排序相关性只能作辅助指标。

## 5. 组合、非线性和低维表示各自需要什么证据

### 5.1 二次形式很自然，“协同”已有先例

在可加前提下，原稿目标就是带成本的二元二次优化：

\[
\|e-Vb\|_Q^2=e^\top Qe-2b^\top V^\top Qe+b^\top V^\top QVb.
\]

两组交互收益为 \(-2v_g^\top Qv_h\)。原稿示例的空集、单组1、单组2、双组损失分别为1、5、10、0。它说明非负单项排序和单调贪心可能失效；不提供通用快速最优解。

仓库 [R4](53_R4补偿感知支持交换的原生筛选.md) 已经用补偿投影后的Gram穷举849个候选，包含单独不利但联合可能有利的双交换。[compensated_support.py](../tools/compensated_support.py) 的 residual 投影和 finite_swaps 直接实现了这一点。因此“双组有符号协同”不能作为重新启动旧搜索的理由。

### 5.2 原生有限响应比形式 Jacobian 更适合作第一份标签

HiF4量化和BF16舍入使实际映射具有离散边界。光滑替代或STE的Jacobian需要与真实有限动作对应。对两个动作测：

\[
\xi_{gh}=y_{gh}-y_g-y_h+y_0.
\]

若其引起的损失变化与预测收益同量级，可加Gram模型不足；此时完整动作库仍有明确语义。

[R7D1](57_固定双层恢复的原生传播诊断.md) 已有实际提醒：四个来源中三个局部/下游排序相反；方向项−11859.538与非线性项+11657.095近乎抵消，净交互只有基线的−0.1114%。这支持研究传播目标，同时说明仅凭方向内积推断大协同会误判。

### 5.3 低维表示应保留决策差异

低秩 \(P\) 总有核空间。若 \(P=[1,0]\)、\(e=(0,1)\)，修复 \(v_1=(0,1)\) 与 \(v_2=(0,-1)\) 的投影损失都为0，完整损失却分别为0和4。本轮已计算该反例。

因此选择r=8/16/32应依据**动作价值与排序保留**，而非只看解释方差。对固定动作库，直接预测标量价值是低维向量方案的强对照；只有低维结构进一步改善泛化、组合外推或成本时，增加它才有理由。

### 5.4 时间项应进入可识别的观测定义

若时间一致性就是轨迹损失的一部分，可定义：

\[
Q=Q_0+\gamma L_t^\top W L_t,\qquad Q_0,W\succeq0.
\]

\(L_t\) 是在参考对应关系上定义的时间差分/运动对齐算子。这样误差单位、权重和是否重复计数都明确。离线用参考视频构建标签时，应保留遮挡、边界及光照掩码；在线若估计对应关系，其输入与费用也要进入算子。

若采用非二次的官方视频指标，则直接用完整动作的实际损失差作为标签，前述二次展开只作为代理分析。

| R16V0：R256幅度驱动dense/UB1行分派 | 已跑通，局部改善与完整RGB参考一致性排序相反 | 通道级净动作、下游价值、条件风险；保留原行分派作为对照 |
| R17E0 | 官方质量流程中断，测速前缀已完成 | 使用已保存测速与后续完成的合法质量证据；不把中断判成算法失败 |

一个可用的判别公式将“有oracle空间”与“可在线利用”分开。对同一信息 \(z\)、同一动作集和损失：

\[
R_{\rm oracle}=\mathbb E[\min_a L_a]
\le R_z=\mathbb E[\min_a\mathbb E[L_a\mid z]]
\le R_{\rm fixed}=\min_a\mathbb E[L_a].
\]

第一段差距可能来自W1前不可知的信息；可部署动态性的目标是 \(R_{\rm fixed}-R_z\)。实际预测器还要支付估计误差与路由成本。

## 7. 成本推导：原稿的“追加”应与哪些基线比较

设位置i基础组数为 \(b_i\)，区域q包含 \(m_q\) 个token，追加 \(k_{iq}\) 组。只计两侧主GEMM：

\[
\rho_{\rm main}
=\frac{\sum_{i,q}m_q(b_i+k_{iq})}
       {\sum_{i,q}216m_q}.
\]

区域权重是实际token数。当前四步基础组数54/108/108/162给出平均0.5。若各位置平均额外27组，则主MAC为0.625；保留R256两投影另加 \(256/13824=0.0185185\)，合计0.6435185。路由、补偿新增读出、QDQ、搬运及分桶开销继续累加。

“追加组”比Dense省算，但比原UB1多算；其主要价值应由**同预算质量提升或同质量时间减少**表达。每个预算档都应包含经过同等训练选择的固定组方案，并与R16规整行分派比较实际耗时。

如果每token都存216个r=16的BF16向量，M=31668时仅该预测张量就约 **208.75 MiB/位置**；从h256投影至全部向量的MAC为Dense主投影的0.625%，但写读与选择成本仍可能明显。区域共享、小型动作库、流式计算可以缩小这一负担。

R17 Dense全160 FFN含共享调制的CUDA中位约9.915秒，占50.858秒wall的19.5%。**在串行、其余开销恒定、计时边界可相加的假设下**，无限快FFN对应约1.242×端到端上界。这是Amdahl条件估算，CUDA事件与wall的比值本身没有识别严格的因果时间分解。它提示首版预测器应服务于质量收益，并认真核算执行固定成本。

## 8. 下一阶段可行方向集与最小判别

| 方向 | 潜力判断 | 推进依据 |
|---|---|---|
| **A. 有限净动作的条件轨迹价值** | **第一优先，结构最简** | 一次把补偿、原生数值和下游响应装入完整动作；直接检验可用信息是否带来相对固定的收益 |
| **B. 传播后的补偿创新协方差** | **机制新意最强，作为A的解释与扩展** | 若均值/幅度不能解释价值而二阶相关可以，形成独立机制；再决定是否采用低秩Gram组合 |
| C. 轨迹敏感的固定保护组＋补偿 | 对照价值高；与项目动态目标的距离较大 | 若价值主要按step/layer固定，作为强静态基线，动态部分另找信息或动作 |
| D. 全216组影响预测＋任意集合补偿＋联合时空优化 | 当前性价比低 | 同时引入多个尚未识别的结构；拆出A/B能更快分清增益来源 |

下一份最小原生干预资产应包括以下内容，先固定一个具体算子及有限动作库：

1. **完整动作语义。** Identity精确回到UB1；固定少数追加组集合，包含宽度匹配静态控制；补偿的输入、系数、bias、舍入和代价均明确。不同动作获得相同训练机会。
2. **同前缀有限响应。** 固定前缀与后续执行策略，记录基线、单动作和少量联合动作的真实下游响应，分别保留Dense输入、UB1输入和候选自身输入的状态标签。完整策略改变之后需检查标签迁移；已存局部FFN样本不能单独还原新动作的完整下游响应。
3. **三种竞争解释。** 比较局部/幅度价值、位置固定传播风险、输入条件的净动作价值；另外比较均值向量与二阶/直接价值预测。这样可以分辨收益来自换目标、输入信息还是组合结构。
4. **来源隔离的决策评价。** 固定动作在训练/选择集确定；留出集报告最佳已选固定、实际条件策略、事后oracle、原UB1和Dense。报告实际损失差与选择regret，按来源聚合置信区间；同一视频的帧与token不当作独立样本。
5. **终端连接。** 首个可运行候选进入完整四步自由视频：配对感知保真、主体/运动事件、时间一致性与官方VBench-I2V分开报告，并测完整FFN/完整生成时间。沿用[学术指标族](77_FFNDS学术指标族与评测协议_20261023.md)与[实际使用指引](80_R15指标实际使用验收与Agent执行指引_20261023.md)，按具体问题选择指标。

结果解释有三种清楚的分支：动作本身优于等成本固定且条件预测有效，推进A；动作有用但只体现位置固定规律，强化C作为对照；组合效应依赖强非线性，使用完整动作库而不是不断扩大线性Gram搜索。若候选oracle在正确预算比较中仍被UB1支配，先更换动作/补偿构造。

## 9. 数学优雅与论文潜力的最终评价

- **问题价值：高。** R7、R11、R16共同给出了局部逼近与传播/完整输出不一致的真实研究入口。
- **原稿独创性：中等。** 多数模块、传播公式、协同二次项均有先例；PulseQuant和R4是实质性重合。
- **原稿数学完成度：需要三处修正。** 用净动作替代裸通道贡献；用条件风险替代均值向量的简单代入；把可加、低维与时序项分别绑定可检查的前提。
- **精简版本的优雅程度：较高。** 一个完整动作、一个条件价值、一个成本约束即可组织全方法；条件协方差解释了补偿与动态计算为何能协同。
- **成为下一阶段探索主线：推荐。** 主张集中在“补偿后净修复的条件轨迹价值”。成功的论文形态是一个新的可利用结构及其原生实现，而不是给已有模块再加若干正则项。

可复现入口：`python tools/check_tacr_deductions.py`。本轮产物为代数反例、代码/文献审查及历史数值复算；新Wan调用和训练步数均为0。研究状态与交接见 [research_state_TACR](../research/20261023/research_state_TACR.json) 和 [HANDOFF_TACR](../research/20261023/HANDOFF_TACR.md)。
