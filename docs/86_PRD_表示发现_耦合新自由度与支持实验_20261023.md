## PRD E：将 FFN 隐藏通道问题改写为净计算动作与可观测信息问题

固定相同 post-Q1 输入、原始权重与实数运算，Wan GELU FFN 可按 hidden 通道组求和
```
F(v)=b2+sum_g W2_g GELU(W1_g v + b1_g)
```
但实际 HiF4 Q2、BF16 归约、alpha、folded b2、R256 补偿会影响物理动作的等价性。即使真实输出增量可加，对平方损失的联合净收益仍有 `-2<d_g,d_h>` 交叉项。再次修改 Gram 目标不是新机制：R4 已研究了带补偿支持交换。真正改变问题的是：预测**完整补偿后的原生动作引发的下游视频轨迹变化**，而不是裸通道激活或单一局部误差。

第二个新信息自由度是 **norm 前 residual 尺度**。设 `u=r-mean(r)`, `sigma²=mean(u²)+eps`, 则 `LN(r+c1)=LN(r)`；当 `eps` 很小时，`LN(10r)` 近似 `LN(r)`，但 Jacobian 的主尺度约变化十倍。因此仅观察 post-Q1，可能无法充分预测后续 residual/norm 的传播敏感性。**这仍是 Wan 待验证假设**，不是实测改进，更不是全新 LayerNorm 理论。[Knittel–Pfister, 2026](https://arxiv.org/abs/2607.11990) 已讨论上游分解中的 norm denominator。本项目要检验的差别是前置信息对**真实补偿通道动作价值**的额外预测收益。

CPU deterministic 数学演示（无需模型）采用 `r=[2,-1,0,3]` 与固定扰动 `d=[.1,-.2,.05,.3]`，`LN` 使用 `eps=1e-6`：`||LN(r)-LN(10r)||≈3.96e-7`，而固定小扰动有限差分响应之比接近 `10.0`。该实验已作为 `tests/test_ffnds_prd.py` 的真实可运行 fixture，并且明确标注 synthetic only。

第三个等价表示已由现有源码确认：`R256(x)=linear(linear(x,first,bias_first),second,bias_second)`。**h256 在补偿输出计算中已经形成**，目前 `predict_y()` 仅返回第二次线性输出。新机制可尝试在保持补偿 BF16 数值不变的前提下，将 h256 同时作为路由统计输入；这不同于再建一份 Proxy，但读取、暂存、读出及分组都要计入成本。既有 HP1/HP2 C-score 预测失败针对其旧目标，并不等于新目标有效。

## PRD T：从论文提取可复用而非用于否决的机制

| 来源 | 借用的机制 | FFNDS必须区别的对象 |
| --- | --- | --- |
| [Sparse Inter-Layer Dependencies](https://arxiv.org/abs/2607.11990) | 上游归因与归一化分母 | 预测真实下游动作收益，而非只预测激活 |
| [PulseQuant](https://arxiv.org/abs/2609.33384) | 扰动跨Block与step传播敏感度 | 冻结视频蒸馏模型上实际通道补算而非离线量化修复 |
| [Prox](https://arxiv.org/abs/2607.27591) | cheap predictor 精确选择主通道计算 | 使用既有R256信息，审计两层GELU、真实QDQ与真实wall |
| [MiTA](https://arxiv.org/abs/2602.01219) | 共用探测信号服务压缩与路由 | 仅借鉴信号复用思想，不能声称实现 attention MiTA |
| [FIS-DiT](https://arxiv.org/abs/2605.11869) | latent 帧交错、结构化执行 | 与动态FFN whole64组、真实质量/延时同预算比较 |
| [TAPE](https://arxiv.org/abs/2605.17837) | 时间重要性平滑 | 固定位置/平滑mask/条件净收益三臂比较 |

严格的**完整机制重复**作为复现或强基线；仅共享思想、子算子、数学表示或目标，不应阻止探索。评价论文差异时按“可观测信号时间、物理动作、补偿、质量目标、实验设置”归因。

## PRD R：将“通道分数排序”变成轨迹风险约束下的有限动作决策

```
a*(Z) = argmax_{a in executable actions} E[downstream_loss(base)-downstream_loss(a)-lambda*cost_native(a) | preW1 Z]
```

这是对既有 TACR 思路的明确任务表示，**TACR 之前已经提出条件动作价值**；不以改写公式宣布独立创新。新增研究种子为 C1（pre-norm 状态影响真实动作价值）、C2（同一次R256同时用于补偿和路由）、C3（时间风险与物理whole64计算布局联合设计）。机器表示与近似/确切关系见 [representation ledger](../research/20261023/FFNDS_PRD_representation_ledger.json)。
