## 已实现的执行链

[真实运行入口](../tools/run_paired_mean_contrast_rollout.py)复用已经跑通的原生 D-Q 模型、常驻量化权重和原 LightX2V 管线。[候选 hook](../tools/rollout_mean_contrast.py)只替换指定位置的两个 linear 边界：原 Q1 后计算四位置均值和三个差分方向；均值用完整 W1，差分用固定 rank256 权重分解；恢复四个 preactivation，原生 GELU/HiF4 Q2 保持四位置；在 Q2 后平均，再做完整 W2，并加回各位置原冻结 A 差分。gate 和 residual 写回仍由原管线执行。

两份专家权重各做一次固定随机低秩分解，q256、niter2、固定 seed；恢复 RNG 状态，不训练、不搜索 rank。复用原有两份冻结 A。来源固定为已暴露 calibration24 的 source0、seed42。实际网格是 **21×29×52**，宽52整除4，全部7917个连续四位置组都不跨水平行边界。

预算是单卡、两次完整生成、两次权重分解、新输出≤256 MiB。失败预扣账保留；没有自动扩大来源、步骤或任务范围。记录两条视频、四步 latent SHA、初始噪声 SHA、8个实际候选边界、20次候选位置的实际 linear。两条视频之外不增加教师/空操作生成。

[解码与审阅工具](../tools/inspect_paired_rollout_videos.py)会解码全部81帧，生成左右并排视频和覆盖每一帧的审阅页。解码完整不自动等于视觉 PASS，仍需完整检查主体、运动、背景小物体和稳定光照。

## 已保存的数据检查

[CPU记录](../research/20261023/R15_mean_contrast_CPU_results.json)覆盖原4个暴露来源、256个完整邻域。组内差分占输入能量49.26%–53.66%；空间最大差分方向的中位能量占比39.82%–44.39%，不能预设邻域差分很小或只剩一个方向。开发128组中有16组连不受限实数共同响应的参考误差都高于各自 UB1；这只是光滑参考类，不能当作原生 BF16 或视频下界。

原量化器反例保留了两个事实：精确实数 preactivation 均值不保证相同 HiF4 后均值；相同目标通道激活在改变另一个通道时，HiF4 输出可从0.25变为0。这些用于避免实现时错误折叠量化路径，不作为继续实现的创新性门槛。

首轮 CPU 检查误将公开脱敏收据 SHA 与其绑定的原始收据 SHA 比较，读取保存操作数前退出；原代码、协议和失败摘要已保留，修复只区分两种收据。首个 GPU 启动在占用检查处被拒绝，没有运行 benchmark；随后保留旧双卡脚本，使用同样身份检查、逐卡锁和占用检查的新启动器，改用空闲物理卡2完成测量。没有终止或占用其他作业。
