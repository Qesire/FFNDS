# 条件信号与跨步方法的真实预算

本轮在固定 D0 执行期间继续查阅不同算子，而不是把两层预算转移当作唯一方向。下面是原文核对、数学反例和成本复算，**不是新模型实验、路线登记或新颖性结论**。实际执行的范围仍由 [D0 协议](../research/20261022/R12_D0_registered_protocol_worker_migration.json)限定。

## 实做一：均值相同，所需非线性方向相反

[标准库复算工具](../tools/analyze_r12_information_budget.py)和[实际结果](../research/20261022/R12_information_budget_discriminators.json)构造二维 FFN：W1=W2=I，零偏置、单位 gate，使用实际 FFN 同形式的 tanh-GELU，但采用 Python 实数标量计算。两块输入分别为

```
X_A = [[ 2, 0], [-2, 0]]
X_B = [[ 0, 2], [ 0,-2]]
```

两块均值都是零，非线性 hidden 能量却分别集中于第一个和第二个方向。仅依赖 tile 均值的确定性选择器无法区分二者；二阶矩能区分这个反例。这否定的是“均值普遍足够”的保证，**没有测得任何 Wan 均值路由器失败，也没有证明二阶矩能预测原生下游收益**。

它打开的信息问题是：在已有 pre-W1 投影上同时保留均值和对比能量，是否比只压缩均值更能区分同预算动作？对任意线性方向 w，有

`E[(x·w+b)²] = wᵀ E[xxᵀ] w + 2b E[x]·w + b²`。

因此均值丢掉的协方差不是装饰性统计。完整协方差显然昂贵；可以探索已有 R256 中间表示的分块二阶统计，但其基底原本用于补偿，未证明适合动作价值，统计聚合和内存读写也不免费。旧 HP1 的 h256 quadratic-C 和 PR3 donor-PCA 失败必须保留；新信号只有在**真实连续 tile、不同原生动作及真实目标**上产生可区分预测，才有实质区别。不能拿 OP2 独立抽样的256行冒充连续 tile。

## 实做二：两次密集冷启动没有给稀疏增量留下50%预算

这是对 [R6 冷启动结论](55_跨步FFN复用的冷启动与配对数据审计.md)的针对性复核，不宣称新发现。实际专家顺序 high/high/low/low；每个专家先做一次完整密集 cache，随后两次 sparse update 的 hidden 比例为 ρ1、ρ3，则相对完整四步主 MAC 为

`(2 + ρ1 + ρ3)/4`。

实际标准库复算：两次更新各为0、12.5%、25%、50%时，总主 MAC 分别为50%、56.25%、62.5%、75%。只要有正的主 GEMM 更新，就超过50%。这里未计选择、缓存和 QDQ，不能用更快 kernel 改写 MAC 算术。

这只限制“每专家一次完整密集初始化”的移植。部分锚点、共享表示或不同计算边界仍可探索，但缓存未计算方向需要自身机制；不能直接沿用 Chipmunk 的完整 cache 身份。旧 R20 已测试同专家输出复用/仿射，重新命名也不会产生新结果。

## 实做三：代理成本属于整个 FFN

若两层 GELU FFN 的准确主路径保留比例ρ，额外一层 W1 代理保留输入比例k，按相同单位 MAC 计数，有

`C_all_projection / C_dense_FFN = ρ + k/2`。

ρ=50%时，k=10%/30%分别对应55%/65%的全部投影 MAC；这不改变主路径自身50%的计数，但必须进入选择器和完整 FFN 的真实成本。更低比特、kernel 融合和已有投影复用可能减少耗时，必须实际测量，不能把 Prox 的成本系数当成本机常数。这里也未计 QDQ、排序/阈值、权重存储和重排。

## 后续可证伪的问题

当前最有区分力的三个方向分别改变信息、动作范围或表示，而非只增大旧搜索：已有 pre-W1 表示中是否存在被均值消去的条件信息；完整64组约束下的真实空间动作能否避免跨层扣预算的代价；部分冷启动表示能否在没有完整缓存的情况下保留有效跨步信息。每个问题都可能给出否定结果，且均未登记模型执行。

最便宜的现成检查已经完成：[HiF4组边界](69_HiF4分组边界与空间动作的可执行布局.md)、实际21帧布局算术，以及本页的信息反例/成本复算。原生 tile 的同坐标操作数、动作值、可预测性与完整速度仍缺，不能用历史输出拼接补上。固定 D0 的结果与处置见 [当前交接](../research/20261022/HANDOFF_R12_D0.md)。
