# 连续小块的支持迁移诊断 TC1

TC1在统计前固定64个连续原生token为一块，复用已验证的24来源、每来源256个均匀采样位置，以及step2/3 block20的贡献谱。每折12来源拟合静态支持、另12来源统计。将一个位置的教师最优支持迁移到同块的另一个位置，与同帧不同块迁移和匹配静态支持比较。原生展平次序为T/H/W，尾块和跨帧块均保留。

主统计使用已知有限总体有序位置对数量及精确二阶包含概率的Horvitz–Thompson均值，随后对来源等权平均。没有用观察到的位置对数替代总体分母，也没有排除零邻居来源。三个单元测试核对总体计数、固定且不依赖抽样的模拟总体上、包含零邻居样本的穷举无偏性及非法输入；全部79项CPU测试通过，CUDA未初始化。

| 步/折 | 同块相对静态增益（百分点） | 同块减同帧远处（百分点） | 同块有序采样对 |
|---|---:|---:|---:|
| 2/0 | -1.1865 | +0.4919 | 1580 |
| 2/1 | -1.4272 | +0.3019 | 1544 |
| 3/0 | -0.8513 | +0.1631 | 1672 |
| 3/1 | -0.8492 | +0.3194 | 1602 |

预设四项均需同块相对静态至少+2个百分点、相对同帧远处至少+1个百分点，且至少500个采样对。四项全部拒绝，因此不由此自动启动完整小块GPU采集或开发新算子。单位置的教师支持迁移不够好，不能推出整块平均后的教师最优支持也无效；此处没有测量整块oracle、原生FFN误差或视频质量。24来源均已参与开发。

## 采样暴露边界的补充核验

后续[完整坐标审计](../reports/worker_20261020/calibration_row_coordinate_exposure_audit.json)核实：原稠密校准和OP1学生采集的24来源×160位置，共3840位置的grid、256个选中坐标、采样seed和包含概率全部相同。C24学生又由该原校准行拟合，因此其学习后状态总体不一定独立于同一抽样。

单元测试的穷举证明仍适用于固定、独立于抽样的模拟总体；它不能证明实际TC1学习后总体上的设计无偏性。以上数值应视为已暴露校准状态上的设计加权描述量，不能据此作独立空间总体推断。原始协议、数值、描述性来源bootstrap及拒绝决定均不改写。新OP2配对数据也有意沿用相同坐标，服务于原生配对控制，不因此获得整条管线或空间总体的独立性。
