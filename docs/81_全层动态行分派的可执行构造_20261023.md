# 全160处动态行分派已完成真实生成与人工初筛

**本轮实际推进：**用户单独授权后，5条完整四步视频和164次原生FFN执行全部完成。动态方案及三个压缩对照覆盖全部160处FFN；实际在W1前分派7917行完整计算、23751行原UB1计算。5条视频均832×464、81帧、16fps，无dense状态重置；原UB1独立公式四项逐位控制及原dense四步轨迹控制全部通过。用户完整播放配对视频后明确回答“已完整观看，没有明显崩坏”，这一固定版本达到 **ROLLOUT_PASSED_SMOKE**。

## 结果如何理解

原dense自身四步第20层输入上，动态相对该位置两个固定行方案中更好的那个，原生写回SSE依次减少 **3.236%、8.243%、11.365%、11.103%**；四位置合并相对最佳单一固定方案减少 **6.128%**。同四位置、每臂两次预热后五次轮换原生FFN计时，dense/动态的“中位数之和”比为 **1.26273×**。它包括norm/AdaLN应用、原生QDQ、权重提取、分派、R256、GELU、gate/writeback；共享modulation准备另记。这是四个真实FFN输入上的局部硬件实测，不是全部160处或端到端反复测速。

**局部优势没有保持相同的自由轨迹排序。** 动态视频相对dense的整体RGB MSE为1122.5782，最佳像素固定方案stride为1037.2561，即动态高8.226%。这是解码轨迹保真差异，包含合理运动分歧，不等于感知质量损失8.226%。逐帧PSNR均值却给动态18.47596dB、stride18.45259dB，和先合并MSE再取log的排序相反，必须同时保留。不能挑一种聚合宣称获胜。

全81帧对照显示熊与场景持续完整，但约1.5–5秒dense的左转更明显，动态/hash更正面，UB1也更静止。用户判定没有不可接受的明显崩坏；这一结论没有证明运动保持。后续应固定当前算法，在全新独立来源上测官方运动/质量，而非在这只熊上微调分数或预算。原生routing的160份行集合SHA均不同，固定stride/hash各仅一份；实际输入条件分派已发生，但其总体收益仍待检验。

5条生成各自仅一次固定顺序观测，core FFN累计GPU事件约为dense9815.69ms、UB16463.30ms、stride7835.21ms、hash7821.46ms、动态7891.24ms。它们是带同步区域分析的观测。**dense的整段wall还包含164次独立FFN检查/预热/计时；所有整段wall值都不能拿来做系统加速比。** 未来需独立计时区间、预热和轮换重复的原生160处及全生成计时。

## 原始构造与执行前推导

R15V0只在第20层四个去噪步替换FFN，证明了真实生成链可以接入候选；它没有实现全模型动态省算。现有R9A仿射矩阵只覆盖第20层，不能把它直接复制到其他层。新构造复用已经存在、完成原生核对的全160处UB1参数，以真实行压缩实现完整FFN与UB1之间的输入条件分派。它是待测工程候选，不是已证实的质量或速度改善。

## 实际计算

原始LightX2V继续执行残差相加、norm、AdaLN、GELU、gate与残差写回。对实际post-Q1输入`X∈BF16[M,5120]`，先运行原有两层R256补偿器`R(X)`，用原始gate计算每行`score_i=Σ_d(g_d R(X)_id)^2`。在W1之前取最高`floor(M/4)`行执行完整FFN，其余行执行当前步原有UB1支持及原有增益、折叠偏置和R256补偿。固定对照采用同数量的stride与预先冻结hash行。

这不是先计算完整FFN再拼输出。W1分别实际执行`[23751,5120,H_s]`和`[7917,5120,13824]`；W2分别执行`[23751,H_s,5120]`和`[7917,13824,5120]`。`H_s`随原有UB1步预算为3456、6912、6912、10368。两支W1结果压成一个一维连续缓冲，原始GELU逐元素处理；W2入口拆回两种宽度，分别执行原生Smooth2/QDQ后线性，恢复原始行序，交回原始gate/writeback。

完整原始DQ权重保持驻留。只在当前FFN边界从驻留原权重提取UB1支持，避免额外常驻一套约同尺寸的全位置打包权重。提取、选择、scatter和R256均计入实测。离线核对发现原有全160处R256参数共840581120字节，不需要重新训练或为80个专家/层生成新的仿射矩阵。

按真实行数，四步平均主GEMM比例为`1/4+3/4×1/2=0.625`。全行R256额外比例为`256/13824≈0.0185185`，两者合计约0.6435185；这不是时延预测。动态与两个固定行对照的矩阵几何完全相同，但动态选择会多花归约/排序时间。UB1本身更省计算，必须独立保留作质量—速度参考。

## 假设与反例

补偿幅度大可能对应遗漏响应重要，因此值得分配完整计算；也可能补偿器已经把这部分预测得很好，幅度大却没有大的剩余误差。设两行真实遗漏响应与预测分别为`(10,10)`和`(1,0)`，第一行幅度选择分数更高，而其补偿误差为0，第二行误差为1。故该信号不是误差上界或oracle。真正待测的是：在完整自由轨迹和实际原生边界上，这个便宜信号能否优于相同主MAC的固定行方案。

比较过的其他可行构造包括：为所有层重建均值/差分算子的A矩阵和W1低秩因子；在已有UB1上跨层分配整块完整计算；当前选择的行压缩方案。第一种仍缺少其他层有效补偿证据并增加资产准备，第二种动作较粗且静态层敏感度可能解释优势。行压缩方案直接使用已有全层参数，能用一轮完整生成检验输入条件动作，不需要把旧局部负结果改判。

最近的旧负结果是R14N0：固定随机双点非线性响应、原范数排序、同数量双点，而非完整FFN/原UB1两支逐行压缩。R12 D0改变两个位置的通道预算，也没有执行这种行分派。这些旧试验的有限拒绝完整保留。R15V0的空间均值/差分机制仍是另一个开放种子，本轮并未宣布其整体失败。新构造可能属于已有动态精度/计算分派的大类；先完成实际实现和对照，不预设原创性。
