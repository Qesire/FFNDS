# 摆脱补算预设：条件稀疏的目标与算子重构

**下一阶段的研究设计不把 dense 补算或 R256 补偿设为前提。** 主问题恢复为：在实际可执行的预算内，哪些输入相关的 FFN 运算可以省掉，以及剩余算子应如何构造。优先研究无 dense 补算的条件算子；完整残差动作价值是各候选共用的评价与学习目标。dense/UB1 行选择、共享前缀补齐属于可比较的附加选项。

本轮应用已安装的 `research-expansion`、`mechanism-research`、`problem-reformulation`，对照仓库 `0033725882c4db2e9fbd6f9ee0c85e20950fbe62`。成果包括原始收据重分析、源码目标审查、文献比对和可执行 CPU 构造。结果见 [CPU证据](../research/20261024/potential_directions_CPU.json)，下一步的明确假设见 [探索记录](../research/20261024/potential_directions_exploration.json)。本轮新增模型调用、原生视频和 C1 特征拟合均为0。

## 1. 补算预设从哪里来

已有 C1 数据方便研究 dense 与 UB1 的差异；R16 已有两个执行分支，R256 又能提供 h256。因此“复用这些资产预测哪些行补 dense”具有工程便利。便利性影响了候选排序，却没有给出补算的必要性证明。

应分别辨认三种动作：

| 动作 | 计算语义 | 是否为本项目的必要条件 |
|---|---|---|
| dense 补算 | 部分行执行全部原 FFN 通道 | 否，作为有成本的候选动作 |
| R256 加性补偿 | 小秩分支向稀疏输出加回一个向量 | 否，单独核算收益与代价 |
| 修改保留算子 | 离线更改保留权重、偏置或合并表示，部署直接计算较小算子 | 可独立探索，需核验原生精度和动态性 |

历史 R12 的 N0 同时移除了 alpha、折叠偏置和 R256，完整 step flow SSE 比 UB1 增加3.1331%。它识别的是这个**校准组合**的移除效应。由此不能单独识别 R256 的必要性，也不能推出 dense 补算必要。原记录已明确这一混杂：[R12实际结果](68_R12_D0等预算原生动作检验.md)。该固定三动作实验保持关闭。

## 2. 一个不补算也不补偿的精确反例

在实数加性组模型中，设 FFN 的四个组输出在两类输入上分别为

\[
f(x_A)=(10,-10,1,1),\qquad f(x_B)=(1,1,10,-10).
\]

完整输出均为2。每次仅执行两个组：输入A保留后两个组，输入B保留前两个组，即可精确复现完整输出。主计算为一半，没有 dense 例外行，没有加性补偿分支。固定同一组对的最佳平均平方误差为2；按单组绝对值选取的误差在两输入上均为4。

这个构造证明“动态稀疏必需补算”不成立。它同时提出真正需要验证的问题：Wan 是否存在稳定的条件协同结构，以及这种结构能否在 W1 前由便宜信号预测。反例使用的完整组输出只用于离线证明。

另一个构造为组输出 `(10,-10,1,0)`，基准保留前两个组。当前误差为1，每个单组交换都变差，而同时替换两个组后误差为0。因此，小邻域的失败不能证明全部联合删组无效。这个数学事实用于界定已有结论的适用范围；C1 的原两种交换及其路由扩展仍保持关闭。

## 3. 无补算方向：条件协同删组

将原生可分解范围内的组贡献写为向量 \(v_g(x)\)。在固定输入、原生 QDQ 分组兼容、暂取线性观测 \(P\) 时，保留集合 \(S\) 的目标为

\[
L(S\mid x)=\left\|P\sum_{g\notin S}v_g(x)\right\|^2
=\sum_{g,h\notin S}v_g(x)^\top P^\top P v_h(x).
\]

独立幅值排序只使用对角项。它无法表达两个大向量相互抵消，也无法表达单组交换越改越坏、联合替换却改善的结构。**新探索的对象是输入相关的组间有符号关系与直接稀疏算子，dense 恢复率固定为0。**

可构造的实现是：便宜 pre-W1 特征预测每组低维有符号响应，按相同64通道组预算作联合选择，随后只执行选中通道。只学习选择器，不加输出恢复分支。若借用现有 R256 的第一投影作为特征，应单独计入该投影成本；没有执行第二投影就不称作 R256 输出补偿。

这是一个有明确判别实验的机制种子。先核查组输出的可加性、Q2布局及已有载荷是否包含所需的有符号向量；标量 SSE 或 C-score 不能恢复交叉项。随后在新的固定动作构造上比较联合目标、独立幅值及最佳固定支持；对状态/来源打乱关系的控制用于检验收益是否真正依赖输入。完整 block/step 的有限响应负责验证线性观测近似。

已有文献 [Correlation-Aware Structured Pruning](https://arxiv.org/abs/2609.22131) 已将通道相关性写成带基数约束的二次规划，并使用依赖感知贪心法。二次目标本身应作为已有基线。潜在贡献在于冻结量化视频模型中的**在线条件关系、预算内选择与完整轨迹效应**；当前尚无 Wan 数据支持这三者同时成立。

与旧路线的区别必须由操作数和对照体现：HP1/HP2 学习的是旧 C-score；R4/C1 是已冻结的支持邻域；本种子研究有符号组响应、联合动作与直接算子。若最终实现仍只是换名重跑旧评分/交换，就归入原关闭实例。

## 4. 另一种无补算表示：在保留算子中合并非线性冗余

若两神经元的仿射输入完全相同，任意逐点激活均满足

\[
w_a\phi(u)+w_b\phi(u)=(w_a+w_b)\phi(u).
\]

可直接合并 W2 列并省掉一个 W1/GELU 通道。对于近似相同输入、同向输出权重，取正权重 \(a,b\)、\(\bar u=(au+bv)/(a+b)\)，若相关区间 \(|\phi''|\le M\)，Taylor 余项给出

\[
|a\phi(u)+b\phi(v)-(a+b)\phi(\bar u)|
\le \frac{M}{2}\frac{ab}{a+b}(u-v)^2.
\]

这给出了可筛查的条件：输入接近、输出方向可合并、曲率余项小。一般 GELU 不具备 ReLU 的正齐次性，任意旋转或缩放不能直接穿过激活；native HiF4/BF16 也要重新核验。合并后是较小的直接 FFN，无运行时误差恢复项。

[Neuron Merging](https://papers.nips.cc/paper_files/paper/2020/hash/0678ca2eae02d542cc931e81b74de122-Abstract.html) 已研究权重分解与合并，并给出 ReLU 条件下的折叠。这里先把它作为结构对照：检查 Wan 是否存在满足条件的成组冗余。固定合并本身属于静态压缩；只有进一步证明输入条件下可执行的不同支持具有增量价值，才进入动态方法。旧 R8/R9 的仿射余项及其量化失败不能通过“合并”名称重开。

## 5. 共用的学习目标：预测动作的收益

现有保存读出的源码使用

`target = log(y) - geometric[group]`

并以预测值排名；评价量是所选行的 \(\sum y\)。在平方回归的理想极限下，前者学习 \(E[\log Y\mid z]\)，而固定数量、等成本、可加损失的最优选择依据 \(E[Y\mid z]\)。逐点 `log` 单调不能消除条件期望造成的差别。

具体反例：A的误差以相等概率取0.1或10，B恒为2。A的算术均值为5.05、几何均值为1；B两者均为2。对数目标选择B，算术目标选择A。该反例已执行。

对自由轨迹或后续完整 block 的动作，目标进一步变为有符号净收益。记基准相对固定参考的误差为 \(e\)，动作产生的有限变化方向为 \(\delta=T(\text{base})-T(\text{action})\)，则

\[
A=\|e\|^2-\|e-\delta\|^2=2\langle e,\delta\rangle-\|\delta\|^2.
\]

当 \(e=1,\delta=3\) 时，动作能量为9，真实收益为−3。这个目标适用于删组、合并、补偿开关、dense补算等所有动作。多个行/组经 attention 后相互作用，联合掩码收益须以完整动作测量，不能将单行收益直接相加。

这与旧 R11 的 R256 参数目标拟合有明确区别：这里学习动作选择器，保持候选算子定义可审计。数学目标的正确性不会自动赋予新的 native 收益。

## 6. 已有读出证据值得保留，但作用范围要准确

同一72处、每处336采样行取84行，已保存的来源分离拟合结果为：

| 选择规则 | 捕获采样下一norm误差 |
|---|---:|
| 训练来源的固定分层算术风险 | 27.1868% |
| 原能量 CPU 参考 | 27.8340% |
| C2 尺度能量 CPU 参考 | 28.8126% |
| 523维当前特征读出 | 34.0071% |
| 当前特征加8维前置信息 | 34.5015% |
| 采样标签 oracle | 36.7028% |

当前特征读出比 C2 高5.1945个百分点；六来源全部为正，来源等权平均增量5.2489个百分点。额外8维特征只贡献0.4944个百分点，因此主要已有证据支持“使用更充分的当前特征学习目标”，而非“新的归一化变量已解释大部分收益”。这些数字支持特征的局部预测能力，没有测试无补算动作或自由视频。

h256 部分由 \(h,h^2,\sum h^2\) 构成。标准化线性头可折叠为 \(a^\top h+b^\top h^2+c\)，全局平方和并入对角系数；合成代数误差小于1e−10。V1统计、前置特征、排序与调度仍计费。523维大矩阵不是在线部署的必需形式。

最新全行原生边界审计选7,917/31,668行，残差写回与下一norm排序平均重合78.2976%。这是与上表**不同选择总体**的证据；不得混用两种 oracle。早步目标错位更大，C2负位置却集中在晚步，尚不能建立同一个因果解释。[完整审计](90_原生残差写回与下一归一化的目标错位审计_20261024.md)

## 7. 共享前缀补齐：保留为可选对照

可先对所有行执行基础通道的 W1/GELU，以实际基础激活决定哪些行计算剩余 W1，随后分别执行稀疏或完整 W2。分叉位置必须在 W2 前；dense 行按原顺序组装全部 hidden，再执行原完整 Q2/W2，使用 dense bias，撤去稀疏 alpha/折叠偏置/R256 语义。

若基础宽度比例为 \(b\)，补齐行比例为 \(q\)，两投影 MAC 相对 dense 为

\[
\underbrace{b/2}_{基础W1}+\underbrace{q(1-b)/2}_{剩余W1}+
\underbrace{((1-q)b+q)/2}_{两支W2}=b+q(1-b).
\]

平均 \(b=.5,q=.25\) 时为0.625，与原 R16 主投影相同。先完成 UB1 输出再重算提升行的基础 W2 则为0.6875。R256 若只在未提升行执行，其两投影 MAC 为 \((1-q)256/13824\)；使用 h256 做选择时第一投影仍需覆盖全部行。QDQ、选择器、GELU、打包、同步和 kernel 分裂另行计入真实时间。

CPU 构造检查了两端点和混合行，包含玩具 BF16 舍入、宽度相关 QDQ、alpha、两类 bias、补偿和残差，输出一致。真实 native GEMM 换形状后的舍入需要独立验证。

[Channel Gating Neural Networks](https://proceedings.neurips.cc/paper/2019/file/68b1fbe7f16e4ae3024973f12f3cb313-Paper.pdf) 已采用基础通道与条件通道。因此共享前缀不是独立原创点。它还改变了当前 `OBJECTIVE_CONTRACT` 中“所有信号在主W1前”的时序条件，只能作为显式的替代计算图假设；原合同保持不变。

## 8. 恢复研究后可采用的判别顺序

发布时最新主线为 `88d123a62ecdfca5f64e98270c3c1d27dc213c01`，已记录用户暂停所有实验。本节保留为后续设计；当前仅归档已完成的分析。

1. **无补算结构研究优先推进。** 审查已有载荷能否支持有符号组响应；先验证条件协同删组或非线性合并的结构前提，再构造新的可执行支持。缺少向量时明确捕获所需操作数，避免拿标量风险代替方向关系。
2. **已有数据完成学习目标对照。** 固定原两折 `[0,8,16]` / `[2,10,20]`、相同523特征、训练折标准化及 ridge=1，比较 log-risk 与 arithmetic-risk；分别使用 post 和 nextnorm 目标，不搜索超参。全部属于已暴露来源上的机制诊断。共享动作价值头最终学习 signed advantage。
3. **可执行候选进入完整动作验证。** 使用真实联合行/空间块掩码，观察残差写回、完整下一block、当前step输出及学生自由轨迹；与同预算最佳固定策略比较。无补算直接算子和补偿/补算对照都计算完整执行成本。独立完整视频、官方质量和重复测速延续现有指标族。

C1 原取样已是各21时间层内16行无放回随机抽样，且同位置跨来源复用抽样索引。需要修订的是模型选样与部署总体的对应、重复空间抽样、几何tile及来源独立性，而非把原设计误述为没有概率抽样。每层同为1,508行，原设计等概率；后续不等概率抽样使用设计权重。完整31,668行上的选择能力需单独验证。六个来源才是独立来源单位；相邻帧、行、层、种子和技术重复不能伪增样本量。新来源分主体/背景/相机并按源图/场景去重；位置覆盖四步和轮换深度，已有12位置读出不能直接外推全部160位置。

截至基准提交，C2N0因GPU冲突、C2N1因导入路径错误而在数值前向前停止，均0视频；C2N2随后获独立授权启动，也因GPU隔离失败在前向前结束，0视频。用户已暂停全部CPU/GPU实验，见[暂停记录](../research/20261024/EXPERIMENT_PAUSE.json)。这些状态保留为工程记录。恢复后的科学研究无需以 C2 重试为前提；R16/R17活动方案、C1原两交换及其他冻结失败实例继续按原范围关闭。

## 9. 查重后的潜力判断

| 路线 | 当前支撑 | 研究定位 |
|---|---|---|
| 条件协同删组，无补算/无恢复支路 | 严格反例、已有相关性剪枝原理；Wan交叉项未测 | 优先检验新结构，原创性取决于条件预测和部署 |
| 保留算子的非线性合并 | 明确等价/误差条件、Neuron Merging前例；Wan结构未测 | 表示探索，静态对照先行 |
| 完整动作的条件收益读出 | 已有特征预测能力；目标错位有源码与反例支持 | 各路线共用方法模块，最接近现有数据 |
| 共享前缀补齐 | 计算图和MAC恒等式通过CPU检查；Channel Gating前例 | 可选有成本对照，替代时序合同 |
| 继续微调C2尺度、R16的q或原C1交换 | 原证据已经限定范围 | 不列入新探索 |

[Prox](https://arxiv.org/abs/2607.27591)提供低成本代理后直接执行稀疏投影的对照思路，但其三投影 SwiGLU 与本项目两投影 GELU 要分别核算。[FastForward](https://arxiv.org/abs/2602.00397)已有块预测、误差补偿和层间调度；[Spark Transformer](https://arxiv.org/abs/2506.06644)通过架构和训练产生可预测稀疏。这些工作分别代表代理、恢复与表示重构，支持开放比较多种路线。新方法的价值由可预测结构和质量—真实速度结果决定，补算或新命名均不构成价值来源。
