# FFNDS 学术指标族与评测协议

本次目标是建立覆盖 Wan 蒸馏动态 FFN 的完整指标族。评价结果组织为 **视频质量、条件保持、时序运动、分布与多样性、感知保真、人类偏好、系统成本** 的向量；局部数值和动作收益用于解释这一向量。正文给出学术依据、指标定义、适用条件和 FFNDS 的执行组合。

审查基线：`aebd37f749b484f0caaf6224c0a1e507e327cf3f`。使用安装的 `mechanism-research`、`research-expansion` 及仓库 `ffnds-paper-discovery` skill，核对论文、官方实现和既有结果。机器可读条目见 [学术指标族目录](../research/metric_system/academic_metric_families.json)，逐项表见 [CSV](../research/metric_system/academic_metric_families.csv)。[L0–L5](76_基于学术文献的FFNDS分层指标体系_20261022.md) 表示项目证据粒度；本文件的十类表示测量对象，两者交叉使用。

## 1. 十个指标族

| 指标族 | 学术界采用的代表 | 测量对象、参考与方向 | FFNDS 用途 |
|---|---|---|---|
| F1 配对重建与感知保真 | MSE、PSNR、SSIM、MS-SSIM、LPIPS | 对齐帧相对参考的保真；MSE/LPIPS↓，其余↑ | 同源同噪声 D-Q 与候选视频的偏移 |
| F2 空间感知质量 | VBench aesthetic/imaging quality、MUSIQ、DOVER aesthetic/technical | 单帧或整视频的无参考质量；通常↑，保留模型尺度 | 清晰度、纹理、结构、美学 |
| F3 条件遵循 | VBench-I2V subject/background/camera motion；CLIPScore；VBench 语义维度 | 输入图像或文本与输出之间的对应 | 主体、背景保持与指令执行 |
| F4 时序一致与运动 | VBench subject/background consistency、motion smoothness、dynamic degree、temporal flickering；warping error | 视频内部的跨帧关系；稳定性、运动量分别解释 | 闪烁、冻结、运动突变、小物体不稳定 |
| F5 生成分布与多样性 | FVD、JEDi、FVMD、frame-FID/KID、precision/recall、density/coverage | 生成样本集合与参考集合；距离↓，质量/覆盖双轴 | 分布偏移、运动分布、模式覆盖 |
| F6 复杂语义与真实性 | VBench-2.0 五大类、十八维 | 物理、常识、人类表现、复杂控制和创意 | 复杂动作与关系子集的扩展验证 |
| F7 人类与学习型评价 | MOS/成对偏好；VideoScore、VideoScore2 | 人类判定或学习型评估器的多维评分 | 感知有效性、自动分数与人类判断的一致性 |
| F8 数值与机制 | 相对 L2、MSE/NMSE、cosine、误差分布；项目动作价值分解 | 算子、token/stripe、flow/latent | 解释何处产生偏差、计算分配是否有价值 |
| F9 效率与资源 | latency、throughput、speedup、MAC/FLOPs、显存、训练成本 | 固定部署与计时边界下的资源 | 真实 FFN 与完整视频加速、质量—成本曲线 |
| F10 统计可靠性 | 配对差、置信区间、效应量、分层统计、尾部/失败率 | 来源与随机种子层面的不确定性 | 可复核的比较和结论精度 |

F1–F7 有明确的视觉/生成评价文献来源。F8 使用通用数值统计，并增加 FFNDS 的机制诊断。F9 是计算系统测量，F10 是统计报告方法。此处的十类划分是 FFNDS 的组织方式。

## 2. 正式核心：VBench-I2V 九维

官方 I2V 扩展提供三个条件维度和六个质量维度。[VBench++ 论文](https://arxiv.org/abs/2411.13503)、[固定版本 I2V 实现说明](https://github.com/Vchitect/VBench/blob/fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490/vbench2_beta_i2v/README.md)。

| 官方名称 | FFNDS registry ID | 所回答的问题 | 解释方式 |
|---|---|---|---|
| `i2v_subject` | `vbench_i2v_subject` | 输出是否保持输入图像主体 | ↑；条件图像—输出对应 |
| `i2v_background` | `vbench_i2v_background` | 输出是否保持输入背景 | ↑；条件图像—输出对应 |
| `camera_motion` | `vbench_camera_motion` | 相机运动是否遵从指定指令 | ↑；使用相机指令子集 |
| `subject_consistency` | `vbench_i2v_subject_consistency` | 主体在视频内部是否持续一致 | ↑；跨帧身份稳定 |
| `background_consistency` | `vbench_i2v_background_consistency` | 背景在视频内部是否连贯 | ↑；跨帧场景稳定 |
| `motion_smoothness` | `vbench_i2v_motion_smoothness` | 帧间运动过渡是否平滑 | ↑；与运动量共同读 |
| `dynamic_degree` | `vbench_i2v_dynamic_degree` | 视频被判为具有显著运动的比例 | 报原值和相对 D-Q 的变化，按运动指令分层 |
| `aesthetic_quality` | `vbench_i2v_aesthetic_quality` | 画面的美学质量 | ↑；独立保留 |
| `imaging_quality` | `vbench_i2v_imaging_quality` | 成像、失真和细节质量 | ↑；独立保留 |

主体/背景“条件保持”与“视频内一致性”各自回答不同问题。固定版本分别使用 DINO、DreamSim 等特征；`imaging_quality` 使用 MUSIQ。按官方代码运行并保存其帧级到视频级聚合，避免在外层将所有帧重新混为一个总体。[I2V 主体](https://github.com/Vchitect/VBench/blob/fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490/vbench2_beta_i2v/i2v_subject.py)、[I2V 背景](https://github.com/Vchitect/VBench/blob/fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490/vbench2_beta_i2v/i2v_background.py)、[成像质量代码](https://github.com/Vchitect/VBench/blob/fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490/vbench/imaging_quality.py)。

**正式主表报告全部九维、官方总分及原始分数。** 官方总分沿用对应版本的归一化/权重，同时保留逐维结果供比较。普通来源集上没有相机指令时，补充官方相机子集；当前阶段的部分维度按具名子集报告。九个维度各自保存实际使用的 source manifest。

## 3. 配对保真：PSNR／SSIM／LPIPS 的角色

令候选与 D-Q 同 seed、同初始噪声的解码帧为 \(I^S_t,I^D_t\)，像素最大值为 \(L\)。

\[
\mathrm{MSE}_t=\frac1{HWC}\|I^S_t-I^D_t\|_2^2,\qquad
\mathrm{PSNR}_t=10\log_{10}\frac{L^2}{\mathrm{MSE}_t}.
\]

SSIM 比较局部亮度、对比度和结构；MS-SSIM 在多个尺度组合结构信息。明确 RGB/Y、动态范围、窗口、下采样及边界处理。[SSIM 作者页面与实现](https://ece.uwaterloo.ca/~z70wang/research/ssim/)。LPIPS 比较归一化深层特征，经学习权重形成感知距离；记录 backbone、权重版本及输入范围。[LPIPS 原论文与实现](https://richzhang.github.io/PerceptualSimilarity/)。

FFNDS 报告逐帧曲线、每视频均值和最差时间段。先求逐帧 PSNR 再平均，与先合并 MSE 再取对数是两个统计量，分别命名。完全相同图像的 PSNR 为正无穷；导出 JSON 时保存 `exact_match=true` 和有限样本统计，保留该语义。

这些指标衡量对 D-Q 的保真。D-Q 是蒸馏模型参考，真实视觉质量由 F2–F7 配合评价。若候选产生合理但不同的轨迹，逐帧距离会同时反映轨迹偏移；因此增加同一候选的无参考质量和人工偏好，区分“离开教师”与“质量变化”。

## 4. 空间、时序、运动三组互补观测

**空间质量。** 核心采用 VBench aesthetic/imaging；扩展采用 DOVER 的 aesthetic、technical 和融合分数。MUSIQ 是图像质量模型，DOVER 源于用户生成视频质量评价，分别固定训练权重及归一化。既有 VBench imaging 已含 MUSIQ，单独再报同一模型时注明复用关系。[MUSIQ](https://arxiv.org/abs/2108.05997)、[DOVER 官方实现](https://github.com/VQAssessment/DOVER)。

**时序稳定。** 除九维中的主体/背景一致性和平滑性，增加官方 `temporal_flickering` 的静态视频子集。固定实现用相邻帧像素差构造分数；完全冻结帧的该分数为 1。该可演绎反例说明：闪烁、动态程度和指令遵从应组成联合观测。[官方闪烁代码](https://github.com/Vchitect/VBench/blob/fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490/vbench/temporal_flickering.py)。

**运动量。** VBench `dynamic_degree` 的固定实现以 RAFT 光流和阈值产生单视频判断，再对视频聚合。按静态、小幅动作、大幅动作、相机运动分别报告，比较 D-Q 在同一子集的运动量与平滑性。[官方 dynamic_degree](https://github.com/Vchitect/VBench/blob/fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490/vbench/dynamic_degree.py)。

**光流 warping error。** EvalCrafter 等视频评价工作采用运动补偿后的跨帧误差。典型形式为

\[
E_{\rm warp}=\frac{\sum_{t,p}M_{t,p}\rho\!\left(I_{t+1,p}-\mathcal W(I_t,u_t)_p\right)}{\sum_{t,p}M_{t,p}},
\]

其中 \(u_t\) 是固定光流模型的输出，\(M\) 表示有效、可见像素，\(\rho\) 按选定实现固定为 L1/L2 等。记录流方向、warp convention、遮挡处理和采样 FPS。运动估计误差也会进入该分数，因此同时展示运动幅度和有效像素比例。[EvalCrafter 论文](https://openaccess.thecvf.com/content/CVPR2024/html/Liu_EvalCrafter_Benchmarking_and_Evaluating_Large_Video_Generation_Models_CVPR_2024_paper.html)、[官方工具](https://github.com/evalcrafter/EvalCrafter)。

**FFNDS 稳定区域诊断。** 针对用户已指出的静态光照与背景小物体问题，在配对 D-Q 上冻结稳定区域/跟踪掩码，记录亮度一阶差、二阶差和运动补偿残差；候选与 D-Q 使用同一掩码并报告覆盖率。把它命名为项目 ROI 诊断，保留官方指标名给官方实现。这补充了全帧分数可能稀释的局部现象。

## 5. 条件语义与高级真实性

I2V 模型同时接受文本时，加入文本遵循。CLIPScore 为图像—文本匹配提供成熟基线；用于视频时，明确逐帧计算与视频聚合的适配方式。视频的动作顺序和关系变化由专门维度补充。[CLIPScore，EMNLP 2021](https://aclanthology.org/2021.emnlp-main.595/)。

VBench 的语义扩展包括 `object_class`、`multiple_objects`、`human_action`、`color`、`spatial_relationship`、`scene`、`appearance_style`、`temporal_style`、`overall_consistency`。选择与 FFNDS 测试集有对应标注的维度，使用其官方提示词/类别协议。[VBench，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Huang_VBench_Comprehensive_Benchmark_Suite_for_Video_Generative_Models_CVPR_2024_paper.html)。

VBench-2.0 提供十八个更高阶维度，适合在动作、交互、物理等关键子集上扩展：

| 大类 | 官方维度 |
|---|---|
| Creativity | Diversity、Composition |
| Commonsense | Motion Rationality、Instance Preservation |
| Controllability | Dynamic Spatial Relationship、Dynamic Attribute、Motion Order Understanding、Human Interaction、Complex Landscape、Complex Plot、Camera Motion |
| Human Fidelity | Human Anatomy、Human Identity、Human Clothes |
| Physics | Mechanics、Thermotics、Material、Multi-View Consistency |

固定相应提示词、视觉评估模型和聚合。这里的 Camera Motion 与 I2V 的同名维度分属不同套件，使用独立命名空间。[VBench-2.0 官方协议](https://github.com/Vchitect/VBench/blob/fd18b3d055cb0fc6f066ca90fe2c3c8cbb698490/VBench-2.0/README.md)、[论文](https://arxiv.org/abs/2503.21755)。

## 6. 分布质量、多样性与运动分布

| 指标 | 学术定义 | 参考集合及执行条件 |
|---|---|---|
| FVD | 视频 I3D 特征的高斯均值/协方差间 Fréchet 距离 | 同数据域真实视频；匹配视频数、帧采样、裁剪和特征权重 |
| JEDi | V-JEPA 特征上的 polynomial-kernel MMD | 同域参考集合；固定 V-JEPA 变体、核与估计器 |
| FVMD | 关键点跟踪得到的运动特征分布的 Fréchet 距离 | 同域运动参考；固定跟踪、窗口、运动特征构造 |
| frame-FID / frame-KID | 图像特征的 Fréchet / MMD 距离 | 匹配抽帧策略的真实帧集合；测量逐帧分布 |
| precision / recall | 生成样本的特征流形质量与真实分布覆盖 | 声明特征空间及近邻参数 |
| density / coverage | 密度与覆盖的分离评价 | 与 precision/recall 同时交代特征、参考及超参数 |

FVD 原始依据为 [Unterthiner et al.](https://arxiv.org/abs/1812.01717)；JEDi 为 [Luo et al., ICLR 2025](https://arxiv.org/abs/2410.05203)；FVMD 为 [Liu et al.](https://arxiv.org/abs/2407.16124)；FID、KID、precision/recall、density/coverage 分别见 [FID](https://proceedings.neurips.cc/paper/2017/file/8a1d694707eb0fefe65871369074926d-Paper.pdf)、[KID](https://arxiv.org/abs/1801.01401)、[P/R](https://proceedings.neurips.cc/paper/2019/hash/0234c510bc6d908b28c70ff313743079-Abstract.html)、[density/coverage](https://proceedings.mlr.press/v119/naeem20a.html)。将图像 P/R 类方法迁移到视频特征空间时，标明该适配和特征模型。

计算 Fréchet 类距离时采用

\[
\|\mu_r-\mu_g\|^2+\operatorname{tr}\left(\Sigma_r+\Sigma_g-2(\Sigma_r^{1/2}\Sigma_g\Sigma_r^{1/2})^{1/2}\right).
\]

FVD、FID、FVMD 的关键区别在于特征及预处理；JEDi/KID 则采用核距离。无偏 MMD 的有限样本估计可能为负，记录估计器和原值。分布距离保存两侧样本量、特征缓存 hash、数值计算版本及重复抽样稳定性曲线。

FFNDS 可采用两种明确命名的比较：`real_reference_distribution` 衡量对真实数据域的分布质量；`dense_DQ_distribution_fidelity` 衡量对原模型的分布保持。I2V 一张输入图像通常没有唯一后续真实视频，因此真实分布评价选择匹配任务域的参考集合。不同输入对应的帧、重叠窗口仍按源视频分组统计。

文献发现 FVD 对部分时序损坏敏感性不足。因此正式分布实验同时保留时序/运动维度，样本量由官方协议或预先冻结的稳定性分析确定。[FVD 内容偏差，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Ge_On_the_Content_Bias_in_Frechet_Video_Distance_CVPR_2024_paper.html)。

## 7. 人类评价与学习型评估器

人工评价采用随机左右顺序、隐藏方法身份的配对视频，观看完整时长。分别问总体偏好、输入保持、运动自然性、时序稳定和视觉细节；允许平局，报告每轴 win/tie/loss、有效评审人数、每视频评分数和来源簇置信区间。若使用 MOS，则固定量表文字、观看环境和评审流程。ITU-T P.910 是主观视频质量方法的规范来源；截至本次查阅，官网列 **07/2026 预发布版**为现行版本，10/2023 为历史版本。[ITU 官方版本页](https://www.itu.int/rec/T-REC-P.910/en)。

严重异常率以全部生成视频为分母，附主体崩坏、冻结、光照闪烁等具名事件数和时间位置。它是 FFNDS 配套的人类审阅统计。至少一条完整配对视频用于开发阶段的逐片判断；正式偏好研究采用预先确定的来源、种子和多评审样本。

学习型评估器可作为辅助：VideoScore 提供视觉质量、时序一致性、动态程度、文本对齐、事实一致性五维；VideoScore2 提供视觉质量、文本对齐、物理/常识一致性三维。固定评估器 checkpoint、采样帧、提示词和推理设置，并在人工子集上报告 Spearman/Kendall 一致性。[VideoScore 官方实现](https://github.com/TIGER-AI-Lab/VideoScore)、[VideoScore2 官方实现](https://github.com/TIGER-AI-Lab/VideoScore2)。自动分数与人类分数在结果表中各占独立列。

## 8. 数值与机制诊断：为演绎提供可辨识量

对同状态参考 \(y\) 和候选 \(\hat y\)，保存 SSE、MSE、\(\|\hat y-y\|_2/\|y\|_2\)、NMSE、cosine 及 p50/p95/p99/max。分别在 FFN 输出、gated update、post-writeback、flow、latent 上命名；分母为相应参考张量能量，零能量单列。`post` 的 residual 可显著增大分母，因此 FFN-only 与 post-NMSE 配对记录。

对于共享空间响应，可记录均值误差与去均值误差；对于动态动作，记录 `dynamic − best_fixed`、`dynamic − oracle`、`oracle − UB1`、跨来源共同动作与逐输入 oracle 的差，以及预测分数对真实边际收益的排序相关性。这些是**从通用统计构造的 FFNDS 机制诊断**，定义与最新数据复算见 [指标审计](78_指标审计与已有实验映射_R15_20261023.md)。

L2 记录教师固定状态、逐步重置和自由学生轨迹三种模式。局部有符号动作收益为 \(2\langle r,\Delta\rangle-\|\Delta\|^2\)，因此范数与方向应同时测。完整四步误差包含跨步传播及交叉项；以实际 scheduler/timesteps 记录 flow/latent 曲线并链接最终视频。

## 9. 效率与统计的可执行协议

**计时边界。** 同一部署分别测 kernel、完整 FFN、完整 denoising、包含 VAE 的视频生成、包含 IO/加载的 wall time；每列写出包含项。完整 FFN 包括实际付出的路由、布局、QDQ、两次投影、恢复和写回。报告主 GEMM MAC、附加计算和实际跳过量；约定一个乘加记 1 MAC 或 2 FLOPs。稀疏率、零值比例、激活参数比例和真实执行成本各自单列。

**测量方法。** 固定 GPU、软件栈、精度、batch、分辨率、帧数、步数、编译/cache 状态；warmup 后交替测量基线与候选，保存独立重复的原始时延、p50/p95及重复数。CUDA event 与同步 wall-clock 按计时目的选用，完整边界外同步，记录多 stream/多 GPU 协调；profiling 用于拆账，正式时延单独测量。[PyTorch benchmark 官方说明](https://docs.pytorch.org/docs/2.14/benchmark_utils.html)、[CUDA synchronize](https://docs.pytorch.org/docs/main/generated/torch.cuda.synchronize.html)。

同时报告 videos/s（固定 batch/并发）、peak allocated/reserved VRAM、模型与训练参数量、后训练 GPU-hours；能耗有计量条件时报告 J/video 和计量区间。速度比 \(T_{\rm base}/T_{\rm candidate}\) 必须来自同边界。Amdahl 关系 \(S=1/(1-p+p/s)\) 用于解释测得的 FFN 占比 \(p\) 如何影响总加速。

**配对统计。** 对来源 \(i\)、种子 \(j\)、指标 \(k\)，定义 \(d_{ijk}=q^S_{ijk}-q^D_{ijk}\)。先对同来源种子聚合，再按预定来源权重求平均差。保存绝对差、原始尺度和 95% CI；较高为好的指标另报 p10，误差/时延报 p90/p95 与最差案例。基准官方汇总和 FFNDS 来源均衡汇总分别输出。

bootstrap 保持两种方法成对，以独立来源或来源簇为最外层单位，嵌套重采样种子/评审者时写明设计。帧和相邻 stripe 留在所属视频中。统计方法的基础见 [Efron, 1979](https://doi.org/10.1214/aos/1176344552)；此处的分层选择来自 FFNDS 的数据结构。预先确定主要维度、等效/非劣效界值及多重比较处理；“差异未显著”与“等效”采用各自的判定方法。新方法的容忍界值依据任务、人类可辨性和基线波动制定。

**质量—成本比较。** 对 D-Q、UB1、最强同预算固定策略和最接近的可复现动态方法，报告每个实际工作点的质量向量、完整 FFN/总生成时延、资源；给出 iso-quality acceleration、iso-latency quality 和 Pareto 图。所有比较绑定相同 checkpoint、精度、scheduler、来源及生成配置。

## 10. FFNDS 的三个评测组合

| 组合 | 必报内容 | 数据与输出 |
|---|---|---|
| 开发诊断 | 对当前机制有区分力的 F8；完整配对视频；LPIPS/SSIM/PSNR 曲线；具名时序现象；原生时延 | 开发来源、逐视频结果和完整片段；选定方法时执行现有完整生成协议 |
| **论文核心** | **VBench-I2V 九维 + 静态子集 flicker / 运动 warp 辅助 + 配对 LPIPS/SSIM/PSNR + 人工成对偏好 + 完整 FFN/denoising/视频时延、显存/训练成本 + 配对统计** | 官方维度来源集及独立项目来源；每视频×指标、每运行时延、原始分数、官方汇总和来源分层结果 |
| 专题扩展 | FVD+JEDi；运动重点加 FVMD；分布多样性加 P/R 或 density/coverage；复杂任务加 VBench-2.0；学习型评估加 DOVER/VideoScore2 | 根据具体论文论点启用，并固定匹配参考集合、特征/评估器和协议 |
