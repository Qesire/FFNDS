# R12 E0：等预算动作、信息时序与条件粒度

2026-10-22；基于 main `b45ef1c` 的真实缓存只读审计及历史 flow 再分析。**本轮没有新模型前向、拟合、量化、视频生成或 GPU 作业。**

## 科学结果

历史 R7 的“局部/下游排序在3/4来源相反”与“动态选择有很大收益”不是同一命题。重新核验原始 flow 后，完整恢复 A/B 中最佳固定动作是 B，总 flow SSE 为178898.819464；按四个来源分别事后选 A/B，降至178592.862694，额外下降仅 **0.171022%**。留一来源、在另三个来源选固定动作的总误差反而高于全体最佳固定 B。这是四个已暴露来源上的描述，不是泛化估计。

另一个真实结构是**条件粒度**：在固定的三个分区中，把已经算出的 A/B 完整 flow 按 DQ 标签事后拼接，误差下降不同：

| 事后选择分区 | 相对最佳固定历史恢复 B 的 SSE 下降 |
|---|---:|
| 每个来源整段视频 | 0.171022% |
| 每个原生 latent frame | 0.314848% |
| 每个原生输出 token（1×2×2 latent patch，64个flow值） | 5.089427% |

**后两项是输出拼接，不是运行过的混合 FFN 动作，也不是其可达上界。** 两次完整恢复前向和事后 DQ 标签都已被使用；attention、norm、QDQ及下游传播使“混合两份最终输出”与“混合中间动作再传播”不同。这个结果只支持继续分辨空间误差偏好，不能拿5.09%当稀疏算法、R12等预算收益或视频质量。

完整记录：[原始操作数审计](../research/20261022/R12_E0_operand_audit.json)、[分区分析](../research/20261022/R12_E0_flow_partitions.json)、[分区分析前固定的CPU协议](../research/20261022/R12_E0_saved_flow_geometry_protocol.json)。来源仍为TF2的00/05/10/15，全部已暴露；R7全恢复超预算，不能替代R12动作值。

## 原生计算与不可辨识项

冻结路径仍是：原生norm/modulation → Smooth1 FP32除法/BF16 cast → 原生Q1 → W1+b0 → GELU(tanh) → Smooth2 → 原生Q2 → W2+b2 → 原生BF16 gate/residual →其余blocks→原生head/FP32flow。代码定位与SHA见审计`source_sha256`；`step_budget_runtime.validate_budget`仍只接收既有UB1/identity，没有被放宽。

配置的`denoising_step_list=[1000,750,500,250]`是**选取坐标**。已有源码先施加shift=5再选取，实际TF2两臂四源都记录模型timesteps约`[1000,937.5,833.333313,625]`，末步sigma=.625。原调度、缓存、结果保持不变；[重构记录](../research/20261022/R12_E0_runtime_reconstruction.json)明确区分配置标签与真实模型输入，不把250误作这次原生末步输入。

设原生基线误差`e=F0−FD`、动作变化`δa=Fa−F0`，精确增益为

```text
Ga = -2 <e, δa> - ||δa||² .
```

本轮从完整原始张量重算了每源A/B的对齐项与变化范数；二者相减才是净收益，局部能量不能代替。更关键的是：R7恢复A实际是`216/162`，而R12希望测`216/108`。令尚未观测的删减影响为`d=F216,108−F216,162`，则

```text
G216,108 = G216,162 - 2 <e + δ216,162, d> - ||d||² .
```

R7没有测这个`d`，连其符号都不能从旧恢复收益推出。另一个动作`108/216`还先改变block30，继而改变block31输入。因而0.171%既不是R12结果，也不是R12上界；原生动作矩阵仍不可辨识。按返回算子的等效宽度，R7是324/378/432组：单层恢复全局主MAC为50.15625%，双层为50.3125%。这还不是实际执行开销：旧诊断会先算UB1、再额外算两处完整教师，不可把这些比例当测速或实际已执行MAC。

## 两个相反机制与开阔后的分支

1. **条件预算交换**：不同输入的signed downstream作用方向不同，同样324组在216/108与108/216之间存在实际rank reversal，且能胜过最强固定分配。相反解释是某个固定分配普遍更好，旧局部误差排序相反主要来自目标失配，动态选择价值很小。最小区分是相同完整步骤输入下，真正运行三动作完整flow；现有缓存不能替代。
2. **空间异质性被全局平均掩盖**：输出拼接的5.09%与整源0.171%差别提示，空间粒度值得独立研究。相反解释是事后逐输出挑选的统计/数值优势，真实中间混合动作经过attention后并无收益。区分必须是新的原生tile混合干预及等成本固定空间模式；当前没有该结果，不扩展旧TC1的单行C-score迁移，也不把旧R4池扩大。
3. **信息不足与动作不足分开**：gate/step本轮已证实不能区分输入；R7完整调制输入不同，但有没有足以预测动作值的信息未知。只有真的动作headroom为正，才研究已有attention/调制输入统计对signed action regret的预测，而不是扩大旧C-score head。
4. **表示改变是另一问题**：signed功能基或树状FFN改变实际函数/坐标和量化误差，不能因改名绕过R8 full-support重编码失败。先要求未压缩数值控制；当前既无新编码，也无新增原理/论文成功声明。

新读/复核了[DiffSparse](https://arxiv.org/html/2604.03674v1)、[E-DiT](https://arxiv.org/html/2602.13993v1)、[DyDiT](https://arxiv.org/html/2410.03456v1)、[树状FFN](https://arxiv.org/html/2604.08565v1)，细节及迁移边界见[四项原始文献账本](../research/20261022/method_search_R12.json)。一般的动态宽度、输入router和token bypass均已有先例；不能把它们本身当新颖性。本地贡献若要成立，仍需量化原生动作值、后训练部署和质量/速度证据。

## 可复核下一步与成本

[新机制记录](../research/20261022/R12_mechanism_record.json)逐项比较R4/R7/R11/RB2/TC1；[R12E1 D0草案](../research/20261022/R12_E1_native_value_DRAFT.json)固定24次完整四步运行上限、三个原始零补偿动作、已有支持、相同输入、先控制后干预和明确停止条件。**它是无补偿诊断，不能冒充完整的匹配R256实验**；后者缺各动作传播后的block31训练数据，另列为未登记D1依赖。

三动作每对均324组，主MAC为6.7242767T，原生全160位置主MAC仍为50%。若把两层三种宽度全部以BF16权重独立驻留，约1.1865GiB，相对原162/162增加约0.7910GiB；最大单个BF16 hidden约0.8155GiB。每对两份R256另有166.0315G MAC，不能省略计费。历史UB1的1.546111×仅给相同基线耗时约3.074%的附加时延余量，不保证新宽度、搬运和selector能满足1.5×。

E0完成；E1草案没有获得模型作业资格。原R4/R7D2/R8/R9/R11固定拒绝、主MAC≤50%、完整FFN≥1.5×、真正新来源自由学生三轴各下降≤2%均保留。唯一下一项模型测量应先独立评审/登记，而不是追加旧rank、q、训练步数或用拼接数值开跑router。
