# 输出方差控制 VM1

VM1 是针对 RR1 模糊现象的机制控制实验。目前只完成校准与局部误差检查，尚无完整视频或速度验收。它与 24 输入新校准分开：仍使用原 12 条校准输入，固定 RR1 的支持、增益、偏置、rank256/lambda1 残差权重及 HiF4 缓存。

## 冻结方法

协议为 `config/output_variance_vm1.json`，在系数拟合前写入。对每个 step/block，使用原 12 输入各 512 行、共 6144 行的实际 BF16 dense 输出和 CPU 原生 BF16 RR1 重建。显式扣除原始 BF16 FFN2 bias，计算 FP64 均值及经固定 gate 加权的中心化能量；用能量比平方根得到一个正标量 beta，再固定为 FP32。FP32 shift 让输出均值与 dense 对齐。

在线位置在原 BF16 主支路与残差相加之后、原 gate 之前。顺序为 `BF16(((S.float-b0.float)*beta_FP32+shift_FP32)+b0.float)`。原 bias 只扣除、加回一次。beta 超出 [0.5,2]、非有限或能量退化则停止，不做裁剪或正式集上的 beta 搜索。融合算子关闭 FMA，需通过真实校准值与完整 token 形状的逐位 GPU 对照，才能写入部署策略；恒等控制直接返回原输入。

这是常规矩匹配控制，不是候选创新。它可能以略高的局部平方误差换取输出能量，但无法单凭能量匹配证明视频更好。

## 已完成的先导结果

先拟合 block20 的 step0/2。训练系数分别为 **1.06083596 / 1.13460708**；校正后的中心化能量与 dense 的比值分别为 **1.00000476 / 0.99991961**。训练原生平方误差分别增加 **3.73% / 4.62%**。

两个既有研究来源 task0/task6、各两 seed/两 step 的 8 个位置全部通过预设 `risk/RR1 <= 1.10` 门槛。实际比值范围 **1.02609–1.04947**。未经校正的 RR1 原生风险与冻结父实验数值重现；同时保留匹配的 FP32 控制。两个研究来源已被其他实验使用，不能称为新的最终测试集，也没有用其目标拟合 VM1 系数。

原始报告位于 `runs/worker_restart_20261020/output_variance_vm1/PILOT_RUN.json` 及 `output_variance_vm1_heldout/RUN.json`。先导拟合指纹为 `37c732857987e4c722a427ec2687489f71968ca614cfaf4548f8cf920060d09b`。全位置拟合已完成148/160，按20分钟资源窗口释放CPU，剩余12位置在主流程CPU诊断后续接。学习参数只存 Hugging Face 派生缓存。
