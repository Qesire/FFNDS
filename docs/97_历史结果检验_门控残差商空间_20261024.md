# FFNDS：用历史原生结果检验门控残差商空间（2026-10-24）

## 检验结论

**强结论：历史 UB1 / C1 两种组交换都不是原生下一归一化的零作用算子。弱但有价值的结论：残差写回 SSE 与下一 norm1 的决策排序明显不一致，尤其早步。未获得的结论：真实 64 组的门控去均值能量/联合相消比例，现有 Git 记录不足以识别。**

此次只读取已保存的 Git JSON 与捕获源码、复核已发布数字并做确定性汇总算术；没有新 Torch、CPU 测试、GPU、模型 forward、视频或选择器训练。结构化凭证：[retrospective audit](../research/20261024/gated_residual_quotient_historical_audit.json)。原研究入口：[文档96](96_门控残差商空间_可观测误差与无补算FFN构造_20261024.md)。保留 [实验暂停](../research/20261024/EXPERIMENT_PAUSE.json)。

## 1. 预期与真正能检验的量

数学构造为每 token 的 P=I−11ᵀ/5120，FFN 候选写回差 e=diag(g)[F_a(q)−F_D(q)]。若 P e=0，且后续只有 LayerNorm 后的路径消费 residual，理想实数下下一 norm1 完全相同。这个是条件精确命题，不是关于旧算子的断言。实际 BF16 逐项舍入仍需单独验证。

旧 C1 捕获源码 [tools/c1_native_probe.py](../tools/c1_native_probe.py) 184–205 行：仅写入每行 post_* / nextnorm_* 标量 SSE 和 336 采样行的 V1、h256、norm_mean/rstd、pre_features。不同完整动作的原始向量状态只在执行进程内临时存在，未写进该 NPZ。因而可以判断**已执行动作是否具有原生零响应**，但不能反推 P e 的能量占比，无法从标量识别真实组 Gram。

## 2. C1：完整原生动作的零响应假设失败

| 历史动作 | 72 位点的 post SSE 总和 | 下一 norm1 SSE 总和 | 下一 norm1 非零位点 |
|---|---:|---:|---:|
| UB1 | 72,120,087.58 | 153,187,325.30 | 72/72 |
| swap_A | 73,472,625.76 | 156,844,592.55 | 72/72 |
| swap_B | 73,382,066.63 | 156,226,328.83 | 72/72 |

来源：[research/20261023/C1N0_native_results.json](../research/20261023/C1N0_native_results.json)，6个独立原始来源簇、每个12处，共72个同前缀完整31668行的位置。Nextnorm 正值证明这些旧动作在原生下一层 norm 边界有实质差异，**不是实测零作用算法**。两列使用不同参考变量，不把数值比解释为误差放大倍数；有限精度也意味着不能把“严格非零”本身当作实数投影方向的完整识别。

更严格的目标反证：上述同一动作集合中，swap_A 和 swap_B 的全位置 nextnorm SSE 都在72/72位点比 UB1 差，离线 whole-site oracle 仍在72/72位点选择 UB1。不能把这个动作集合的结果投射为所有可重设计的无补算组算子的上界。

## 3. C1：变化的确在动作决策层存在

[原始72位点后验目标审计](../research/20261024/C1_boundary_target_audit.json)：post 和 nextnorm 逐行 Spearman 均值0.87563494，取各自前7917/31668高损失行的平均重合0.78297580。不同目标会挑选不同的行。

[原始有限组交换几何](../research/20261023/C1N0_geometry.json) 将 post-vs-nextnorm 相对 UB1 的逐行行动优劣符号作了对照：

| 比较动作 | 行-位置总数 | 相对优劣符号翻转 | 下一 norm1 比 UB1 更优的行 |
|---|---:|---:|---:|
| swap_A | 2,280,096 | 161,784（7.0955%） | 194,205（8.5174%） |
| swap_B | 2,280,096 | 171,062（7.5024%） | 259,996（11.4029%） |

逐步差异：swap_A 的0/1/2/3步符号翻转分别75,308/42,130/31,025/13,321；swap_B为72,944/45,485/33,507/19,126。观察的是对固定历史动作、同一旧来源重复行的**离线标量排名**，并非执行了逐行swap；2.28m 行不是独立样本量。此结果同时支持“下游选择目标改变”和“当前旧动作族总收益仍不足”，**不能定位为均值 gauge、尺度、径向、attention 或其它单一机制**。

## 4. 用 R9 的全216组 Gram 检查 G2/G3 的证据边界

[R9A1 native](../research/20261021/R9A1_native_affine_results.json) 记录 all216_cross_terms=true；真实训练程序 [tools/screen_learned_affine_remainder.py](../tools/screen_learned_affine_remainder.py) 计算组贡献 Gram 并优化学习型 BF16 仿射余项。等宽的 step1、step2 每步各选68个组，交集44、并集92、Jaccard 44/92=0.47826。

这是**已发生过联合有符号组优化与跨步支持变化**的历史证据，不能直接支持新的 G2：其 Gram 目标是旧仿射余项的带门控训练风险，不是 Pdiag(g) 投影之后的 FFN 直接省组误差；saved Git JSON 不含 Gram 元素。step1→2 又同时改变 expert、时间输入与样本分布，不能把差别归因于 gate。R9 实际旧配方的拒绝仍然有效。

因此 G2“可观测组相消大到可以省算”和 G3“当前 gate 单独改变最佳保留组”的真实效应均为**尚不可识别**，不是从 R9 获得正验证。

## 5. R12/R7/R16/R17：为什么不将代理优势误认为算子价值

- [R12 D0](../research/20261022/R12_D0_native_results.json)：四开发来源、两连续末步层的三种原生零补偿等预算分配。oracle 对最强固定 NA 只改善0.2319275% flow SSE，依然比 UB1 高2.5741%；排除该三动作集，不排除新投影组算法。
- [R7](../research/20261021/R7D1_results.json) 与 [C0重算](../research/20261023/C0_coupling_offline_results.json)：原有完整恢复动作的下游线性方向交叉项−11859.54、有限非线性传播项+11657.10，净交互−202.44；说明净 SSE 接近相加并非传播向量线性，**不是64组 P 投影证据**。
- [R16](../research/20261023/R16V0_analysis.json)：一个旧来源的 dynamic row 决策改善四处 same-input local SSE 6.1276%，但自由四步完整视频的 pooled RGB MSE 比最好固定行方案高8.2257%。RGB差异不等于官方质量；可以确立 local-to-video 目标错位。
- [R17](../research/20261023/R17E0_system_timing_prefix.json)：一个旧来源、每动作五个技术重复。UB1 的完整160 FFN 1.5333×而完整生成墙钟仅1.07568×；原 dynamic_residual 分别1.25665×和1.04469×。新投影评价若要转化为加速，必须降低实际 GEMM/QDQ/gather/选择开销，不能将理论零方向作为 speedup。

## 6. 从“精确一维核”扩展到“局部二维低响应”更有判别力，但仍须真值

对无仿射 LayerNorm，令 x_c=Px、s²=||x_c||²/d+ε，有

J_LN(x) = (P/s) − (x_c x_cᵀ)/(d s³)。

Jacobian 在均值方向的特征值为0，在当前中心化径向 x_c 上为 ε/s³，余下 d−2 个切向方向为1/s。因而**除了精确一维 gauge，径向还可能是一条很弱的一阶响应方向**；相对切向奇异值比为 ε/(σ²+ε)。这不是额外精确全轨迹对称性；有限大动作可旋转状态方向，C0 synthetic scale/action 翻转正是提醒。

已保存的 C1 几何 JSON 仅含**当前 pre-FFN norm2** 的 336采样行/位点前attention写回后标准差范围0.3765到9.6455。对 ε=10^-6，当前 norm2 的径向/切向导数比按理想公式约介于 1.075×10^-8 和 7.055×10^-6。这是条件理论与真实输入尺度的结合，**不是下一block norm1 施加了同一衰减的测量**，因为 C1 未保存这些位置的下一层完整残差向量。

值得将后续问题从唯一常数方向扩成：省略组的有符号贡献是否集中于 **当下/后续状态依赖的近零响应空间**？其成本是误差方向与 residual 的相对位置，而非新增默认 Dense 补算。这也更紧密连接旧 C0 的尺度丢失信息与 R7 的有限传播。

## 7. 现有数据可支持的最小下次检验

**第一步不启动模型**：仅在已经可访问的旧 HF 原始载荷中检索同前缀的 5120维成对写回状态、每64组 Q2/W2贡献及对应 gate；C1 NPZ 明确没有成对状态向量，R9 Gram 完整元素在原 HF 支持产物而不是当前 Git JSON。先核对路径、SHA和真正含哪些字段，不要把不同source/step/bias的向量拼成“同一动作”。

若找到已保存匹配向量，回顾性计算每 row/step/source：η=P e、ρ_mean=||(I−P)e||²/||e||²、当前/下一状态的一阶径向占比和剩余切向能量；同时检查小尺度与全幅有限 nextnorm loss 的关系。独立来源按source聚合，并比较同一动作旧 post SSE 排序、nextnorm 排序。没有误差向量时，ρ_mean 的合法结果是 **不可识别**，不是0。

若找到原生固定组贡献和 gate，再计算投影前后的 signed Gram、固定组 budget 支持，首先以 source-held-out 比较 G2 联合优化与未投影联合优化。所有历史动作不能换名复活，尤其已关闭的 R12/R9；要产生全视频 Pareto 仍须另行解除既有实验暂停。

**当前评价：** 精确不变性为真实的条件数学结构，但在已执行的三种历史动作中**没有实现完整下一层无变化**；改变局部评价边界得到明确而有限的决策差异；是否形成真正省算方法仍需旧数据中未能取得的有符号向量。
