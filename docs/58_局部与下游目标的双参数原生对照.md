# 局部与下游目标的双参数原生对照（R7D2）

[R7D1](57_固定双层恢复的原生传播诊断.md)完成24次原生生成，三个来源的局部误差排序与下游收益排序不一致。两层dense恢复共减少3.029%同状态flow SSE；净交互只有−0.111%基线SSE，而方向项与非线性项相互抵消，不能据此声称强联合增益或候选质量恢复。本轮进一步测试目标函数，保持极小且匹配的参数族。

## 改动与匹配对照

只在step3/block30、31，把**现有**R256预测残差各乘一个固定增益，再执行原生BF16主输出加法与gate写回。支持、主权重、bias、R256参数与rank全部冻结。两个参数的增益范围预先固定为[0.75,1.25]；增益1绕过乘法，须逐位复现旧TF2 UB1四步input/flow/post。

最近的旧配方是AR1/C-static局部增益、OP3局部重拟合与LR2增秩；这些拒绝保持关闭。这里不提出新修正架构，只用同样两个参数比较**局部FFN目标**与**完整下游flow目标**。后者使用两个原生扰动的方向Gram，包含非对角项；这不同于重跑独立局部拟合或扩大rank/搜索范围。

## 固定数据与18次运行

[协议](../research/20261021/R7D2_residual_gain_protocol.json)使用原TF2四个已暴露来源。00/05/10用于拟合；15只排除出拟合，仍是已用于研究的开发来源，不能称为全新独立最终测试。完整原图/文本/seed42、四步原生推理和逐步D-Q输入保持不变。

先4次增益1恒等控制；全部通过后，在三个训练来源分别运行A增益1.125和B增益1.125，共6次固定正向扰动。按训练数据解两个有界凸二次问题：局部目标来自gated FFN误差与原残差的内积，flow目标来自完整flow的原生割线方向。约束边上的自由坐标重新求最优，不能把无约束解简单逐项截断。没有超参搜索，也不在开发留出来源上选择参数。

两个工作作业独立计算并核对拟合结果；全部扰动与恒等控制完成后，才对四个输入各执行local-fit和flow-fit，共8次原生比较。总18次完整四步生成，附加完整局部教师仅用于离线诊断。所有失败保留；若任一控制失败，后续阶段中止。

## 决策与边界

比较冻结UB1、局部拟合与flow拟合的每来源完整flow SSE、局部SSE、拟合预测与原生实际差异，报告两个增益及是否触及边界。割线在HiF4/BF16非线性下只是代理，不能把二次模型预测当作实际收益。若flow-fit未优于local-fit的开发留出结果，关闭本固定双增益配方，不扩大层对、参数范围、epsilon或来源划分。

主MAC保持50%，两次额外BF16乘法属于候选成本；没有继承旧1.546×测速通过。Teacher-forced诊断视频由构造恢复D-Q轨迹，不代表候选视频质量。即使开发flow改善，也需另行冻结真正新来源与完整候选轨迹，接受原始完整FFN≥1.5×、三项官方质量各≤2%下降的联合验收。

## 当前状态

固定原生运行器、两个目标的求解器与边界控制已实现。全部18次原生生成完成，4恒等控制逐位通过，两作业拟合完全一致并由CPU重新计算复现。固定配方按预登记开发留出规则关闭。当前决定、路线表和交接记录约束执行，旧R4有限拒绝不变。
