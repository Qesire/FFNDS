# R11G1：真实输出头梯度的准备检查

固定准备检查已完成：完整原生字节等价与真实梯度均通过，一次预先固定更新的来源内flow MSE下降0.291%。这不是训练候选或恢复验收。先保留[R10完整复盘](61_全路线失败归因与组合方案复盘_R10.md)及[R9A1拒绝结果](62_广泛复盘后的学习型仿射表示检验.md)。[协议](../research/20261021/R11G1_native_head_protocol.json)、[机制对照](../research/20261021/R11G1_mechanism_record.json)与当前决定共同限定执行。

R7D2暴露的具体问题是冻结割线响应与真实BF16传播不一致：方向余弦约0.57，预测的训练收益只兑现1.806%。OP3则只拟合同一学生输入的局部教师FFN，没有检验独立教师轨迹。这里检查真实下游算子能否直接反传；不加rank、支持、增益或新参数。

## 算子与边界

选择step3/block39，因为其后不再有attention。原LightX2V的`WanTransformerInfer.infer_ffn`、`post_process`和`infer_non_blocks`对应：

\[
Y=\operatorname{BF16}(Y_{main}+R_{256}(u;\theta)),\quad
X=\operatorname{BF16}(X_{base}+\operatorname{BF16}(Y\odot g)),
\]
\[
F=\operatorname{addmm}_{BF16}\bigl(b_{head},
  \operatorname{BF16}(\operatorname{BF16}(\operatorname{LN}_{BF16}(X)\odot(1+s))+t),W_{head}\bigr).
\]

每次乘法、加法、BF16转换分别保留，不能合并为FP32近似。原head是无仿射参数的torch layernorm（eps=1e-6）；Default矩阵乘法带`out=`，该接口不支持autograd。重放只去掉输出缓冲参数，其他数学操作及原BF16权重保持，是否数值等价以完整原生输出逐字节检查决定。源文件哈希随登记保存。

`u`是实际Q1之后的完整31668×5120输入。主分支与更早各层固定，仅原有R256的first/bias_first/second/bias_second可更新。因此无需对HiF4量化器定义梯度，也没有跨attention反传。参数FP32主副本在原两个GEMM前转BF16；cast的autograd导数不等于证明离散更新有效，故还要检查一次实际舍入后的参数和flow变化。

原post-infer把31668×64输出经固定patch=(1,2,2)排列为16×21×58×104 flow，然后转FP32。这是双射排列，故完整token MSE与完整flow MSE相等。代码使用相同排列并核对逆变换，不能拿256个随机缓存行拼成完整flow。

## 固定检查与解释边界

仅运行原TF2来源00，原图像、seed42、conditioning及四步输入保持原身份。每个完整步骤结束后恢复旧DQ post，复现原TF2 UB1的input/flow/post；它不是自由学生轨迹。捕获完整末层操作数后退出模型进程，再单独做可反传重放，避免全模型驻留与训练显存叠加。

先检查原四步与旧记录一致，再检查R256、门控写回、完整head token和完整flow零更新一致。任何一项失败，停止梯度。通过后，以独立DQ原flow为目标计算当前真实MSE梯度；仅做一次全参数L2相对位移0.001的归一化负梯度更新，不搜索步长。记录所有梯度的有限性、实际BF16参数变化、实际flow变化、更新前后损失及显存/耗时。

一次来源内损失下降只能证明实现可用；损失上升也按原结果保留。它没有检验匹配局部目标、跨来源泛化、自由学生轨迹或官方质量。后续训练必须另外冻结来源、优化步数、local/native对照与停止条件；不从本次结果自动增加窗口、来源、训练次数。

额外大张量只进HF缓存，预计低于3GiB，保持80GiB空闲余量。部署参数量和UB1主分支预算保持；完整160位置速度、三项官方质量及真正新冻结来源的最终验收均未由本检查建立。

## 已观察结果

[完整结果](../research/20261021/R11G1_native_head_results.json)保留协议、源码、模型资产、原始收据与HF张量SHA。第一次尝试在生成前因量化函数导入层级错误退出，0次生成/0次梯度；[修复记录](../research/20261021/R11G1_execution_repair.json)保留旧实现SHA和失败收据，第二次仅修正同一函数的导入，实验协议未变。

一次完整四步生成的12项input/flow/post控制通过，原1600线性/1600量化调用和完整160位置覆盖通过。R256输出、门控写回、完整head token、完整flow及排列逆变换的五项整数字节与SHA检查全部通过，然后才反传。

四组既有参数均取得有限非零梯度。一次相对全参数L2位移0.001更新改变1023955个实际BF16参数，flow MSE由0.01895713061降至0.01890193857，下降0.291141%。实际flow变化SSE为36.976667。没有增加部署参数，末层既有参数共2626816个。

隔离进程峰值分配显存3337916928字节（3.109GiB），峰值保留约3.408GiB。首次完整M前向/控制/反向合计0.2404秒，更新后的单次前向0.02579秒；前者包含重复残差预测及控制，不是严格热身吞吐基准。大张量约1.836GiB只保存于HF缓存，80GiB空闲底线保留。

该结果排除了“末层真实head目标无法在现有两卡环境反传”这一准备障碍；不排除R256表达力、跨来源迁移或自由学生轨迹的障碍。下一项有判别力的研究是固定相同参数/来源/优化预算，对比局部教师FFN目标与独立DQ flow目标；必须先另外冻结协议，不能从本检查自动触发训练。
