# 新计算图优化的五源配对实机测试

实验绑定到 `a366f68950c8d5afcd053d9c040061d230648eac` 和已完成的学校 50 源作业 `206224`。各方法在同一组五个来源、seed 42、同一个四步 HHLL 模型上各生成一条质量原片。冻结对照使用原 centered attention＋BF16 wide8192 FFN。

| 来源 | 筛选依据 |
|---|---|
| `vbi_0632` | 旧 50 源自然组的成像质量尾部 |
| `vbi_0016` | 旧 50 源场景组的成像质量尾部 |
| `vbi_1095` | 旧 50 源主体组的成像质量尾部 |
| `vbi_0440` | 旧 50 源具有明显绝对运动幅度差的一例 |
| `vbi_0616` | 旧 50 源端点 latent 对 Dense 的中位距离附近 |

旧结果只用于冻结筛查样本。每项使用实际新原片与逐源端到端指标判断。画面和时间诊断在生成完成后计算，评分使用同一套固定 VBench I2V 官方函数。五源筛查用于比较实现、寻找质量和速度异常。

每个候选与冻结基线在同一个 Slurm 单卡分配下顺序运行，各自初始化和热身，候选先行与对照先行随配置交替。正式墙钟包括四步推理、缓存、解码及保存，四步 CUDA 事件时间另记。最终 latent 在原计时窗结束后读取，并与末步指纹一致才作为指标输入。独立的冻结对照出片与旧 `206224` 对照逐源验明身份。

无需新资产的八个配置进入作业 `210172`。四个依赖资产的模板复用真实学校 CAL。FFN 资产作业 `210194` 使用实际冻结 CAL pack，试验 rank 512 随机化 SVD 初始化与单独的 16 维最小二乘规范变换。Attention 资产作业 `210195` 在三个原 CAL 来源上捕获实际 `Z,G` 配对，每层 128 个非 P 行，以 rank 64、八步配对目标优化生成低噪历史基。压缩秩和拟合步数是本次明示的试验参数。

启动时学校 QoS 允许 4 个运行和 10 个已提交任务。所需的后续作业按该限额滚动入队。每个候选的完整视频、逐源数值、正式计时及运行状态由执行收据给出。
