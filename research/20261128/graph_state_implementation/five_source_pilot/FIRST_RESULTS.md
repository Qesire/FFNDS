整块流式路径第一次进入真实 Wan BF16 命中块时，压掉了原生 Triton `modulate_func` 所需的 batch/token 轴。真实 GPU 日志在 `scale.shape[1]` 报 `IndexError`。修复将共享调制绑定为 `[1,1,C]`，将当前 tile 的逐 token 调制绑定为 `[1,L,C]`，gate 仍使用原来的末轴广播。修复后保留相同五来源，三个整块相关配置在学校作业 `210311` 重跑，联合状态配置使用 `210312`。失败尝试不计入视频和时间结果。
