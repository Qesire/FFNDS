# 当前方法的理论空间：固定图边界、可构造旁路与状态资源

2026-11-28。本轮只做真实形状的整数算量、最新计时的条件分解、源码检查和 CPU 线性代数证书；新 GPU 作业、模型运行和视频评分均为 0。

## 1. 当前已经利用约四分之三的限定算量空间，仍有两种不同的余量

在固定“2 个原生锚点＋2 个命中，QKV/O 和 cross attention 保持原生”的作用域内，当前列明 GEMM 账本节省 **27.807%–27.900%**。让所有命中 FFN/self-attention core、额外状态建立及恢复费用都归零，乐观结构参照为 **37.017%** 节省。因此当前已移去这一指定可移去份额的 **75.12%–75.37%**，距离该参照还差 **9.12–9.21 个 Dense 主算量百分点**，相当于当前已列算量的 **12.65%–12.76%**。

这同时给出两个正面的判断：已有方法已经利用了该作用域中的主要空间；通过共享重复计算、重写状态与改变作用边界，仍有明确可研究的余量。37.017% 绑定保留的节点集合，不是模型函数的复杂度下界，也不是墙钟上限。

## 2. 独立重算固定图账本

真实形状为 $N=31668,d=5120,m=13824,K=2560,H=40,d_h=128,L=40,P=64$。一个 MAC 记 2 FLOPs。本文沿用已有账本的 512 文本 keys 配置。

一个层、一个去噪调用的主矩阵量为

\[
A=4N^2d,\qquad F=4Ndm,
\]

其中 $A$ 为 self QK/AV，$F$ 为 FFN 两次投影。保留部分为

\[
R=8Nd^2+4Nd^2+4Cd^2+4NCd,
\qquad D=A+F+R.
\]

| 主项 | TFLOP / 层步 |
|---|---:|
| self QK/AV | 20.53862 |
| FFN | 8.96570 |
| self QKV/O | 6.64126 |
| cross Q/O | 3.32063 |
| cross K/V | 0.05369 |
| cross QK/AV | 0.33206 |
| 合计 | **39.85196** |

四步 40 层共 **6.37631 PFLOP**。当前 FFN 命中的主要作用为

\[
F_h=2Nd^2+4NdK=3.32063\text{ TFLOP},
\]

其中 $\Delta U A_0$ 与 selected W1/W2 各占一半。完整周期还须保留两次原生 FFN，并加入 P64 教师、80 列联合读出和显式特征矩阵乘。

attention 每个 query 选择 31 个 key block。N 的末块只有 52 行，实际 selected keys 为 3892–3968，因此 $\alpha\in[3892/N,3968/N]$，$\beta=P/N$。四步 self core 含 2 次原生、3 次 selected、2 次 P64 全键教师：

\[
r_A=\tfrac12+\tfrac34\alpha+\tfrac12\beta.
\]

上述调用次数与当前 centered 代码一致。centered 增加的均值/方差、编码/解码是 $O(Nd)$ 操作，不改变这些主矩阵调用。已有 low anchor 的少量 rho fallback、非线性、求解、归约、padding、访存和模型块外操作未计入“列明 GEMM”；这就是该账本的范围。

### 剩余的 9.1 个百分点具体在哪里

| 相对乐观结构参照的剩余操作 | 占 Dense 全四步主算量 |
|---|---:|
| 3 次 selected attention | **4.750%–4.843%** |
| 2 次 FFN $\Delta U A_0$ | **2.083%** |
| 2 次 FFN selected W1/W2 | **2.083%** |
| 2 次 attention P64 教师 | **0.052%** |
| 已列特征、拟合和读出 GEMM | **0.149%** |

恢复的小矩阵求解不在这个 GEMM 数字内，但表内相对尺度已表明：压缩几个恢复列能影响的算术体量较小。主要方向是共享 selected 的重复计算，以及重新组织 $A_0$、选中非线性和历史状态。

若将作用范围扩到整个 hit block，原本保留的 self QKV/O 在两个 hit 中合计占 Dense 全图 **8.332 个百分点**，cross Q/O 另占 **4.166 个百分点**。它们说明改变图边界可以移动 37.017% 参照；要获得这些份额，需要给出实际可计算的读出或替代映射，不能只把节点设为免费。

## 3. 一个明确的图旁路：低噪锚点共享一次 attention 扫描

low anchor 当前同时产生 native 输出与 selected 输出，两者使用同一组 Q/K/V。route 由 Q/K 的块统计决定，因此可以在全 attention 前取得。对每个 query，将 key blocks 分为 selected 集 $S$ 和补集 $R$。

对一个 key block $B$，只计算一次局部状态

\[
m_B=\max_{j\in B}s_j,\quad
\ell_B=\sum_{j\in B}e^{s_j-m_B},\quad
z_B=\sum_{j\in B}e^{s_j-m_B}v_j.
\]

该块的 QK 和 AV 矩阵乘各执行一次。按 B 的归属，把同一局部状态并入 $S$ 或 $R$ 的稳定归约状态；最后由两组状态同时得到：selected 条件输出、full 输出、遗漏质量与 centered 历史。它利用在线 softmax 状态的可合并性，复用同一块乘积。

在实数算术中，这删除当前低噪锚点第二遍 selected QK/AV：每层节省 **2.5242–2.5735 TFLOP**，全 40 层节省 **100.968–102.940 TFLOP**，即 Dense 全图 **1.583–1.614 个百分点**。因此列明 GEMM 节省从约 27.8%–27.9% 移到 **29.421%–29.483%**，对应约 **1.417–1.418×** 算术倍率。

新实现还要增加每块的状态合并、缩放及必要输出，故该数值是主矩阵账本，不是延迟预测。分区归约和当前两个内核的 softmax、BF16 舍入路径不同；实数等价与逐位复现应分别处理。attention 专项推导给出相应恒等式和合成 CPU 数值核验。

这一构造有两项作用：减少已知重复主算量；使 native、selected 与遗漏质量来自同一组归约统计。它直接改善当前图，而无需提高恢复自由度或修改支持密度。

## 4. 墙钟空间须用实际时间重新界定

job 206224 的来源等权算术均值为：

| 时间部分 | 当前 M |
|---|---:|
| 两个 anchor GPU | 16.92099 s，**48.40% 请求** |
| 两个 hit GPU | 8.76491 s，**25.07% 请求** |
| step 事件之外 | 9.27180 s，**26.52% 请求** |
| 完整请求 | **34.95769 s** |

只改变 hit、保留其余时间时，若移去 hit 的比例为 $q$，则严格的条件账本为

\[
T(q)=9.27180+16.92099+(1-q)8.76491.
\]

| 假设移去当前 hit 时间 | 条件请求时间 | 相对当前请求节省 |
|---|---:|---:|
| 10% | 34.0812 s | 2.51% |
| 25% | 32.7665 s | 6.27% |
| 50% | 30.5752 s | 12.54% |

这些是用于衡量改写价值的敏感度数值，不是新方法已实现的速度。它们也说明为什么锚点重复计算值得处理：当前 anchor 已占请求近一半。

还可以建立一个明确带条件的算术—时间参照：若所有列明 GEMM 达到 Dense 整个去噪器的平均有效 FLOP/s，且 Dense 的事件外时间 9.21046 s 固定，则当前算量比对应 **31.976–32.005 s** 请求，约 **1.274–1.275×**；37.017% 结构节省对应 **29.097 s、1.402×**。这不是硬件上界，它只是将 FLOP 参照映射到相同未变费用后的结果。

实测 M 为 34.958 s，差异同时包含各类矩阵形状、稀疏调度、状态处理和未列算子的有效成本。原始计时只记录 step，不足以把这约 3 秒差异全归于某种可消除开销。当前有充分依据区分三层事实：主算量有余量；锚点与命中时间有清楚占比；具体旁路的收益由其调用和数据流确定。

## 5. 当前缓存是一个时间—空间配置，并非信息论下界

当前主要字段容量为 FFN **30.20096 GiB**、low attention **15.19486 GiB**，合计 **45.39582 GiB**。高低专家分时使用 40 个 FFN 槽，容量不乘二；但两者均写入并读取一次，因此字节流量要计两个周期。

按当前图，主要历史字段的一次写入和一次读取至少构成逻辑载荷

\[
Q_{history}=4C_{FFN}+2C_{attn}
=151.19355\text{ GiB/视频}.
\]

该数值未计 P64 重读、路由、其他中间量和实际内存事务，不等于 profiler 测得的 HBM traffic。即使容量相同，状态读取次数、读取时点和重算方式不同，也会改变真实执行成本。

### 可构造的空间—算量点

| FFN 表示 | 主要状态 | 相对当前额外 Dense 全图算量 | 构造及条件 |
|---|---:|---:|---|
| 当前 $u_a,y_a,z_{a,K}$ | 30.201 GiB | 0 | 当前已执行配置 |
| 只重算 $z_{a,K}$ | 24.161 GiB | +1.042 pp | 在 hit 从 $u_aW_{1,K}+b_K$ 恢复；浮点 kernel 的舍入需对应 |
| $c_a=y_a-u_aA_0$、$j_a=u_aJ$、$z_{a,K}$ | 18.196 GiB | $A_0$ 部分 +2.083 pp，另有很小 J 投影 | c/z BF16、j FP32；属于新的数值编码，实数等价不代表当前 BF16 逐位等价 |
| 只存 $u_a$ | 12.080 GiB | +11.249 pp | 在 hit 用同一 anchor 输入重算原生 FFN，恢复其余字段 |

折叠配置若为 c 保留 FP32，c/z/j 合计约 **30.276 GiB**；因此实数状态维数减少与实际 16 位缓存的精度选择要同时给出。FFN 专项推导进一步展开可保留的舍入语义与误差项。

只存 $u_a$ 的构造已经证明：在固定权重、条件及确定性执行下，其余 FFN 字段是可重算函数，当前 30.2 GiB 并非数据独立维数的下界。它付出额外原生 FFN 计算，作为资源曲线的一端有意义，而不是当前速度目标下的默认选择。

### 全图重放可以进一步改变容量

先完成原生 anchor，取得下一步的输入；随后从保存的 anchor 输入重放，将第 $\ell$ 层 anchor 与第 $\ell$ 层 hit 交错执行。该层历史产生后立即被 hit 消费，下一层不需要它。于是主要历史从全部 40 层同时保留，变为约一个层的 **1.13490 GiB**，另保留两条 BF16 hidden 流约 **0.60402 GiB**，以及参数、路由和临时工作区。

这种调度仍有四个采样步骤，但每个专家多计算一次原生 anchor，整片额外主算量约为 Dense 的 **50%**。同一层的两条流可共享已加载权重，是否减少权重传输还取决于真实卸载调度。它提供构造性空间上界，并展示为何“层间历史必须全部驻留”属于当前调度选择。这里不给独立峰值或速度预测。

## 6. 用任务读出定义最小状态，才能找到合适的压缩对象

算子 skill 的 C03 线性状态证书可直接应用：若未来读出为 $G_\theta s$，编码为 $z=Es$，要求对所有允许的状态 s 和未来条件 $\theta$ 精确恢复，则

\[
\ker E\subseteq\bigcap_\theta\ker G_\theta,
\qquad
r_{min}=\operatorname{rank}\operatorname{stack}_{\theta}G_\theta.
\]

这里是允许线性编码时的维数结论。位长、误差容限与非线性可达状态集另需定义，因此不能直接把秩换成某个 GiB 的信息论下界。

对固定当前特征的 attention，令 S 选出 P 行，Q 选出其余行，K 为 ridge 恢复算子。历史对未探针输出的作用为

\[
G_K=Q(I-KS),
\]

再右乘当前 value 通道尺度。由于未探针历史列含单位块，单个固定 K 的秩为 $N-P$。P64 恢复的低秩说明“新增校正”低维；全部历史的可读部分可以远大于这部分。未来 K 变化时，共同可读行空间进一步扩大。

本轮用 $N=257,P=64,r=32$ 的合成数组实际计算，三组单独读出均秩 **193**，一组、两组、三组未来读出的堆叠秩分别 **193、255、257**；单个读出的最小维数分解误差为 **1.44e−15**。这验证线性证书及查询族的作用，不代表真实 Wan 历史的实测秩。

因此，更小缓存的积极构造应利用实际历史的可达结构或任务敏感度。若 $s=s_0+Ua$，所需线性增量维数由 $\operatorname{rank}(G_\theta U)$ 决定。近似编码则可直接优化联合目标

\[
\mathbb E_{\theta,s}\|G_\theta(s-\operatorname{decode}_\theta(Es))\|^2,
\]

并将 $G_\theta$ 换成最终任务读出的局部作用。历史和当前条件相关，保持联合期望，不预先拆成独立协方差。这样，缓存可以朝“下一次实际读取需要的信息”缩减；当前数据本身还未给出这个任务谱，因此不能由 P64 或 31 维特征直接推断全历史只需同样宽度。

## 7. 对当前理论问题的回答

当前方法已经利用了固定作用域中的大部分算量空间，尚有具体且可构造的余量。最明确的一项是低噪锚点共享 native/selected 的块归约；状态层面则有折叠、重算和按层立即消费等不同资源配置。更大幅度的算术收益需要改变目前保留的作用边界，并给出恢复所需信息的具体读出。

这些推导让下一步理论研究有了准确对象：保留输出所需的状态等价类、避免重复的块收缩、以及完整锚点—命中周期的时间—空间成本。此文不提出新消融任务。
