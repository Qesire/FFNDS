## 全键见证

8 个 self 见证覆盖 4 个头和全部视频 keys。有限割线三通道恒等式的最大绝对重构误差为 9.68e-14。一阶切线对实际输出变化的合并相对 L2 误差为 115.39%。
96 个 text-cross 面板的两端 K/V 字节相同。在 anchor→hit 全步长上，一阶和二阶近似的相对 L2 误差中位数分别为 93.77%、105.67%。

采集的 FP32 LSE 容差内，anchor/hit 分别出现 12 / 11 条极小负质量值，最小 -3.05e-05，拟合沿用原始有符号值。
