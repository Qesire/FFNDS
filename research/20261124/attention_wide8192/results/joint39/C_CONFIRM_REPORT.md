# 冻结 C 的独立六来源配对

学校 A100 作业 `196504` 按冻结清单生成 6 对 A/C 视频，每对 81 帧。六个来源簇在生成前按室内／建筑、自然／植物、人物／动物各两个锁定。同一来源两臂使用相同输入图、提示、seed 42、初始噪声和第 0 步状态。采用 warm full-request 墙钟，去噪四步用 GPU 事件。

整片 C/A 逐源时间比的几何平均为 **1.0318×**，四步 GPU 为 **0.8652×**。六簇描述性 bootstrap 95% 区间分别为 0.8274–1.4793× 和 0.8526–0.8804×。A/C 峰值分别为 47.57 和 65.41 GiB。
