# C 高噪声第 0 步 OUT-ABS 的同卡验证

方案固定于 `090ae3aea20f`。学校 A100 作业 `196295` 复用 DEV0392 和 DEV1013 的输入与 seed 42。基准 C 在第 0 步执行原生 attention，C0 在同一步逐层用当前 Q/K 建立支持，再运行 OUT-ABS＋P64。第 1 步复用对应层的路由；low OUT-D、CAL、P64、选中规则与 BF16 wide8192 FFN 沿用原配方。
