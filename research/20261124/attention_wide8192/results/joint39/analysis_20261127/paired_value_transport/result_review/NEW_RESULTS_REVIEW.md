# 新结果复核：历史恢复优势与完整 value 矩阵的实际增量

日期：2026-11-27。实验事实固定于 `b26f644923646dcd9d853849cf58fdd122c55a54`；相对上一轮 `9dec5f1` 新增三个提交。学校新执行为 204479、204487、204740，本次分析环境只复算归档数值与源码语义，新增模型/GPU运行数为0。

## 结论与研究决定

**当前低噪历史方案已经在固定稀疏支持、固定P64、等权覆盖的SparsePR v2输出恢复对照中胜出；新增完整value通道矩阵则没有给现有centered对角方案带来稳定增量。** 保留centered对角解码作为工作参照，结束当前J256、lambda=.001、全128矩阵配方的全面推广。本轮结果保留为有效的机制消融。

上一轮对“历史路线可以胜过当前输出恢复”的中等偏积极判断，现在有了匹配实验支持。对新矩阵的期待则按本轮实测更新。完整SparsePR的RCP分组、probe选择、coverage权重和系统成本仍需在对应范围比较；本次没有SparsePR自由轨迹成片臂。

## 2. 已有历史方案对PFRR的优势

旧面板与新固定轨迹均为low、wide8192背景。以下是PFRR误差能量除以各自历史参照；来源内四层与来源间等权几何平均。十二站嵌套于三个反复使用的开发来源。

| 度量 | 旧面板：PFRR／OUT-D | 新固定轨迹：PFRR／centered |
|---|---:|---:|
| 完整128通道attention head | 4.8837 | 5.5667 |
| W_O＋gate点误差 | 3.9859 | 4.4242 |
| 同输入Dense块出口 | 未在这组旧对照测量 | 2.3044 |

新轨迹中centered的gated point平方误差约为PFRR的22.60%，同输入Dense块出口约为43.39%。这直接支持当前恢复方案在所测S/P接口下的实际优势。旧面板PFRR相对CAL32 OUT-ABS的gated point比也为1.5286；完整通道并未自动改善有限P64下的外推。

已检查PFRR完整S128、P64标准化、未惩罚截距、lambda=1、无输出截断和probe覆写。其FP64对偶求解与论文primal形式一致。64行居中输入的秩至多63，因此完整输入通道数与当前可识别的预测方向数应分别理解；当前数据支持历史/校准结构在这组估计预算下有效，并不单独证明任何current-S函数族都不能恢复目标。

## 3. 新矩阵在哪一阶段产生增量，又在哪一阶段失去优势

B/C/D保持相同的路由、rho、当前均值尺度、CAL32差分、attention ridge和P64；只替换历史解码ZD_t、ZM_C、ZM_D。

| 度量 | C／B | C／D |
|---|---:|---:|
| 留出value | 1.4235 | 0.0859 |
| P64前attention | 1.1888 | 0.1304 |
| P64后attention | 1.2154 | 0.1763 |
| W_O＋gate | 1.2091 | 0.1463 |
| 同输入Dense块出口 | 1.0841 | 0.3200 |
| Dense块空间邻边 | 1.0799 | 0.3877 |
| Dense块时间邻边 | 1.0675 | 0.3967 |

真实配对在所有这些指标上均12/12优于打乱配对；B已经保留位置对应，所以C/D说明对应关系有用，新增非对角自由度的价值仍由C/B判断。

第0层三个来源的value比为0.7761，attention底座比为0.8593，证明这里有实际可预测的通道变化。进入P64后变为1.0410，新更新能量只保留27.18%–35.91%。第13、26层在value留出和P64前底座就已经高于1，问题并非统一发生在后继FFN。样本泛化、全位置共享变换族与attention目标加权是不同的解释，现有收据不能将其中某一个直接定为唯一原因。

唯一的同输入Dense块净改善是0392/39：C/B=0.98249，而该站attention C/B=1.00698。块出口自身扰动与FFN背景交叉项分别贡献约0.808和0.943个基准误差百分点的降低。这再次确认attention与后继模块的方向关系会改变排序。

P64后记录输出的Gram还表明：C−B在12站都含有朝向目标的分量，后验最优幅度在0.106–0.601；逐站使用H448选择最优幅度后的几何比约0.9727。这只是两个已记录输出场的离线插值诊断，不是可部署系数或新生成轨迹，也不足以支持围绕系数开展大规模扫描。

## 4. 完整四步成片的实际结果

两臂初始噪声及前三步flow/latent逐字节相同，第3步分别运行完整40层。八条候选视频均完成。0128是对本次配对机制此前留出的来源；其余三个为DEV。

| 来源 | 最终latent/Dense相对L2，B→C | 差值，百分点 | RGB RMSE/Dense，B→C |
|---|---:|---:|---:|
| 0392 | 38.7464% → 38.8207% | +0.0743 | 0.154590 → 0.155050 |
| 0800 | 25.6956% → 25.6329% | −0.0627 | 0.113339 → 0.113620 |
| 1013 | 17.3738% → 17.4262% | +0.0524 | 0.088646 → 0.088909 |
| 0128，本机制留出 | 20.7991% → 20.8028% | +0.0037 | 0.087625 → 0.087746 |

latent/Dense只有1/4改善，RGB/Dense为0/4，帧间差分RMSE/Dense为1/4。四源描述性几何比分别为1.000667、1.002452、1.001163；三DEV与一留出分别保留，不把四源合并成独立确认。

两臂最终latent之间的相对L2为1.59%–2.19%，视频间RGB RMSE为0.02322–0.03806。因此新矩阵确实产生全局变化。令e=R−B、d=C−B，使用三组配对RMSE可恢复

\[
\|e\|^2-\|e-d\|^2=2\langle e,d\rangle-\|d\|^2.
\]

最终latent更新与Dense误差修正方向的余弦为−0.0191、0.0714、0.0141、0.0475，只有0800同时满足方向与幅度的获益条件。这描述的是该配对的欧氏几何；视频动作、纹理与语义需由原片判断。
