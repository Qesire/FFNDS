# 配对 value 的完整四步轨迹复核

此前固定轨迹的四臂消融保留为机制证据。局部的 H448 和块出口误差只能说明给定输入下的误差传播，不能决定候选自身的终点或成片。学校 A100 作业 `204740` 将对角运输和完整同位置配对分别接入模型的正常生成路径，全程运行四步、每步 40 层，直接保存两臂的 flow、latent 和解码视频。

实验在三个原开发来源 0392、0800、1013 及配对机制的一条留出来源 0128 上运行。两臂使用相同的起始噪声、源图、提示词、原生锚点和高噪恢复，FFN 均为 BF16 wide8192。低噪命中侧沿用冻结路由、CAL32、原生 P64 和旧值配对消融固定的 256 个位置。两臂唯一区别是对角解码和每头完整 128×128 配对通道矩阵。配对拟合使用 BF16 锚值样本和 FP32 岭回归与矩阵应用，均式目标的正则系数为 0.001。

前三个来源的 Dense 和原生 attention＋wide8192 控制来自原作业的签封张量与视频，0128 在本作业中同机生成两个控制。逐步张量相对 L2 以参照的范数为分母，视频像素 RMSE 使用同样的已解码 81 帧、像素范围 [0,1]。帧间差分比较与 Farnebäck 光流代理用于描述时间变化，画面内容与动作是否符合目标需结合实际视频。

## 完整轨迹与成片结果

两臂四个来源的初始及前三步 flow/latent 均逐字节一致。两臂均完成低噪命中的 40 层计算，共生成八条候选视频。三条开发来源复用六条封存参考，留出来源补跑两条参考。16 条 MP4 均通过学校记录的 SHA-256 核验。每项指标按对角 → 真实配对列出。
