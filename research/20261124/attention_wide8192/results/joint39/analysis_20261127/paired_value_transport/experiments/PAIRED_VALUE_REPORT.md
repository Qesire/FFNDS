# 全通道当前恢复与同位置 value 配对消融

实验方案固定于 [PR #65 的 9dec5f1](https://github.com/Qesire/FFNDS/commit/9dec5f1baf85c089b65dcbc142d0115fdf2308ae)。本轮使用四步 Wan I2V 的三个开发来源 0392、0800、1013，观测低噪专家第 2 步锚点到第 3 步命中，在第 0、13、26、39 层各测一次。误差比采用平方能量，来源内四层与来源间分别取等权几何均值。

## 旧面板的 SparsePR v2 恢复对照

学校作业 `204479` 读取原生 attention 与 BF16 wide8192 FFN 的封存面板，使用原来的稀疏输出 S、P64 标签和 H448 评分行。PFRR 保留全部 128 个当前输出通道，按 P64 逐头标准化，使用未惩罚的残差截距与和式岭回归系数 1，并覆写已观测的 probe 行。旧数据保留固定 P64，缺少 SparsePR 原生动态分组的覆盖元数据，本轮采用等权覆盖。[SparsePR v2 §4.2、A.3 与 C.2](https://arxiv.org/html/2608.18484v2)

| H448 误差能量 | PFRR / CAL32 OUT-ABS | 追平 OUT-D 所需上界 | PFRR / CAL32 OUT-D |
|---|---:|---:|---:|
| attention head | 1.6918 | 0.3464 | 4.8837 |
| 输出投影与 gate | 1.5286 | 0.3835 | 3.9859 |
| 空间邻边 | 1.9216 | 0.4537 | 4.2358 |
| 时间邻边 | 1.6154 | 0.3929 | 4.1119 |

PFRR 在四项指标、两个参照上均为 0/12 站胜出。PFRR/OUT-D 的 gated point 比在 0392、0800、1013 分别为 4.6105、3.5082、3.9151。重放的 CAL32 指标与封存指标最大相对偏差为 1.82×10⁻⁶。这个对照限定在已有路由、固定探针和低噪命中侧，验证的是 PFRR 恢复器在同输入下的误差。

## 固定轨迹四臂

学校 A100 作业 `204487` 将候选作为影子分支评估，公共轨迹由原生 self-attention 与 wide8192 FFN 生成。四臂使用同一个冻结支持、P64 和 H448。A 使用完整当前 S128 PFRR。B 使用已有的质量中心化对角解码。C 用同位置的 256 对 value 拟合每头 128×128 通道矩阵。D 将 C 的当前配对位置按固定全错位排列打乱，保留两侧样本的边缘分布。B/C/D 使用同一个 CAL32 跨步字典、attention 岭回归和 P64 覆写。三个来源共用由随机种子 `20261127` 抽取的 256 个拟合 key 位置及另取的 64 个 value 留出位置，配对拟合的均式岭回归系数为 0.001。

各阶段保存误差 Gram。对块出口，记 $e_a$ 为臂 $a$ 相对同输入 wide8192 块的偏差，$b$ 为该宽 FFN 块相对同输入 Dense FFN 块的偏差。到 Dense 的平方误差由 $\|e_a\|^2+\|b\|^2+2\langle e_a,b\rangle$ 复算。空间与时间邻边分别在同一组 H448 中计算。注意力标签来自公共轨迹本来执行的原生 attention，Dense 块参考额外计算 H448 的原生 FFN。

| 留出误差能量 | A / B | C / B | D / B | C / D | C 优于 B |
|---|---:|---:|---:|---:|---:|
| value 按位置预测 | — | 1.4235 | 16.5780 | 0.0859 | 3/12 |
| P64 校正前 attention | — | 1.1888 | 9.1180 | 0.1304 | 6/12 |
| P64 校正后 attention | 5.5667 | 1.2154 | 6.8956 | 0.1763 | 1/12 |
| 输出投影与 gate | 4.4242 | 1.2091 | 8.2638 | 0.1463 | 2/12 |
| 同输入 wide8192 块出口 | 4.1684 | 1.2180 | 7.2131 | 0.1689 | 1/12 |
| 同输入 Dense 块出口 | 2.3044 | 1.0841 | 3.3878 | 0.3200 | 1/12 |
| 同输入 Dense 块出口空间邻边 | 2.2653 | 1.0799 | 2.7851 | 0.3877 | 1/12 |
| 同输入 Dense 块出口时间邻边 | 2.1566 | 1.0675 | 2.6907 | 0.3967 | 0/12 |

真实配对在每项指标上均为 12/12 站优于打乱配对，说明相同位置的跨步对应携带可预测信息。三个来源的 C/B 在留出 value、恢复后 attention 与同输入 Dense 块出口三项上均大于 1。局部收益集中于第 0 层，该层三个来源的 C/B 几何均值在留出 value 为 0.7761，P64 校正前的 attention 为 0.8593，校正后为 1.0410，Dense 块出口为 1.0406。该信号进入已有 CAL32＋P64 恢复器后没有保留净收益。第 13、26 层在底座已存在配对误差的增量，校正后的 C/B 分别为 1.5449、1.3082。

唯一的 Dense 块出口净改善出现在 0392 第 39 层。以 B 到同输入 Dense 块出口的误差能量为分母，C 比 B 相对 wide8192 块出口的扰动平方项少 0.81 个百分点，与 FFN 背景的交叉项少 0.94 个百分点，合计少 1.75 个百分点。三个来源在第 0 层的两个差项均为正，Dense 参照下的差距受 FFN 背景关系进一步放大。

三个公共轨迹的初始噪声、四步 flow/latent 和解码视频哈希均与封存参考一致，12 站的 FFN 探针输入与在线教师调用一致。wide8192 原生分支的面板块出口与在线输出最大相对 L2 偏差为 5.03×10⁻⁶。冻结锚点代码因 FP32 LSE 单调性误差对 1173 个 head-query 行做了遗漏质量复算，原生 attention 教师调用次数保持原轨迹口径。

这个全矩阵方案未达到进入独立来源自由轨迹的验收条件。本轮到固定轨迹机制判断为止。四臂只参与影子评估，公共轨迹的生成时间只用于调试执行。

源码入口和复算方法见 [实验复算](REPRODUCE_EXPERIMENTS.md)。
