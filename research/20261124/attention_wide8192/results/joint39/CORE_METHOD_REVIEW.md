# 回到核心：恢复什么作用，保留什么状态，省去什么计算

日期：2026-11-25。证据固定于 FFNDS c5e4ee8168708a8e57cdb981103c4dbf715e3bfa。使用 evidence-analysis、operator-tensor-analysis 与 active-abstraction。本文结合实际回执复算、真实 CAL 矩阵的 NumPy QR/SVD、基于执行代码的算子重写及 SymPy 恒等式核验。新增模型/GPU执行数为 0；视频判断引用已归档人审，本轮没有重新解码视频。

**当前判断：跨模块方法已形成可继续确认的完整候选 C。下一项最有价值的证据，是已经生成的六对完整视频的人审。首步阶段换基已经按约检验并收束；更长远的问题是如何组织完整状态、廉价当前作用与稀疏真实观测，而不是继续微调同一个读出。**

## 1. 原始目标与可变实现

原始目标是：在相同输入图、文本条件、权重与采样任务下，用更少计算生成保留动作、时间连续性、空间关系和画面细节的视频。研究约束包括四步蒸馏模型、BF16 wide8192、真实稀疏教师、可用显存，以及完整生成周期。

可以改变的是昂贵作用的计算方式、保留状态、当前观测接口及其分配位置。当前实验中采用的 P64、32 列设计、选中 31 个 key blocks、原生/恢复交替时序，是具体实现选择。各自应由信息作用与成本解释，而不自动变成研究目标。

适合这一目标的抽象为：选择图上保留状态 S、当前廉价计算 L、稀疏真实观测 O 与恢复 R，使完整图的输出进入任务可接受集合，同时减少真实执行成本。这里“信息”指计算预算内实际进入恢复器的表示；原始权重与输入当然仍确定完整模型输出，不能把未计算的作用写成输入本身没有信息。

### 1.1 可恢复性要相对于信息接口和目标作用定义

在一组待处理状态 z 上，令 I(z) 表示恢复器实际可用的信息，H(z) 表示需要保留的目标作用。精确恢复 H=R∘I 的条件是：I(z₁)=I(z₂) 时，H(z₁)=H(z₂)。必要性来自同一输入只能得到同一恢复结果；充分性来自在每个相同观测的集合上定义其共同 H 值。允许误差时，应考察这些集合内部目标作用的差异，而不仅考察特征矩阵的秩。

这个条件本身不提供便宜的 R。实际方法还需要合适的表示族、观测稳定性、有限精度和可执行成本。模块恢复应以模块作用为 H；讨论成片时，则应把残差、其他模块、缓存更新和采样共同纳入 H。由单个 attention 分支的表示限制，不能直接推断整条生成图的信息限制。

## 3. 一个有区分力的重写：OUT-ABS 实际校正了什么

固定某一次调用和一个 head，令 B∈R^(N×128) 为 selected attention 输出，P_v∈R^(128×64)、T∈R^(64×31) 为固定投影。P64 拟合出的系数分成偏置 b∈R^(1×128) 与 W∈R^(31×128)，并把统一输出尺度吸收到系数中。

忽略内部 BF16 舍入，在非 probe 行有精确重写：

\[
\widehat A=B+[\,\mathbf1,\;BP_vT\,]\begin{bmatrix}b\\W\end{bmatrix}
=B(I+P_vTW)+\mathbf1b.
\]

因此，当前 OUT-ABS 是针对每个 head、在当前调用中由 P64 拟合的 **query 共享仿射通道校正**。W、b 随当前 P64 改变，具有动态性；一旦拟合完成，它们在这一 head 的所有非 P query 上共享。I+P_vTW 的改变量秩最多为 31。

阶段换基改变了校正子空间及 ridge 几何，仍然保留“由当前 B 构造 query 特征”的信息接口。这个具体过程解释了为什么一次阶段换基只在同一母族中移动。

### 3.1 关系方向比单个张量的秩更有说明力

对两个非 P query i,j：

\[
\widehat A_i-\widehat A_j=(B_i-B_j)M,\qquad M=I+P_vTW.
\]

在实数域中，对任意只作用于非 P 行、且行和为零的空间/时间差分算子 D：

\[
D\widehat A=(DB)M.
\]

这说明当前恢复器可以校正 selected 输出已经呈现的关系；它通过共享通道映射来改变这些关系的幅值与方向。若某一对 query 的 B_i=B_j，恢复器在这两行也给出相同 attention 输出。增加同一 B 派生特征的维数、改变 CAL 或 λ，仍保留“相同输入表示得到相同输出”的性质。

在 B_i=B_j 时，任意共同预测 m 满足：

\[
\|m-A_i\|^2+\|m-A_j\|^2
=
\tfrac12\|A_i-A_j\|^2+
2\left\|m-\tfrac{A_i+A_j}{2}\right\|^2.
\]

右侧第一项给出该对 query 在此信息接口下的误差下界。它不是对当前视频已经测得的下界，而是一个能检验表示是否合适的精确条件。

实际实现的特征是 BF16(BP_vT)。令 ε=BF16(BP_vT)−BP_vT，并将输出 cast 舍入记为 δ，实际差分还含 (Dε)W+Dδ；P 行最后直接覆盖原生教师。因此任意 D 的线性关系用于实数域分析，实际相同 B 行仍具有相同特征与预测的确定性。P64 教师使用全部 keys，其信息进入共享系数；“逐位置特征来自 B”与“只有 selected 信息”是不同的说法。这个结论只针对 attention 分支。主残差中的不同 h_i、位置/时间条件与后续 FFN 仍可产生差异，不能由此直接推出整个视频相同。

## 4. 锚点为什么改变恢复问题本身

### 4.1 跨模块的共同对象：廉价底座之外的有限创新

固定一个模块、层和专家，将输入与条件共同计入端点 s、a。Fₛ=F_m(zₛ;cₛ) 表示昂贵原生算子的响应值，Gₛ=G_m(zₛ;cₛ,Sₐ) 表示同一输出空间中的廉价底座响应；锚点响应按相应端点定义。令 Eₛ=Fₛ−Gₛ、Eₐ=Fₐ−Gₐ，则有精确恒等式：

\[
F_s=F_a+(G_s-G_a)+(E_s-E_a).
\]

保存 Fₐ，计算当前廉价变化 ΔG，并用 P 行真实观测约束 ΔE，可写出恢复器：

\[
\widehat F_s=F_a+\Delta G+\mathcal R(\Delta E_P),
\qquad
\widehat F_s-F_s=\mathcal R(\Delta E_P)-\Delta E.
\]

这里没有一阶 Taylor 或“小步长”前提。全响应 Fₛ 的恢复负担被移到廉价底座误差的有限变化 ΔE；它是否更有结构、更容易由 P 观测恢复，属于需要验证的数学与经验问题。恒等式可作为共同分析语言，方法的具体内容落在 G 的选择、ΔE 的可观测性、状态更新及完整周期成本上。

FFN 的当前线性底座和选中非线性变化可以按这一形式组织；low attention 则具有自己的全键锚点、selected 输出与质量字段。两类模块可以共享“保留完整状态、恢复有限创新”的原则，同时使用各自的计算结构。

### 4.2 当前 C 的具体组织

以 C 的 low OUT-D 为例，在实数域中：

\[
\widehat A_{s,i}
=A_{a,i}+(1-\rho_{a,i})(B_{s,i}-B_{a,i})
+(B_{s,i}-B_{a,i})L+b.
\]

A_a 与 ρ_a 是逐位置字段。它们将先前完整计算产生的 query 差异直接带入当前结果；共享系数需要估计的是剩余创新。冻结锚点支持与 ρ_a，取 Gₛ=(1−ρ_a)Bₛ，即得到上面的共同形式，Fₐ−Gₐ 对应缓存的 uₐ。当完整有效 Q/K/V、支持和算子条件均回到锚点，在理想实数域中底座回到原生锚点响应、P 创新为零，恢复项也为零；仅 Bₛ=Bₐ 还不足以保证原生响应相同。实际缓存、特征和输出格式另有舍入。

这与从 B_s 重新回归整个 A_s 的负担不同。FFNDS 的核心可以表述为：

> 保存已经支付成本得到的全位置结构；计算当前能够廉价取得的真实变化；由少量真实观测约束剩余创新。

当前 C 是混合组织：FFN 与 low OUT-D 使用锚点和创新；high step1 OUT-ABS 使用当前 P64 的共享通道校正，并没有缓存 high attention 的逐位置原生输出。high step0 的原生计算同时参与形成后续 latent、FFN 锚点与路由。因此，C 的证据支持这一完整组合；它还没有单独隔离出每个状态字段对最终动作的因果贡献。

逐位置锚点直接携带先前原生响应中的空间和时间差异，减少当前读出从少量位置重新建立这些差异的负担。C0 把其中一个完整状态构建阶段交给了仅以当前 B 构造 query 特征的 OUT-ABS。这个差别是可由代码核查的机制差别。

这也避免把“初始化必定要原生”写成普遍原则。真正需要研究的是：某一计算阶段缺少既有状态时，可以用什么当前信息建立同样有用的状态；存在锚点时，剩余创新需要哪些观测即可恢复。

进一步迁移到其他模块时，可以据此检查五个实际条件：廉价当前作用是否覆盖有用变化；全位置状态的保存是否合算；稀疏真实教师是否确实便宜；剩余作用在所用恢复族中是否可由这些教师稳定识别；复用次数是否足以偿还建锚和恢复开销。不同模块应分别回答这些条件，再进入联合生成图验证。

## 5. 联合作用如何进入这个问题

将 attention 后的残差与 cross 记为 T(A)，FFN 输入记为 U(A)，门控记为 G_F。固定当前入块状态和条件后：

\[
B(A)=T(A)+G_FF(U(A)).
\]

对候选 attention 与 FFN，完整块误差在实数域精确拆成：

\[
\widehat B-B^*
=
[T(\widehat A)-T(A^*)]
+G_F[F(\widehat U)-F(U^*)]
+G_F[\widehat F(\widehat U)-F(\widehat U)].
\]

三项分别是 attention 直接作用、真实 FFN 对改变后输入的响应、FFN 自身恢复误差。它们的方向和交叉项决定完整块效果。当前方法已经在相同 P 行依次计算原生 attention、cross 与 FFN，能够保留模块教师的结构约束；将它们最终投影成一个很低维的终端标签，会改变实际保留的辨识信息。之前 D176 的结果已经为这一区别提供了实验边界。

跨步时还应保留 (latent, FFN anchors, attention routes) 的联合状态。某个缓存值正确地对应候选自己的输入，确保定义相容；生成任务是否保持，则由整条联合轨迹回答。因此下一次真正改变方法的动作，应说明它新增/保留了哪种当前作用或历史状态，而不仅给出一个新的局部拟合分数。

## 6. 一条可计算的新接口示例：把遗漏的当前交互重新带入计算

以下是说明“改变信息来源”的一个具体构造，尚未实施，也不作为继续 C0 的自动任务。它用于与在 B 上换基区分。

对一个 query/head，q、k 使用 norm/RoPE 等处理之后实际进入 attention 的操作数。selected blocks 使用已有精确输出 B_i 和归一化分母 Z_i^S。对每个遗漏 key block b，当前可计算：

\[
n_b,\qquad
\bar k_b=\frac1{n_b}\sum_{j\in b}k_j,\qquad
\bar v_b=\frac1{n_b}\sum_{j\in b}v_j,
\qquad
\bar z_{ib}=n_b e^{q_i\bar k_b/\sqrt d}.
\]

定义：

\[
\widetilde A_i=
\frac{Z_i^SB_i+\sum_{b\notin S_i}\bar z_{ib}\bar v_b}
{Z_i^S+\sum_{b\notin S_i}\bar z_{ib}}.
\]

它直接读取当前 query 与遗漏 K/V 的粗粒度作用，因此两个 B_i 相同的 query 仍可能得到不同的遗漏质量与 value 响应。若每个遗漏 block 内 key 完全相同，块内 value 任意，则这一合并在实数域精确。实际实现可用 selected/coarse 两组 LSE 做稳定加权合并。

### 6.1 有限误差的精确来源

令 block 内 k_j=bar k_b+δk_j、v_j=bar v_b+δv_j，并设 s_ij=q_iδk_j/√d。对块内均匀平均定义：

\[
a_{ib}=\mathbb E_b[e^{s_{ij}}]-1,\qquad
c_{ib}=\mathbb E_b[(e^{s_{ij}}-1)\delta v_j].
\]

其中 a≥0 由 E_b[s]=0 和 Jensen 得到。完整 block 贡献为

\[
Z_{ib}=\bar z_{ib}(1+a_{ib}),\qquad
N_{ib}=\bar z_{ib}[(1+a_{ib})\bar v_b+c_{ib}].
\]

因而真实 attention 与上述粗细合并满足精确有限等式：

\[
A_i-\widetilde A_i
=
\frac{
\sum_{b\notin S_i}\bar z_{ib}
\{a_{ib}(\bar v_b-\widetilde A_i)+c_{ib}\}
}{
\widetilde Z_i+\sum_{b\notin S_i}\bar z_{ib}a_{ib}
}.
\]

这将剩余问题具体化为块内 score 波动产生的质量修正，以及 score/value 相关作用。它没有假设整个 anchor→hit 变化足够小，也没有把一阶切线当作全局近似。

### 6.2 真实形状下的静态代价

本模型 N=31668、40 heads、每头128维、block128，共248块。31块精算，217块参与粗算：

- 若只计算217个遗漏块，新增 coarse QK/PV 成对项约为完整 attention 的 **0.685%**。
- 若实现为计算全部248块再屏蔽，约为 **0.783%**。
- 当前层 K/V 两份 block 均值使用 FP32 时净载荷约 **9.69 MiB**，属于临时当前状态。
- 若单独保存全行 coarse 输出，BF16 约 **309.26 MiB**，LSE FP32 约 **4.83 MiB**。
- 将 N×40×248 scores 全部物化会占约 **1.17 GiB**，因此应使用流式归约。

这些是实际模型尺寸下的算术量与净载荷，不是实测加速。K/V 归约、支持掩码、归一化合并、输出工作区和 kernel 形状都会影响执行时间。原 C 仍保留 low 锚点，使用这项当前计算本身不会自动减少它的约15.19GiB low attention 状态。

### 6.3 方法品味与先例

“稀疏精算加全局低成本响应”已有直接先例。SLA 在视频 DiT 中组合 sparse 与 linear attention 并微调；SPLA 将未选块的残余 linear 作用写为 global 减 selected；AB-Attention 则通过按 inclusion probability 加权的块采样估计完整 attention。这些工作在信息入口、归一化与训练要求上不同，但都提示：保留遗漏交互是值得明确建模的作用。

这里的粗细合并应作为具有精确条件和代价的接口示例，而不是新的首创主张。与当前研究更贴近的问题是：这样的当前作用怎样与全位置锚点、有限创新、稀疏真实观测以及跨模块状态组织共同工作。是否投入该路线，应由 C 的完整结果和剩余计算/显存预算决定。

原始资料：[SLA](https://arxiv.org/html/2509.24006v2)、[SPLA](https://arxiv.org/html/2601.22379v1)、[AB-Attention](https://arxiv.org/abs/2610.39663)。

## 7. 当前应采取的研究次序

1. 完成已经生成的六对完整视频盲审，以动作、时间连续性、布局/遮挡和细节判断 C 的质量范围。模型代码与配方已经冻结，不需要继续改变恢复器来完成这一证据。
2. 同时保留 full-request 与 denoiser 两个成本边界。保存长尾是实际用户等待的一部分；去除保存阶段的诊断用来定位执行阶段，不能替代正式总耗时。已有12个请求的保存时间戳可先解释边界，只有剩余问题会改变部署判断时再复测相应阶段。
3. 将 C0 与 phase0CAL 的既有分支收束为信息接口边界。今后的方法提案需指出它引入什么当前作用、保留什么历史场，或减少哪项真实状态/执行成本；在相同信息母族内继续调参数的收益已不应占据主线。
4. 若 C 通过独立成片判断，完整方法的重点转向跨模块组合的机制表述、公平基线与实际质量—时间—显存结果。进一步扩大替换范围是一条后续研究轴，其价值由额外收益和所需信息共同决定。

本轮核心认识是：保留完整状态的模块可以将恢复目标改写为当前创新；首步全层 OUT-ABS 则要求一个共享仿射通道校正仅以当前 selected 表示和 P 教师建立完整作用。前者已经在 C 的组合中形成可测的周期收益；后者的当前构造给出了明确的表示边界。明确两种恢复负担，才能选择真正改变问题的下一步。
