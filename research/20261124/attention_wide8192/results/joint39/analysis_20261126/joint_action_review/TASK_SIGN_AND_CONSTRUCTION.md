# 从共同探针到任务收益的可辨识条件

依据：证据提交 `6baa2a44ffaac5cd90d9a4f4df81809a651a784d`，A100 作业 `201276`；两条 native-attention + wide8192 固定轨迹，16 个嵌套站点。本文使用归档 Gram 的真实数值，并将直接代数推导及合成反例分别标明。没有新增模型运行。

## 1. 已知的运输方向与仍需观测的关系

固定一个专家、层、命中步和 head。令查询轴为 \(q\)，value 通道轴为 \(c\)，\(P\) 选择 64 个查询。当前特征 \(\Psi\)、探针特征 \(\Psi_P=P\Psi\) 和 ridge 参数固定，定义

\[
K=\Psi(\Psi_P^\top\Psi_P+64\lambda I)^{-1}\Psi_P^\top,
\qquad M=I-P^\top P,\qquad L=M(I-KP).
\]

\(K\) 只作用于查询轴。\(M\) 表示最后将探针覆盖为真实值；\(L\) 一般不是正交投影。若历史底座为 \(E\)，预测及误差为

\[
\widehat A_E=M\{G+E+KP(A-G-E)\}+P^\top PA,
\qquad \widehat A_E-A=-L(A-G-E).
\]

令 \(C_a=(A_a-G_a)D_a^+\)，在活跃通道上 \(E_a=C_aD_a\)。raw 和 transport 只改变历史项，因此实数计算下

\[
\boxed{\widehat A_t-\widehat A_r=L\big[C_a(D_s-D_a)\big].}
\]

这是**已知缓存、当前尺度和既有恢复算子**产生的更新方向。它不需要新的原生 attention 标签。查询轴的恢复与通道轴的缩放可交换，\(L(CD)=(LC)D\)；实际代码的 BF16 舍入和独立 FP32 路由重算仍按各自证据处理。本文合成核验最大差分别为 \(1.11\times10^{-15}\) 和 \(1.78\times10^{-15}\)。

这也给出一个确定的可执行族：对预先指定的 \(\alpha\)，用历史项 \(E_a+\alpha C_a(D_s-D_a)\)，复用同一批当前 P64 教师、同一特征和一次拟合，得到

\[
\widehat A_\alpha=\widehat A_r+\alpha L[C_a(D_s-D_a)].
\]

已有 raw 与 transport 是 \(\alpha=0,1\)。这个恒等式说明如何生成预定更新；**它没有决定哪个 \(\alpha\) 对未知留出位置或完整视频更好**。本文没有使用 H448 选取新的在线参数。若缓存仅保存标准化 \(C_a\)，实现此整个族还需保存每 head/channel 的 \(D_a\)；无需增加第二份逐查询历史场。

### 共同 P 的具体含义

上述更新满足 \(P(\widehat A_t-\widehat A_r)=0\)。因此，覆盖之后的 attention P64 误差完全相同。在本次 Wan 图中，固定块输入和文本条件，输出投影、门控、残差、逐 token 归一化及 cross-attention 的查询路径保持同一行的依赖；于是这两个分支的 FFN P64 输入也相同，可共用现场捕获的原生 FFN 标签和一次 fitted state。16 站点的真实记录支持这个闭合接口。

这一事实只约束**覆盖后的同一组 P 输出与其共享下游探针**。当前 Q/K/V、覆盖前 innovation、特征、历史状态和当前尺度仍包含其他信息。完整 Q/K/V 通过真实模型确定 attention，问题是指定计算预算和查询接口能否经济地获得所需目标关系。不能把探针处相等推广成“所有生成时信息都无法区分候选”。

## 2. 路由、形状与尺度通过恢复算子后分别留下什么

令 \(R_s=S_s-S_s^0\)，其中 \(S_s^0\) 是当前 selected + grouped 的规范化注意力核。因 \(R_s\mathbf1=0\)，有 \(A_s-G_s=R_s\widetilde V_sD_s\)。在同一固定支持和成员标签上，定义

\[
u_r=(R_s-R_a)\widetilde V_sD_s,\quad
u_h=R_a(\widetilde V_s-\widetilde V_a)D_s,\quad
u_d=C_a(D_s-D_a).
\]

raw innovation 等于 \(u_r+u_h+u_d\)，transport innovation 等于 \(u_r+u_h\)。评分的比较对象是 \(L(u_r+u_h+u_d)\) 和 \(L(u_r+u_h)\)，保留所有交叉项。尺度运输的净收益为

\[
\|L(u_r+u_h+u_d)\|^2-\|L(u_r+u_h)\|^2
=\|Lu_d\|^2+2\langle L(u_r+u_h),Lu_d\rangle.
\]

因此尺度本身变化大，并不足以判断其收益。新实验测到了上述关系：第 0 层四个站点的净尺度惩罚为 raw 恢复后剩余能量的 **40.59%–44.53%**，这说明当前探针与特征恢复之后，继续沿用历史尺度仍留下了很大的可消除误差。

逐分项“恢复后／恢复前”能量如下。它们是当前恢复算子的方向作用，不能当作方差解释率或唯一的观测秩。

| 来源 / 步 / 第 0 层 | 路由项 | 形状项 | 尺度项 |
|---|---:|---:|---:|
| 0392 / 1 | 47.76% | 26.69% | 26.38% |
| 0392 / 3 | 44.19% | 44.74% | 19.60% |
| 1013 / 1 | 48.71% | 33.24% | 26.49% |
| 1013 / 3 | 53.01% | 53.11% | 19.17% |

中间层的路由项通常接近 100%，例如 1013 low13 为约 104.0%。这种上升允许发生，因为 \(L\) 不是正交投影。结果支持“第 0 层这几类变化在当前接口下较容易恢复”，还没有把剩余误差单独归因于点位数量、特征表达或拟合正则化。\(\widetilde V\) 本身的相对变化更小，也不能替代 \(R_a(\widetilde V_s-\widetilde V_a)\) 的作用测量。

## 3. 联合尾部的收益由方向投影支付更新代价

设 \(T_\theta\) 是固定当前条件、固定共享 FFN 拟合状态的实际 wide8192 尾部。对于两个已运行分支，定义有限量

\[
z_r=T_\theta(\widehat A_r)-T_\theta(A),\quad
z_t=T_\theta(\widehat A_t)-T_\theta(A),\quad d=z_t-z_r.
\]

设同一块输入上的 Dense 背景为 \(b=T_\theta(A)-T_{Dense}(A)\)，则 raw 到 Dense 的误差为 \(e_D=b+z_r\)。两个分支的准确有限差满足

\[
\Delta_D=\|b+z_t\|^2-\|b+z_r\|^2
=2\langle e_D,d\rangle+\|d\|^2.
\]

当两个范数非零时，transport 改善的充要条件为

\[
\boxed{\cos(e_D,d)<-\frac{\|d\|}{2\|e_D\|}.}
\]

这比“更新与旧误差方向相反”更强。真实 Gram 说明两来源 low39 的差异恰好落在此处：

| 站点 | \(\cos(e_D,d)\) | 改善阈值 | 到 Dense 能量变化 |
|---|---:|---:|---:|
| 0392 high0 | −0.46651 | −0.31521 | −41.64133 |
| 1013 high0 | −0.42758 | −0.29397 | −38.80405 |
| 0392 low0 | −0.46614 | −0.26365 | −7.77426 |
| 1013 low0 | −0.42378 | −0.25302 | −7.14242 |
| 0392 low39 | −0.12177 | −0.09480 | −2.39789 |
| 1013 low39 | −0.03404 | −0.06470 | +2.66242 |

1013 low39 的更新也具有负方向投影；其负交叉项不足以抵偿更新的平方能量。这个判断直接由两个实际分支的出口 Gram 得到，不使用局部线性化。

定义归一化符号余量

\[
m=-\frac{\Delta_D}{2\|e_D\|\|d\|}.
\]

若仅考虑固定更新 \(d\)，再给未知误差扰动 \(\eta\) 一个欧氏球约束，则 \(\|\eta\|/\|e_D\|<m\) 是保持改善符号的充分条件。四个第 0 层站点的 \(m=0.1336\)–\(0.2025\)，0392/1013 low39 分别为 \(+0.02698/-0.03067\)。这是已测几何的敏感性尺度，不是抽样置信区间，也未约束真实新来源或非线性轨迹变化。

### 门控与残差需要分别看待

两来源 high0 的未门控 FFN 响应能量比分别为 0.8276/0.8387；施加 FFN gate 后却是 1.1682/1.0878；最终块出口仍为 0.6714/0.6957。门控改变了输出方向的权重，残差合成再加入其真实交叉作用。这个测量支持逐阶段、有限方向上的目标判断，不能简化成一种统一的“FFN 总会修复 attention”机制。

## 4. 下一步所需信息可以弱于完整误差恢复

以下是固定线性化对象上的直接命题，与上节无须线性化的真实有限量分开。

固定可用 side information 和候选 attention 更新 \(d_A\)，把未知当前 attention 误差限制为 \(e=e_0+Ua\)。实际观测是 \(o=Oa\)。假设当前尾部线性化 \(J\) 与 Dense 背景 \(b\) 已知，则目标改变量为

\[
\Delta_D(a)=c+2\,d_A^\top J^\top JU a,
\]

其中 \(c\) 包含 \(e_0\)、\(b\)、\(d_A\)。整个标量改变量能由观测恢复，当且仅当

\[
\boxed{\ker O\subseteq\ker(d_A^\top J^\top JU).}
\]

证明：若两个参数相差 \(v\in\ker O\)，目标差为 \(2d_A^\top J^\top JUv\)，故必要；反之目标在每个观测纤维上为常数，能在 \(\operatorname{range}O\) 上定义相应线性读出。若所有纤维方向无界且该条件失败，同一个观测可使 \(\Delta_D\) 取任意正负值。只有收益符号而非完整标量被要求、且未知集合有界时，还可利用目标余量与扰动上界给出较弱的区间证书。

这个条件比恢复完整下游变化的 \(\ker O\subseteq\ker(JU)\) 弱。合成例：\(O=(1,0)\)，\(J=U=I_2\)，\(d_A=(1,0)^\top\)。第二个误差分量完全未知，但它不影响沿第一方向更新的收益。反例：把 \(d_A\) 换成 \((0,1)^\top\)，误差 \((0,-1)^\top\) 与 \((0,1)^\top\) 具有相同观测，却分别产生能量变化 −1 和 +3。

若背景本身也未知，需将其允许变化纳入未知向量。比如 \(b=b_0+Va\)，判据中的行泛函改为 \(d_A^\top J^\top(JU+V)\)。已归档 H448 Dense 背景使本轮可以事后算出这一项；生成时的免费可用性仍需具体构造。

上述例子是**指定压缩观测、固定 side information 的受限模型**。它不声称真实网络在保持全部 Q/K/V 不变时能有不同输出，也没有用两个已看 DEV 来源证明真实变化子空间 \(U\) 或其可辨识秩。

## 5. 从当前证据形成的构造方向

可以将原来的“是否恢复整个 attention 场”细化成三件有不同信息路径的事：

1. 利用缓存和当前尺度直接生成 \(L[C_a(D_s-D_a)]\) 这一已知更新。第 0 层的真实分解显示，它能在既有 P64 恢复之后消除可重复的尺度惩罚。
2. 保留共同精确 P 接口，使后继 FFN 的当前输入和拟合状态闭合。这是计算图上的复用关系，已由本次 16 站点验证。
3. 对这个已知方向研究目标收益所需的单个方向泛函，而不是先要求估计完整 Jacobian 或恢复所有误差。当前真实 Gram 已测到所缺的投影；下一构造需用生成时已存在的信息，或明确付费的新观测，逼近这个泛函。

一个有区分力的后续证据是：在独立 CAL 来源上，固定原 P64、特征、\(\lambda\) 和缓存机制，仅检验候选低成本目标泛函对 **收益符号与余量** 的预测；再在未用于构造的来源做同一检验。先明确该泛函实际读取哪些量及其成本，不能用已经覆盖为相同值的 P 误差作“在线验证”，也不能把 H448 Gram 伪装为推理时可用信息。

若该泛函要穿过完整尾部，单方向 JVP 或有限差分比完整 Jacobian 更贴合目标，但它们仍有实测费用，BF16 分支的有限响应也不自动由光滑 JVP 保证。新证据当前最强地支持“已知结构运输 + 任务方向判断 + 闭合探针接口”的研究对象；一个可靠的、低成本的目标方向读出仍是需要完成的操作。

每个 anchor 只服务一个 hit，所以构建 \(G_a\)、编码历史场、统计尺度、读写缓存和当前恢复的费用必须在这一周期比较。本文恒等式没有消除这些费用，也没有把第 0 层的相对收益自动换算成整网加速或视频质量提升。
