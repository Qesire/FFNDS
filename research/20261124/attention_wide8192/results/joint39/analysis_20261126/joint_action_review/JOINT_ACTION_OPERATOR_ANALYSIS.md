# 从联合作用证据推进到可运输状态与任务读出

分析日期：2026-11-26。实验依据：FFNDS 提交 6baa2a44ffaac5cd90d9a4f4df81809a651a784d，学校 A100 作业 201276。对照上一轮分析提交 51b6e235964df2f1fb1370604387cb9c998f6591。本次分析使用更新后的 operator-tensor-analysis、active-abstraction 和 evidence-analysis，实际完成归档真实 Gram 的 NumPy 复算、源码审查、方向读出推导，以及新缓存构造的 SymPy/合成数值核验。

## 1. 现在可以确立什么

这轮证据将方法推进了三个层次。

**第一，历史状态的结构运输已经有可重复的真实作用解释。** 两来源、两专家的第 0 层，运输使实际 attention 拟合误差能量下降 40.48%–43.67%，固定 wide8192 尾部的块出口能量下降 30.43%–46.21%，同块输入的 Dense 目标能量下降 15.71%–21.35%。尺度分项的方向与交叉项解释了这些收益，也解释了部分深层沿用旧尺度反而较好的现象。

**第二，目标已具体到“门控、残差与 FFN 组成的实际读出”。** 新数据直接测到中间 FFN 响应、门控响应和完整块出口的不同排序，也测到了 Dense 背景造成的中间排序翻转。最终块出口是本轮完整局部目标，视频生成质量则仍由整个去噪轨迹决定。

**第三，现有资产足以定义一个更轻的运输构造。** 冻结 C 的 low OUT-D 缓存有非零遗漏概率质量。按该质量去除 value 均值，再以当前均值和尺度解码，可以复用已有 selected attention 和完整历史槽。这个候选具有明确的精确作用类与信息路径；本轮完成数学参考，尚未将它记为 Wan 实测结果。

整体推进方向是：先利用当前可计算结构搬运历史作用，再让探针处理剩余创新，并用实际后继读出评价哪些恢复有价值。P、rank、λ 的进一步扫描不是这轮证据引出的主要问题。

## 2. 新证据的身份与复核

两条轨迹为原生 self-attention + BF16 wide8192 FFN，来源 0392、1013；每条读取命中步 1/3 的层 0/13/26/39，共 16 个嵌套站点。每站用 P64 真实教师和 H448 留出，记录 10 个阶段的两误差 Gram，并在 FFN 响应、FFN gate 和块出口加入同输入 Dense FFN 背景。

独立复算确认：

- 160 个逐阶段 2×2 Gram、48 个背景 3×3 Gram、48 个创新 Gram，共 256 个矩阵通过有限性、对称性和半正定检查。
- 归档汇总的 1,924 个数值字段逐项一致。
- 两来源的初始值、四步 flow、latent、RGB/MP4 和专家身份均复现历史 194188；0392 的 attention 能量与 198062 一致。
- 16 处 FFN P64 输入与现场捕获输入的相对差均为零；原生回放尾部与现场块出口最大相对 L2 为 \(5.96227\times10^{-6}\)。

统计单位仍为两个来源。raw 是当前两组底座内的“未运输历史”机制对照，不是冻结 C。Dense 背景是同一当前块输入上的原生 FFN，不是另一条 Dense 整轨迹。[原始结果](../joint_action/JOINT_ACTION_REPORT.md) · [独立数值复核](JOINT_NUMERIC_AUDIT.md) · [真实计算图语义](RUNTIME_SEMANTICS_AUDIT.md)

## 3. 尺度运输为什么在第 0 层有效

固定一个 head，\(S_t\) 为完整 attention 的 query×key 权重，\(S_t^0\) 为 selected + 当前两组摘要定义的同归一化权重，\(R_t=S_t-S_t^0\)，所以 \(R_t\mathbf1=0\)。value 在 key 轴中心化并逐通道标准化：

\[
V_t=\mathbf1\mu_t^\top+\widetilde V_tD_t,\qquad
A_t-G_t=R_t\widetilde V_tD_t.
\]

固定当前特征、P64 和 ridge，记 \(K\) 为探针到全场的线性提升，\(L_H=M_H(I-KP)\) 为留出剩余算子。它通常不是正交投影。定义：

\[
r=L_H[(R_s-R_a)\widetilde V_sD_s],\quad
h=L_H[R_a(\widetilde V_s-\widetilde V_a)D_s],
\]
\[
s=L_H[R_a\widetilde V_a(D_s-D_a)].
\]

在该实数分解中，transport 剩余为 \(x=r+h\)，raw 剩余为 \(x+s\)。于是移除旧尺度项的净收益为

\[
\boxed{\|x+s\|^2-\|x\|^2=\|s\|^2+2\langle x,s\rangle.}
\]

尺度改变的幅度和它与其他误差的方向共同决定收益。真实 Gram 给出：

| 已测站点 | \(\|s\|/\|x\|\) | \(\cos(x,s)\) | 去掉尺度项的净收益／raw |
|---|---:|---:|---:|
| 0392 high0 | 0.8656 | −0.0103 | +42.24% |
| 1013 high0 | 0.8255 | +0.0011 | +40.59% |
| 0392 low0 | 0.7842 | +0.1198 | +44.53% |
| 1013 low0 | 0.7251 | +0.1550 | +42.88% |
| 0392 high26 | 0.0837 | −0.5417 | −9.14% |
| 1013 high26 | 0.0674 | −0.4910 | −6.57% |
| 0392 high39 | 0.1043 | −0.3625 | −6.92% |
| 1013 high39 | 0.0852 | −0.2522 | −3.71% |

第 0 层旧尺度误差与剩余创新近乎正交或略同向，移除它稳定降低能量；上述深层的小尺度项与其他误差明显反向，原历史单位带来了净抵消。这个差别由实际内积给出，无需将层编号本身当作机制。

独立分解使用 FP32 全键作用，和实际 BF16/FP32 路径的物理缺陷最大相对 L2 差为 2.04%；四个第 0 层独立拟合比与实际结果的差不超过 0.008614。因此它是有数值对照的机制见证，实际效果继续由实际 BF16 分支评分。

### 现有接口恢复的是作用后的创新

第 0 层运输创新经过当前 P64/特征/ridge 后保留 31.13%–46.58% 的能量，其他十二处保留 70.95%–103.09%。低噪第 39 层标准化 V 的变化只有 0.211–0.228，甚至小于第 0 层的 0.275–0.301，恢复却更弱。

由此得到的研究对象是 \(R_a\Delta\widetilde V\) 与 \(\Delta R\,\widetilde V_s\) 通过当前恢复和后继读出的作用。单独的 V 变化范数不能代替它。当前恢复比例也不能独自区分特征表达、点位观测和正则化的贡献，更不能作为 P64 的信息论下界。

### Dense 背景的交叉作用

固定当前块输入、条件和共享 FFN 拟合参数，令

\[
z_m=T^{wide}_\theta(\widehat A_m)-T^{wide}_\theta(A),\qquad
b=T^{wide}_\theta(A)-T^{Dense}(A).
\]

则到 Dense 的有限能量变化严格为

\[
\boxed{
\Delta_D=(\|z_t\|^2-\|z_r\|^2)
 +2\langle b,z_t-z_r\rangle.
}
\]

0392 low39 的 FFN gate 在固定 wide 下改善（0.91284），背景交叉项 \(+3.77318\) 超过原改善 \(-2.58139\)，到 Dense 后变为 1.00780；同站完整块出口则为 0.98977。另有两处中间翻转。16 处块出口的 wide/Dense 改善符号一致，其中 11 处改善；这个事实限定在块出口。

## 5. 当前缺少的信息可以进一步精确定义

令 \(d=z_t-z_r\)、\(e_D=b+z_r\)。两个实际分支的有限比较满足

\[
\Delta_D=2\langle e_D,d\rangle+\|d\|^2.
\]

因此有收益的准确条件为

\[
\boxed{\cos(e_D,d)<-\frac{\|d\|}{2\|e_D\|}.}
\]

| low39 | 实测余弦 | 改善阈值 | Dense 能量变化 |
|---|---:|---:|---:|
| 0392 | −0.12177 | −0.09480 | −2.39789 |
| 1013 | −0.03404 | −0.06470 | +2.66242 |

两个更新都带有反向分量；只有 0392 的反向投影足以支付更新能量。这比“存在反向误差”更能区分两个来源。

### 已知更新与收益判断是不同的信息任务

固定当前特征及 P64，在实数域两种历史底座的预测差为

\[
d_A=M_{\bar P}(I-KP)[C_a(D_s-D_a)].
\]

这个方向由当前尺度、历史缓存和现有恢复算子给出。共同 P 覆写使 \(Pd_A=0\)，后继 FFN 的同一组 P 输入和拟合也闭合。因此共同 P 的覆写后误差不能继续给出 H 上的两分支优劣；覆盖前 innovation、当前 Q/K/V、特征和其他状态仍可能含有判别信息。

用 skill 中任务因子分解的判据，可以把待研究信息进一步缩小。以下是固定线性化、受限误差模型上的直接推导：设未知 attention 误差 \(e=e_0+Ua\)，观测 \(o=Oa\)，已知候选更新 \(d_A\)、尾部线性化 \(J\) 及 Dense 背景。收益中未知的部分只有

\[
2d_A^\top J^\top JU a.
\]

因而该标量可由观测确定，当且仅当

\[
\boxed{\ker O\subseteq\ker(d_A^\top J^\top JU).}
\]

它弱于完整目标恢复要求的 \(\ker O\subseteq\ker(JU)\)。若背景也未知，必须把其变化并入未知量。这提供了一条具体研究方向：为已知结构更新获得足够的任务方向信息，可以先于恢复全部误差场或完整 Jacobian。

该命题针对指定压缩接口和允许变化，不声称完整 Q/K/V 缺少确定输出的信息；本次真实 Gram 也没有给出完整变化子空间或在线廉价 \(J\)。证明、实际方向数值与合成反例见 [任务读出推导](TASK_SIGN_AND_CONSTRUCTION.md)。

## 6. 把结构运输接回已有 C 的轻量构造

冻结 C 的 low OUT-D 实际历史是

\[
u_a=A_a-(1-\rho_a)B_a,
\quad \operatorname{base}^{old}_s=(1-\rho_a)B_s+u_a.
\]

这里的历史权重行和为 \(\rho_a\)，不是零。直接照搬零质量缺陷的标准化会遗漏 value 均值的变化。令 \(\mu_t,D_t\) 为当前 key 轴 value 均值与通道标准差，定义

\[
\boxed{
C_a=(u_a-\rho_a\mu_a^\top)D_a^+,\qquad
\operatorname{base}^{new}_s
=(1-\rho_a)B_s+\rho_a\mu_s^\top+C_aD_s.
}
\]

标量 \(1-\rho_a\) 按 query 广播；完整 \(C_a\) 保留每个 query 的历史。该底座在实数域返回锚点；在完整/selected 权重固定且 value 按正对角仿射映射演化时精确。两时独立 affine 坐标下的底座等变性也成立，但保留旧 OUT-D 特征不自动证明整个恢复器等变。

本候选选择直接用 BF16 \(C_a\) 替换旧历史槽，使用原 selected 输出、原 P64 与原特征。这样不增加第二份全位置缓存，也不要求两组 G 的全 query 构建。anchor 编码、当前统计、解码和写回都计入一次 anchor→hit 周期；归约和流量仍需付费。只自然作用于已有 low OUT-D，high OUT-ABS 没有对应历史槽。

已用真实源码绑定、SymPy 和 128 通道合成见证核验：anchor 最大差 \(2.22\times10^{-15}\)，仿射演化重建差 \(1.42\times10^{-14}\)，独立两时底座等变差 \(1.77\times10^{-13}\)，固定 P64 恢复差恒等式 \(4.44\times10^{-15}\)。这是可实现的候选构造及数学参考；其真实 BF16 编码误差和 Wan 任务收益还需要实际运行。[完整定义与成本](MASS_CENTERED_LOW_CACHE.md) · [核验程序](verify_mass_centered_transport.py)

## 7. 继续推进的判断

**已有成果足以继续研究结构运输，并将重点转向在已验证系统里经济地保留它。** 第 0 层两来源的作用结果、Dense 背景和共享 P 接口都支持这一决定。新的低噪声缓存运输给出了具体操作；目标方向的可辨识判据说明下一层理论问题是什么。

优先保持原 P64、CAL、特征、\(\lambda\) 和 high 调度，在真实 low OUT-D 数据流上检验这个已明确的缓存构造，记录实际块出口作用及完整一次复用成本，再验证候选自己的完整轨迹。当前两个 DEV 来源用于开发，选择收益不能按 16 个独立站点或事后最佳层汇报。若选择只在部分层使用，应在独立来源验证其选择规则。

完整运输方法继续作为机制参照，冻结 C 继续作为完整成本/成片参照。此前六源 C/Dense 的墙钟比 0.86478、GPU 比 0.81485 仍属于冻结 C；本轮带全键路由交叉和 7,168 行额外 Dense FFN 的诊断时间不用于替代生产计时。[既有完整成本](../../c_dense_baseline/C_DENSE_BENCHMARK.md)

回到最初问题，已由 FFN 和 attention 的真实执行证明这种组织能跨模块工作；本轮进一步明确跨模块可迁移的数学对象：**带质量与坐标的历史作用、当前可计算的运输、探针可恢复的剩余，以及完整后继读出上的目标误差。**
