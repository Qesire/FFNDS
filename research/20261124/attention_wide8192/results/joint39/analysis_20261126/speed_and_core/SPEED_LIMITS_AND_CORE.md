# 能节省多少：完整成本、方法核心与蒸馏叠加指标

日期：2026-11-26。当前证据提交 `973135c7f213b8fe4d063029cb17f60fad573659`，已包含用户对 job 201500 两条 centered 开发视频“基本没问题”的整体反馈。本轮实际新增工作为 CPU 静态算术、原始计时复算和代数核验。

## 核心判断

1. **当前完整方法的主矩阵算量约可减少 28%，折合约 1.39× 算术倍率。** 在保留现有两次原生锚点、QKV、输出投影、cross attention 等边界时，连 hit 的 self-attention 核心和 FFN 都假设为免费，指定范围的结构上限也约为 37.02%／1.588×。两者属于指定图上的乘加账本，不是硬件延迟承诺。
2. **完整 FFN＋attention 方案已经实测到 1.227× 去噪 GPU 加速和 1.156× 预热后完整请求加速。** 最新 centered 在冻结 C 上另有约 0.73% GPU、0.60% 整片耗时改善；它主要改进现有状态的表示，保留主要矩阵调用次数。
3. **方法可以收束为“结构预测＋当前观测校正”。** attention 的历史运输内收进预测器；在线只从 P64 原生响应拟合未解释部分，再一次读出。FFN 已使用先 P 拟合、后分块输出的执行结构，attention 可以按同一接口重排。
4. **可以把蒸馏与本方法的叠加效果作为合并系统加速指标。** 同时保留相对同一蒸馏学生的额外收益。总倍数以同组输入、同硬件和同计时边界直接测量；相同中间基线下，乘法分解是恒等式，无需假设两种机制独立。

## 1. 理论预算从实际计算图开始

当前每视频有 4 次去噪器调用，专家顺序为 high/high/low/low；每次 40 层。FFN 的原生锚点在步骤 0/2，命中在 1/3；low attention 在 step2 建原生锚点、step3 命中。high attention 在 step0 原生执行，在 step1 使用 OUT-ABS。wide8192 的 8192 是命中块的 token 行数；FFN 选中隐通道仍为 2560、探针64、共享模式16。

使用真实形状 \(N=31668,d=5120,m=13824\)，一个乘加计 2 FLOPs。每层每步的主要矩阵运算为：

| 项目 | TFLOP | Dense 主要矩阵算量份额 |
|---|---:|---:|
| self-attention 的 QK 与 AV | 20.5386 | 51.54% |
| FFN 两次投影 | 8.9657 | 22.50% |
| self QKV/O、cross 投影及 cross QK/AV | 10.3476 | 25.97% |
| 合计 | 39.8520 | 100% |

这些是有效乘加，不包含 padding、GELU、softmax、归一化、求解、gather、布局、通信、VAE 和保存。实际性能另由配对计时确定。[完整静态账本](THEORETICAL_SPEED_BUDGET.md)

### FFN：命中计算并不只有选中通道

原生 FFN 两次大投影约为

\[
F_D=4Ndm.
\]

当前命中仍有完整折叠线性投影 \(\Delta U A_0\)，以及选中通道的 W1/W2：

\[
F_H^{major}=2Nd^2+4Ndk,
\qquad k=2560.
\]

因此

\[
\frac{F_H^{major}}{F_D}
=\frac{d}{2m}+\frac{k}{m}
=\frac{10}{27}\approx0.37037.
\]

单次 hit 的主要矩阵算量省 62.96%，但一锚点只服务一次 hit，所以完整周期为

\[
\frac{F_D+F_H^{major}}{2F_D}
=\frac{37}{54}\approx0.68519,
\]

即省 31.48%。加入已列出的 P64 原生教师、80列联合读出、特征和探针矩阵乘法后，周期剩余比例约 0.68903，节省约 31.10%。其中还未计入逐元素操作与访存。

当前 \(k=d/2\)，所以 \(\Delta U A_0\) 和 selected W1/W2 恰好各占主要 hit GEMM 的一半。大幅改变命中算量，需要改变这两个主要对象之一；进一步微调 P64 的求解费用只涉及较小部分。

### Attention：把低噪锚点的 selected 计算也计入

设 selected 有效 key 密度为 \(\alpha\)，P64 查询占比 \(\beta=64/N\)。当前四步保留两次完整 QK/AV，在 step1/2/3 计算 selected，并在两个 hit 计算全 key 的 P64 教师。仅核心乘加的比例为

\[
\frac{2F_A+3\alpha F_A+2\beta F_A}{4F_A}
=\frac12+\frac34\alpha+\frac12\beta.
\]

源码选取31个128-key块；尾块是否被选中使有效支持在3892–3968之间。由此得到 attention 核心剩余比例约 0.59319–0.59499，核心节省约 40.50%–40.68%。保留 QKV/O 后，整个 self-attention 主要矩阵算量节省约 30.61%–30.74%。

### 联合全块预算与结构上限

将上述两部分与保留的其他矩阵运算一起计入，主要 GEMM 节省约 27.96%–28.05%；进一步计入显式特征、P64 教师、恢复读出、路由矩阵计算和本批遗漏质量回退后，已列 GEMM 节省约 **27.80%–27.90%**，对应 **1.385–1.387×** 算术倍率。

centered 与 C 的主要矩阵调用相同，增加的是 \(O(Nd)\) 的统计、状态编码和解码；本轮速度和峰值改善由它与编译融合组成的完整执行实现测得。

若固定当前模块边界、保留两个原生锚点，把两个 hit 的 self-attention QK/AV 和 FFN 都假设为免费，并且状态构建也免费，则

\[
\rho_{min}
=1-\frac12(0.51537+0.22498)
\approx0.629826,
\]

\[
S_{arithmetic,max}\approx1.58774.
\]

这说明当前图中可删去的主要乘加份额至多约 37.02%。当前已列账本与该结构边界相差约9.1–9.2个 Dense 百分点；突破它需要改变锚点频率、复用寿命或被替换的模块范围。更多 hit 可改善摊销，但会改变调用次数或状态寿命，本轮没有据此增加采样步数或声称新的质量结果。

## 2. 实际表现：完整周期已经包含锚点代价

Dense 在下表中均指同一四步蒸馏权重的原生 attention＋FFN。

| 方法比较 | 证据范围 | 四步 GPU 加速 | 预热后完整请求加速 |
|---|---|---:|---:|
| wide8192 FFN-only／Dense | job185220，3开发来源×2轮 | 1.03685×，省3.55% | 1.05303×，省5.04% |
| 冻结 C／Dense | job199260，6独立来源×2轮 | **1.22722×，省18.52%** | **1.15636×，省13.52%** |
| centered／冻结 C | job201500，2开发来源×2轮 | 1.00735×，省0.73% | 1.00606×，省0.60% |

185220 使用登记的均时比；后两批先在来源内平均重复，再对来源比值取等权几何平均。三行各自是直接对照，跨行不组成同批因果分解。[逐项原始收据复算](MEASURED_SPEED_AND_DENOMINATORS.md)

199260 的净节省可以完整解释为：

\[
\underbrace{7.06487\text{ s}}_{\text{两个 hit 节省}}
-\underbrace{1.23848\text{ s}}_{\text{两个 anchor 增量}}
=\underbrace{5.82639\text{ s}}_{\text{四步 GPU 净省}}.
\]

Dense/C 的四步 GPU 均值为31.4684/25.6420秒，完整请求为40.2453/34.8028秒。事件区间外的流程使最终墙钟净省5.4424秒。

FFN-only 的原生 FFN＋post 在旧批次只占四步 GPU 时间约18.43%；保留两个原生 anchor 时，即便两个 hit 的 FFN 完全免费、其他成本不变，最多也只省约9.22%的去噪时间。该实测份额解释了扩展 attention 的实际必要性。

centered 的 low 完整周期四对均更快，约省1.45%；完整墙钟的正负差随运行顺序分开，0.60%保留为本批顺序平衡读数。199260与201500的来源集合没有交集，因此 1.22722×1.00735≈1.23624 只能是跨批迁移估算，目前没有相应的 Dense／centered 直接配对。

表中是预热后的请求；初始化、首次编译和一次性准备另计。完整报告给出22.4499秒准备费的条件摊销算例，避免把稳态请求倍率解释成单次冷启动倍率。

## 3. 方法再收束：一个预测器，一次观测校正

在固定当前输入和可复用状态后，可将共同过程写成

\[
\boxed{
\widehat Y_t=b_t+K_t(Y_{t,P}-Pb_t),
}
\]

并在 P 位置直接覆写当前真值。\(b_t\) 是当前可计算的结构预测；\(K_t\) 将真实观测到的剩余响应传到其他位置。它只表示共同接口，FFN 的16增益模式＋核校正与 attention 的 ridge 恢复仍保留各自的具体定义。

对于 centered low attention，预测器为

\[
b_t=\operatorname{diag}(1-\rho_a)A_t^{\mathrm{sel}}+\rho_a\mu_t^\top+Z_aD_t,
\]

其中 \(A_t^{\mathrm{sel}}\) 表示当前 selected 响应，\(Z_a\) 是编码后的完整历史响应场。均值与尺度运输已成为预测器内部的一部分。

因此方法核心可以表述为：**用结构与历史预测当前响应，以少量当前位置的原生观测恢复剩余变化。** 对 attention，非零质量和当前 value 坐标明确了历史怎样被重新读取。

先取得当前必要的 selected 响应和全场 value 统计，随后可以采用一个具体的等价执行简化：

1. 仅在 P64 上计算预测底座并取得当前原生教师；
2. 拟合小规模恢复系数；
3. 全场按块计算预测器与校正，一次生成最终输出，再覆写 P。

FFN 的 wide8192 已采用这种“先 P、后分块读出”的结构。当前 attention 先生成全场底座再拟合，数学上可以移动到同样的执行顺序，减少全场 base/correction 临时量。代数与分块重排已用 CPU 核验；当前 BF16 边界、内核利用率和真实速度仍属于实现验证对象，未计入上方实测收益。[最简接口与等价构造](CORE_AND_COMBINED_SPEED_CLAIM.md)

## 4. 蒸馏＋本方法：合并指标可以作为系统结果

对同一输入 \(i\)，定义三个完整配置的耗时：

\[
T_{0,i}=T(\text{原模型、原调度}),\quad
T_{D,i}=T(\text{蒸馏模型、原生算子}),\quad
T_{M,i}=T(\text{同蒸馏模型＋本方法}).
\]

则

\[
\boxed{
S_{total,i}=\frac{T_{0,i}}{T_{M,i}}
=\underbrace{\frac{T_{0,i}}{T_{D,i}}}_{S_{distill,i}}
\underbrace{\frac{T_{D,i}}{T_{M,i}}}_{S_{ours\mid distill,i}}.
}
\]

这是约分恒等式，不要求两种加速机制独立。第二项直接是在蒸馏模型条件下测量的新增作用。相同来源集合与权重的几何平均也满足

\[
\operatorname{GM}(S_{total})
=\operatorname{GM}(S_{distill})\operatorname{GM}(S_{ours\mid distill}).
\]

因此可以同时声称：

> 相对原始多步模型，蒸馏与本方法组成的系统实现 X× 完整请求加速；其中本方法相对同一蒸馏模型额外实现 Y× 加速。

X 和 Y 使用各自直接配对的实测值，并区分 GPU 与完整墙钟。当前冻结 C 已有 Y=1.156×完整请求、1.227×GPU的六来源证据；本轮核对的计时收据缺少相同条件的原始多步模型一臂，因此 X 仍待直接测量。centered 的 Y 则需以同批 Dense／centered 比较确定。

### 步数、NFE 与墙钟分别计量

官方 Wan2.2-I2V-A14B 配置为40个采样步，源码每步分别执行 conditional 和 unconditional 模型调用；官方 LightX2V 对应蒸馏配置为4步、`enable_cfg=false`。在这一明确配置例中，调用次数是80→4，NFE减少20倍。

这20倍属于调用数量。按相同单次调用成本作条件算术示例，20再乘当前约1.386的算量倍率，会得到约27.7倍主矩阵算量比；它不是已测系统延迟。蒸馏与原模型可能使用不同调用后端，VAE、编码、保存和初始化也不按NFE等比缩放。

### 最小可报告的合并对照

同一组来源、同硬件、同计时边界下，完整运行三个臂即可支撑总系统与条件增量两项指标：原始模型；四步蒸馏原生模型；四步蒸馏＋固定候选。对三组输出评价画面和运动。

只有进一步研究“本方法在原始和蒸馏模型上分别产生何种交互”时，才需要第四臂“原始模型＋本方法”。总系统倍率本身并不要求这个额外因子实验。已有不同批次的比值及文献倍率可作估算参考，直接配对测量负责最终主表。

## 5. 当前研究重点

用户对当前两个 centered 视频的反馈已登记为整体可接受观察。该反馈与当前成本结果共同支持固定方法版本，推进简洁的执行形式和直接的系统对照。

当前最有作用的收束是：把 attention 恢复也组织成先探针、后一次分块读出；以原始模型、蒸馏原生、蒸馏＋固定候选三臂报告总系统与额外收益。数值表示、当前信息和联合块响应继续解释方法为何成立，实际主张由完整调用周期和成片对应。
