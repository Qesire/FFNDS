# 核心恢复过程、可等价简化的执行与合并加速口径

日期：2026-11-26。依据实际 `attention_online_structured.py`、`attention_mass_centered_low.py` 与 `fourstep_hit.py`。本次执行为 CPU 代数核验和源码依赖分析；模型、GPU、视频与性能新增执行数均为 0。用户本轮已反馈“新的视频基本没问题”，其对象为当前 centered 候选；这里不把它扩写为相对原多步教师的质量评价。

## 1. 最简而准确的核心：预测当前响应，观测并恢复剩余创新

令当前模块输出为 \(Y_t\in\mathbb R^{N\times d}\)，\(P\in\mathbb R^{p\times N}\) 选择原生计算的 \(p=64\) 行，\(M_{\bar P}=I-P^\top P\)。将当前廉价计算和允许复用的历史信息组成预测底座 \(b_t\)，记当前观测为 \(Y_{t,P}=PY_t\)。当前实现的实数过程可统一写为

\[
\boxed{
\widehat Y_t=P^\top Y_{t,P}
 +M_{\bar P}\{b_t+\mathcal K_t(Y_{t,P}-Pb_t)\}.
}
\]

三个实际动作已经包含在这一式中：形成底座，执行少量原生行，按当前特征提升观测到的创新。P 行最后使用原生教师。

对当前输入、锚点与条件固定时，这轮 attention 的 \(\mathcal K_t\) 是逐 head、对输出通道共享的 ridge 提升。FFN 的 \(\mathcal K_t\) 则是其 16 个 gain 模态与探针核的组合，作用于整块 \(p\times d\) 标签，可以耦合通道；两者使用同一个信息接口，而不是同一个回归矩阵。

FFN 源码的 gain 解右端对 `target=observed-base` 线性，gain 系统由当前 `q/x` 与固定 `v` 决定；后续 coeff 同样对 target 线性。因此，在这些当前条件固定时，FFN 的整套 gain/coeff 提升也是线性作用。整个模型对输入仍然是非线性的。

对应误差恒等式为

\[
\widehat Y_t-Y_t
=M_{\bar P}(\mathcal K_tP-I)(Y_t-b_t).
\]

它把恢复目标直接定位为底座尚未解释的响应。模块扩展要寻找的是合适的 \(b_t\)、当前观测和提升结构；需要的信息、可恢复方向与实际费用都可以沿这三个对象检查。

当前 low attention 的底座已经足够简明：

\[
b_t=\operatorname{diag}(1-\rho_a)B_t
 +\rho_a\mu_t^\top+Z_aD_t.
\]

其中 \(Z_a\) 是唯一的完整**历史响应主场**。实际缓存还包含既有 route、rho 和 projected anchor design；“一个历史响应场”不等于只有一个缓存张量。均值和尺度在当前调用中取得，anchor 的均值与尺度无需继续保存。high OUT-ABS 使用当前 selected 响应作为底座，没有完整历史响应项。

可用于介绍方法的一句话是：**在少步生成中，以当前廉价计算重读可复用的响应状态，再用 P64 原生观测校正剩余变化。** 蒸馏改变模型调用数，这套执行改变每次调用中需要重新计算的作用。

## 2. 恢复和运输可以合成一个表达，已有步骤不必各自物化

对 attention，令

\[
K=\Phi(\Phi_P^\top\Phi_P+\alpha I)^{-1}\Phi_P^\top,
\quad \alpha=64\times0.1=6.4,
\]

并定义

\[
H=P^\top+M_{\bar P}K,
\qquad L=M_{\bar P}(I-KP).
\]

则完整过程可写为

\[
\boxed{\widehat A=H A_P+Lb,\qquad HP+L=I.}
\]

代入 centered 底座，运输与恢复已经在同一表达中闭合。这里 \(H,L\) 只是分析记号；实际实现继续解 32 维系统和读取状态，不构建 \(N\times N\) 矩阵。

这个合成式还解释了为什么底座大幅改变，最终输出变化会更小。若底座变化恰为 \(\delta b=\Phi U\)，则

\[
L\delta b
=\alpha M_{\bar P}\Phi(\Phi_P^\top\Phi_P+\alpha I)^{-1}U.
\]

无正则、满列秩时，这类底座变化会被已有恢复完全补偿；当前正则化下保留相应收缩项。实际 centered−raw 更新还包含独立缓存量化与最终 BF16 写回，所以这条实数式用于结构解释，真实能量比例仍按归档实际输出报告。

### 2.1 一项直接的执行简化：先解码 P，再一次分块输出

当前 attention 路径按以下顺序执行：全场 decode 底座 → 取 P 拟合 → 全场残差 → 加回底座。源码表明拟合只需要 \(b_P,\Phi_P,A_P\)，并不需要先物化全场 \(b\)。可以改成：

1. 取得当前 selected 响应与 value 统计，在 P64 上解码 \(b_P\)；
2. 用相同教师、特征和正则化拟合系数；
3. 按 token 分块读取历史、生成当前特征并直接输出 \(b_i+\Phi_i\Theta\)；
4. P 行写回相同教师。

这保持预测底座、教师和恢复规则，没有新增状态、分支选择或超参数。现有 `fourstep_hit.py` 已经采用这个执行组织：`operands(P)` → native FFN(P) → gain/coeff → tiled operands/addmm → P overwrite。因此，attention 可以与 FFN 共享这条执行接口。

实际 \(N=31668,H=40,d=128\) 下，一个全场 FP32 响应为 648,560,640 字节；相同类型的 P64 响应为 1,310,720 字节，8192 行分块为 167,772,160 字节。这是可避免物化对象的形状预算，不是新的显存或时延实测；编译器可能已经消除了其中部分临时量。

上述重排在实数域等价。在 FP32/BF16 中，融合、FMA 和分块 GEMM 的求和顺序可能不同，需保留现有中间舍入的语义并验证最终输出。CPU 合成核验得到 P-first 分块与全场表达最大差 0，算子合成最大差 \(5.33\times10^{-15}\)；这些是数值恒等式见证，不是新 Wan 结果。

### 2.2 删项需要另一种证据

当前数据支持收拢表达与减少物化。删掉均值、尺度、P64 或某层恢复会改变已测试方法。已有恢复对某方向的补偿较强，也不代表该分量可以无条件移除；当前 ridge、数值写回和后继响应都可能留下实际作用。

优先考虑的简化是同一方法的 P-first、分块和融合读出。若要研究进一步压缩状态，则需要证明或测量整族当前 \(L_t\) 对状态所需的共同信息；单次 \(L_t\) 对一个更新方向的衰减不足以给出状态维数结论。

## 3. 蒸馏与本方法可以使用合并加速作为系统指标

对同一来源 \(i\)，定义同一硬件与计时范围下的请求耗时：

- \(T_{0,i}\)：原多步模型／规定教师基线；
- \(T_{D,i}\)：蒸馏模型，原生模块执行；
- \(T_{DM,i}\)：同一蒸馏模型权重，加本方法。

那么

\[
\boxed{
S_{total,i}=\frac{T_{0,i}}{T_{DM,i}}
=\underbrace{\frac{T_{0,i}}{T_{D,i}}}_{S_{distill,i}}
\underbrace{\frac{T_{D,i}}{T_{DM,i}}}_{S_{ours\mid distill,i}}.
}
\]

这是相同中间量约分的恒等式，**不要求假设两种机制独立**。第二项已经把本方法在蒸馏轨迹下的实际行为计算在内。

因此可以把总加速作为组合系统的主指标，同时报告同蒸馏权重上的增量加速，让读者看清总效果与本方法的贡献。当前四步蒸馏骨干上的执行和新视频反馈，已经支持两者可以在这个系统中组合使用。

若改用耗时减少比例 \(r_D,r_M\)，则同一配对的总减少比例为 \(1-(1-r_D)(1-r_M)\)。减少比例先转为剩余耗时相乘；加速倍率则直接相乘。

### 3.1 汇总统计也应保持共同分母

对相同来源和相同权重 \(w_i\)，

\[
\prod_i S_{total,i}^{w_i}
=\left(\prod_i S_{distill,i}^{w_i}\right)
 \left(\prod_i S_{ours\mid distill,i}^{w_i}\right).
\]

每源先对重复耗时取均值、再计算来源比值与几何平均，即可保持当前项目已有口径。总耗时之比也能严格约分，但与“每源倍率的算术均值”是不同统计量；后者的两个均值通常不能直接相乘。脚本用明确合成例验证：两项几何均值 4×、2× 对应总 8×，两项算术均值的乘积为 12.5×，而总倍率算术均值仍是 8×。

若中间蒸馏基线来自另一批来源、另一运行配置或文献数字，直接相乘得到的是组合估算，不是本批配对实测。当前 frozen C/Dense 六源与 centered/C 两源的阶段不同，也要保留各自比较身份。

### 3.2 NFE 是工作量因子，真实时间还包括每次调用成本

应按真实 denoiser 调用数计量。设第 \(j\) 个采样步需要 \(g_j\) 个条件分支或等效批处理分支，NFE 与分支执行费用都要从实际实现取得。原始 CFG 双分支与 distilled CFG=1 的调用成本不能仅用名义步数替代。

总时间一般写为

\[
T_0=H_0+\sum_{j=1}^{n_0}c_{0,j},\quad
T_D=H_D+\sum_{t=1}^{n_D}c_{D,t},\quad
T_{DM}=H_{DM}+\sum_{t=1}^{n_D}c_{DM,t}.
\]

\(H\) 包括与所计去噪事件不同范围的固定费用，例如 VAE、编码与保存；其是否包含在指标中应保持一致。步数／NFE 比可以单独报告为调用数减少因子。只有额外假定每次调用费用相同、固定费用可忽略时，才能把它当时间倍率。

## 4. 足以支撑主张的最小比较

| 执行臂 | 用途 | 是否为组合总加速所必需 |
|---|---|---|
| 原多步教师，原生执行 | 总加速的规定起点、质量参照 | 是 |
| 四步蒸馏，同权重原生执行 | 分离蒸馏与本方法贡献 | 是 |
| 四步蒸馏，本方法 | 最终系统 | 是 |
| 原多步教师，本方法 | 研究跨轨迹效果与交互 | 仅在提出这类额外主张时需要 |

组合加速的最小三臂无需重新蒸馏。对同一来源、输出尺寸和设备做配对执行，同时给出质量指标或成片评价即可。若主张“质量保持”的总加速，应评价原多步教师与最终系统这一对；当前用户对新视频的肯定是有用的候选证据，其比较范围按原反馈保留。

建议论文正文采用两层表述：

> 我们在冻结的四步蒸馏模型上复用 FFN 与注意力状态，通过当前稀疏原生观测恢复有限创新。相对同权重的四步原生执行，实测增量加速为 \(S_{ours\mid distill}\)；相对规定的多步教师基线，蒸馏与该执行方案共同达到 \(S_{total}\) 的端到端加速。两项均在同一配对来源和计时口径下测得，质量结果随同报告。

在多步教师尚未取得匹配计时之前，可以已经报告“在四步蒸馏骨干上进一步加速”，并分别展示已测增量与明确标注的 NFE 工作量因子。把老师端点加入相同基准后，总倍率就成为直接可报告的系统结果。
