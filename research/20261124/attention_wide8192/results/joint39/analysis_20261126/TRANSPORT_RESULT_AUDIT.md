## 1. 当前得到的肯定判断

新方法已完成真实 Wan 的算子绑定、BF16 缓存与短 P64 教师执行、一条固定 DEV 轨迹上的八站点机制对照、两条完整候选视频。对照直接显示：逐通道尺度运输在两专家第 0 层均显著减小剩余 attention 误差；低噪声第 39 层显示后继模块会改变两种误差的排序；共享 P 对 FFN 当前拟合输入的保护已在真实尾部实测成立。

这些结果把研究主张推进到**当前输入统计确实能更新一部分历史缺陷，而且其价值取决于层位置和后继读出**。当前证据最有区分力的对象是相同底座/特征/教师下的历史作用变化，及它经过真实尾部后的有限响应。

## 2. 证据身份和实际对照

- 固定轨迹：DEV0392，原生 self-attention 加 BF16 wide8192 FFN。两专家分别在 step 1/3 的 layer 0/13/26/39 记录，共八站点。独立来源数是 1，八站点是嵌套观测。
- 真实尾部：只在两个 step 的 layer 39 执行。保留实际输出投影、门控、cross-attention、AdaLN、残差和 wide8192 FFN，比较 H448 位置的块出口。
- 完整候选：0392、1013 各一条完整 81 帧视频，每条执行 160 个 attention 站点、80 个锚点、80 个命中和 5,120 个完整 key 查询行，峰值 40 个槽。
- 两视频视觉结论在归档中为 PENDING。光流和灰度代理只描述相应测量，不能用作质量结论。

代码对照确实固定同一个当前 G、当前 Ψ、全查询 P 教师和 α=6.4。raw 使用 FP32 原始历史 panel E_a；transport 使用 FP32 标准化 panel C_a 乘当前 D_s；两者均在同一当前标准化特征中拟合，再以 BF16 写出。`transport_bf16` 才使用生产 BF16 完整 C_a 缓存，单独隔离其数值影响。

固定轨迹返回原生 attention 以保持轨迹一致；短 P64 教师仍计算并与全查询对应行核验。完整候选运行才用短 P 教师驱动真实命中输出。因而固定轨迹对照隔离状态运输；两源完整视频则检验候选自身轨迹的可执行性。

两份运行源码的 SHA-256 与 receipt 完全匹配；receipt 字节的 SHA-256 与 summary 完全匹配。另与现存 `ONLINE_QUALITY_194188.json` 独立比较：0392 固定回放的 initial、四步 flows、四步 latents、experts、整个 video 字典（含解码 RGB 与 mp4 SHA）均一致；两源候选 initial 与第 0 步 flow/latent 各自匹配历史基线。

## 3. 分层复算揭示作用分布

源码 `energy(a,b)` 返回平方 Frobenius 误差，即能量。现有 summary 的四层聚合是这些**能量比的几何均值**，不是 L2 比。

| 命中步 | 层 | 运输/原始底座能量 | 运输/原始拟合能量 | 对应拟合 L2 比 |
|---|---:|---:|---:|---:|
| 1，高噪声 | 0 | 0.59666 | 0.57902 | 0.76093 |
| 1，高噪声 | 13 | 0.98779 | 0.98849 | 0.99423 |
| 1，高噪声 | 26 | 1.09155 | 1.09134 | 1.04467 |
| 1，高噪声 | 39 | 1.06902 | 1.06923 | 1.03403 |
| 3，低噪声 | 0 | 0.31057 | 0.56328 | 0.75052 |
| 3，低噪声 | 13 | 0.94247 | 0.94510 | 0.97216 |
| 3，低噪声 | 26 | 0.99712 | 0.99762 | 0.99881 |
| 3，低噪声 | 39 | 0.98296 | 1.01080 | 1.00539 |

两专家第 0 层的拟合后能量分别减少 42.10% 和 43.67%，L2 分别减少 23.91% 和 24.95%。它是当前最强的局部机制证据，来自同特征/同教师控制。

层位置差异同时显著。高噪声去掉 layer 0 后，其他三层拟合能量比的几何均值是 1.04874；低噪声对应为 0.98409。研究应保留这种层与专家条件关系，而非将四层单一平均值解释为均匀收益。

### 聚合口径

|---|---:|---:|
| 层等权能量比几何均值 | 0.90401 | 0.85597 |

## 4. Attention 与真实后继作用的有限分解

需要在同一 layer 39 比较 attention 与 tail；把四层几何均值直接对比终层出口会混合不同统计对象。

| 同一 layer 39 | attention 拟合能量比 | 实际块出口能量比 |
|---|---:|---:|
| 高噪声 step 1 | 1.06923 | 1.07728 |
| 低噪声 step 3 | 1.01080 | 0.98436 |

真正的同站点排序反转发生在低噪声：attention 能量增加 1.08%，块出口能量减少 1.56%。

令 e_m 为方法 m 的 attention 误差，T 为固定共享读出参数的实际尾部，定义该条有限误差的响应因子

\[
g_m=\frac{\|T(A+e_m)-T(A)\|_F^2}{\|e_m\|_F^2}.
\]

由定义得到精确的比较分解：

\[
\frac{\|\delta T_{\rm transport}\|_F^2}{\|\delta T_{\rm raw}\|_F^2}
=\frac{\|e_{\rm transport}\|_F^2}{\|e_{\rm raw}\|_F^2}
\frac{g_{\rm transport}}{g_{\rm raw}}.
\]

实际测量给出

\[
\text{step 1}:\quad 1.06922625\times1.00752853=1.07727595,
\]

\[
\text{step 3}:\quad 1.01080148\times0.97383889=0.98435780.
\]

低噪声运输误差在真实尾部上的相对有限响应因子降低 2.62%，足以改变其输出排序。这是按任务读出研究误差方向的直接实证。g 只描述这两条给定误差的有限作用；不是整个尾部的算子范数，也没有单独识别 W_O、gate、cross 或 FFN 各自的贡献。

两处所有分支的 FFN P 输入均逐位等于 native 分支，支持同一 FFN 当前拟合状态的条件。native panel tail 与现场真实块输出的相对 L2 分别为 3.10e−6、1.20e−6，说明该尾部复算在本样例上准确接近实际运行。

## 5. 数值路径已经得到具体边界

八站点中 BF16 缓存相对 FP32 运输的拟合能量变化最大绝对值为 0.01685%；分步几何均值分别为 1.00000407 和 1.00003426。该结果支持本组站点中完整标准化缓存的 BF16 表示保留了 FP32 运输的主要作用。

短 P 教师与全查询对应行的最大相对 L2 为 0.09740%。这里的分母是原生 P 响应，而非缺陷创新；它不能直接换算成恢复标签的相对误差。固定轨迹采用全查询 P 值锁住教师，已经将此项与运输作用分离。

Torch 对 NumPy 的 CUDA 合成核验分别为 FP32 最大绝对误差 3.06e−7、BF16 为 1.85e−3。实际 Wan 的上述误差与这一合成核验承担不同证据角色。

## 6. 调用周期与当前可主张的执行结果

两源完整候选四步 GPU 时间分别为 36.00634 s、36.23484 s。锚点两步分别合计 22.57670 s、22.73695 s，命中两步 13.42964 s、13.49789 s。峰值 allocated 均约 60.29 GiB。每源只有一次记录，且本作业中没有同批相同流程的原始历史项完整成片对照；这些是候选执行的绝对读数。

固定 replay 的 94.02 s 包含审计和额外工作，不应作为候选加速分母。完整周期需要同时计入 anchor 的 grouped G 构建、统计/尺度、hit 的 grouped 响应、教师、恢复和状态读写。更新后的 skill C02 正好要求把构建与有限复用次数放在一起；本任务每个专家/层锚点仅复用一次。

## 7. 由现有结果形成的研究方向

1. **保留已成立的早层作用。** 两专家 layer 0 的同条件收益已经说明当前 V 统计含有能用于更新历史作用的信息。下一分析应解释该作用随层发生怎样的变化，关注路由缺陷和标准化 value 形状的贡献。
2. **把后继读出写入判别对象。** 低噪声 layer 39 已给出同站点排序反转，直接支持沿真实尾部比较有限误差方向。现有数据足以说明联合评价必要，尚不能把它归因到某个单独非线性模块。
3. **把资源换算接到真实动作上。** 完整锚点和两组当前交互是可执行构造；其计算周期成本应与需要恢复的任务作用一起优化。数值证据先支持 BF16 缓存可行，下一项成本问题在当前/锚点工作量而非缓存位宽本身。
