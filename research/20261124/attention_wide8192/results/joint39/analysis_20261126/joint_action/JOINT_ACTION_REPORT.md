## 作用位置与构造取舍

0392 的低噪第 39 层在输出投影后仍为 1.0009×，经 self gate 才降至 0.9838×，进入 self 残差后为 0.9624×。两误差方向的余弦从注意力入口的 0.9960 降至该残差的 0.9462。纯 FFN 响应继续偏向 transport（0.9227×），残差合成后的块出口为 0.9844×。1013 的同一站点在 self gate 后为 1.0206×，纯 FFN 响应达到 0.9930×，最终块出口回到 1.0061×。这界定了门控与真实尾部的有限读出如何改变排序，以及该排序的来源依赖。

令 $d=z_t-z_r$。到 Dense 的能量改变量为 $(\|z_t\|^2-\|z_r\|^2)+2\langle b,d\rangle$。0392 的低噪第 39 层两项约为 −1.378 和 −1.020，背景进一步加强运输收益。1013 的对应两项均为正。四个第 0 层站点的背景项都为正，部分抵消固定 wide 尾部收益，到 Dense 的块出口能量仍下降 15.7%–21.4%。这 16 个站点中，背景交叉项改变了收益幅度，固定 wide 与到 Dense 两种出口比较的改善方向一致。

第 0 层的关键差异在固定恢复算子之后仍然存在。继续携带原始尺度会增加相当于 raw 剩余能量 40.6%–44.5% 的净误差，包含尺度项与路由、形状两者的交叉作用。其余层的同一比例为 −9.1% 至 +5.5%。P64 恢复后，第 0 层运输创新还剩 31.1%–46.6% 的能量，其余层为 70.9%–103.1%。低噪第 39 层的标准化 value 变化本身还小于第 0 层，说明应测量缺陷算子作用后的形状变化以及当前特征对它的可恢复性。独立 FP32 分解在四个第 0 层的拟合能量比与实际 BF16 输出相差不到 0.009。

第 0 层原始注意力误差只占同专家四个测点总能量的 1.36%–1.70%。这个可重复的相对收益优先支持一种按后继作用选择的轻量构造。以到 Dense 的块出口改善作为筛选量，以 anchor 新增统计、编码与读写成本加上单次 hit 作为验收周期。当前结构每次 anchor 只服务一个 hit，完整字段的构建费用需在这一周期收回。[冻结 C 和原生 Dense 的既有配对成本](../../c_dense_baseline/C_DENSE_BENCHMARK.md)

16 处回放的 FFN P 输入与现场捕获输入逐位相同。回放原生分支对真实块出口的最大相对 L2 为 $5.963\times10^{-6}$。固定轨迹的两来源是分析单位，同一来源各层为嵌套测点。完整 Gram 和背景交叉项在 `JOINT_ACTION_201276.json.gz` 中，运行 `python report_attention_joint_action.py --raw JOINT_ACTION_201276.json.gz --reference ../../method_transport/wan_runtime_receipt_198062.json --out recomputed` 可复算各表及机器可读汇总。
