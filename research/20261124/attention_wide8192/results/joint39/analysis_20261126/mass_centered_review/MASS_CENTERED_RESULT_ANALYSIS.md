## 3. 均值、质量和尺度构成一个对当前注意力成立的精确分解

固定一个 head，\(S_t,T_t\in\mathbb R^{N_q\times N_k}\) 分别为完整注意力及选中 keys 内归一化、嵌回全 key 轴的权重，\(V_t\in\mathbb R^{N_k\times d}\)，\(A_t=S_tV_t\)、\(B_t=T_tV_t\)。固定 query 轴的锚点质量 \(\rho_a\in\mathbb R^{N_q}\)，令

\[
W_a=\operatorname{diag}(1-\rho_a),\qquad M_t=S_t-W_aT_t.
\]

无论当前 Q/K 怎样改变，权重行和给出

\[
M_t\mathbf1=\rho_a.
\]

令 \(\mu_t\in\mathbb R^d\) 为沿 key 轴的均值，\(D_t\in\mathbb R^{d\times d}\) 为通道标准差对角矩阵，在非零尺度上写

\[
V_t=\mathbf1\mu_t^\top+\widetilde V_tD_t,\qquad
C_t=M_t\widetilde V_t.
\]

便得到精确关系：

\[
\boxed{
A_t=W_aB_t+\rho_a\mu_t^\top+C_tD_t.
}
\]

这里的 \(C_t\in\mathbb R^{N_q\times d}\) 是状态张量。该实数恒等式不要求路由权重固定；精确常量列由均值项表达。若实施阈值把微小非零方差也置零，则还需计入相应截断余项；本批八处 anchor/current 均未触发该分支。若 \(\rho_a\) 带极小有限精度负值，实数代数依然成立，只需把它解释为带符号的行质量。

**真正近似的是当前形状作用的有限创新。** anchor 保存 \(C_a\)，命中利用当前 \(\mu_s,D_s,B_s\) 形成底座，再由 P64 在原输出坐标中拟合剩余响应 \((C_s-C_a)D_s\)。完整/selected 权重固定、value 正对角仿射演化，且保留非零尺度支撑时，\(C_s=C_a\) 是先前证明的精确特例；一般路由变化仍可由同一分解表达。

因此，原问题可以准确重写为：当前廉价路径提供 selected 响应及全局 value 统计，历史槽保存逐位置形状作用，原生 P 教师观测剩余创新。这是本轮实际实现的数据流，不需要显式存储 \(M_s\) 或 attention 权重矩阵。所需信息由全位置历史、当前统计和教师共同承担；P64 是否足够，取决于剩余创新在当前恢复特征及任务读出中的可辨识程度。本轮真实结果验证了这组接口在已测位置上的实际作用。

## 4. 真实效果，以及它与原恢复器的关系

以下均为 centered/raw 的平方误差能量比。Dense 参照保持当前同一个 C 块输入，以 native attention 和 native FFN 形成目标。

| 来源／low 层 | 底座 | 拟合后 attention | wide 块出口 | Dense 块出口 |
|---|---:|---:|---:|---:|
| 0392／0 | 0.1177 | 0.6111 | 0.5758 | 0.7337 |
| 1013／0 | 0.1722 | 0.6197 | 0.6000 | 0.7982 |
| 0392／13 | 0.8530 | 0.9552 | 0.9598 | 0.9862 |
| 1013／13 | 0.7991 | 0.9660 | 0.9783 | 0.9902 |
| 0392／26 | 0.6111 | 0.9610 | 0.9676 | 0.9932 |

第 0 层的拟合后注意力改善 38.03%–38.89%，同输入 Dense 块出口改善 20.18%–26.63%。第 39 层的 wide 块出口改善约 10%，到 Dense 仍改善 4.17%–4.46%。这些结果描述内部恢复及后继作用，不把平方误差改变量当成视频质量分数。八个站点嵌套在两个开发来源内，计时重复用于观察执行稳定性。

### 为什么底座改善很多，拟合后改善较小

令 \(\delta B\) 为两个底座之差，固定当前特征与 P64 后，新旧预测的实数差为

\[
\delta\widehat A=M_{\bar P}(I-KP)\delta B.
\]

本次实现在最终 BF16 转换前核验该恒等式，最大相对 L2 为 \(2.34231\times10^{-6}\)。由实际两个分支 Gram 计算恢复及最终 BF16 写回后的 H448 更新能量，相对恢复前 H448 底座更新能量的比值：

| low 层 | 0392：恢复与写回后更新能量／底座更新能量 | 1013 |
|---|---:|---:|
| 0 | 3.381% | 3.780% |
| 13 | 19.494% | 16.219% |
| 26 | 11.636% | 12.963% |
| 39 | 2.591% | 2.365% |

经现有恢复与最终写回，这个已知更新在 H 上的实测能量显著降低。底座中的大变化只留下较小的差，但该差仍在八处改善 attention，并改变后继读出。恢复公式及实际方向共同说明，结构运输与原恢复具有重叠作用；本轮改进来自它们组合后留下的响应。

这些比值是已实现方向上的能量传递，未单独分离恢复和最终量化的贡献。分母只取 H，恢复同时依赖 P 标签，因此它们也不是 H 子空间算子范数、恢复维数、正交解释率或完整谱。当前 H 上的恢复非正交，例如 low13 的拟合后误差可以高于其底座误差；这与 centered 相对 raw 仍改善同时成立。

首次排序翻转在 self gate 加入 X 的真实残差写回。FFN 的输入、响应和门控响应都改善，最终残差状态却增加误差。因此该例定位了真实写回与残差合成的作用，不能用单个 FFN 响应解释。

令 \(z_r,z_c\) 为两条路径相对 native-attention/wide 尾部的误差，\(d=z_c-z_r\)。该站 wide 块出口满足：

\[
2\langle z_r,d\rangle+\|d\|^2
=-12.82480+43.09503=30.27023.
\]

Dense 背景交叉再贡献 \(+3.34346\)，总变化 \(+33.61370\)。更新带有反向分量，但该投影不足以抵偿更新能量。

low39 则出现另一个可重复关系：两个来源的 self gate 都略增误差，完整块出口却都改善约 10%。1013 的 FFN gate 本身也略增误差，最终出口仍改善。这些结果支持对完整复合状态建立目标度量，保留实际有限精度边界。

当前同阶段 Gram 可以准确给出上述方向和 Dense 背景关系；它没有存储跨阶段 residual/FFN 误差内积。进一步拆解内部抵消需要对应量，但现有结果已足以推进总体判断。[联合数学分析](MASS_JOINT_DERIVATION.md)

## 6. 新表示也改变了 BF16 缓存的数值对象

八处 anchor 重建误差都下降。low39 两来源分别由约 0.0752%/0.0745% 降至 0.0218%/0.0225%；这里是相对 L2，而非上表的平方误差比。

可以给出一个与观察相容的条件性解释。令旧历史 \(u_a\) 写入 BF16，新历史写入 \((u_a-\rho_a\mu_a^\top)D_a^{-1}\)。在正常数域的相对舍入模型下，暂时分开统计量形成和 FP32 解码误差：

\[
\|e_{\rm old}\|\lesssim u_{\rm fmt}\|u_a\|,\qquad
\|e_{\rm new}\|\lesssim u_{\rm fmt}\|u_a-\rho_a\mu_a^\top\|.
\]

尺度乘除在这一相对界中抵消；把可解析的均值质量项移出被量化的历史场，改变了量化误差作用的对象。该推导给出一种数值机制，现有测量还未把均值、尺度和编码的单独贡献分开。

本批八处 anchor/current 没有通道触发尺度阈值；保留了原 rho 的 2,430 个微负 query/head 值，最小约 \(-3.052\times10^{-5}\)。因此本轮收益发生在既有数值规则下。

## 8. 回到整个研究问题

现有证据支持三项进展：

1. **方法已经跨过实现与完整周期这一步。** 原有宽 FFN、attention 教师、校准和逐位置状态能够接纳这种历史坐标运输；当前两来源自身轨迹也已真实执行。
2. **信息恢复对象更加准确。** 当前 selected 响应、均值与尺度负责确定可计算部分，历史形状作用及 P64 承担剩余。已有恢复与运输的方向重叠已经被测量。
3. **联合目标继续决定方法取舍。** 块出口方向关系可以与 attention 或 FFN 单项不同，自己的完整去噪轨迹进一步包含层间交互。

回到最初的模块扩展问题，本轮给出了 attention 上已经执行的构造。可推广的对象是一组具体接口：当前可计算的作用、可随当前坐标重读的全位置历史、观测有限创新的教师，以及后继任务读出。FFN 与 attention 可以共享这组组织原则；各模块的历史状态、可利用变化规律和成本仍需由实际算子确定。这里 attention 的非零质量、value 均值及通道尺度，已经把这些接口具体化。

本次前 3 步精确一致，使干预明确落在最终 low hit；候选实际第四步已经包含 40 层依次改变输入、当前 attention 教师与 FFN 响应的联合过程。固定站点诊断解释局部作用，完整生成负责验证这种作用经过层间传播后是否保留所需内容。不同层的局部误差不能直接相加成最终视频指标。

因此，下一笔实验投入优先用于**冻结当前候选的完整视频与独立来源配对评价**，并继续记录同一完整复用周期、GPU、含保存墙钟和峰值。当前两来源都是开发来源；若以后提出分层选择，应单独验证选择规则。关于纯工程加速的单独主张，可以用融合版 raw 对照隔离实现贡献；它不影响当前完整候选已经跑通并测得成本的事实。
