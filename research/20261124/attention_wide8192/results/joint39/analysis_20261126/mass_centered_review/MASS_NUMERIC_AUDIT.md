## 1. 核验与比较身份

原始收据解压 SHA256 为 979e68efc18c1f999e0370c7698e435880190598aa79add6d23567d7eea4ff20；主执行源码 SHA256 与收据一致。80 个逐阶段 2×2 Gram、8 个底座 2×2 Gram、24 个 Dense 背景 3×3 Gram，共 **112 个矩阵**，全部有限、完全对称并通过 PSD 检查，最小特征值为 \(2.04408\times10^{-4}\)。

从原始收据独立重建汇总的非视频部分，183 个数值字段的最大绝对差为 \(4.55\times10^{-13}\)。运动代理依赖视频字节，本次仅保留归档身份，没有将其记为重新计算。

两个 fixed 轨迹、四条正式 raw 轨迹及一次 raw 预热，共七条 raw 轨迹，其 initial、四步 flows、四步 latents、video 全字段和 experts 均与历史 194188 的 C 轨迹相同。每源 centered 两次重复的四步 flow、latent 和 RGB 均相同。四组配对的初始状态及前 3 步 flow/latent 逐位一致，第四步发生实际方法差异。

当前比较对象需按执行图定义：

| 名称 | 实际对象 |
|---|---|
| raw | 冻结 C 的自身轨迹，low 使用原 OUT-D |
| centered | 固定当前 C 入块状态，替换已归档 low 历史槽；保持原特征、P64、CAL 和正则化 |
| native attention | 在 H448 查询行上执行全部 keys 的原生 SDPA，P64 则复用现场相同教师 |
| wide 尾部参考 | 上述 native attention 经同一共享 FFN fitted state 的尾部 |
| Dense 参考 | 同一当前 C 入块状态，H448 原生 attention 加原生 Dense FFN |
| live 一致性 | raw 回放对实际现场 C 块出口；LowTail 的 live_arm 为 raw |

因此最大 replay/live 相对 L2 \(3.04292\times10^{-6}\) 是 **raw 回放对 live C**，不应写成 native 回放对 live。所有 8 处 FFN P64 输入对现场捕获输入的相对差为 0。

本次两来源、8 个嵌套站点，与 201276 使用的 native-attention + wide 固定轨迹不同。旧运输方法还使用 selected + 两组底座、另一组特征。因此新旧 low39 的比值可以帮助识别结构差异，但不构成两个方法在同输入上的效果排名。

### 当前恢复与结构运输存在明显重叠

固定原特征和探针后，新旧输出的实数差为

\[
\delta\widehat A=M_{\bar P}(I-KP)\delta B.
\]

当前归档在最终 BF16 转换前验证该差恒等式的最大相对 L2 为 \(2.34231\times10^{-6}\)。实际恢复与最终写回后的 H 输出差能量为 H 底座差能量的 2.37%–19.49%。这测到了整个恢复输出路径对该方向的作用：底座的大幅变化会成为更小、但仍影响目标的更新；单独恢复与量化的贡献尚未分开。

这个比值是有限方向上的能量传递，不是信息维数、解释方差或完整算子谱。由于 \(I-KP\) 一般非正交，恢复也不保证每个 H 误差单调下降。比如 low13：

| 来源 | raw 拟合后／底座误差能量 | centered 拟合后／底座误差能量 |
|---|---:|---:|
| 0392 | 1.1960 | 1.3392 |
| 1013 | 1.3065 | 1.5794 |

这组事实提示，应继续研究结构运输和现有恢复对哪些实际方向重叠，而不是把底座改善幅度直接当作最终增益。

第一次翻转出现在 self gate 加入当前 X 的真实残差写回。FFN 输入、响应和门控响应本身都改善，最终残差状态却增加能量。因此不能把这一站点归因为“FFN 预测更差”。当前数据已经能够定位排序变化的边界；要进一步分解内部残差与 FFN 误差的交叉作用，需要同次执行中的跨阶段内积和舍入项，现有同阶段 Gram 不包含它们。

在 wide 块出口，令 \(z_r,z_c\) 为两误差，\(d=z_c-z_r\)：

\[
2\langle z_r,d\rangle+\|d\|^2
=-12.82480+43.09503=+30.27023.
\]

更新有反向分量，但不足以支付更新的平方能量。加入 Dense 背景后再增加 \(+3.34346\)，总变化为 \(+33.61370\)。对应到 Dense 的误差与更新余弦为 −0.01763，改善所需阈值为 −0.08013。

## 5. 编码、阈值与有符号质量

八处锚点重建的 centered 相对 L2 都小于 raw；这是直接从现场原生输出重新编码后测得的结果。它支持新编码数值误差较小，但不把 anchor 重建差当作完整 hit 收益的因果归因。

八处 anchor 和 current 的 inactive 通道总数为 0，说明本批站点没有触发尺度阈值分支。原有有符号 rho 被保留，累计 2,430 个 query/head 行为微负，最小 \(-3.05180\times10^{-5}\)。它们属于已记录的有限精度质量值；没有在这轮中插入新的截断规则。
