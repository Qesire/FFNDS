# 从质量中心化运输的真实结果继续推导

依据：FFNDS ec8a39b8a6c8c6a6cb25badfe11e8b6a38b09f63，学校 A100 作业 201500。本文从归档真实模型 Gram 计算有限方向与恢复关系，并另行核验实数恒等式。新增模型运行、视频评分和性能测量为 0；两个来源的八个站点按嵌套测量解释。

## 1. 新结果支持的机制层级

本轮把上轮质量中心化构造接到了冻结 C 的真实 low OUT-D 数据流：保持当前 selected 支持、P64、特征、CAL、正则化和 high 调度，替换 low 历史编码与解码。八个站点的 anchor 重建误差、底座误差和拟合后 attention 误差均下降，七处同输入 Dense 块出口改善。

这支持两项可以分别表述的机制：历史缓存使用当前 value 坐标解释，能使当前底座更准确；其收益经过原有 P64 恢复和真实后继读出后，仍在多数已测站点保留。实际实现同时有融合点运算与归约，成本改善应与运行审计一起解释，不能仅由数学式计算出提速。

与 job 201276 的比较需保留背景差异：旧诊断在原生 attention + wide8192 固定轨迹上使用 selected + 两组底座；本轮在冻结 C 轨迹上使用原 low OUT-D 底座。两轮都给运输原则提供证据，但它们的误差比不能相除并归为某一单项改变的因果效果。

## 2. 非零质量状态可以成为任意当前路由下的精确表示

固定一层、一个 head。在理想实数算子中，完整 attention 权重 \(S_t\) 和 selected 键内归一化权重 \(T_t\) 都是 query×key 矩阵，后者对未选中键补零；两者行和为 1。输出为 \(A_t=S_tV_t\)、\(B_t=T_tV_t\)。锚点保存的质量记为 query 向量 \(\rho_a\)，令 \(w_a=1-\rho_a\)。

定义随当前 Q/K 改变的有符号权重：

\[
M_t=S_t-\operatorname{diag}(w_a)T_t.
\]

不论当前路由怎样变化，恒有

\[
M_t\mathbf1=\rho_a.
\]

在 value 通道的非零尺度支撑上，令

\[
V_t=\mathbf1\mu_t^\top+\widetilde V_tD_t,\qquad
C_t=M_t\widetilde V_t.
\]

于是得到精确读出：

\[
\boxed{
A_t=\operatorname{diag}(w_a)B_t+\rho_a\mu_t^\top+C_tD_t.
}
\]

当前常量 value 列由前两项重建，中心化项为零。这个表示对任意当前 \(S_t,T_t\) 成立；固定权重加正对角仿射 value 演化，只是使 \(C_s=C_a\) 的一个充分条件。若实现将微小但非零的方差也阈值化为零，则须另加被截断中心化列经 \(M_t\) 作用后的余项；上述无余项等式要求非零列保持 active，或被丢弃列确为常量。本轮所有已测 anchor/current 通道均 active。有限精度 SDPA 与缓存另有数值误差，不能由实数表示直接推出逐位精确。

因此，方法近似的对象已可准确写成标准化作用的有限创新：

\[
A_s-\operatorname{base}^{centered}_s=(C_s-C_a)D_s.
\]

当前 route 变化仍包含在 \(C_s-C_a\) 内，并未被定义消除。若当前真实 selected 概率质量为 \(w_s\)，遗漏键归一化权重为 \(U_s\)，则

\[
M_s=\operatorname{diag}(w_s-w_a)T_s+
\operatorname{diag}(1-w_s)U_s.
\]

这说明固定锚点质量时，当前 selected/omitted 质量重新分配也作为明确的创新进入状态，而不是被漏掉。

实际 P64 恢复器继续在原输出坐标中拟合 \((C_s-C_a)D_s\) 的剩余响应；当前实现没有把恢复器的标签改成标准化的 \(C_s-C_a\)。

上述代数对任意有限 \(\rho_a\) 成立；当它是理想概率质量时有概率解释。本轮实际沿用微负的数值 \(\rho\)，不破坏有符号质量恒等式。当前合成核验故意允许 \(\rho\in[-0.1741,1.1989]\)，精确读出误差 \(2.22\times10^{-16}\)，创新恒等式误差 \(3.05\times10^{-16}\)。这些是代数核验，不是新的模型数据。

## 3. 大幅改善底座，为什么经过 P64 后收益变小

保持相同当前特征和恢复器，记 \(K\) 为 P 标签到全查询的提升，\(L=M_{\bar P}(I-KP)\) 为包括 P 覆写的剩余算子。先对同一个理想 anchor 使用上述无截断的实数表示，暂不计 BF16 缓存量化；其新旧底座差为

\[
\delta B^{ideal}=\rho_a(\mu_s-\mu_a)^\top+C_a(D_s-D_a),
\]

这里 \(u_a=\rho_a\mu_a^\top+C_aD_a\)。实际旧缓存保存 \(Q(u_a)\)，新缓存保存 \(Q(C_a)\)，所以记 \(E_u=Q(u_a)-u_a\)、\(E_C=Q(C_a)-C_a\) 后，实际底座差为 \(\delta B^{actual}=\delta B^{ideal}+E_CD_s-E_u+\varepsilon_{32}\)，其中 \(\varepsilon_{32}\) 汇集 FP32 统计、编码和解码运算余项。下面的均值／尺度分量式及其因式分解描述未量化的理想构造。

对任意给定的实际底座差，共享恢复在实数运算中的差关系仍为

\[
\delta\widehat A^{precast}=L\delta B^{actual}.
\]

本轮 compare_shadow 直接相减实际两个底座，将包括编码余项在内的差代入 \(L\) 核验；最终 BF16 转换前的最大相对 L2 差为约 \(2.34\times10^{-6}\)，此前 FP32 运算仍有舍入。P64 处理的标签中已经包含这些尺度和均值变化，所以搬运历史与探针拟合具有部分重叠作用。新底座节省了多少误差，不能直接乘到恢复后的结果上。

由归档同阶段 Gram 可以独立计算：

\[
\|\delta B_H^{actual}\|^2
 =\|e^{base}_c\|^2+\|e^{base}_r\|^2
 -2\langle e^{base}_r,e^{base}_c\rangle,
\]

以及实际恢复并最终写入 BF16 后的 \(\|\widehat A^{BF16}_{c,H}-\widehat A^{BF16}_{r,H}\|^2\)。因此这些归档比值度量实现后的组合，而非单独去除最终量化后的 \(L\)。真实结果如下：

|---|---:|---:|---:|
| 0392／0 | 0.1177 | 0.6111 | 3.381% |
| 1013／0 | 0.1722 | 0.6197 | 3.780% |
| 0392／13 | 0.8530 | 0.9552 | 19.494% |
| 1013／13 | 0.7991 | 0.9660 | 16.219% |
| 0392／26 | 0.6111 | 0.9610 | 11.636% |

这组数据支持一个具体结论：经过原恢复与最终写回，新旧底座差中的大部分没有保留到输出差中，运输仍改变了留下的方向，并使八个 attention 站点的误差下降。上面的实数恒等式解释了恢复器如何补偿这一结构方向，归档比值还包含最终量化的影响。这里分母只取 H，恢复后场还依赖 P 标签，所以上表不是仅作用于 H 子空间的算子范数。

另一个相关事实是，第 13 层两个来源的 raw/centered 拟合后能量分别为各自底座的 1.196/1.339 和 1.306/1.579；1013 第 26 层为 1.021/1.434。现有恢复器在 H 上是探针驱动的延拓，通常不是正交投影，局部能量可以增加。当前数据分清了结构运输与拟合的相互作用；它没有单独分解特征、点位和正则化各自的贡献。

查询轴恢复与通道轴作用还允许更精确地组织已知更新：

\[
\boxed{
L\delta B^{ideal}=(L\rho_a)(\mu_s-\mu_a)^\top
 +(LC_a)(D_s-D_a).
}
\]

均值变化对每个 head 是一个 query 向量与通道向量的外积，尺度项则解码已有全位置形状。该因式分解不需要新的原生教师，并明确了两部分分别依赖什么信息；是否采用不同收缩次序仍应由完整实测代价决定。

## 5. 新编码还改变了被 BF16 量化的对象

本轮八个 anchor 重建相对误差都下降，low39 最明显：0392 为 0.07520%→0.02182%，1013 为约 0.0745%→0.0225%。这提供了一个额外的数值表示视角。

暂不计 FP32 统计、形成和解码误差，在正常数值范围内令 \(Q\) 表示 BF16 就近舍入，单位舍入误差为 \(u_B\)。旧缓存保存 \(Q(u_a)\)，新缓存保存

\[
Q(C_a)=Q((u_a-\rho_a\mu_a^\top)D_a^{-1}).
\]

旧、新 anchor 存储误差的逐元素界分别为

\[
|Q(u_a)-u_a|\le u_B|u_a|,
\]
\[
|Q(C_a)D_a+\rho_a\mu_a^\top-u_a|
\le u_B|u_a-\rho_a\mu_a^\top|.
\]

因此，把可解析的均值质量项移出历史字段，可能降低需要 BF16 表示的数值幅度。单独的尺度乘除在该相对误差界中抵消，不能把全部量化收益归给标准化本身。当前实测八处改善与这个机制相容；现有统计尚未分开均值、尺度及算术路径各自的贡献。

本轮 anchor/current 通道都高于尺度阈值，所以这些真实站点未经过退化支撑切换。其他输入上的阈值与常量列仍按已定义分支处理。

## 6. 同块作用与完整轨迹现在各有了证据

固定诊断在冻结 C 轨迹上，将同一块输入送入原生、raw 和 centered 分支，并保持现场 P64 教师和 wide FFN 拟合状态一致。这回答局部机制和目标方向。

完整 centered 成片则在 low hit 的全部 40 层运行自己的状态。两臂初始值和前三步 flow/latent 逐位一致，说明变化从最后一个 low 命中步引入；但命中步内，早层改变后的输入会继续影响后面各层的 Q/K/V、P64 和 FFN 拟合。局部诊断的共享 P 结论不意味着完整两臂在所有后层 P 输入相同。

所以，当前进展可以准确表达为：已形成有完整输入、缓存、解码与探针恢复流程的方法，并在实际网络完成自身轨迹和配对成本执行；局部误差给机制证据，完整轨迹承载层间联合作用，画面收益由这些候选视频及其对应任务评估回答。两个开发来源为当前实现提供了证据，独立来源验证负责后续泛化主张。

## 7. 更一般的中心选择关系

下面是数学延伸，不作为本轮追加候选或参数选择。若中心本身随 value 正对角仿射变换而协变，可以选择其他中心。令 \(\Xi_t,\Xi'_t\in\mathbb R^{N_q\times d}\) 为两个按 query 组织的中心场，全局均值对应 \(\Xi_t=\mathbf1\mu_t^\top\)，记 \(\Delta\Xi_t=\Xi'_t-\Xi_t\)。两种运输底座的差为

\[
\operatorname{base}'_s-\operatorname{base}_s
=\operatorname{diag}(\rho_a)[\Delta\Xi_s-\Delta\Xi_aD_a^+D_s].
\]

例如取每个 query 的中心为 selected 输出 \(B_t\)，式子化为

\[
B_s+(A_a-B_a)D_a^+D_s.
\]

它与当前均值中心构造共享固定权重下的正仿射精确类，却具有不同的路由变化响应；其差正是 selected 相对全局均值的标准化有限变化。这个关系说明，相同精确类可以对应不同的创新和成本结构。当前实测认可的是本轮全局均值中心构造，替换中心的效果并未测量。

这两条换中心式是同一 \(D_a^+D_s\) 下的直接代数恒等式，即使 \(D_a\) 有零列也成立；“正仿射精确类”的断言则使用前述支撑条件：非零方差列保持 active，被丢弃列在 anchor 确为常量，并在正对角仿射演化下保持常量，中心对这些列给出相同常量。若阈值截断了非恒定列，需要保留截断余项，不能仅因使用伪逆就称为精确运输。
