# FFNDS 新方法的机制位置：当前粗算子、缺陷状态及其运输

更新日期：2026-11-25。范围：round 8 已公布推导与 round 9 正在形成的 value 尺度运输。基础研究提交：`Qesire/FFNDS@7c8196fa5380dbe67dd9772f942553085fde55b3`。本文件只报告本轮实际核验过的原论文、作者代码及由公式得到的比较；详见 `novelty_sources.json`。

## 1. 已经形成的方法对象

现有工作已经形成一个可明确指定输入、状态、更新与输出的方法原型：当前步重新计算可负担的近似算子，历史锚点保存它未表达的逐位置缺陷，少量当前精确行观测负责更新缺陷。其研究对象是**缺陷如何随当前输入运输，以及当前稀疏观测如何恢复运输后的创新**。

对单个 batch、head，令当前完整注意力输出为 `A_s ∈ R^(N×d_v)`，当前粗算子输出为 `G_s`，锚点时刻为 `a`，行选择算子 `P ∈ R^(M×N)`，其中本项目 `M=64`。令 `K_s ∈ R^(N×M)` 是由当前特征建立的正则化重建算子。round 8 原型为

\[
E_a=A_a-G_a,\qquad
\widehat A_s=G_s+E_a+K_sP\{(A_s-G_s)-E_a\}.
\tag{1}
\]

其中 `G_s` 包含选中 key 的精确贡献和遗漏组的当前 K/V 均值贡献。最终将 P 行覆盖为精确值，是额外的插值约束；讨论未采样行机制时应单独列出。

本轮核验说明，式 (1) 的各部件能与既有方法精确对应。因此最有价值的进一步工作是说明**为什么要保存这个状态、这个状态在什么变化类下可被当前低成本信息准确更新、剩余创新是否更容易被 P64 观测恢复**。这给方法的数学贡献和实验贡献都规定了可检验对象。

## 2. 最近的五种过程：按操作对应

| 来源与实际核验范围 | 输入、状态与更新过程 | 与式 (1) 的具体关系 | 可据此形成的贡献位置 |
|---|---|---|---|
| **ClusterAttention**, arXiv:2608.26965；作者主分支生产代码已读，全文未取得 | 当前 K/V 分组；选中贡献精算；遗漏组用当前 centroid 和计数参与同一归一化。生产路径采用 Sage 量化实现 | 在分组、选中集合和数值精度匹配时，`G_s` 的实数算子相同；两子组属于分组精细度选择 | 将其作为可保持当前全局 V 信息的基础算子；贡献需落到缺陷状态更新，或有证据的分组准则 |
| **MC-Sparse**, arXiv:2610.06801；作者代码已读，全文未取得 | 锚点计算完整输出与稀疏输出，缓存逐位置差；后续用新 Q/K/V 重新算稀疏输出，再加缓存差 | 同一基础算子与路由条件下，式 (1) 令 `K_s=0`，即得到其残差复用主过程 | 当前精确 probe 更新和 value 运输是与这个直接先例区分的变量 |
| **SparsePR**, arXiv:2608.18484v2；正文与附录 A/B 已读，当前官方仓库仅 README | 当前分组与选取；每次、每头算 64 个完整注意力行；对当前 dense−sparse 差做覆盖加权 ridge；输入特征为 sparse 输出；最后覆盖精确 probe 行 | 在 `E_a=0`、基础算子取它的 hard-drop sparse、特征及权重相同时，退化为同类当前残差拟合；P64 与覆盖步骤均有直接先例 | 完整锚点使重建目标变成有限创新；运输进一步改变创新的信息量与可辨识性 |
| **EasyCache**, arXiv:2507.02860v1；§III-C 已读 | 缓存模型输出与输入之差；复用步用当前输入加该差；通过变化量估计决定刷新 | 属于 `G_s=x_s` 的历史变换向量复用。其粗细算子和观测机制与本项目不同 | “保留当前基底并复用历史差”是成熟构件；具体当前算子和缺陷动态仍需分析 |
| **DEIM / gappy POD**, Chaturantabut–Sorensen 2010；Peherstorfer–Drmač–Gugercin 2020 全文已取得，引言与 §2.1 已读 | 由少量选中分量，在已知低维子空间内插值或过定约束最小二乘恢复全场 | `K_sP` 是正则化、当前特征条件化的经验重建算子；在方阵无正则情形与 DEIM 公式一致 | 应证明字典与 probe 对运输后创新的可观测性；新名字不改变其重建原理 |

这里的对应以条件等价为依据，范围小于“所有稀疏注意力或缓存都是同一方法”。例如 SparsePR 的 key centroid 用于路由，作者附录明确说明不把 centroid 作为遗漏输出贡献；这与当前 `G_s` 有实质过程差别。MC-Sparse 缓存全位置残差，SparsePR 当步重建当前残差，这两种信息来源同样需要区分。[S1–S5]

## 3. 两个容易混淆的精确对应

### 3.1 当前 centroid 基础算子的对应

对 query `i`，选中 key 集合为 `S_i`，未选中组为 `C_i`，每组计数 `n_c`、均值 `k̄_c,v̄_c`。实数形式为

\[
G_i=\frac{\sum_{j\in S_i}e^{q_i k_j^T/\sqrt{d_k}}v_j+
\sum_{c\in C_i}n_c e^{q_i\bar k_c^T/\sqrt{d_k}}\bar v_c}
{\sum_{j\in S_i}e^{q_i k_j^T/\sqrt{d_k}}+
\sum_{c\in C_i}n_c e^{q_i\bar k_c^T/\sqrt{d_k}}}.
\tag{2}
\]

ClusterAttention 的实际主路径 `backend.py → sage_query_mean_compensation` 计算当前 key/value centroid，处理尾组计数，并把未选中 centroid 与选中输出/LSE 合并。其生产精度是 Sage 的 int8 QK / FP8 V 路径，故这里成立的是**给定同一分组和选取后的理想算子对应**，不是不同实现间的逐位相同。[S1]

其作者还提供 `diagnose_comp_error_parts.py`，把 centroid 补偿误差分解为 Jensen 与 covariance 项。因此这两项分解可作为已有分析工具引用；本项目的两组构造可以证明所保留信息更多，却需要独立证据说明划分准则的价值。

### 3.2 缺陷创新拟合与经验插值的对应

设当前字典 `Ψ_s ∈ R^(N×r)`，令 `X=PΨ_s`，采用 ridge：

\[
K_s=\Psi_s(X^TX+\alpha I)^{-1}X^T.
\tag{3}
\]

若 `M=r`、`X` 可逆、`α=0`，则

\[
K_sP=\Psi_s(P\Psi_s)^{-1}P,
\tag{4}
\]

即 DEIM 型插值。若 `M>r` 且满列秩，`α=0` 给出 gappy 最小二乘恢复；`α>0` 给出正则化恢复。[S5] 本项目的区别来自字典由当前注意力信息构建、目标是有限缺陷创新、锚点保留了全位置高维信息，以及观测成本由完整 key 扫描决定。称其为“在线校准”或“innovation”本身不会改变式 (3) 的数学关系。

这也澄清了信息容量：64 行只限制**新恢复的变化**，不限制已保存的完整锚点缺陷。全位置锚点保留的结构，不能用“P64 只能恢复 64 秩”概括掉；反过来，当前未被 P 和字典表达的变化也不能由旧状态保证。

## 4. round 9 更有区别的方向：依据 value 的变换运输缺陷

对于固定的当前 Q/K、分组与选中集，完整注意力和式 (2) 都对 V 线性，可写为

\[
A_s=\Pi_sV_s,\quad G_s=\widetilde\Pi_sV_s,\quad
R_s=\Pi_s-\widetilde\Pi_s,\quad E_s=R_sV_s.
\tag{5}
\]

两者都保持常量 value，所以 `R_s 1=0`。若在一个变化类上 `R_s=R_a` 且

\[
V_s=V_aT+\mathbf1b^T,
\]

则有 **`E_s=E_a T`**。这为缓存状态给出一个实际的更新法则。此结论是由式 (5) 直接推得的本项目分析；不需要假设完整输出或缺陷本身恒定。`R_s=R_a` 要求的是两种注意力权重之差保持不变，单纯保持 selected indices 不足以保证这一点。

最简可实施特例取逐通道正尺度：`T=diag(γ)`，其中 `γ_ν>0`。令 `D_s=diag(std_j(V_s))`，对锚点非零方差通道有

\[
C_a=E_aD_a^{-1},\qquad
\widehat E_s^{base}=C_aD_s.
\tag{6}
\]

在固定 `R`、逐通道正仿射 V 变化类中，式 (6) 精确。由于 `R1=0`，value 的平移项自动消失。随后可以对标准化缺陷创新 `E_sD_s^{-1}-C_a` 使用式 (3)，并恢复到当前 value 尺度。

这与 AdaIN 的通道尺度匹配共享通用运算。[S6] AdaIN 对内容特征本身去均值、除标准差，再匹配另一组特征的均值/标准差；这里运输的对象是输出缺陷，尺度来自输入 V，平移由 `R1=0` 抵消。因此应把贡献主张写为**attention 缺陷的 value 等变状态与其观测更新**，并引用已有统计匹配原理。`E_a` 通常不具有零 token 均值，对它额外做 AdaIN 式中心化会改变应保留的缺陷。

精确类需要写在算法旁边：零方差通道应单独处理；正尺度排除了符号翻转；通道混合需要一般 T；路由误差变化产生另一个创新源。固定绝对 `epsilon` 的方差地板会让尺度等变变成近似性质。这个边界有助于构造正反判别数据。

### 4.1 完整方法在两时刻独立正对角仿射变换下等变

式 (6) 的跨步精确变化类之外，还可证明完整方法的一致性。分别对 anchor 和 hit 作不同的变换：

\[
V'_r=V_r\Gamma_r+\mathbf1b_r^T,
\qquad r\in\{a,s\},\qquad
\Gamma_r\text{ 为正对角矩阵}.
\tag{7}
\]

`Γ_a` 与 `Γ_s`、`b_a` 与 `b_s` 均可不同。每次调用的 Q/K、分组、选中集和 P 在这个坐标变换前后保持原值；anchor 与 hit 之间的 Q/K 本身可以变化。由于 `E'_r=E_rΓ_r`、`D'_r=D_rΓ_r`，标准化缺陷 `C_r=E_rD_r^+` 分别不变，因此 **`C_s−C_a` 也不变**，无需假设 `R_s=R_a` 或创新为零。

完整实现将 value 特征改为 `((G_s−B_s)D_s^+)P_v`，其中 `B_s` 是当前选中 key 的重归一化 sparse 输出；Q 特征与注意力质量比例也在式 (7) 下不变。因此字典、ridge 系数和重建算子 `K_s` 都不变。于是

\[
\widehat A_s=
G_s+\{C_a+K_sP(C_s-C_a)\}D_s
\quad\Longrightarrow\quad
\widehat A'_s=
\widehat A_s\Gamma_s+\mathbf1b_s^T.
\tag{8}
\]

最终 P 行精确覆盖同样保持这个关系。性质要求方差地板不激活，零方差通道按理论零分支处理。旧的“先投影 `G−B`、再除每头 scalar RMS”特征一般不具有这个逐通道性质；标准化必须在 value 投影前按通道完成。

该性质已经有两套独立 CPU 构造核验：[参考实现的结果](reference_attention_verified.json)在 anchor/hit 使用不同增益与平移、且两步 Q/K 不同的非零创新例中，完整输出等变最大误差为 `2.6645e−15`；[独立运输推导核验](defect_transport_verified.json)相应误差为 `3.9968e−15`。这些是双精度数学语义核验，不代表真实模型质量提升。

这个结果把方法特性从一个静态标准化技巧推进到**具有两时刻独立尺度一致性的缺陷状态与观测更新**。同时，原始缺陷缓存的精确假设 `E_s=E_a` 与新状态的精确假设 `C_s=C_a` 是不同的作用类；应表述为新增了可精确处理的正对角 value 演化族，而不能声称新方法覆盖原方法的全部精确输入。

### 4.2 查新范围与尚需核验的先例

本轮已核验的 ClusterAttention、MC-Sparse、SparsePR 主公式/代码中，没有找到式 (6) 所指定的输入 V 尺度运输历史 dense−coarse 缺陷过程。这里的判断范围仅覆盖已读版本。检索还发现 OnlineCache（arXiv:2607.29398）使用学得的缓存误差纠正器；已取得原始摘要。[S7] 最后一轮定向追踪使用题名、作者、GitHub 与官方 arXiv/export 路径，仍未取得全文或能关联到该论文的官方实现。同名 `neu-spiral/OnlineCache` 属于网络缓存研究，不作为该论文的实现。OnlineCache 的 corrector 是否含输入统计驱动的残差尺度运输仍是明确开放项；本轮检索在这里停止。

## 5. 新颖性与方法成熟度的肯定判断

**可以确认已经形成方法原型，并且本轮把方法的核心变得更清楚了。** 它规定了当前可计算部分、保存的状态、当前精确观测，以及状态回到输出空间的方式。round 9 的尺度运输提供了一个独立于经验“变化很小”的充分条件；这是值得继续研究的具体原则。

方法论文最有区分力的主张可以组织为：

1. **计算图表示：**把注意力改写为当前已覆盖信息和可运输缺陷；保持常量 value 的两个算子之差消去 value 平移。
2. **状态与精确类：**标准化缺陷在固定权重差、逐通道正仿射 value 变化类下不变；由当前 V 的低成本统计准确解码。在一般非零创新下，包含 ridge 恢复的完整方法对 anchor/hit 各自独立的正对角仿射坐标变换等变。
3. **观测分配：**P64 用于恢复运输后残差创新，并用可观测性、未采样行误差和后续模块影响共同检验它是否够用。
4. **实证贡献：**在同一 wide8192、同一当前粗算子、同一 probe 和预算下，证明动态运输相对于静态缺陷复用提高输出/下游质量，或者在相同质量下进一步减少观测或锚点成本。

前两项已有可完成的推导；第三项需利用真实张量检验；第四项需要当前候选的执行结果。六源视频接近提供了继续研究计算冗余的依据，不能把它代入新候选尚未执行的结果。若真实 V 尺度几乎不变，式 (6) 仍是正确构造，但可能不是当前模型上最有效的自由度；此时应回到 `R_sV_s` 的误差分解，而不是继续微调尺度系数。

## 6. 最短的判别实验与资产要求

同一真实 Q/K/V 与同一 coarse G 上，固定特征、probe、正则和锚点间隔，比较：`G_s`；`G_s+E_a`；`G_s+E_a+P64 创新`；`G_s+C_aD_s`；`G_s+[C_a+P64 标准化创新]D_s`。另设当前绝对残差拟合以连接 SparsePR。顺序比较可以分别测出历史状态、运输和新观测的贡献。

保留三个判别构造：正仿射 V 变化（运输应精确）；保持 std 的 V 通道旋转或局部重排（尺度统计不足）；单独改变 Q/K 权重（观测是否恢复新的 R）。实际质量评价至少跟踪未采样注意力行、输出投影与后续 FFN/残差合成；若只在 probe 上评价，最终 overwrite 会掩盖重建差异。

必须记录每次真实 dense 行调用、anchor 构建、group summary 更新、std 归约、重建、状态读写的成本。主结果只在相同算子接口、数值精度和调度预算下比较；其他论文的设备、token 数和采样步数用于定位方法，不用作直接性能证据。
