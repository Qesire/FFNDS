## 2. 三种「集中」之间的真正差别

令 `q_t` 为当前**Q2 后 W2 实际输入**，而 `a_t`、`h_t=GELU(a_t)` 是 Q2 前对象；令 `V_t=diag(g_t)W_{2,e_t}`。

1. **逐 token/后验坐标集中**：`Δu_r=V_t(q_{t,r}-q_{t-1,r})` 的后验重建可由逐行少量 `Δq` 坐标实现；本例的跨步减法只在同 expert 权重合法复用时定义。
2. **共享集合集中**：给整块 token 相同 `S`，`Σ_r||V_t(Δq_r−P_SΔq_r)||²` 是否足够小？这不从 (1) 推出。
3. **可执行工作集中**：选择是否在**足够早的信息时点**和指定 GEMM/量化核布局上减少主 W1/W2 工作。由 (2) 也无法直接推出；后验当前完整`q_t`已经付出W1/GELU/Q2的成本。

给每个新机制标注三个坐标 `representation; observation_time_and_cost; actual_removable_work`。函数重要性还要独立添加 `downstream_video_effect`。这些是**用来解释差异的维度**，不是迫使所有 ideas 走同一算子步骤的审批门。

## 3. 下一轮保持竞争的六个切面（可派生第七种）

### M1 · FFN 条件函数基，而不只是 channel top-k

当前`q`中单元对角 `q_j²||gW2[:,j]||²` 不含 signed cross terms；构造性叠加、相消、GELU 分支之间的相关可令逐通道排序与净输出贡献排序相反。比较完整`W2`/gate的共同模式、局部 Jacobian `W2 diag(GELU'(a)) W1` 的方向，以及真正能保持函数的结构。**重点可查**：有符号低维共同更新/高阶配对、特殊GELU反向对、条件子空间。GELU **之后**的严格分解与 GELU **之前**一般不能随意旋转分别处理。

**可分辨预测**：同预算不同表示若使 signed net error 改善而单元幅度排序未改善，则选错了功能坐标。优先复用六来源完整权重与保存值，不重复采集随机32行。

### M2 · 空间组织与时序因子化，而不是固定 raster M128

在相同latent位置不等于同一运动物体的前提下，对照 raster 连续、空间邻近、时间邻近、特征相似/图聚类，以及不同层是否需要不同粒度。可以提出公共函数场加 token 特有残差，或直接让 token 计算单位随几何关系变化。对中间层低均值能量的结果，竞争解释是**错的空间聚合**或**确实缺少低维共享更新**。

**可分辨预测**：改变空间组织后共享支持的变化是否超出置乱基线？这种变化能否预测下游影响而非只降低后验 SSE？现存两来源M128用于初步分析；物体运动对齐可能需要其他源字段，不能直接从 raster 推断。

### M3 · FFN 非线性与输入条件可辨识性

真实 FFN 的 `W1→GELU→Smooth2/Q2→W2` 决定可预测变量和最便宜的信息时点。研究 exact/conditional GELU 恒等式、近线性局部段、激活差分的 Taylor 剩余、跨 token 非线性 Jensen gap、condition/gate 对功能方向的作用。**微16前置观测**需要全宽 W1 对聚合行的额外投影，属于“早出现但需要付费”的信息。

**可分辨预测**：同 preactivation 均值不同分布若导致不同`mean GELU`/净输出，说明均值统计损失信息；若有源固定特征能预测该差异，探索更省的感知统计，而非仅改 top-k。

### M4 · 下游四步视频功能与时空误差模态

已有历史 A5+HWG 的**背景光照、细小物体抖动而主体较稳定**、E0 原生写回非加性、local/flow排序翻转。将误差分成**时空低频公共模态、局部结构模态、step间支持切换模态**，与 Gate/Attention/残差/flow 消费者的实际传递对照。

**可分辨预测**：控制同等局部`||δr||²`后，时间不连续性与误差方向哪个更能预测背景闪烁？使用现存配对流/视频索引先检查指标能否定义；未来真实候选再用完整多指标视频因果对照。局部创新SSE好不构成视频质量通过。

### M5 · 真实省算单位及自由实现空间

分别设`ρ_W1`、`ρ_W2`、前置观察器成本、native Q2尺度依赖、weight layout/gather/packing与缓存。本轮组闭包对**按原生group尺度忠实计算、使用原始布局**的假说有直接限制。另可比较与该约束不同的**post-Q2 W2计算、不同量化/表示、组级重参数化、静态/条件低秩因子、kernel融合、少量后训练**（各有数学/预算身份）。

**可分辨预测**：固定正确数值作用时是否真的能省一个 M/N/K tile？若换实现或选择不同分母，理论MAC与实测端到端墙钟是否反转？早期只需算子式与资源账本，不先作GPU kernel定案。

### M6 · 少步蒸馏特有的层/步/专家重构

high/high/low/low让每个专家只有一个可直接使用的同专家历史；文献的长去噪轨迹及CFG双分支不能移用其训练/信息时点。用户关心更实用的蒸馏模型；研究应比较**蒸馏如何改变动态FFN的层异质性、时间创新、功能重要性以及可复用状态**。先从真实四步和其他已保存结果提出竞争解释。

**可分辨预测**：首尾层与中间层差异来自 FFN 层角色、时间条件还是特定源和空间划分？可在已存step/block/source子集中反推不同解释，而不是将五层平均成“全Wan规律”。

## 4. WARD 补充近邻（2026-10-25 原始页面检查）

- [SVD-Cache（arXiv 2601.07396）](https://arxiv.org/abs/2601.07396)：从**主子空间可预测、残差空间易抖动**提出不同表示；该论文缓存的是DiT特征而非本研究准确Q2 FFN创新，提供M1/M2对立假说。
- [SparseDiT，NeurIPS 2025](https://papers.nips.cc/paper_files/paper/2025/hash/83fe5a77502e3d4cfab5960aed0ee6c3-Abstract-Conference.html)：按不同网络层采用不同空间token粒度，给M2/M6层异质性一种外部类比；并非本 Wan FFN shared-column 实测。
- [Sparse Video-Gen，ICML 2025](https://proceedings.mlr.press/v267/xi25c.html) 与 [DFSAttn，ICML 2026](https://proceedings.mlr.press/v306/hu26p.html)：注意力领域用空间/时间分型或Hilbert重排改变**表示与物理局部性**。供探索FFN新空间组织的类比，不将attention稀疏结果/速度直接套用于FFN。
- [RSTR，ICML 2026](https://proceedings.mlr.press/v306/sun26aw.html)：时空预算和block敏感性的比较启发，但其CFG节省前提未必属于当前Wan D-Q四步执行路径。
- 本项目 [Chipmunk源码级对照](E0_SHARED_TILE_PRE_W1.md) 是最近完整实现竞争机制；自家micro16与对方的完整token重排/缓存/packing不能直接等同或宣称优胜。

## 5. 任务交接的合理动作

- 已完成 K1 的“字段是否存在”、K2 的“原布局占用”、K3 的“同专家简单创新/连续shared-column”应视为**已获证据**，供下一问题直接引用。当前无需重复同样的dense采集、后验topk或径向统计。
- 鼓励不同 Agent 自主研究 M1–M6 的**不同机制**；可以提出完全不同的数学构造，不把M1–M6作为限制性枚举。最佳交付是一个**新解释或新表示 + 强竞争机制 + 区分预言 + 现有可用证据或最小下一动作**。
- 多 Agent 的 independent review 应选源/方程确有差异的反例，原有讨论 [QUEUE](../method_discussion/QUEUE.md) 的历史 OPEN 提案不变。
- 想让方法成为执行候选时，才明确其 FFN 计算支出、原生数值依赖、最强等成本baseline和四步视频质量；历史已完成GPU/模型范围均不自动续授权。

**审核结论**：证据正面指向 FFN 条件函数与时间创新值得研究；仅“逐通道、原64组、共享raster列”的局部实现被现有结果限定。维持 E0，扩大表征/因果/计算空间；严格保留所有历史原始数字与独立来源单位。
