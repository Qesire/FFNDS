## 1 · P0：当前真正阻碍机理判断的问题

### GAP-E0-01 · 局部 LN 径向消去不等于完整后续计算的不敏感

**目前知道：** FP64 理想 `epsilon`-LayerNorm 对固定组输出的切向/径向分解显示 Block 0 较强的残差径向对齐，且写回前和 algebraic leave-out 对照削弱纯自写回解释。

**还不知道：** 真实 BF16/RMS/LayerNorm 或实现中的具体消费者、残差旁路、后续 attention、跨 block、跨 denoising step，能否仍感受到这个差异。理想 `J_{LN}` 的局部投影、中心化角度和下一层输出是**不同命题**。

**现在必须改善（不执行新实验）：**
1. 独立 Agent 从绑定源码重建 Block 0 的实际下游数据流，标明每条**归一化分支与残差旁路**、dtype/cast、门控顺序；用正式等式说明理想导数为何只能描述该分支、不能自动描述残差承载的差异。
2. 对五组的 pre、post、leave-out 解释分别提出至少两种**不等价的竞争性机制**：例如结构化 FFN—residual 同向输出，或仅 normalization 的局部几何现象；研究哪些已存字段能否区分。
3. 利用原有保存张量验证中心化角度 / 原始组输出能量 / gate-weighted 能量 / FP64 理想切向评分之间的分歧和例外（数据若未在 Agent 工作环境可直接获得，则列出最小字段缺口，不虚称已验证）。

**后续有条件的区分观测：** 同源同前缀、`||δy||` 相近但径向对齐程度不同的**完整有限动作**，比较真正的 nextnorm/后续 flow/自由视频；这属于需用户独立授权的新模型干预，**当前不能启动**。

**验收：** 独立来源推导至少一条“若仅 LN 短程抑制 / 若确有下游冗余”会产生不同结果的可检测预测；归档一个反例或受限适用条件。不得把 19.82% 称作省算率/可跳过组比例。

### GAP-E0-02 · 当前成果缺少针对性的**另一位 Agent 的独立复核**

**目前知道：** 最新 E0 几何、量化分布、时序统计主要作为单次综合成果合入 main。旧 G6A–G6F 的 Draft PR #9/#12/#13/#19 是不同旧命题的讨论材料，**不能自动充当这份新 E0 结果的独立支持**。

**现在必须改善：**
- 让未参与该分析写作的 Agent **先独立读原始方法和源码**，复建核心 LN 导数、`epsilon` 对径向项的作用、`post−δ_g` 自包含对照，以及报告聚合口径；然后再核对结论，不复制作者摘要。
- 第二个 Agent 从不同机制路线挑战结论（如 residual bypass、group sample 固定选择、离群行/来源聚类、几何同构到已有角度方法）。
- 两位 Agent 使用**不同署名的单独记录**，写明版本/blob、亲自核对了什么、仍不能证明什么；没有实际独立检查时只写 `PENDING_REVIEW`。
- 可以参考 [E0 独立发现目录](../method_discussion/discoveries/E0/README.md)；不伪造同行 SUPPORT，不竞争改共享 `QUEUE.md`。

**验收：** 至少一份有原始式子/源码与反例的独立推导，以及一份来源不同的竞争解释。不得把 PR merged、测试绿灯或引用旧审查当成真实 peer validation。

### GAP-E0-03 · 最关键的功能标签缺失，因果主张不能替代为代理评分

**目前知道：** 保存了原始 dense 轨迹和分解所需部分操作数；没有同前缀的真实“删去/改变一组后” Q2 重算、真实 nextnorm/flow 响应、完整四步视频对照，故原生 `quality_or_speed_acceptance=false`。

**现在必须改善：**
- 形成**标签地图**：`已存可重算的几何/分布指标`、`缺少的动作后条件反应`、`需要新生成/新 native kernel 才能知道的终端质量和成本`，分别列清楚。
- 按“哪个未知能区分两个机制”倒推后续最小字段和同前缀控制，**不先选择最终算子**，不把某个 oracle/hindsight 后置值冒充在线可得特征。
- 理论上正反结果都须推进机制判断：径向结构若在旁路后的后续网络失效，明确这种失败的作用域；若仍有信号，再分析计算自由度。

**验收：** 一个最小、针对竞争解释的观测合同**草案**（对照/输入绑定/标签/排除混杂/独立来源/结果归类），标记 `NEEDS_SEPARATE_USER_AUTHORIZATION`。**没有新实验授权时，以这个可审查草案为完成，不因为实验未运行判为未完成。**

## 2 · P1：防止已有现象被错误泛化或重新偏向 FP4 / 固定算子

### GAP-E0-04 · 输入来源覆盖有真实空档，不能把重复测量当独立来源

**事实：** 当前冻结 CAL24 六源为**主体3、背景3、相机0**；扩展协议中写“各2个”与真实索引不符，原始协议应保留版本及 SHA 作为历史证据，不篡改。

**改进：** 单独做审计表：source id / seed / latent 与视频哈希、source 类别、step/expert/block/row、哪些与旧 CAL24 实际重合；所有聚合先做**逐来源**对照，关注 Block 0 高/低噪声专家与背景/主体差异。后续若要验证相机泛化，先提出真正补齐相机类来源的单独采样建议，**不是自动采集新场景**。

**验收：** 主文将 6 个独立来源、120 个位置、480 个几何案例和 12 次成对运行清晰区分；复核表准确标记 `camera=0`，不得写“已覆盖三种来源”。

### GAP-E0-05 · Q1/Q2 格式机制仍未被直接分离；“量化保存的元数据可利用”未获实测支持

**事实：** 真实新样本是 **A100 HiF4 QDQ → BF16 GEMM**；层级 64/8/4 `lv0/lv1/lv2` 等是在 CUDA 内产生的临时量，现有数据保存的是 pre/post 解码数值，不等于直接保存了内部 scale / code / exponent。**MXFP4 E8M0/32 与 NVFP4 E4M3/16 + 全局尺度是另一种原生 packed 计算路径**。

**改进：** 从 Q1 与 Q2 生产者/消费者源码画出并列状态图，注明各量是持久参数、kernel-local、外部可见操作数还是只存在于格式规范。将现有 `Q2新增零值`、`能量轮廓` 与 BF16/GELU 前已存在的结构分开；讨论尺度层级/符号/边界能否解释高杠杆行，但**不要假装已有代码/尺度频率数据**。比较原生 MX/NV 的公开规范及最新相关论文需按 [深度 Web Search 协议](../agent_protocol/DEEP_WEB_RESEARCH.md) 继续查重，给出最接近机制与反例。

**验收：** 一张 `真实 HiF4 QDQ / 原生 FP4 假设` 的信息时机、可见性、格式、额外读取价格地图，以及“本轮没有测量什么”的字段清单。若需原生 FP4 真实分布，单列将来独立采集需求。

### GAP-E0-06 · 时空相关性的共同均值和专家切换尚未充分解释

**事实：** Block 39 同专家跨步 raw cosine `≈0.919`，去共同均值 `≈0.814`；跨专家样本还包含不同 high/low 专家切换。单个 cos 值不等于可复用的 FFN 计算或稳定视频。

**改进：** 对时间/空间/去噪 step/expert 区分`同坐标`、`相邻坐标`、`跨专家` 与 `被均值中心化后`。对每个主要机制提出对照：跨步相似来自样本共同成分、输入 latent 轨迹或模型功能特征？直接引用保存的 `E0_TEMPORAL_STRUCTURE.json`，不把同 latent 下标叫作同物体跟踪。

**验收：** 至少一条能区分“共同均值造成高相似”与“变化分量本身稳定”的假设，附已存来源级证据；不以 0.919 承诺缓存命中。

### GAP-E0-07 · 高杠杆异常行不能在平均值下消失

**事实：** source8/block30 的 step2、3 轮廓指标明显变化，主要受同一 `row1981/[1,9,5]` 影响；移除它后两个指标均转为小正值。该行的物理/视频意义尚未知。

**改进：** 保留原始行，报告有/无该行的两个版本用于诊断；比较其 BF16 量化前后、code/scale可能性、W2有符号输出、gate、residual、时空邻接，排除采样索引或跨步绑定错误。考虑与视觉 register/outlier 的**机制类比**，但不直接宣布它就是 register。

**验收：** 给出至少一个无需删样本的可检验解释和一个反解释；重现 `E0_PROFILE_OUTLIERS.json` 原始留一结果；局部现象不得被“均值基本不变”一句话覆盖。

### GAP-E0-08 · 文献广度和机制级查重已开始，但还不是独立完成的评议

**事实：** 最新报告已记录 Ba/Brody/Gupta、ShortGPT、Geva、视觉 register/高范数 token、HiFloat4/SmoothQuant 与少步缓存相邻工作；这些构成论文背景，不能把已知 LN 投影/角度重要性当成新数学创新。报告对 Web Search 的描述不等同于其他 Agent 亲自验证了所有来源。

**改进：** 另一 Agent 根据 [深度 Web Research](../agent_protocol/DEEP_WEB_RESEARCH.md) 对 **LN/RMSNorm 不变方向、残差主分支敏感性、FFN gated 方向、动态稀疏/角度重要性、视频蒸馏时空结构**至少形成一个不同的引用追踪路径。对每篇主要竞争论文核对原始公式、对象、实现代码/实验局限；把 `数学同构`、`已有直觉` 与 `本批首次真实 Wan 操作数观测` 明确拆开。

**验收：** 报告可追溯的搜索日期、关键词簇、第一手链接、最近同构方法或反例，以及它**具体改变了哪个机制判断**；没有联网能力的 Agent 明言缺口；不宣称全面查重完成。

**验收：** 新/旧入口均能正确表述这一时间顺序；纯静态核验不会无故拒绝合法完成的旧观测，也不会把新实验开放。完整检查如未在真实环境执行，则如实记为未执行。

**第三步（E0 交付汇合）：** 归档短的**现象/反解释/来源/下一观察**索引，指出 E0 的实际发现和剩余未知；所有 Agent 只做科学讨论，旧方法版本与审查各自保留。若必须新增模型数据，只提交一份可供用户另行选择/授权的最小观测需求，不抢先实现/执行。

### 交付记录约定

每项问题在各 Agent 自己的文件中提交：`GAP-ID`、`发现的问题`、`真实源/数学证明或反例`、`与旧结论的关系`、`解决到了什么边界`、`能区分解释的下一观测`、`是否需要另行授权`。建议写到 [E0 发现目录](../method_discussion/discoveries/E0/README.md) 中各自独立文件；**本清单不是为了让每个 Agent 机械填写十个问题**。Agent 应选择最能改变科学认识的 GAP，并提出不同竞争解释；禁止把问题排查变成大量形式化免责声明。

### 不属于 E0 完成判据的事项

不要求立刻实现新算子；不要求当前就跑全部 GPU/video 实验；不要求为提升 PR 数量而重复写提案；也不要求把所有 GAP 都解决才允许发表新的科学机制。**修复的价值是更准确、更能区分机制的科学认识，而不是纯粹增加文档或“审查通过”的标签。**
