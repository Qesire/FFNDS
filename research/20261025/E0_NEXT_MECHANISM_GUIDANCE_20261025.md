## 第一优先：用已存四臂完整距离，精确定位共享参考解释的失配

这是下一次讨论中的**一个具体、零新模型调用、能够独立复核的科学任务**。当前 [已存结果 JSON](E0_SHARED_REFERENCE_MOMENTS.json) 已包含六个来源 × 四个 step × flow/post 两个边界，以及各子空间的全部六距离和响应 Gram。

### E0-D1 · 简单零模型的代数不变量

取真实四臂 `D,A,B,AB`，`D_{ij}=||F_i-F_j||_2^2`。若四臂输出在考察的二阶统计中能写成 `F_i=μ+e_i` 且臂间误差交叉矩为零，则有非负 `v_i` 满足 `D_{ij}=v_i+v_j`。因此三个**不需要拟合参数**的配对和应相等：

```
S1 = D_(D,A)  + D_(B,AB)
S2 = D_(D,B)  + D_(A,AB)
S3 = D_(D,AB) + D_(A,B)
S1 = S2 = S3            [exact star-null necessary condition]
```

再记录 `range(S1,S2,S3)/mean(S1,S2,S3)`；这是确定性描述量，不是 p-value。即使三和接近，仍需要四臂 `v_i>=0` 才可满足完整零模型；使用已有非负最小二乘拟合作为补充。

**本轮从已有结果 JSON 独立核算的末步 Flow：**

| 来源 | 三配对和的相对极差 | 已有非负零模型六距离相对 L2 拟合偏差 |
| ---: | ---: | ---: |
| 0 | 30.69% | 13.54% |
| 4 | 5.02% | 2.24% |
| 8 | **47.44%** | **20.01%** |
| 12 | 5.70% | 2.57% |
| 16 | 19.84% | 8.56% |
| 20 | 9.92% | 4.01% |

相对极差是 `(max S-min S)/(mean S)`，由 `E0_SHARED_REFERENCE_MOMENTS.json.records[*].subspaces.full.squared_pair_distances` 重算。与已有报告的一致性为强交叉核对；**这项代数必要条件显著失配意味着简单零模型并非精确结构**，而不是直接将失配归因于“网络学会修复”或数值舍入。

### 要比较的三种机制

- **M1 · 共享参考下的近似去相关：** 某些来源和整体投影近似符合四臂 star-distance 关系；子空间的相关矩可能正负抵消。预测：经空间正交分解后，拟合残差在特定子空间显著不对称。
- **M2 · 原生有限数值边界：** BF16 gate multiply/residual add 在离散格点引入组间交互。预测：真实写回后的首个观测边界，三配对和、有限交互 `c=F_AB-F_A-F_B+F_D` 的变化会比冻结 Q2 后的连续组合更突出。
- **M3 · 后续连续传播：** LN、attention、residual 分支及后续去噪使交叉响应产生结构相关性。预测：即便固定本次写回数值状态，随计算深度仍可能出现新的不变量偏离；实际后续图应解释它出现的边界。

可在当前已保存的 `step × {flow,post}` 和 `{full,global_channel_mean,time_varying_spatial_mean,spatially_centered_per_time}` 上先做 M1 分布与 M2/M3 的**可判别性审计**；若数据只有后期边界，直接定位“缺哪个中间操作数”。按前向时间顺序归因，避免把后验子空间统计当成前置决策信息。

**完成判断：** 独立 Agent 复建三个配对和、4臂 Gram/交互等式、非负零模型约束；给出最强的 M1–M3 分歧、一个来源/子空间反例、下一条最短源码或保存数据核对。Agent 应保留独立原始推导与版本哈希。可以直接提交分析文档；模型实验仍需单独用户授权。

## 第二条并行探索：Block0 逐 token 对齐是否超出共同方向？

不同 Agent 可以沿 [E0 原生几何](E0_RESIDUAL_GEOMETRY.json) 和 [竞争机制记录](../method_discussion/discoveries/E0/codex-01a171da-competing-mechanisms-20261025.md) 独立研究：

- 对每个真实 `source/step/block/group` 的 32 个**固定采样行**，使用 LayerNorm 中心化算子 `H=I−11ᵀ/C` 定义 token residual `Hr_i` 与 gate-weighted group contribution `Hd_i`。比较**真实配对**与组内固定种子置换的有符号 cosine 和按贡献能量加权的 `cos²`。
- 再从各自 32 个跨位置向量减去 **5120 维跨位置均值**，比较配对优势是否保留。跨位置去均值与每行的 LN channel 均值是不同操作；二者分开保存。
- 以相近向量范数、来源/step/expert、空间位置等设计受限置换对照，观察是否只是高范数行或邻接性决定了对齐。报告六个来源的逐来源结果，不将 `32行×五组×多个层` 当独立视频。
- 首先检查已保存原始 payload 是否真正包含可重建每行 residual 和 group contribution 的字段；若仅剩 `E0_RESIDUAL_GEOMETRY.json` 的聚合比例，**不能从这些汇总数字反推出 token 置换结果**。先给出可直接运行在已授权保存资产上的最小数据需求/算式。

**H0：** 共同方向、gate 或高范数位置导致普遍对齐，真实配对与置换接近。**H1：** token-residual 与组输出有额外条件耦合，去共同分量和匹配位置后真实配对仍显著高于置换。结果影响未来静态共享基底 vs 条件信息的探索，但两者此时均属于科学发现而非默认算子。

## 第三条并行探索：跨步可转移共同模式 vs 真正位置变化

利用 [已存跨步校准](E0_TEMPORAL_CALIBRATION.json)：

- 比较 `step-conditioned fixed scale`、`fixed scalar + 5120-channel shift` 与更便宜但可前置计算的输入 RMS；明确每类方法拥有的历史字段、校准参数与在线读写开销。
- 注意这份报告的跨位置均值是在 **5120 维 FFN 输出**上的分量；四臂报告的全局/逐帧均值是在 **16 通道 latent flow** 上定义。将其作为两个独立机制视角，除非实际源码与同前缀观测建立跨层映射。

如果将来从这类规律推演缓存，必须按真实调用频度和代价计算：单独只复用 Block39 在 step1、3 对 40层×4步的 FFN 投影，仅相当于 `2/160=1.25%` 的名义 FFN 投影调用数，尚需计算读写、gate、norm 及真实整视频效果。

## 文献比较：把新现象与已经发表的机制区分

根据 2026-10-25 可检索的原始出处，重点比较：

1. [SVD-Cache / Forecast the Principal, Stabilize the Residual，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Chen_Forecast_the_Principal_Stabilize_the_Residual_Subspace-Aware_Feature_Caching_for_CVPR_2026_paper.html)：主/残子空间的不同跨步动力学及 SVD 预测。我们的**跨位置共同均值是一维位置子空间（在每个通道上）**，既不等同于通道 SVD 主空间，也尚未得到真实缓存质量结论。
2. [MagCache，NeurIPS 2025](https://papers.nips.cc/paper_files/paper/2025/hash/311207bb626e36a8f1d3eb92aa67af22-Abstract-Conference.html)：跨步残差幅度比的时间规律与整段 residual 缓存；当前 Block39 固定缩放属于强近邻原语，科学新意应来自真实 Wan 的输入/功能差别及其可检验解释。
3. [Cache Me if You Can（arXiv:2312.03209）](https://arxiv.org/abs/2312.03209)：时间条件下的 scale/shift 与教师轨迹信息。比较本项目的已暴露来源整来源留出、预先可用输入与在线代价。
4. [Relational Feature Caching（arXiv:2602.19506）](https://arxiv.org/abs/2602.19506)：输入变化与输出变化的局部关系、近似条件与官方实现。阅读原始公式后再判断是否有新的条件信息自由度。
