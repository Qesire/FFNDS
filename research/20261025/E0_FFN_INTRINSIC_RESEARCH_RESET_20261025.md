# FFNDS · FFN 本征计算研究纲领（2026-10-25 · Skill/WARD 修订）

**当前科学主线**：从 FFN 真正执行的计算出发，研究输入与上下文如何决定必要计算，以及哪些功能变化可由更少、更共享或重新组织的运算产生。**研究对象**是 Wan2.2 四步蒸馏视频模型的真实 FFN；**当前有界测量环境**是 LightX2V 的 D-Q/HiF4 QDQ→BF16 路径。历史观测维持原样。任务入口：[第一任务](E0_FFN_FIRST_TASK_20261025.md)；[机制与先例地图](E0_FFN_INTRINSIC_PRIOR_ART_20261025.md)；[唯一活跃状态](../ACTIVE_RESEARCH.json)。

## 1. 核心科学问题

> 对给定的 token、层、专家、去噪步和状态，FFN 的哪部分函数作用值得计算？这些作用能否通过提前可获的结构、共享计算或新的表示实现，同时维持四步视频的真实质量？

这个问题连接**计算函数、可获得信息、输出功能和硬件代价**，也允许回答“某种结构适于静态实现”“某种结构具有真实输入依赖”等有价值的科学结论。目标是推动真实 FFN 与整体生成质量—时延的 Pareto 前沿，尽量使用训练自由或小型后训练方式。

### 研究观察的四层对象

1. **内部系数**：preactivation `a`、GELU 输出 `h` 的大小、稀疏性、条件变化；
2. **输出向量与表示**：由 `h_j W_{2,:,j}` 组合成的有符号 FFN 净更新，其有效方向、相关和相消；
3. **功能作用**：该更新通过 gate/residual/norm/attention、后续层与去噪步产生的质量效应，包括背景、光照、细节、运动一致性；
4. **物理计算**：真实可减少的 W1/GELU/W2、权重搬运、tile、索引与路由，以及它们的执行成本。

不同层之间的**对应关系**才是需要发现的机制；既有“通道幅值”“局部误差”“Jacobian 几何”只是各层的可用坐标。

## 2. 从真实代码构造数学对象

对于单个位置，以已绑定 LightX2V 源码为准，抽象 FFN 为

```
r  --norm2/AdaLN--> z --W1(+b1)--> a --GELU--> h
      --(actual Smooth/QDQ boundaries where applicable)-->
      --W2(+b2)--> y --gate--> gated y --residual write--> r'
```

实数简化：
`a_i=W1 z_i+b1,  h_i=φ(a_i),  y_i=W2 h_i+b2,  r'_i=r_i+g_i⊙y_i`。
对固定 gate `g_i`，定义 value vector `v_{i,j}=g_i⊙W2[:,j]`；精确实数分解是
`g_i⊙y_i=Σ_j h_{i,j}v_{i,j}+g_i⊙b2`。
**同一个神经元的 value vector 在不同位置可随 gate 变化**；恒定的 `W2[:,j]` 是更底层的基向量。实际 BF16/QDQ 的加法次序另行审计。

该分解打开三个互补研究坐标：

- **条件系数与基向量**：`W1` 决定输入模式响应，`GELU` 提供连续门控，`W2` 组合输出方向；[Geva 2021](https://aclanthology.org/2021.emnlp-main.446/) 提供语言模型中的 key-value 解释，[Chipmunk Part II](https://sandyresearch.github.io/chipmunk-part-II/) 直接给出 DiT MLP 的 weighted-value 表示。
- **表示几何**：`||Σ_j d_j||²=Σ_j||d_j||²+2Σ_{j<k}〈d_j,d_k〉`。低单元幅值、有符号相消、可压缩子空间、时间稳定方向是不同命题；[Toy Models of Superposition](https://transformer-circuits.pub/2022/toy_model/index.html) 提示 feature 不必一一对应神经元。
- **局部敏感结构**：在固定权重与 conditioning 的连续实数模型下，`D_z y=W2 diag(φ'(W1z+b1)) W1`，其中 bias 不影响导数。对于 gated FFN 对 z 的直接响应，在 gate 与 z 独立固定时左乘 `diag(g)`；当真实 conditioning/gate 随所扰动对象变化时，将其额外链式项列出。**输出的有效子空间**与**Jacobian 的敏感子空间**分开衡量。

**非线性与重表示的分界**：`W2h` 的输出线性组合可以在 GELU **之后**作严格的基变化，例如将 `W2=UV` 写成 `W2h=U(Vh)`；但 `GELU(Ra)` 一般不等于 `R GELU(a)`，所以一个任意旋转不能由 W1 与 W2 的权重吸收并保持相同函数。也要计入因子分解后的两次乘法与中间访存，只有真的低有效秩/复用结构才可能降低总代价。

上述是发现新问题的数学坐标，不预先选择 SVD、神经元掩码、Proxy、W2 分组或缓存。

## 3. 优先探索的四族机制

| 机制族 | 关键分歧 | 能改变认识的观测 | 可能打开的自由度 |
|---|---|---|---|
| **F1 有符号贡献与表示** | 少数 hidden 有独特价值，还是大量 hidden 组合为冗余/互相干扰的方向？ | `h` 幅值、`W2` 向量、贡献 Gram、不同 token/条件下的有效子空间；与随机/静态同预算基线比较 | 通道、组合方向、共享基、条件低维函数表示 |
| **F2 时间—空间创新** | 稳定的是绝对 FFN 输出、方向、幅度，还是跨步变化量？ | 同/跨 expert 与相同 latent 坐标的 `a,h,y` 差异、时空局部变化、固定参考 vs 条件预测 | 条件共享、跨步增量、空间重组、计算重排 |
| **F3 功能敏感性** | 低局部误差是否对应低整段视频作用？哪种误差会扩大成闪烁、背景或运动漂移？ | 匹配幅值的有符号作用、原生有限响应、空间/时间差分、后续 block/step 路径 | 功能加权预算、对时间稳定性敏感的动作设计 |
| **F4 实际计算表示** | 神经元级弱贡献怎样映射到 GEMM tile？更换计算单位是否改善稀疏可利用性？ | token×hidden 散点与 tile occupancy、执行节点先后、权重/索引成本 | 预计算、结构重排、稀疏核、精确或条件近似计算 |

F1—F4 是**开放的机制切面**，不是必须分配的四项算子或规定实验顺序。一次好研究可以从任意一个切面进入，通过数学推导找到新的第五种表示或作用机制。

## 4. 信息何时出现：把发现与部署自然接起来

| 观测时点 | 可用内容 | 对应可考虑的工作 |
|---|---|---|
| **FFN 前** | residual、已算 attention、conditioning/timestep、上一次可合法共享的状态、固定权重 | W1/W2 或完整 FFN 的提前决策、静态/条件选择 |
| **W1 后** | preactivation `a`、GELU 可推的结构 | 以后续 GELU/W2 为对象的条件执行；W1 已付成本 |
| **GELU 后** | hidden `h`、其分布/统计与已有 value vectors | W2 贡献的压缩、共享或条件计算；W1/GELU 已付成本 |
| **W2 后** | 全输出与后验方向 | 解释机制、提供监督或后续步共享；不能回溯节省本次完整 W2 |

分析中标记字段究竟是**源码现成、采样保存、离线 oracle、下一步待采**。任何「前置预测」先写清实际时点；真实动作成熟后再按原生 kernel 比较总代价。

**量化位置**：尺度、码字和动态范围可充当低成本**幅值/范围近似**；其附带离散结构如能改变强对照结果，再作为具体机制研究。HiF4、MXFP4、NVFP4 属于实现/数值生态，不决定 F1—F4 的数学问题。

## 5. E0 既有证据如何服务新的发现

- [径向配对](E0_RADIAL_PAIRING.md)：32 个采样 token、五组 decoded W2 面板上的理想 LN 几何。适于挑战「局部幅值等于后续作用」；不是完整 FFN 可省算比例。
- [四臂有限作用](E0_FOLLOWTHROUGH.md)、[六距离零模型](E0_SHARED_REFERENCE_MOMENTS.md)：在实际 D-Q/QDQ-BF16 条件下，部分有限删除的下游响应和数值边界；适于 F3。
- [跨步结构与校准](E0_TEMPORAL_CALIBRATION.md)：同/跨 expert、共同分量、幅度漂移；适于 F2。
- [实验结果目录](../EXPERIMENT_EVIDENCE_INDEX.md)：过去 A5+HWG 主体外光照/微小物体不稳，是 F3 的新机制线索；历史方法成败对应各自固定计算图、预算和数据域。
- [源绑定](../20261023/C0_coupling_offline_results.json)、[运行时重建](../20261022/R12_E0_runtime_reconstruction.json)：为 claim 选择真实算子、形状、epsilon、step、gate、dtype 和权重布局。

既有统计在精确数值对象上有效。要向 BF16、原生 FP4 或新模型迁移时，先区分**代数恒等、对象结构、经验大小和部署时延**四种可迁移层级。

## 6. AutoResearcher / WARD 默认研究行为

- **开启**：从现象、源码或一篇改变解释的论文产生积极的科学猜想。
- **重构**：只读取与结论直接相关的真实计算图，确认 shape、非线性、gate、时间和残差消费者。
- **推导 / PRD**：构造新的表示、贡献恒等式、条件定理或反例；使不同机制给出**不同的可观察预言**。
- **扩展 / WARD**：多轮搜索经典 FFN 功能、representation/superposition、视频时间一致性、少步计算、稀疏系统与相邻数学；读原论文公式、作者代码与反证。见 [证据地图](E0_FFN_INTRINSIC_PRIOR_ART_20261025.md)、[项目搜索协议](../agent_protocol/DEEP_WEB_RESEARCH.md)。
- **区分**：优先源码、证明、已存证据；对新计算密集型动作编制独立实验方案。
- **沉淀**：各 Agent 在 [E0 独立发现区](../method_discussion/discoveries/E0/README.md) 记录自己的新认识、机制对照、证据身份和后续观察；独立 reviewer 提出实质性证明或反例。

**推荐的写作顺序**：`新机制认识 / 有吸引力的猜想 → 为什么（数学与真实源码）→ 最近先例的相同与差异 → 另一解释的可分辨预测 → 最小下一观测 → 潜在计算自由度`。文档内将「已测」「严格恒等」「条件推论」「跨模型类比」「待验证想法」贴在相应命题旁，证据说明简短而具体。

## 7. 当前阶段与验收

**当前为 E0 开放机制发现与独立讨论**。科学成果可以是更好的数学表述、真正不同的解释、关键反例、一个已存数据上的判别结果或值得深入的理论构造；每项成果说明能改变什么研究决策。

进入后续方法评价时，才对最强静态/动态/文献基线、真实可省 FFN 与总延迟、自由四步视频的背景/闪烁/运动/细节维度做完整评估。已完成的原生实验、授权范围、历史结果均保持原状；新的模型/GPU/训练/视频实验由用户另外指定范围。
