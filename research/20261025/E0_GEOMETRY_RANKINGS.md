# E0 补充：方向对齐改变排序，但角度对照已解释该局部现象

**新结果：首层残差对齐并非所有组共用的缩放，但不能把约20%的投影衰减解释为20%的选择收益。** 对同一批保存张量，按 gated 输出能量挑出最小组，与按理想有限 LN 响应挑组，在 block0 的768个采样行位置中有118个选择不同（15.36%）；前者的合计理想 LN 误差只比逐行最优高 **1.99%**。已有的非中心化角度对照在该 block 的768行全部选中相同最小组。中心化角度则在全部3072行与有限 LN 一致。

这是 [E0 原生观察](E0_DISCOVERY.md)的保存操作数描述，不是实际删组、BF16 nextnorm、后续 flow 或视频结果。6个已暴露来源仍是独立来源单位；4步、32行及5个固定组不增加独立场景数。未新增 GPU、模型调用或视频。

## 为什么先做这个区分

- **解释一：** 首层对齐是近似统一的缩放，只改变损失量级，不改变同位置组排序。
- **解释二：** 不同组、不同位置的方向对齐不同，幅度相近的组也可能交换排序。
- **最强已有对照：** 这种差异本来就由角度重要性表达。即使解释二成立，也不等于出现了新的评分信息或可部署选择器。

本次用保存张量切开前两种解释，并量化第三种解释覆盖多少现象；没有继续拟合新分数。

## 定义与实际数据

复用原生采集的96个非末层位置：来源 `[0,4,8,12,16,20]` × 四步 × blocks `[0,10,20,30]`。每位置32个均匀坐标，固定完整64组 `[0,53,107,161,215]`。逐一校验原始 RUN、操作数及 W2 面板 SHA。排除 block39，因为它没有下一 block norm1。

对真实写回后 residual `x` 和 decoded FP64 面板方向 `δ_h=diag(g) W2_h v_h`，定义：

| 对照量 | 精确定义和用途 |
| --- | --- |
| gated 能量 E | `E_h=||δ_h||²`，局部幅度对照 |
| rstd 缩放能量 B | `B_h=E_h/(||Px||²/d+ε)`，分离行间尺度权重 |
| 去通道均值能量 | `||Pδ_h||²/(||Px||²/d+ε)` |
| LN 切向能量 | `||J_LN(x)δ_h||²`，使用前次已核对的导数 |
| 理想有限响应 F | `F_h=||LN_ε(x−δ_h)−LN_ε(x)||²`，本次描述性目标，`ε=1e−6` |
| 中心化角度 | `2d[1−cos(Px,P(x−δ_h))]` |
| 非中心化角度 | `2d[1−cos(x,x−δ_h)]`，BI 类基础组件对照 |

`P` 去掉每行通道均值，`d=5120`。角度计算使用等价的单位向量弦长，避免小角度下直接 `1−cos` 的消减误差。`ε=0` 时中心化角度与 F 严格相等；实际 `ε=1e−6` 时，全样本最大逐项相对差为 **9.22e−6**。

所有量都依赖完整 post-Q2/W2 贡献和写回后状态，**没有前置低成本可用性的结论**。代数 `x−δ_h` 不是原生 BF16 删组后的状态：分解 GEMM、舍入和残差写回均可能不交换。

## 排序差异与误差差距

每行只在五个已保存组中比较“删去一个组”的代数方向。表中额外误差为 `Σ_r F(r,argmin_h E)/Σ_r min_h F(r,h)−1`；配对比较均在同一来源/步/block/行内，不跨场景混排。每个 block 有24位置、768行、7680对组比较。

| block | 能量与 F 的最小组不同 | 所有组对顺序翻转 | 能量选择的额外 F | 非中心化角度与 F 的最小组不同 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 118/768，15.36% | 9.78% | **1.991%** | 0/768 |
| 10 | 47/768，6.12% | 2.36% | 0.122% | 0/768 |
| 20 | 34/768，4.43% | 1.85% | 0.100% | 1/768 |
| 30 | 30/768，3.91% | 1.65% | 0.089% | 2/768 |

block0 六来源各自的额外 F 为 **0.986%–3.096%**，没有单一来源决定其符号。其751个翻转组对中，有245个原始能量差不超过较大值的10%；该10%仅是描述分层，不是选择阈值。去通道均值不改变 block0 的上述选择结果，支持径向部分而非通道均值解释。

**行间归一化尺度不能解释逐行翻转。** 同一行的 rstd 对所有组都是同一正数，严格不改变组排序；实际 E/B 的逐行选择和翻转计数也完全相同。聚合到整个位置则不同：rstd 会改变不同行的权重，不能把两种比较混为一谈。

**角度对照已覆盖几乎全部局部差异。** 非中心化角度在3072行仅3行选组不同，block0 无差异；中心化角度为0差异。这与已知 LN 几何一致，当前证据不支持把径向投影包装成新增的局部重要性信息。切向近似虽在数值上接近有限响应，仍有少数近似打平的组交换顺序，因此排序翻转数本身不能代替损失差距。

## 匹配固定对照说明了什么

另用其余五来源，在相同 step/block 的五个固定组中按合计 F 选一个固定组，应用于留出的第六来源。该描述性固定对照的合计 F 相对逐行理想最优分别高 **47.03%、57.24%、45.01%、49.91%**（blocks0/10/20/30）；即使事后逐位置选一个组，仍高约 **34.63%–38.73%**。

它说明这五个方向的行间异质性比“径向改分数相对能量再改善多少”更大，不能仅用一个永久最小组解释全部样本。它不是新来源视频验证、216组动作族上界、可实现动态收益或省算率：五个来源均已用于发现，且逐行最优具有全部事后信息。

## 本轮文献核对如何改变判断

检索日期2026-10-25。使用 Web Search、arXiv 原文及作者源码，从归一化/角度剪层、DiT 剪枝的量级与粒度、视频量化的时序敏感性三个方向搜索，再沿残差缓存引用回溯。实际核心阅读如下：

- [ShortGPT，§3.1–3.2](https://arxiv.org/html/2403.03853v3)及作者 [metrics.py](https://raw.githubusercontent.com/icip-cas/ShortGPT/main/shortgpt/metrics.py)：原 BI 是输入/输出 cosine，经校准静态删层。此处只借用角度组件，改为同状态的五个组方向；不是复现其整层方法。该对照解释了几乎所有有限 LN 选择，削弱“新指标”的说法。
- [6Bit-Diffusion，§4.1–4.3、§5.1](https://arxiv.org/html/2603.18742v1)：用前一步 block 相对 L1 预测层量化误差，并用前两步增量距离判断缓存。其 CogVideoX/50步/RTX5090 与本项目四步双专家 HiF4 不同。历史时序信号与本轮事后方向量的信息时机不同；不能把当前角度结果当成已经找到廉价选择器。
- [Post-Training Pruning for Diffusion Transformers，重要性及粒度章节](https://arxiv.org/html/2607.00927)：原文区分重要性量级与比较分组，促使本轮将逐行、位置聚合和匹配固定选择分开。没有采用其新的幂次评分或借用其质量结论。

从6Bit-Diffusion回溯 [Δ-DiT](https://arxiv.org/abs/2406.01125)，检索获得原始摘要；本轮尝试的 v2 HTML 地址404，未将其完整方法计为已读证据。未找到并核对6Bit-Diffusion官方实现，故其低开销/加速数字未作本项目可用性的证据。这里不是穷尽查重或新颖性认证。

## 下一项有区分力的工作

这一步已经回答：对齐能改变局部排序，但角度对照已表达它。**下一问应是同一原生前缀、局部输出误差匹配但角度不同的有限动作，是否仍在后续 flow 上存在方向一致的差异。** 保留能量、角度及匹配固定动作，才能区分“只在下一次 LN 看起来较小”和“具有后续功能意义”。

当前保存张量没有这些原生干预标签；旧 C1 的标量标签也不能与这里不同来源、不同组动作逐行拼接。本轮未登记或启动新模型任务，E0阶段及未选定算子的状态不变。
