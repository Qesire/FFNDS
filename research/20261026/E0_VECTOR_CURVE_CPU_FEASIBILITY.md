# 共享投影曲线：原始权重几何的小规模可行性判别

**新实测结构是：这四个预指定 W1 方向周围的最近邻仍很分散，真实保存输入上的一投影曲线丢失大量小簇功能，而 signed W2 交叉项在这些簇上接近零。** 这把下一问题指向输入流形上的可获得坐标与有符号值几何：原始权重余弦低，是否仍有少量实际投影足以表达必要输出？竞争解释是这些神经元确实携带许多独立系数，或原生 Q2 又引入额外变量。最便宜的下一判别是对同一固定16坐标做有明确基数预算的函数空间残差见证，而非重选锚点或拟合部署 bank。

本独立记录读取 root 已完成的唯一 CPU RUN、冻结计划及工具，并汇总其中已存标量；没有重读操作数作数值复算、重跑诊断或启动模型/GPU。执行范围已完成；后文的新判别是提议。正式视频质量仍 `quality_accepted=false`。

## DISCOVERY：本次检验的是原始 W1 共享投影

在真实 post-Q1 输入 `q` 上，连续参照为

\[
c_i(q)=\phi(w_i^Tq+b_i)/s_i,\qquad
y_C(q)=\sum_{i\in C}v_i c_i(q),
\]

其中 `φ` 为 tanh-GELU，`w_i/v_i` 是原始 decoded BF16 W1 行/W2 列，`s_i` 是原 Smooth2。代表为 `u=w_anchor`，固定 `α_i=<w_i,u>/||u||²`，曲线为

\[
\hat y_C(t)=\sum_{i\in C}(v_i/s_i)\phi(\alpha_i t+b_i),\quad t=u^Tq.
\]

该构造保留每个原 bias、Smooth2 和 W2 向量；它没有把四个 GELU 合成一个 GELU，也没有拟合多项式。若 `w_i=α_i u`，它是连续算术下的条件恒等式；本次直接检验这些特定权重及保存输入能否接近这个条件。参照由 FP64 重构，真实 Q2 与中间原生舍入另列。

### Q2 余项的正确闭合域

对同一小簇，以 FP64 原 W2 做投影，定义

\[
e_P=V_C(c_{pre}-c_{cont}),\quad
e_Q=V_C(c_{post}-c_{pre}),\quad
e_N=V_C(c_{post}-c_{cont})=e_P+e_Q.
\]

保存重组残差 SSE 为 `3.18e-32–2.03e-31`，核对了同一 FP64 代数分解。`e_P` 包含原 W1/GELU/Smooth 的中间数值差；`e_Q` 直接使用实际保存的 Q2 前后系数。表中 `e_Q` 除以 `||V_C c_pre||²`，其余对照除以 `||V_C c_cont||²`；gate 版两者同时乘原 gate。

在这些簇上 Q2 项能量显著大于 pre-Q2 连续差额，而曲线方向误差又大于这两者。**向量余项可相加，SSE 仍含交叉项。** 这没有重放完整量化依赖组、原生 BF16 W2 GEMM、bias/gate/residual 写回，也没有证明删去 Q2 是可接受的数值改动。完整 Q2 共享 scale 的其它 hidden 依赖仍在原保存系数里。

## 竞争表示：输入流形与值几何可以不同于原权重余弦

写 `w_i=α_i u+e_i`。原始余弦度量 `||e_i||²`，但保存分布上的投影残差由

\[
\mathbb E[(e_i^Tq)^2]=e_i^TC_qe_i,\quad C_q=\mathbb E[qq^T]
\]

控制；此处用二阶矩，保留固定 bias。若残差落在输入低能量方向，原权重近似正交仍可能有强数据相关。反过来，小范数残差也可能是被大 W2 差分放大的功能模式。最终要判别的是 `E_q[r(q)^T K_G r(q)]`，`K_G=V_C^TG²V_C`，而非任一单独余弦或激活幅度。

本次 α 来自原权重投影，且在实际四份面板上失败；它没有求数据加权 α、联合投影或任意非线性映射。输入流形解释因此仍有独立预测，尚无实证支持。只有16个 neuron、一个 block、两个来源/两个同专家 step，无法据此判整个曲线或 reduced-coordinate 家族失败。

一个必要的可辨识条件是**绑定可执行函数复杂度**：有限样本的标量 `t` 若互异，总能被高阶一维多项式插值。高 covariance rank、低线性相关或本次曲线误差，都不能单独否证“任意非线性 ridge”。插值所需基数可能使实际 W1/W2 无收益；研究应比较可省算的固定函数空间。

### 最便宜的下一判别：固定特征空间的 signed 空间残差见证

保留当前16坐标/四锚点/四面板，不重选 neuron、不生成部署 bank。用4个原 anchor 投影 `T=q Uᵀ`，预先规定两个函数空间：每簇自己的单坐标 cubic `[1,t,t²,t³]`，以及16坐标联合响应的四坐标 quadratic `[1,T_j,T_jT_k(j≤k)]`，后者共15列。多项式只作为有固定计算预算的鉴别器。

对32行的特征矩阵 `Ψ`，用小 QR 构造其列空间正交投影 `P_Ψ`。目标系数矩阵 `C` 可分别取连续、保存 pre-Q2、post-Q2。直接计算

\[
L_\Psi=\operatorname{tr}\{K_G C^T(I-P_\Psi)C\},\qquad
E=\operatorname{tr}\{K_G C^TC\}.
\]

`L_Ψ` 是所有该固定基 readout 的样本内最小 signed 输出 SSE；等价地，`I-P_Ψ` 给出所有该空间必须消失的行方向对照。它无需拟合/保存可部署 bank，但数学上是一个数据后验函数空间 oracle，不能当持出误差或上线效果。分别查看四份面板，避免把128行拼接后的覆盖当跨来源泛化。

- **输入流形/联合坐标解释：** 四坐标 quadratic 的 raw 与 gated `L/E` 显著低于单坐标 cubic，pre-Q2 上改善并随来源保留；原 raw-cos 划分遗漏了联合信息。
- **多独立系数解释：** 这些固定小函数空间在连续目标上仍残留大量 signed 能量。该结论只限制两个指定基空间，理性函数/其它低维坐标仍独立。
- **Q2 依赖解释：** pre-Q2 的 `L/E` 小而 post-Q2 大，提示这些输入坐标未包含实际共享-scale的其它变量；仍需区分量化跳变与缺失变量。

预计预算：重构原16个 W1 投影约10.49M MAC，原 W2 的16×16 raw/current-gate Gram 约6.55M MAC，加小特征/投影计算后总上限20M MAC、1 CPU线程/2GiB/30秒/1MiB输出；输入和原 shard 已有，无新模型/GPU/QDQ。该后续尚未实现、登记或执行。若 root 选择此研究，应另冻固定源/预算，保留当前计划与 RUN 原字节。

## FFN 工作与完整视频功能的含义

本次确实支付了离线 W1/W2 计算，没有运行省算算子。共享投影若只复用 W1、仍计算原16个 GELU/读出，就没有自动减少 W2。未来若把 `H_a` 个 neuron 写为 `k` 个输入坐标、`R` 个非恒定共享基，保留其它 `H_e` 个通道，理想投影工作为 `MD(2H_e+k+R)`，原来是 `2MDH`；基构造、Q1、Q2闭包或替代误差、packing、读出权重和 gate/residual 仍须计账。

对16坐标的四坐标 quadratic，常数可并 bias，`k+R=4+14=18<32` 是理想形状可省算条件；四变量 cubic 有35个含常数基，已经超过同一16坐标的此预算。这里没有相应误差、物理 kernel 或时间测量。小簇低残差只会支持继续研究表示。

最新[完整 dense 有限映射结果](E0_WHOLE_FLOW_COUNTERFACTUAL_RESULTS.md)说明这些特定 Student 状态偏移经完整 dense 单步也扩张，且候选 signed 注入随来源改变。该证据要求未来表示保留必要状态方向；它没有测本16个 neuron 的因果作用。图锚点为 `G18→F04/F06→F08R/F08→F09→F12/F13`：当前是 posthoc CPU function evidence；通向原生替代、少算 GEMM 和正式视频质量的边均 conditional/OPEN。`P23/P24` 提供独立完整路径背景，不作为本曲线成功或失败的因果证据。
