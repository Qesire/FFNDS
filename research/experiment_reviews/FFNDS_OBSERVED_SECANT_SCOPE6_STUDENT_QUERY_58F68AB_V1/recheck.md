# Scope6 教师回放独立复核

`/root/full80_review` 批准 `e52ec140b0e4c02111f6e60022e658a2e0febabd35b25fe9e8634ec9765b22ae`。独立复核核对了范围文件和打包源码哈希、三个不同 V2 生成作业的成功退出，以及 18 份真实载荷的预检。三臂共享的 64 个查询 ID 都位于两个探针集合之外。预检没有执行模型或教师。

回放只用各臂实际保存的学生 U1、当前 gate 与自身 anchor，在原生 BF16 checkpoint 上计算 18 次 64 行 FFN。总量为 1,152 token-FFN、0 D4 和 0 NFE，单卡、零重试。局部结果的解释范围为单一来源各臂自己的学生轨迹。
