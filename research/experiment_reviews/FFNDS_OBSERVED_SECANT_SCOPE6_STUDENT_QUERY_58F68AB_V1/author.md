# 0392 六位置教师回放自审

独立复核范围为三条已完成的 vbi_0392 真实生成视频的 18 个命中位置。三臂为 readout-static-6、readout-online-6 与 Global-P64-6，分别使用自己的缓存、当前 gate 和真实学生 U1。教师仅在保存的 64 行上执行冻结 Wan BF16 MMWeight.apply W1、tanh GELU 和 MMWeight.apply W2。由已完成的视频退出回执绑定各查询载荷，每臂另核对 148 个严格 Q1 调用和 12 个目标调用。

相同的查询 ID 排除新读出及历史 Global-P64 观测 ID 的并集。Global-P64 的观测只读其历史 canonical IDs 与实际 W1/GELU 路径，读出则使用本轮固定探针。教师目标独立于生成，在原生 gate 加权下逐位置提供 MSE 及相对自身 Dense anchor 的风险。局部误差可随各臂学生状态漂移，不能单独判断视频的晕眩、重影和动作是否保留。视频比较及最终功能判断由完整播放另行完成。

一项 A100、4 CPU、64 GiB 主存、最长 1 小时的无重试作业。18 次 64 行教师调用上限为 1,152 token-FFN，无新的完整视频和去噪步骤。只读数据预检校验归档头、真实退出、门控字节及载荷哈希，预检不加载模型权重或计算任何教师输出。
