# Root self-audit: bounded P64 history representation and dead-write probe

Author: /root. Implementation author: /root/teal_full_llm_calibration_build_terra; root owns job materialization, ACTIVE and actual execution. This is a new four-case, training-free FFN operator experiment proposal, not an executed result or a video candidate acceptance.

The completed high-stage P64/Y-only videos motivate preserving the selected correction: Y-only produces lower continuous flow and visible overlapping bird contours, while the previous high-P64 arm preserves substantially more motion. Independently, the actual packed source clones and updates a full old-h array that it never returns. This exposes two different freedoms: remove an unused write without changing arithmetic, or represent the historical h with fewer bits while retaining the same action. No denoising step, attention, token, frame or block is skipped.

Four exposed development cases are source898/source96 × high/low expert, block20, seed42, full native M31668 raster rows. The high transition is step0→1 and low step2→3. Old closed raster/causal-proxy RUN/EXIT and asset identities remain unchanged. Same raw BF16 checkpoint, current x, old h/Y and current gate are used. Teacher h/Y never selects a mask. B/C/D must match A's real selected-index SHA, and A must match the already frozen P64 SHA; an observed mismatch is a failed scope, not a reason to substitute another mask.

A is the existing packed action. B omits the dead full-h clone/update, with identical BF16 selection, rounding, W1/GELU/W2 and gate; actual output bytes must match A before compressed arms proceed. C is saturated E4M3FN history plus an exact BF16 64-row shadow. D is per-column signed-int8 history with FP32 scale plus the same shadow. The shadow preserves the causal selector. The int8 zero-column and tiny nonzero scale rules explicitly avoid GPU flush-to-zero division by zero. Native E4M3 storage conversion on A100 is to be observed, not assumed from the API.

Competing predictions are (1) signed history quantization errors mostly cancel in the selected W2 correction so C/D remain close to B, versus (2) quantization error can exceed a small temporal innovation or align with W2/gate, so local cache RMS is misleading and C/D drift. E4M3 clipping/relative error and per-column int8 range/absolute error provide different counterexamples. A/B equality is a separate single-transition claim: a future consumer of updated h would invalidate that optimization.

Each arm has one warm call, three timed calls and one output comparison call. All actual proxy, selection, weight/cache gather, mask identity, finite checks, encode/shadow/scale, selected decode, GEMMs, BF16 delta/merge, gate and synchronization costs are paid and labeled. The real current full FFN Dense reference is run five times only after all candidate actions, using the same device and parameters, and compared separately with saved teacher Y. Encoder one-time cost and online action cost are reported separately, with their sum for the actual one-reuse-per-expert setting; warm repeated timings do not amortize encoding over imaginary reuses. Logical resident payload size does not establish cumulative allocator peak or physical I/O.

Per case proposed bounds: CPU preflight2 threads/600s/outer720s, one checkpoint full SHA; GPU1 A100/2 threads/1800s, cumulative reserved≤24GiB, host RSS≤32GiB, new HF≤16MiB; independent metadata verifier1 CPU/300s/≤32MiB input and≤16MiB output. Known instrumented read budget≤40GiB per case includes the28.58GB CPU checkpoint SHA, backend/source/environment hashes and selected captured/weight loads; OS mmap and uninstrumented metadata reads are UNKNOWN, not a claimed physical disk quota. Four disjoint GPUs and CPU pairs may run concurrently, global cap4. Full-model loads, video generation, fitting, training and quality-model calls are zero. Each scope is single-attempt with durable predebit/completion/UNKNOWN failure state and actual exit receipts; no automatic retry.

Independent review must challenge actual arithmetic/aliasing, source/asset/job closure, budget accounting, typed verification and failure behavior before root registers exact scopes. If B matches A and C/D preserve local corrections at lower observed cost, the next question is a separately reviewed all160 free-student video implementation and multi-source quality, not immediate deployment. If C/D distort corrections or conversion exceeds savings, retain the measured counterexample and evaluate another historical representation rather than retuning K on these two sources.
