## Actual reference and write semantics

Each arm adds 40 full-M W1/GELU and 40 full-M W2 shadow evaluations. Dense shadow uses the active native MMWeight layout and `torch.addmm(..., out=BF16)` and must match actual native h/Y bytes at every high-step1 site. Student shadow consumes its own current normalized/modulated W1 input; it is a same-state local reference, not the input of the separate free Dense trajectory. Shadow outputs never replace model outputs.

At the W1 interception the live residual R already contains cross-attention. Each expected write clones R and evaluates the original two-operation BF16 `clone.add_(Y * gate.squeeze())`; it does not add attention again or fuse FP32 arithmetic. The original post_process executes once. Its result must match the expected candidate write byte for byte at each observed site. Runtime gate identity is BF16 `[1,1,5120]`, stride `[30720,5120,1]`; metadata retains shape/stride/dtype and flattened values. Live weights, inputs, caches and residuals are read only. Observation completes on the active compute stream before cache release and original offload swaps.
