# 两类全 80 位置 Wan 视频作者自审

最新方案固定两类各一组静态与在线在 DEV3 上的完整自由生成。若当前观测恢复了固定算子漏掉的有用响应，在线臂可能改善 `vbi_0392` 的额外画面破碎，同时保留 Dense 的晕眩重影和动作。若 64 行观测混叠有用方向，侧重欧氏目标的拟合可使在线臂破坏动作或背景。匹配静态、逐臂的固定 query 教师审计，以及完整连续盲评能辨别这些观察。

- 每个独立范围只运行一个预定实验臂、三个冻结源 `vbi_0392`、`vbi_1013`、`vbi_0800`，均为 seed42。四项范围总计 12 D4、48 NFE。绑定每源图像、prompt、裁剪、生成前噪声、checkpoint、HHLL 调度及原生输出配置，与归档 Dense、Q1r2 和 Global-P64 视频同身份。
- 每个学生轨迹自生各专家 40 层的 Dense anchor，命中时由绑定的六个 L64 与其余 74 个严格 Q1 底层矩阵执行本臂更新。读出和模式各自共享静态、在线舍入以及缓存路径。在线真正调用 80 次 64 行 BF16 FFN，静态调用零次。每层检查 CAL 所见原生权重的字节和一次当前 gate 写回。
- 当前 probe 是冻结 NumPy seed42 全 raster 排列。共同 query64 排除新方法 probe 与历史 Global-P64 canonical64 并集。在线只读取 probe，生产时只保存 query 的学生输入、当前 gate、cache/预测等，结束后另立一次固定教师回放分析，预算为 61,440 行。
- 每任务 1 张 80 GB A100、4 CPU、160 GiB 主存、90 分钟。有效并发上限两张。最宽模式缓存每专家约 24.2 GiB，加每臂逐位置证据和中途 40 GiB 空间下限，提交要求共享归档至少 96 GiB。运行证据包括四步调用与 latent、160 个 gate/作用位置、MP4、80 个逐位置 query 文件和数值配置。各段研究落盘耗时不作为部署加速指标。
- 两类的合法执行仅由参数与部署数值合同、冻结资产和资源决定。局部曲线与历史 oracle 仍是诊断。人审以全程画面为依据，逐维指标并列呈现，保留 `METRIC_HUMAN_DISAGREEMENT`。
