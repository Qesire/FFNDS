# 学生状态的离线 64 行教师自审

每条完成的自由视频在 80 个命中位置保存独立 query64。设计固定 12 条 Main 视频之后回放 960 个位置，最多 61,440 个 token-FFN，新的 NFE 和完整视频数均为 0。

使用已绑定的 Wan 原生 BF16 W1、tanh GELU、W2 在保存的学生输入上重新计算 64 行教师。逐位置核对视频、真实 gate、query 与固定观测器及历史 Global-P64 行的互斥、归档的 native weight hash。实际 gate 加权，锚点为同臂自己生成的 Dense 输出。某臂逐位置误差更低，仍可能因自身学生前缀状态漂移而导致不同的动作结果。配对功能结论以完整连续视频为依据。

一项 80 GB A100 作业，4 CPU、64 GiB 主存、1 小时。按位点装入一套专家权重，处理已登记的每个视频的已存 query，保留输出身份和预算消费，无自动重试。
