# FFNDS E0 · Agent 阶段锚定与偏航回收

## 默认深入联网检索：探索的第一手外部证据

**每次 E0 科学探索在工具允许时主动开展广泛、深入、多轮的 Web Search**，参考 [跨领域检索与证据追溯规范](DEEP_WEB_RESEARCH.md)。不要停留在 3–5 条关键词结果或同一批论文摘要：从量化机制、FFN 内部数学、视频蒸馏、时空与下游质量、原生硬件执行等互补方向搜索，沿最有启发的论文追溯引用与后继工作，阅读方法公式、局限性和官方源码，主动寻找可能推翻当前直觉的机制。检索的产出应该是**新现象与竞争解释**，不是照抄热门论文或立即敲定 G6D/G6E/G6F。独立 Agent 应主动检索不同的反例与最近先例。记录日期、主要检索方向、原始链接和尚未覆盖的范围；无法联网时明示限制，不伪造已查证的文献。


**唯一活跃阶段以 [ACTIVE_RESEARCH.json](../ACTIVE_RESEARCH.json) 的 `current_stage` 为准。** 本文件解释如何在 E0 开放探索中工作，不能自行改变主研究目标、实验权限或独立评议规则。上游方法论固定为 [AutoResearcher source manifest](ACTIVE_SOURCE_MANIFEST.json) 的 `5bd7ec537ae63f2b6a6dd579f0e886aff58a177c`；按问题选用 research-expansion、problem-reformulation、mechanism-research，而非机械重复其标题。

## 启动时的最小锚定动作

**开始任何新的 FFNDS 研究回合**（包括只说“继续”、GitHub Copilot / 外部 agent 的 PR、独立评议）先读取：

1. `research/ACTIVE_RESEARCH.json`：主目标、唯一阶段 `current_stage`、执行边界。
2. `research/20261024/FIRST_TASK_E0_QUANTIZATION_FFN_DISCOVERY_20261024.md`：当前唯一 E0 问题、原始证据入口。
3. 只针对自己选择的科学问题读取需要的真实源码或旧结果；既不无目标扫库，也不按旧 HANDOFF 的“下一任务”走。

**E0 的研究产物**不是算法路线图，而是一个有意义的*现象 / 条件结构 / 未解张力*及其至少一种不同解释，说明下一条可观察事实会怎样改变认识。相互竞争的探索方向 A/B/C/D 均有效，A 只是第一个进入点，不是预设“量化最有价值”。

## 发生偏航时怎样纠正（回收，不是封禁）

| Agent 出现的倾向 | 为什么偏航 | 纠正后仍有产出的做法 |
| --- | --- | --- |
| 从“FP4 带尺度”立刻跳到 Q1 K-panel、Q2 W2-panel、N 组或 rank-r 算子 | 将候选算子当作已发现的规律 | 将算法写成 **unpromoted idea seed**；抽出它依赖的隐含结构，问“这一结构在真实 Wan 是否存在，有何竞争解释？” |
| 沿某一个旧 Proxy 指标持续微调公式和阈值 | 优化既定度量而非解释 FFN | 问该指标与另一真实现象何时分歧；找最短源码/旧资产对照。若只有已知 RMS/amax 重新编码，则转向新结构 |
| 直接说“原生 FP4 省算”或把 HiF4 QDQ 统计当 MX/NV 样本 | 混淆表示、量化步骤、真实执行 | 将 HiF4 源实证 / FP4 格式事实 / 原生硬件推论**并列分层**；指明实际缺少的操作数字段 |
| 从 C0 合成反例、旧 C1/R13 负结果泛化到所有路线 | 把局部条件事实当自然数据频率或普遍排除 | 保留其已证边界，提出哪一项真实 FFN 条件会决定它是否普遍 |
| 围绕风险、不确定性列出大量拒绝理由 | 丢失科学创造性 | 给出**最强可成立机制**、一个能切开两解释的对照，指明即使失败会获得哪条结构认识 |
| 创新性讨论把“可能实现”提升为主研究方向或安排 GPU/coding agent | E0 尚未完成现象选择且方法讨论没有执行权限 | 旧提案不删除；登记为 candidate seed，明确不改变 `current_stage`、实验暂停和下一任务 |

**偏航判据只针对“过早提升研究权威或执行权限”，不是禁止任何类型的创意。** 在 E0 中可以随时产生强算子想法、数学等价、反例或跨领域假说；它们是供将来解释/检验的种子，无须先得同行支持或视频验证。真正要纠正的是**把种子变成了唯一行动计划**。

## 独立多 Agent 的三种讨论职责

**发现者：** 从真实源码、论文或旧结果提出一个具体有意思的结构和两种竞争解释；可以从量化、FFN 内部、蒸馏时空、下游质量任一入口开始。每个 agent 独立存档到 `research/method_discussion/discoveries/E0/` 下自身文件，不相互覆盖。

**挑战者：** 不重复发现者的摘要；选择最具科学价值的反解释，独立检查一个算式、源分支、字段语义或旧数据反例。挑战要推进认识：“哪一个观察能分辨？”而非“没有大样本无法做任何结论”。

**整理者：** 区分已经有源码/数学/历史资产支撑的观察与尚未观测的假设；从真正的独立论证中抽取下一项现象检查，不统计空洞共识、不指定算法。只有在用户明确改变阶段或完成被认可的 E0 发现总结并得到明确阶段更新指令时，才可以序列化修改唯一主研究状态；讨论者不竞争修改它。

外部 Agent 若不会自动读取 `AGENTS.md`，**启动器必须显式附带**上面两个文件以及本文件，单靠 Git 文件无法强迫模型遵守。

## E0 任务启动提示（供外部 agent launcher 直接粘贴）

> 你在 FFNDS 的当前阶段是 **E0_OPEN_DISCOVERY**，任务是发现并解释真实 Wan FFN 中的有意义结构，不是找一个立刻实现的算法。先读取 `research/ACTIVE_RESEARCH.json` 和 `research/20261024/FIRST_TASK_E0_QUANTIZATION_FFN_DISCOVERY_20261024.md`，再按本题选用固定 AutoResearcher 的一个或多个技能。独立选择一处真实源码、历史观测或数学张力，提出不同的机制解释，并指出一项最有区分力的下一个观察。可以自由构想新算子，但只能作为 idea seed；不要因此更改默认研究方向。区分已测数据、条件定理、格式规范与待证假说，不运行 CPU/GPU/model 实验，不修改共享 `QUEUE.md` 或 `ACTIVE_RESEARCH.json`。回答从**新发现的结构/未知**开始，而不是从防御性说明或合规声明开始。

## 观察质量的最小复核

合格的 E0 发现不是填满模板，而是**当这一结论为真/为假时，另一种机制解释或下一步信息选择真的会改变**。同行复核要据此判断：
- 现象源自真正的 Wan 计算流/已存资产，还是只从格式名称推测？
- 给定同一个观察，两种机制是否有不同的可见预言？
- 最经济的下一个动作是在查一个源字段、证明一个式子，还是需要后来单独授权的原始数据？

**没有这种分歧也可以写理论种子，但不要把它宣布成“已确定研究方向”。**

## 工具能够强制与不能强制的边界

`tools/check_autoresearcher_binding.py` 的**手动静态运行**只核对入口指向同一个阶段、阶段文件存在、固定 AutoResearcher 未被篡改、实验暂停仍在。它不能读懂所有 agent 的推理，也不能取代独立科学评议；当前 workflow 仍是 `workflow_dispatch`，不自动运行测试或实验。真正的思路偏航需要在 PR 与发现记录中按上述回收方式审查；GitHub 分支权限若未启用必需检查，不能宣称自动阻止合并。
