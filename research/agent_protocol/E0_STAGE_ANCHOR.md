# FFNDS E0 · Agent 探索锚点

**当前阶段：`E0_OPEN_DISCOVERY`。** 以 [ACTIVE_RESEARCH.json](../ACTIVE_RESEARCH.json) 为唯一研究阶段与授权来源；本文件用于将 AutoResearcher 的创造性原则传递给每位研究 Agent。

## 每次研究从一个科学问题开始

启动时读取 [E0 第一任务](../20261024/FIRST_TASK_E0_QUANTIZATION_FFN_DISCOVERY_20261024.md)、[当前关键问题](../20261025/E0_GAPS_REMEDIATION_REQUIREMENTS.md) 和与所选问题相关的原始计算流/实验记录。优先选择**最能改变科学认识**的未知现象，而非平均分配十个缺口。Block 0 的 residual 径向对齐是当前有价值的入口，量化层级、FFN 内部几何、蒸馏时空与高杠杆 token 是同等开放的竞争线索。

用固定版本 [AutoResearcher](ACTIVE_SOURCE_MANIFEST.json) 的 research-expansion / problem-reformulation / mechanism-research 选择最适合的推理路线：

**观察或问题 → 新的机制解释 → 最强不同解释 → 来源/数学检验 → 一项区分性下一观察。**

新的算子、等价变换和跨领域启发可以自由提出，作为 `idea seed` 归档；E0 的阶段成果以现象和结构认识为中心。方案成熟后，由用户决定是否进入算子实现和原生实验阶段。

## 广泛深入的 Web Search

每轮实质性研究主动按 [DEEP_WEB_RESEARCH.md](DEEP_WEB_RESEARCH.md) 扩展检索：近期与经典论文、量化/计算几何、少步视频生成、FFN 数学、残差传播与硬件执行，沿关键论文双向追踪引用并检查原始公式、消融和代码。独立 reviewer 应主动寻找最接近的机制与反例。最终说明检索时间、实际范围，以及哪条外部证据改变了当前解释。

## 遇到路径依赖时，转换为更好的问题

| 当前思考容易收缩到 | 转换后的科学探索 |
| --- | --- |
| “FP4 有尺度，因此应该做 K-panel / N-group 稀疏” | 量化尺度、符号、组耦合在真实 Wan 中揭示了什么独特结构？哪种相同幅度反例能区分？ |
| 持续细调 Proxy 评分公式 | 在什么条件下两个指标会对同一 FFN 的功能价值给出不同排序？ |
| 将旧局部负结果推广到整个方向 | 精确指出旧动作与证据范围，再构造另一种信息、表示或机制的可测预测 |
| 把理想 LN 消去当可省算比例 | 沿真实 gate / bypass / nextnorm / flow 追踪差异，分辨短程几何和长程功能 |
| 只阅读最熟悉的量化论文 | 搜索残差商空间、角度重要性、视觉 registers、蒸馏视频时空及原生数值格式的最强竞争解释 |
| 讨论陷入风险罗列 | 写出最强可成立的机制，给一个可区分反例，并说明两种结果各自意味着什么 |

这套转换旨在拓展搜索空间。一个猜想可以先保存，随后通过源码、数学、已有数据或经另行授权的针对性观测发展。

## 多 Agent 的三种角色

- **发现者：** 独立研究一处真实现象，提出解释 A/B 与能够区分它们的观察，保存在 [E0 独立发现目录](../method_discussion/discoveries/E0/README.md) 自己的文件中。
- **挑战者：** 从原始源码、数学或新文献独立重建关键前提，寻找最强反解释，指出如何改善理论或区分实验；记录自己核查的精确源版本。
- **整理者：** 汇总有证据支撑的发现、分歧与下一条高价值观察；保持旧提案和 reviewer 的独立署名。共享 `QUEUE.md` / `ACTIVE_RESEARCH.json` 由串行协调者在获得用户阶段指令后更新。

## 可直接传递给外部 Agent 的启动提示

> 你正在参与 FFNDS 的 **E0_OPEN_DISCOVERY**。先读 `research/ACTIVE_RESEARCH.json`、`research/20261024/FIRST_TASK_E0_QUANTIZATION_FFN_DISCOVERY_20261024.md` 与 `research/20261025/E0_GAPS_REMEDIATION_REQUIREMENTS.md`。默认使用固定 AutoResearcher，并主动开展多方向、深入、迭代式 Web Search。选择一处最有意义的 FFN 结构现象，独立核对真实 Wan 源码或已保存证据，提出有不同预言的竞争性解释。输出：**最重要的新认识 → 关键数学/来源依据 → 最强反例或竞争解释 → 下一项有区别力的观察**。欢迎创新算子作为探索种子；当前先完成科学发现。讨论成果写自己的文件。真实模型实验按当前授权状态另行办理。

## 证据、状态和权限

引用时并列标明 **真实保存操作数 / 条件定理 / 论文公式 / 格式规范 / 尚待观察的假说**。已完成的六来源 E0 被动采集及早期暂停回执均有时间绑定记录，当前方法讨论以源码、文献、数学和获准的保存资产分析为工作范围。新的 CPU/GPU/model 作业需用户另行明确授权。

[静态路由检查](../../tools/check_autoresearcher_binding.py)负责核验阶段、链接及权限记录的一致性；对科研内容的独立判断由不同 Agent 的真实推导和讨论承担。验证工作流仍为手动触发。
