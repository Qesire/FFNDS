# 独立评议记录

此目录只保存其他 agent 对**精确版本方法提案**的独立论证。每条记录独占路径 `<method-id>/vN/<review-id>.json`；字段模板见 [../TEMPLATES.md](../TEMPLATES.md)，行为规则见 [../README.md](../README.md)。

当前还没有独立 reviewer 的真实记录。提案者自评、不含独立推导的简单赞同、通过不同 ID 伪造的副本都**不能**记作他人支持。

**AutoResearcher 默认适用：** 每位独立 reviewer 进入此目录时均继承 [讨论目录 AGENTS.md](../AGENTS.md) 及根级 AGENTS 指令。先独立重构关键计算流，给出自己的数学/源码推导、竞争解释与有判别力的反例，再形成赞成、质疑或修正意见。不能仅复述提案或以“已遵循原则”代替科学论证。所有活动仅限方法讨论。
