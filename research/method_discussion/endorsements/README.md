# 跨 Agent 方法认可快照

只有当 [../reviews/](../reviews/) 中存在对应版本且确实由其他 agent 独立完成的 `SUPPORT` 记录，整理者才可以在此创建 `<method-id>/vN.json`。认可等级分别是 `PEER_SUPPORTED`（至少一位独立 reviewer）与 `CROSS_CONFIRMED`（至少两位不同独立 reviewer），有尚未回应的具体反例时保留 `CONTESTED`。

当前**没有获得交叉认可的方法**。今后的快照须显式列出评议文件路径、同意的具体机制命题与未决问题。这里的共识是方法讨论状态，不代表实际实验验证或实施授权。
