# 敏感度与状态统计的配对：加权投影与两来源反例

**ALG**：固定同一个正定后缀敏感度度量时，最优 rank-r 幂等输出投影由 `G^(1/2) C G^(1/2)` 的前r个特征方向构造；当度量与状态统计共同随来源变化时，必须保留它们的配对。一个二维例子里，分别平均产生的代理选择与真实配对风险的全局最优方向相反，损失差100倍；这个结论对全部斜投影成立，不只比较坐标轴。

## 固定 G、C 的全局解

设 `G ≻ 0`、`C ⪰ 0`，`rank(P)=r`、`P²=P`。令 `S=G^(1/2)`、`A=S C S`、`Q=S P S^(-1)`，则Q同样为rank-r幂等矩阵，目标化为

`L(P) = ||(I−Q) A^(1/2)||_F²`。

对任意给定Q的值域U，逐列最小二乘说明把Q替换为到U的欧氏正交投影 `Π_U` 不增损失。于是最小值由标准谱截断给出：若 `A=U diag(λ1≥…≥λd≥0) Uᵀ`，取前r列 `U_r`，则

`P* = G^(−1/2) U_r U_rᵀ G^(1/2)`，`min L=Σ_(j>r) λj`。

P*满足幂等、rank r、`P*ᵀG=GP*`，通常在欧氏坐标是斜投影。若第r与第r+1特征值有严格间隙、A满秩，最优子空间及此投影唯一；重特征值和C的零空间可产生多个最优解。G仅半正定时不可直接用逆平方根，需在其支撑子空间处理并另外说明零空间自由度。该结果针对固定G/C的局部二次代理，并不直接证明原生量化Wan的后缀或视频质量。

## 两来源配对不能由边际乘积替代

实际共同投影目标为 `E_s tr[G_s (I−P) C_s (I−P)ᵀ]`。写 `G_s=Ḡ+ΔG_s`、`C_s=C̄+ΔC_s`、`R=I−P`，则

`L_pair(P) = tr[Ḡ R C̄ Rᵀ] + E tr[ΔG_s R ΔC_s Rᵀ]`。

最后一项是投影依赖的配对交互；独立、任一量固定、或该收缩对所有允许P恒为零，才可用边际乘积完整替代。仅有 `E[G_s C_s]=Ḡ C̄` 也不一般保证对任意R的四阶收缩为零；若交互对所有P恰为相同常数，仅最优排序可相同而目标值仍不同。原提案已经把表达式定义为代理，本推导是对随状态变化扩展的条件，而不是反驳其固定对象。

取等权 `C1=diag(1,0)`、`C2=diag(0,1)`、`G1=diag(1/10,1)`、`G2=diag(100,10)`。分开平均有 `C̄=I/2`、`Ḡ=diag(1001/20,11/2)`，所以固定平均代理选择 `P=e1e1ᵀ`。真实配对下该选择损失5，`P=e2e2ᵀ`损失1/20。

对任意实二维rank1幂等P写 `P=[[a,b],[c,1−a]]`，约束 `bc=a(1−a)`，配对风险为

`2L = (1/10)(1−a)² + c² + 100b² + 10a² ≥ (1/10)(1−a)² + 20|a(1−a)| + 10a²`。

当 `0≤a≤1`，右端减去1/10为 `a(99/5 − 99a/10) ≥ 0`；当 `a<0`，前项已超过1/10；当 `a>1`，10a²超过1/10。等号仅在 `a=0,b=c=0`，故全体实rank1幂等投影中唯一最优为 `e2e2ᵀ`，损失1/20；所提轴投影差距确为100倍。

若交换两份G与C的配对而保持边际完全相同，则坐标轴损失为e1方向1/2、e2方向50；同理可用上面的参数化或下界得e1为全局最优。边际相同却最优方向改变，证实数据采集应保持相同source/seed/step/block、状态与敏感度的关联。

## 竞争解释与下一判别

**OPEN**：若低能高敏方向跨source稳定，paired敏感度应在预先冻结的独立来源上优于分开平均和能量PCA；若真正主因是student状态转移、纹理观测或条件敏感方向互相抵消，paired基未必优于同rank普通窄学生。最低成本的后续判别是在固定4位置及来源划分上，先生产同一真实state的FFN输出统计和可验证的后缀有限差或Jacobian代理（明确量化不连续与采样坐标）；匹配rank、训练预算和后缀调用预算比较paired、打乱配对、边际平均与PCA，按来源聚类heldout报告。现有后量化teacher输出不足以直接提供该同状态敏感资产；完整训练、自由视频、真实执行成本另需证据。

建议将此作为独立 B 方法的 ALG 节点：`conditional output-statistic × suffix-sensitivity pairing`，边指向现有函数/后缀和编译候选，以 `ALG` 链接上式、以 `OPEN` 链接未来原生同状态判别；不要把二维构造挂为已观察Wan低能高敏。它是并行数学发现，不是A线训练的前置门槛。

**既有 gate 的具体边界（NATIVE/SRC）**：[CAL24 source profile](../../../20261028/UB1_CAL24_SOURCE_ENERGY_PROFILE_RESULTS_20261028.md) 在 step 0/3、block 0/39 四位置核验24来源的 gate tensor 与对应固定SHA一致。因而在每一固定位置，若只取原caller的 `G=diag(g²)`，该来源集合上的G固定，上述来源配对反例不否定现有 gate-only consumer。要检验新机制，必须生产随source/state变化的真实suffix或readout敏感度，并与同状态输出统计配对；反复平均相同 `g²` 不会产生这一新信息。协调者另行独立复核了上面的二维全局最优代数；这不是Wan低能高敏的实测或算法实验通过。
