# C02 保存行 Q2 直接项与旁侧项：独立结果审阅

**结论（NATIVE-OBS，局部数值）**：八个保存条件、每个条件160行，在固定 group 108 中按行选择 Smooth2 后绝对值最大通道时，gate×W2 的 FP32 旁侧项范数为直接项范数的 **13.36%–23.63%**（每条件将160行及输出维度展平后各算一次范数）。最小值和整组置零的对应旁侧投影范数在记录中均为零；24个臂组外变化计数均为零。此范围属于已选条件和后验掩码，不能外推到任意组、选择器或视频行为，也不代表能以低成本在线取得掩码。

审阅独立读取冻结协议、实现、已保存标量结果及执行快照，没有重算张量。协议 SHA256 `d182d0e7d7eea7e8be7a1224a6931e0e16f5907c182f53a167c607301b3ff6db`；原 RUN SHA256 `c2e23b2a3650c017f7c87daa14c42318f2187df7869c082537dfa8b199b10d29`，6,435,432 字节；RUN 内协议 SHA 一致，状态 `COMPLETE_LOCAL_DIAGNOSTIC`。快照协议哈希一致，37个冻结源文件快照逐一匹配协议哈希。结果与预定的 source 0/seed 42 和 source 12/seed 54、step 0/2、block 0/39 八个条件一致；24臂各160个行号与冻结行计划一致。

**计算身份**：代码从保存的 BF16 GELU 输出除以实际 Smooth2 scale（FP32 除法后回转 BF16），在 group 108 的64个通道中按每行绝对值 argmax/argmin 选择；整组是第三个控制。D 在已保存 Q2 后值上置零，Q 在相同原 GELU 位置置零并重新执行原 Smooth2/HiF4 Q2。直接项是原 post-Q2 选中值的负值，旁侧项是未选位置 Q 与原值差，total 是全差；输出分解使用 FP32 W2 乘法和原 gate。代码要求 Q 目标为零，并对组外做逐元素相等检查。八次原生 Q2 no-op 都在任何干预前用 `torch.equal` 对照保存的 BF16 post-Q2，若数值不相等即中止；完成状态及账本支持其全部通过，而 RUN 没有单独保存每次 no-op 的差异摘要。旧协议将此称为 bitwise 超过实际检查：`torch.equal` 将正零与负零视为相等，故旧数据未建立 signed-zero 字节身份。

账本与循环相符：8 no-op 加 24 Q 干预为32 QDQ；8 base 加24×2 D/Q为56 BF16 linear；24次批处理分别包含 direct/collateral/total 三个逻辑投影，合计72 FP32 logical、24 batches。运行记录的目标非零和组外变化在24臂均为0。最小臂有少数选中坐标本身改变，但非选坐标旁侧投影记录为零；整组臂的非选组内坐标为空，其旁侧为零属于该定义下的控制结果。最大臂旁侧项范数非零不单独确定其视频功能或质量影响。

**数值边界**：M160 的 BF16 base W2 重放相对保存的 full-M W2 输出范数差为 **0.2916%–0.2944%**；这是已观测形状/数值路径差异，不能将 M160 重放视为 full-M 字节等价，也不能单凭此确定具体内核原因。24臂记录的 FP32 投影分解最大绝对误差均为0，仅是本次所记录计算的现象；它不证明任意输入或后端恒等，也不意味着原生 BF16 D/Q 有相同输出或 gate BF16 残差写回无差异。代码的浮点误差界明确排除 underflow/backend 偏差，不是后端证书。

GPU监测记录46个采样、零违规、`sampled_isolation_pass=true`，峰值使用 2146 MiB；这是采样性记录，并非连续证明。RUN 最终包含完整8条件、24臂和精确账本；实现中最终写入在监测器关闭后执行，监测违规会改成失败。外部进程 exit=0 的消息与该最终状态一致，但本次审阅的结果目录仅含 ATTEMPT/RUN 及源码快照，没有可独立复核的外部退出码日志，因此退出码本身仅能按外部消息身份引用。

这是一项保存行的局部数值因果分解，尚未执行残差后续路径、完整视频质量或新方法的真实性能比较；无质量通过或加速通过主张。下一步若获相应具体授权，可用匹配 full-M 原生路径与 gate BF16 写回对照区分局部项的有限精度影响，再按完整视频协议评估行为。


## W2 形状控制的独立复核

对后续独立控制，协议 SHA256 `ccf43273cac6ce932a43fcea70417876b36da87c2fb85d63f3639b795dd7d6d3`，RUN SHA256 `8641125e95e55f64ff083d64e3d215391cec829e3a63cb17ec1f30802da4b948`，RUN 引用协议一致；两份执行源码快照和协议快照均匹配其绑定 SHA。`COMPLETE_W2_SHAPE_CONTROL` 包含8个条件，账本为16次 BF16 linear、0 QDQ、0 FP32 projection、0 W1、0 full model。

该控制将已保存的160行放回原始 M=31668 行号，其余行填零，再运行相同 BF16 W2 并抽取保存行；逐字节比较每个 BF16 元素。八个条件各819,200个输出元素均与保存输出 bitwise 匹配。直接 M160 重放的相对 L2 差为0.2916%–0.2944%，逐条件与旧 C02 base 统计一致；每条件约270,018–294,651个元素的字节不同。此结果支持该测量中的 W2 输入行数/执行形状影响，不能单凭它确定具体 kernel 算法，亦未重建未保存的原始其他行。

GPU监测记录3次采样、零违规、`sampled_isolation_pass=true`；这个有限采样不构成连续监控证明。此控制只涉及选定行的 W2 基线，未验证新的全形状 C02 干预、后续残差或完整视频。

## 原 M 形状 C02 的独立结果复核

原 M=31668 形状的保存行干预已完成，协议 SHA256 `e55e937b4b73771069d887352a3775575d5ba8a36b0db5cb9b6af7913c896a30`，RUN SHA256 `14330ddc20a2544b237fdb9672f3018eed9961f8a1a9da486a697890153c2e4a`，6,443,937 字节；RUN 协议身份、协议快照与41个执行源码快照均匹配。状态 `COMPLETE_LOCAL_DIAGNOSTIC`，包含8条件、24臂及冻结行号，账本为32次全形状 QDQ、56次全形状 BF16 W2、24次 M160 FP32 批处理（72个逻辑投影）。外部 launcher 报告退出0；本审阅以 RUN 和源码快照为直接证据。

代码将160个保存行填入31668行矩阵中的原 row_id，其他未知行填零；13824通道每行恰为216个64组，group108的6912:6976不跨行。八次 Q2 no-op 全在干预前对保存 Q2 采用 BF16 `int16` 位模式比较；八次基线 W2 也采用同样严格比较，任何不符即中止。完成路径因而支持这些检查通过，RUN 中每个 base 相对差均为0；这仍不重建未知行的原始值或完整生成状态。组外闭合的 `torch.equal` 是数值等价检查，不能扩展成组外 signed-zero 位模式保证。

与旧 M160 结果逐臂核对，24臂的保存行 FP32 直接/旁侧/总项统计、逐行记录、组内外变化计数及分解误差统计全部相同；最大臂 gate×W2 FP32 旁侧/直接范数仍为13.36%–23.63%，最小和整组的旁侧投影为0，24臂组外数值变化计数为0。这里的 FP32 投影是 M160 诊断，并非原 M 的 BF16 计算或残差写回。全部24臂记录的 FP32 分解最大误差为0仅属于本次测量，不是普遍精确性证明。

原 M BF16 干预的 D/Q 统计相对旧 M160 有变化：例如 source 12、step 0、block 39 的最小臂 D 差范数由0.08393变为0.09828；source 0、step 0、block 0 的最大臂 D/Q 差范数由11.35025/11.48520变为11.33658/11.47216。原 M 的最小与整组臂各自 D/Q 差范数相等，最大臂 D 与 Q 差范数不同；这些是展平范数和相关统计，不能替代逐元素 BF16 差异或 gated residual 验证。

监测记录68次采样、零违规、`sampled_isolation_pass=true`，物理使用峰值7802 MiB，耗时179.71秒；采样并非连续隔离证明。结果限定为保存行的局部 Q2/W2 数值干预，不是完整视频功能因果、质量验收或算法加速证据。
