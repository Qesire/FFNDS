# Independent review: same-stream deferred completion

Reviewer /root/asset_readiness_terra. Static SRC/ALG review, not an authorized experiment. Within one FFN, deferring completion until a block barrier can remove intermediate device-wide synchronizations while retaining the same arithmetic; the synchronous mask D2H/SHA remains an actual dependency and may substantially limit any gain. Host journaling, mask and transfer work and the final barrier must remain charged in total wall time. Event gaps are not a decomposition of arithmetic or a proven source of the previous phase differences.

The live weight buffers and old x/shadow/Y, indices and intermediate allocations must stay valid until the queued compute and block barrier complete, before cache release or load/compute swap. Same-stream enqueue ordering only proves ordering on that stream; cross-stream prefetch, allocator reuse and error propagation require explicit proof. `DeferredLedger` currently retains returned values, which alone does not prove lifetime of every transient dependency or original offload buffer. The draft must wire and test the real tap and its barrier; a synthetic helper is not a native result.

Initial helper counterexample: the first `reserved_before_call` journal operation occurs outside its `try`; if that write raises, a RESERVED_UNKNOWN entry remains but `poisoned` is false. A caller that catches the exception could enqueue more work. The author has been asked to poison on this failure and add fault injection. Barrier, async errors and journal failure must retain UNKNOWN without falsely completing; production owner/VERIFY failure paths need direct tests.

ABBA/BAAB and separately paid warmups offer a useful ordering control only if same source, masks/recipe, resource conditions and bytes are actually verified, all 160 sites and complete videos are covered, and fixed-order temporal effects remain reported. Byte failure or monitor failure stops without retry; A/B equality and speed are not assumed. This design does not itself establish video quality or system acceleration.
