# 全 FFN 奇偶组与输入二次表示：竞争解释和分阶段原生采集

2026-10-29 · 实际作者 `/root/new12_raft_metric_build` · 独立设计，无 SUPPORT 票。本次未运行模型、GPU、拟合、生成或修改 ACTIVE；下文成本是指定 payload 的算术预算，不是已产生资产。提案与 full-K 修订分别由[原作者](s2-whole-ffn-even-group-and-quadratic-units-20261029.md)和 root 提出；[独立 primary review](../../../literature/20261029/S2_WHOLE_FFN_REPRESENTATION_PRIMARY_REVIEW_20261029.md)提供竞争先例及 full-K 复核。

**最有区别力的切口 [ALG/OPEN]**：奇偶组先问“固定组的偶函数误差，经真实 W2 和 gate 汇合后是否仍小”；输入二次先问“遗漏的输入方向与低阶非线性，哪一项使实际输出不可预测”。这两个问题只在部分环节需要新 `a`。已有两图 spatial52 的 `x,h,Y,g,r,u` 可以先在固定坐标上测试整个输出的可预测性与保存行的 typed postwrite，不能从 `h` 唯一还原 `a`。在 full-M W1 原调用返回、GELU 前增加被动 hook，才得到对应 full-M 的真实 BF16 pre-GELU `a`；在保存的 `x` 上小 M 重算 `a` 是另一个计算形状的 replay。

## 源码、对象与可复用观察

[SRC] Wan 实际顺序见 [transformer_infer.py](../../../../.runtime/code/LightX2V/lightx2v/models/networks/wan/infer/transformer_infer.py)：attention 残差后 norm2 与 modulation 得 `x`，原 `ffn_0.apply(x)` 返回 `a`，`gelu(a, approximate='tanh')` 返回 `h`，原 `ffn_2.apply(h)` 给含 b2 的 `Y`，gate 后按原 BF16 residual 路径写 `u`。`M=21×29×52=31668, D=5120, N=13824`。原 BF16 支路无 FP4 Q1/Q2。

[NATIVE-OBS] [spatial52](../../../20261029/S2_SPATIAL52_DENSE_STUDENT_CAPTURE_RESULTS_20261029.md)有 898、96 两图，Dense/value10/dcac10 各正常自由轨迹、每条全160位、52xy×21τ 的 `x,h,Y,g,r,u`；`a` 未捕获。`g/r/u` 与 x 属各自轨迹；同坐标不意味着相同输入。旧同 h 四角重放支持研究状态项与读出投影，但其平均 signed cross 不构成视频因果占比，且小 M 桥未逐角认证；见 [L/P/I](../../../20261029/S2_SPATIAL52_FULL160_LPI_REPLAY_RESULTS_20261029.md)。这些是两幅曝光图的嵌套行，不是多源确认。

[SRC/ALG] `f(a)=a/2+ψ(a)`，`ψ(a)=a*tanh(√(2/π)(a+0.044715a³))/2` 且为偶函数。以实数权重写 `K=W1 W2/2`、`c=b1 W2/2+b2`，full-K 动作为 `xK+c+ψ(z)V_group`，不要求 K 低秩；原生 W1/激活/W2 的 BF16 四舍五入、拆路相加及 gate 写回产生额外数值误差。G=4608 时两线性主项算术比 `D/(2N)+G/N≈0.5185`，不含构造、访存、ψ 与 kernel。输入二次动作以固定 `z=xA` 和 `1,z,φ₂(z)` 直接预测 Y；k=64 时特征数 `1+64+2080=2145`，与 full-K 偶支路不是同一个物理动作。离线权重、bias 和 source-free 固定变换可在 W1 前获得；`a,h`、未来 Dense Y、观测者误差均是付费后验信息，不可作为免费在线路由。

## 两种竞争机制，各自反例

### A：偶项函数组是可压缩的，还是 W2 恰好抵消？

[ALG] 对组 g 的代表 z 及符号 s，令 `δ_j=ψ(a_j)−ψ(s_j z)`，组输出误差 `E_g=Σ_j δ_j v_j`。真正风险由 `||Σ_g E_g||²` 中**组内及组间 signed cross**、gate 和 typed 写回共同决定。比较两种可同时成立的解释：

- **A1 稳定镜像函数共享 [OPEN]**：离线确定的 `(w_j,b_j)≈s_j(w_g,b_g)` 在 source-held 的 Dense 与 student 输入上继续保持小 `|δ_j|`；同宽度的符号偶组在多个实际输入状态上都比不利用偶对称的同号合并更小。组结果不依赖在 held source 重新选择代表或符号。
- **A2 读出抵消或数值偶然 [OPEN]**：镜像不稳定但 W2 行方向造成 `Σδ_j v_j` 小，或单组小而跨组相互抵消。固定分组下，残差大／局部扰动却输出小；在对照输出方向、组间 signed cross 或 gY/u 上出现变化。若只有 `Σ_g E_g` 小而 `Σ_g ||E_g||²` 很大，这是抵消证据，不是独立可合并组的强证据。以输出权重规模和组大小匹配的随机分组、普通同号合并及离线 W2-aware 组作为强对照，分别保留它们实际成本。

**反例**：`ψ(a_i)=ψ(a_j)` 可由每个 token 的符号关系变化产生，即便不存在一个对全部 token 都固定的 `s`；因此固定 ± 镜像是充分的结构候选，不是偶函数共享的必要条件。相反，近权重列也能因偏置或 student x 投到差向量而跨零错配。须同时报告 sign-switch、`|a|` 尾、偶函数差、group Gram、`E_g` 与 cross；后验最佳符号/分组只作 oracle 上界。

**独立数值竞争 [OPEN]**：即便 A1 成立，full-K 拆路可能因原 W1 BF16 加法/GELU/W2 的舍入产生与组误差同量级的 remainder。以真实 full-M `a`、`h`、`Y` 分别定义 ideal parity 基准和实际 typed 路径，报告 `e_round`、`e_group` 与 `2⟨e_round,e_group⟩`，再经真实 g 和 r 做 BF16 写回。这里 `a/2` 和 `xK+c` 的差也包含 full-M W1 数值误差；不能把它误记为纯 GELU 舍入。不要把各分支误差平方相加。

### B：输出真的依赖少数输入坐标，还是拟合/局部曲率造成幻觉？

- **B1 投影充分＋二次可迁移 [OPEN]**：预先固定/只用训练图选择的 A，对 held image 的 teacher 和 student x 都保留目标输出相关方向；相同 k 和相同可支付的特征预算下，`1,z,φ₂(z)` 对持出 source 的 gY/u 改善优于 affine 与同维度随机/可分离特征，误差没有集中于跨零、高幅值、时间变化或学生尾部。
- **B2 输入子空间遗漏或多项式形状失配 [OPEN]**：若存在 x₁A=x₂A 而 `F(x₁)≠F(x₂)`，任何只用 z 的次数任意高函数都无法同时恢复两者；这是输入子空间遗漏的构造反例。另在 z 给定后，真实 a 在大绝对值区使 `ψ(a)≈|a|/2`，`c₂a²` 会过冲；此时即使投影充分，二次近似也失败。二者可共存。

固定 A 后分别测 `(i)` 投影残差 `x−xAAᵀ` 与输出关联（A 需正交化或按其真实投影定义），`(ii)` 实际 a 的幅值/bias 分层及 exact ψ 与二次的差，`(iii)` 配对 observed-Y 条件风险。可另注册 `x→P_Ax` 的 full-M 同层干预，以未压缩原 FFN 量 `F(x)−F(P_Ax)`；选择行的小 M W1/W2 重放是付费探索，不是该 full-M 干预或原生字节锚。再以固定 A 比较线性、对称二次、同特征数随机乘积及成本匹配低秩双线性；加 full-K 的二次偶支路是**额外成本的另一行动**，不能和原 B 混称同一预算。

已有 spatial52 的 `x,h,Y,g,r,u` 可在单独获准的离线拟合/重放后先比较直接输出基线及 D/S 差异；即使拟合成功也无实际 pre-GELU a、full-M 空间覆盖或独立来源外推。高维拟合须测训练矩阵真实 rank/条件数、按 image 簇 holdout、计 ridge/选择预算；分层、阈值、候选和选择规则在查看对应 held 结果前冻结。

[LIT] [TARDIS](https://arxiv.org/html/2501.10054v1) 已研究局部线性折叠与在线付费离群预测；不能将线性折叠本身作为新颖性。 [Whipp](https://arxiv.org/html/2606.19379v1) 的低秩乘积残差在小 LLM 上提供负面竞争证据，但不是 Wan 的完整二次或自由学生验证。 [Neuron Merging](https://arxiv.org/html/2010.13160v1) 的 ReLU 正比例合并条件不能直接用于 GELU；论文实现/commit 和数值限制以本地 primary review 为准。

## 哪些判断不用新 a，哪些必须新原生观测

- **可直接做但本次未运行 [SRC/ALG]**：静态 W1/b1 的 signed近邻/偏差、W2 行符号 Gram、全 K 公式/物理尺寸与成本上界；比较权重邻近与带bias的匹配、W2抵消风险。实际读取/分解69GB模型与离线 fitting 仍需具体CPU资源/授权，静态权重几何不是激活同分布证据。对于PCA/随机A，旧空间资产上的 x 和已存 Y/g/r/u 足以组织探索性的同输入拟合及 gated/postwrite重放；配套有限计算和模型选择须另登记。
- **必须新 native [OPEN]**：原 full-M W1 `a` 的行幅度、符号、真实相关和 BF16形状桥；新的 SM120 D/S 真实状态及源外比较；已训练 A/组在真实自由学生状态上的原位 typed postwrite、后续attention/flow、完整视频与系统速度。postGELU `h` 对负区非单调不可反演a；小 M `xW1+b1` 不是全M native a。全深度或全空间声称分别需要对应完整站点/空间观测，不能由样本或流式标量升级。
- **实际部署动作需单独付费 [OPEN]**：A 的 full-K 构造/存取及两路累加、B 的 A/φ₂/输出 mixing、所有权重转换、dtype/预取/访存；匹配直接同号组、full-K、低秩W1+W2、affine、随机组/基及需要时TARDIS式付费 predictor，按真实 MAC、GPU延迟、显存和全系统测量。位级差可反过来改变分支交叉项，不能以数学相等宣称数值等价。

## 36 条候选新视频将如何改变判别

[OPEN] 当前36条是12源×3行动的设计目标；只有分别验证父 RUN/EXIT 和对应完整视频/指标后，才把具体行记作 VIDEO，失败或缺项保持缺测。每源与**同SM120新Dense**配对，并分别看动作/主体、相机、背景、几何/闪烁和时间窗口；[已实看 Dense 接触表](s2-new12-dense-all81-independent-visual-review-20261029.md)显示 923/616 高光流可与水面/云纹相关、911/456 存在短事件，不以全画面RAFT单值代替主体运动。

1. 若 `value_all` 普遍运动弱而 early10 恢复更强，优先扩 early 位点的 D/S a、相邻τ及输入子空间尾：A 检查镜像误差和 W2 signed cross 的状态漂移，B 检查投影遗漏及大幅值非二次误差；这支持早期行动影响后续轨迹的可检验位置，**不证明** parity或 quadratic 有效，也不能把视频差全部归因于前缀。两候选仍需同输入输出误差与真实后缀因果桥。
2. 若 late10 恢复更强，优先对末层读出、当前 gY/u 与消费者敏感方向做配对，分别检验 A 的 `E_g` 与 B 的输入投影/二次残差在末层输出方向是否更有影响；大局部L/P/I不必对应可恢复的视频效应。
3. 若三候选整体流量相近但主体/相机/背景退化不同，按独立视频审阅定义的事件和空间层补采，而不是只拟合全局top-5%流；若都无动作恢复，直接增加与早晚10不同的物理行动对照，不能把两种新表达当作已解决问题。若 Dense本身无明确动作，则观察结构一致性及语义时序，避免以零/极小Dense作比例断言。
4. 若差异只出现于少数来源或窗口，既保留来源级尾部和明确反例，也按预冻结图簇规则分层补新source和独立seed；已用来发现事件的源是开发，不担当盲确认。任何为了视频结果改变采集位置/模型超参的版本须单独登记，不能事后重写本设计的 held 身份。
