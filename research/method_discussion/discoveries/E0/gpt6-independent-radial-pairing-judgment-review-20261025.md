## 审查结论：认可修正方向，进一步把「几何解释」和「真实局部响应」分开

六来源的正确配对、精确错排和跨位置中心化结果确实揭示了两个可区分结构：

- **共有方向主导原始平方径向对齐**：Block0 写回后，真实 token 配对 `19.794%`，组内非自身错配 `20.542%`；同一批样本残差跨位置共有能量 `87.93%`，所以原来的约 `19.82%` 是强公共方向对齐而非逐 token 匹配优势。
- **位置特定联系在中心化后仍可观测**：同一写回状态的操作数分别减去各自跨位置均值后，真实配对 `8.839%`，错排 `3.590%`；六个来源、四个 step、固定五组的聚合均有正配对优势。真实来源层面分别是 source 0/4/8/12/16/20 的 `+4.697/+4.776/+5.536/+4.909/+5.666/+5.914` 个百分点。由此研究对象从单一“高 LN 径向”变成**共享方向与条件变化之间的功能分工**。
- **方向跨来源稳定**：固定 `step/block/seed=42`，其他五来源的 residual 位置均值与留出来源均值方向平均 cosine `0.99645`。这证明本已暴露的六来源条件下方向稳定；它对 seed / 相机 / 新提示词分布的迁移仍是另一研究问题。

报告对原结果的 `1440` 项精确复核，最大误差 `4.996e−16`，源码的径向公式及 off-diagonal 期望符合解析恒等式。历史数据、数学定义和结果的差别总体上交代清楚。

## 核查过的数学

令 `P=I-11ᵀ/D`，`u_i=Px_i`、`v_j=Pδ_j`，`s_i=||u_i||²`，则对标准 **ideal epsilon-LN**，将 `J(x)/rstd(x)` 与中心化单位映射 `P` 比较所得的径向**平方能量消去**为

```
R_ij = [(s_i+2Dε)/(s_i+Dε)^2] · (u_i^T v_j)^2.
```

这个式子和分析脚本 `radial = ((s+2Dε)/(s+Dε)**2)[:,None] * (x @ d.T)**2` 一致。等规模分层错排的 off-diagonal 总期望确为 `sum_{i!=j} R_ij/(n−1)`；`expected_trace()` 的做法正确地区分不同分层和 singleton。

**额外需向后续 Agent 强调的恒等式（推导，非新观测）：** 对任意 n 个样本，令 `x_i=μ_x+ξ_i`，`δ_i=μ_δ+η_i`，其中 `sum_i ξ_i=sum_i η_i=0`。则

```
mean_i <x_i,δ_i> = <μ_x,μ_δ> + (1/n)sum_i<ξ_i,η_i>
mean_{i≠j}<x_i,δ_j> = <μ_x,μ_δ> − [1/(n(n−1))]sum_i<ξ_i,η_i>.
```

因此配对与错排的**有符号内积**差必然与位置交叉协方差成正比。中心化后错排的有符号内积总和，也必然是正确配对和的 `−1/(n−1)`；所以“有符号中心化对照中错排接近零/略负”包含**样本中心化的代数效应**。平方径向投影、rowwise cosine 及其非线性加权**不直接服从该线性恒等式**，仍可提供有内容的结构证据，但最好独立报告 covariance、范数与平方交互分解。

该恒等式解释了为何原始 signed cosine 可以为负、中心化后的 signed cosine 为正，并且平方径向原始配对低于错配。**中心化后出现更强配对结构，是有价值的表示相关性观察；并非已经证明真实 LN 在原始网络中删除了相同的 8.839%。**

## 四项对下一轮判断最有影响的科学修订

### R1（最高优先）：保留真实 residual 的归一化 Jacobian，不改变比较对象

当前 `position_centered` 调用的是

```
pairing_statistics(x_i−μ_x, δ_i−μ_δ)
```

它的 Jacobian 系数按 **新构造的** `x_i−μ_x` 重算，且分母按 **新构造的** `δ_i−μ_δ` 重算。这是一个合法的表征探针，却不等于真实 residual `x_i` 位置处的局部网络灵敏度。

推荐在**同一原始状态、同一个真实的 J(x_i)** 下做精确分解：

```
δ_i = μ_δ + η_i,
J(x_i) δ_i = J(x_i) μ_δ + J(x_i) η_i,
||Jδ_i||² = ||Jμ_δ||² + ||Jη_i||² + 2<Jμ_δ,Jη_i>.
```

其中 `J` 由该 block 下实际 norm1 实现决定（可并列报告 ideal LN 与真实 scale/epsilon/cast 的影响）。可以进一步保留不变的各位置 `rstd(x_i)` 归一化分母和 gate/组定义，比较真实配对与不配对的交互贡献。这样才能回答“公共 vs 变化哪一部分实际影响下一层”，而不是只说明去均值表征中哪个关系更明显。

**最小可验收：** 每来源/step/五组给出 `||Jμδ||²`、`||Jη_i||²` 和交叉项，定位 raw/centered 排序反转的具体贡献；保持 `J` 评价点不变。已有保存操作数可实现这一解析检查；需要真实 BF16 norm1 才可进一步比较执行误差。

### R2：准确表述「跨来源可迁移」的条件

当前六个来源是三主体/三背景，**全部 seed42**，且 step/block、模型、配置一致。留出来源的结果证明跨**这六份 prompt/场景**的共享方向一致，尚无法把它归为学习得到的通用条件偏置、固定网络常量，或共享 latent seed / 采样方案。未来用不同 seed、不同 prompt、相机类或另一个 checkpoint 对照有高信息价值；在 E0 阶段先写清它们各自的不同预测和所需字段，模型采集需新授权。

可以先用已有数据检查公共方向相对 pre/post/cross-attention/step/expert 的变化，对“静态权重偏置”和“动态条件载体”提出不同预测。

### R3：平方径向指标必须搭配有符号交互和来源级异质性

原始正/负共线在 `(uᵀv)^2` 中等价，而对 BF16 residual 和后续非线性传播的作用可能不同。已存源数据显示 Block0 raw signed cosine 均值约 `−0.13175`，去跨位置均值后约 `+0.17570`。推荐显式分解 signed `μ_x^T μ_δ`、`μ_x^T η_i`、`ξ_i^T μ_δ`、`ξ_i^T η_i`，再分析平方交叉项及来源差异。保留实际 gate、原组面板和各步尺度，以分析高杠杆样本是否主导差异。

### R4：把已有近邻论文当竞争机制，而不是直接的 Wan 结论

- [Ethayarajh 2019](https://aclanthology.org/D19-1006/)提供各向异性/随机配对的比较动机，`raw cosine` 的高值必须结合本表示自己的错配基线。
- [Timkey & van Schijndel 2021](https://aclanthology.org/2021.emnlp-main.372/)表明少量维度可以支配余弦相似性，与模型实际行为价值可能脱节；可启发对 `μ` 和协方差谱的独立区分。
- [Sun et al. 2024, Massive Activations](https://arxiv.org/abs/2402.17762)及 [Sun et al. ICML 2026, Anatomy of Massive Activations and Attention Sinks](https://proceedings.mlr.press/v306/sun26d.html)都提示稳定的共享隐状态可能承担**有效的隐式模型参数或条件偏置**。在 Wan 中这是值得检验的解释，而非已证的同构机制。
