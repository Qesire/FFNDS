The new tap derives the fixed H-readonly path. At each high-step1 candidate, its callback receives the actual current x, active weight/bias buffers, old full h/Y, true mask/score and candidate pre-gate Y immediately after the original readonly action and before the sentinel is installed. The callback return is discarded; the original candidate remains the forward output. Cache/weight identities and active compute stream are checked by the inherited tap. The caller must supply a source-audited writeback formula matching actual original post_process gate/residual/dtype semantics, and a bounded durable sink. Both are drafted, not approved; same-dtype BF16 shadow writeback follows the independent source audit, but comparison with an actual post_process return is not yet integrated. Full-video byte neutral checks against a same-scope unobserved control are mandatory. Do not run this component as a scope.

For each student video, fullM shadow adds 40 W1 GEMMs plus 40 GELUs plus 40 W2 GEMMs. The explicit current prototype additionally uses 124 chunks/site (last chunk 180 rows), totaling 4,960 omitted-projection matrix multiplies and 4,960 diagonal vector products after 40 per-site diagonal-weight reductions, and 4,960 gate/write and spatial partition reductions. Each chunk is synchronously charged; 40 more explicit release barriers are charged. Counts exclude existing original candidate and cache work. The current prototype converts and selects omitted W2 columns once per site and computes q_j from W2 squared and the shared output gate once per site; it rejects a per-row gate. The 40 conversions/gathers/reductions and their temporary storage/traffic remain real additional costs. GPU peak, allocator effects, physical traffic, actual runtime and serialization size are UNKNOWN. It is a faithful cost-explicit prototype, not a performance proposal. Finite tests, mask uniqueness/range checks, indexing and scalar synchronizations are contained in the charged observer chunks; a final producer must freeze granular byte/element budgets as well as each action count.

Same-mask ideal omitted projection `d_U W2_U` is explicitly distinct from actual candidate-vs-shadow BF16 pre-gate, algebraic gated and actual writeback errors. Signed cross is ideal squared norm minus its diagonal; it neither decomposes actual rounded packed output nor establishes H2 causality. `partition_sums` covers all rows in fixed 21 temporal slices × four raster quadrants; it produces counts and additive energy sums, not unsupported quantiles or object-level guarantees. Exact 64 original selector identities are required; 256 disjoint stratified evaluation rows include explicit conditional inclusion probabilities. No evaluation rows feed mask or action. Four specified blocks expose full h/Y/candidate plus coordinates and mask/score to the sink; the final durable implementation must preserve exact typed identities and budget all copies/hashes. Four blocks retain six separate full tensors: logical payload 12,192,940,032 bytes per student video; 40 samples of 320 rows add 1,232,076,800 bytes. Two student videos therefore hold about 25.006 GiB logical tensor payload before headers, video and other outputs; the final reviewed cap must account for all output and failure cases.

CPU small fixtures exercise signed cross, gate/writeback arithmetic, deterministic disjoint raster sampling and operation-count arithmetic. They do not exercise CUDA, actual model, fixed numerical recipe, stream lifetimes, full writeback, output neutral or memory limits.
