## 新任务分工是开放发现切面

- **FFN 输出机制**：从真实 preactivation、GELU、W2 value vectors 和表示叠加出发，寻找条件集中、相互干扰或新的敏感子空间；通过有符号对照确认它们的函数意义。
- **时空动态机制**：哪部分变化需要重新计算？跨 step/expert/位置是否有可追溯的规律和反例？
- **功能/计算机制**：哪个局部改变能够跨 residual/attention 影响四步视频？能否导出新计算表示或动作，而不仅是微调旧分数？

独立审查需要亲自看源码、数学或反例，形成真正不同的预测；按 [DEEP_WEB_RESEARCH.md](../../../agent_protocol/DEEP_WEB_RESEARCH.md) 搜索首发论文、官方代码和最强竞争机制。旧描述性任务及历史报告保留于 Git 历史和原始 E0 资料；本入口只指向当前工作。

## 简短科学记录模板

```markdown
# 新发现/待解释结构：一句准确、可检验的话

**科学张力：** 什么现象值得解释？它对 FFN 的理解意味着什么？

**原始依据：** 精确源码/计算流、已保存数据、条件数学或原论文；注明证据来源和版本。

**机制 A 与机制 B：** 它们各自如何解释这一现象？在哪个条件下会产生不同预测？

**最有价值的检验：** 一个证明、现有数据对照、独立源码检查或未来的最小观测需求。

**可能开启的新自由度（可选）：** 信息源、表示、计算动作或新问题；算子构想先保留为 idea seed。

**实际 Web 检索与学术关系：** 日期、关键词簇、原论文/代码、最接近机制和区别。
```
