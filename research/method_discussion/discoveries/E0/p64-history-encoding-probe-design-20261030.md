C stores old h as saturated E4M3FN (±448), plus a BF16 shadow of the 64 frozen sample rows. The shadow supplies the exact same old-h sample for the current P64 proxy and fixes the selector independent of compression. Only selected encoded columns are decoded for the W2 delta. D uses per-column FP32 scale max(abs(h[:,j]))/127 with a finite zero-column rule, signed int8 round-to-nearest/clamp, plus the identical shadow; it incurs a full history reduction and scale storage. Both encode old h after it is produced and before the next transition; no current full h or teacher is visible to selection. Compute the current full h/Y reference only after every candidate mask and action is fixed. Old Y remains BF16 and is shared in all arms.

For error e=decoded(old_h)−old_h, the selected correction changes by approximately −e_S W2[:,S]^T before BF16 delta rounding, output rounding and current gate. Competing predictions: (1) consumer-projected signed errors cancel despite local cache error, producing similar output to A with less resident h; (2) correlated signed errors align with W2 and gate, giving large output drift even when RMS history error is small. E4M3's relative quantization/clipping and per-column int8's absolute dynamic range yield distinguishable channel and tail signatures. B tests a separate prediction: its output must be bitwise identical while avoiding one full h clone and indexed write; if it fails, arithmetic, aliasing or future-state assumptions differ.

One old h is 875,556,864 BF16 bytes; encoded payload is 437,778,432 bytes plus 1,769,472 bytes of BF16 64-row shadow; int8 adds 55,296 bytes of FP32 scale. Old Y is 324,280,320 bytes.
