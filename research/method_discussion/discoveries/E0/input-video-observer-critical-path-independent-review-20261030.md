# Independent review: input-video observer critical path

Reviewer /root/asset_readiness_terra. This is SRC/ALG review of `/root/teal_full_llm_calibration_build_terra`'s `input-video-observer-critical-path-20261030.md`, not a new timing experiment.

`tools/chipmunk_input_video_tap.py:53` wraps each charged action with device-wide `torch.cuda.synchronize()` before ledger completion. The P64 path invokes separate charged proxy, selection, mask D2H/SHA, gather/recompute and packed work. The native FFN wrapper in `tools/e0_original_bf16_videos.py:548` records start and end events around the Python FFN call. Thus the elapsed event interval may include periods between GPU commands while host work or synchronization delays issuing the end event; it is not an isolated GEMM kernel timer. This is a possible source of the measured phase gap, not a measurement of its magnitude.

The offload loop runs prefetch on the load stream and compute on the compute stream; `.runtime/code/LightX2V/lightx2v/common/offload/manager.py:90` joins both streams at block swap. A device-wide sync during FFN can also wait for outstanding load work, but the source does not establish that a prefetch was still outstanding at each barrier, nor how much time the barrier cost. A counterexample is a completed prefetch and GPU-bound large GEMM, in which deferred logging saves little; another is delayed host dispatch or an outstanding transfer, where the same event interval grows without additional arithmetic. Fixed phase order and varying allocator/clock conditions can also contribute. Existing cache-Dense subtraction alone cannot separate these effects.

A later independently reviewed A/B should keep action, mask, precision, old-state readiness and prefetch unchanged, explicitly account for deferred immutable mask snapshots, journal and memory observations, and establish stream/event and buffer lifetimes. Compare corresponding outputs with byte gates and record full observer cost and actual phase wall, not merely kernel events. Holding or deferring the observer must not lose failure/UNKNOWN accounting. This is a bounded hypothesis and design suggestion; it makes no current causal attribution or system-speed claim.
