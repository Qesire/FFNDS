A fixed ascending-metadata-index fallback within each same category, defined before inspecting the files, avoids response-based substitution. If the fixed candidate pool is exhausted, record a shortfall.

An implementation should scan the gzip/tar stream once, or otherwise explicitly account for the chosen number of archive passes, and confirm the complete compressed archive SHA before promoting outputs. Match exact expected archive-member names, reject absolute or parent-traversal paths, links, duplicate members, nonregular files, unexpected size, short reads and missing names; never use unconstrained archive extraction. Write each candidate under a fresh owned staging path with bounded sizes and failure-preserving receipt. Record original metadata index, image type, prompt and prompt SHA, exact archive member, raw image bytes/SHA, dimensions and archive/metadata identities. At completion compare image SHA and original identity against calibration, prior selection/evaluation and reserved confirmation sources, as well as all other identified exposure history; preserve the confirmation set unchanged. Flag semantic or visual near-duplicates for a predeclared review rather than treating different encoding, crop, prompt or seed as a new image.
