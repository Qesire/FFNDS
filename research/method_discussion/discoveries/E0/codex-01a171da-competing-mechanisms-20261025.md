# FFNDS 最新实验：竞争性机制解释与应用种子

作者记录：Codex，聊天标识 `01a171da-c63b-7c11-85fd-a5f284b030ae`。记录类型：E0机制发现、条件数学与归档标量重表达；应用建议为待检验种子。本文是本作者的发现记录，独立同行评议状态为待评议。

审查日期：2026-10-25（北京时间）。证据固定到 [FFNDS 375dc760](https://github.com/Qesire/FFNDS/commit/375dc760c71c279d3011e7d252d48d8b5bff0de9)，提交时间为14:48:21。本文核对了原生结果 JSON、干预驱动和分析代码，并对已有标量做代数重表达；没有重新运行模型，也没有独立下载和重放全部原始张量。

**最值得新增的解释是：干预引起的数值误差去相关，加上各臂共用同一 dense 参考，能够产生“单独响应同向、联合能量小于单独能量之和”的现象。** 它应当与连续网络的方向选择/非线性收缩竞争。现有数据同时约束了这个解释：最简单的独立噪声矩模型不能完整拟合六个来源，仍需要结构化相关性或真实连续响应。

## 1. 本次解释的事实基础

[原始有限干预](https://github.com/Qesire/FFNDS/blob/375dc760c71c279d3011e7d252d48d8b5bff0de9/research/20261025/E0_FINITE_GROUP_DIAGNOSTIC.json)与[实验说明](https://github.com/Qesire/FFNDS/blob/375dc760c71c279d3011e7d252d48d8b5bff0de9/research/20261025/E0_FOLLOWTHROUGH.md)记录：

- 原生路径是 A100 上 HiF4 QDQ→BF16 GEMM，四步专家顺序 high/high/low/low。
- 六个已暴露 CAL24 来源，3主体、3背景；每来源 dense、A、B、AB、dense_repeat 五臂。仅在 step0/block0 的 Q2 **之后**，对所有 token 将64通道组0、53分别或共同置零。两次矩阵乘法仍是完整 dense GEMM。
- 30条主诊断轨迹，加两个来源的10条跨节点技术重复。210项哈希一致支持固定数值现象可复现；独立来源数仍为6。
- 连续面板对真实残差写回差异的相对预测 SSE 为15.72%–46.00%。在固定误差分解中，残差加法舍入的有符号份额为79.21%–92.87%；这个份额包含交叉项，分母是预测误差，不能解释成视频质量损失比例。
- 两个单组动作的局部/最终 flow 排序在3/6来源不同；source4最后的A/B为0.9984，属于接近并列的翻转。
- 六来源末步两个单臂响应内积都为正，而联合 SSE/(两单臂 SSE 之和)为0.336–0.739。联合动作不总比两个单动作都小。
- 当前 Q2 在各臂完全相同，mask发生在Q2之后。因此“当前组选删导致当前共享量化尺度变化”不符合这次干预的因果顺序。

这里的flow、latent和RGB平方差都以dense D-Q为参考；本批没有新的感知质量或稀疏执行速度验收。

被动观察另有两条应用线索：[首层残差对齐与时序结构](https://github.com/Qesire/FFNDS/blob/375dc760c71c279d3011e7d252d48d8b5bff0de9/research/20261025/E0_DISCOVERY.md)。Block0五个固定组平均约19.82%方向能量被理想LN均值/径向投影消去，写回前24.71%、去掉该组自身贡献后19.88%。Block39在当前gate加权下跨步cosine约0.963，但直接复用相对SSE约0.373，事后最优标量可降至0.072。

## 2. 竞争机制一：离散舍入单元改变了实际干预方向

令R_b为BF16舍入、Y_S为某动作的真实FFN输出：

    x_S = R_b(x + R_b(g ⊙ Y_S))

这条路径包含门控乘法和残差加法两个离散边界。相同大小的连续输出变化，若距离舍入阈值不同，可以一个被吸收、一个跳到相邻格点。实际作用更接近“改变了哪些残差坐标、跨了多少数值格点”，而非仅由连续δ的范数决定。

**已支持的部分：** 保存的32行/臂写回可以由两个BF16操作逐值重建；以真实写回状态计算LN并再转BF16后，与原生norm1响应的相对预测SSE最大仅4.04×10⁻⁵。这定位了局部失配，尚未分解全部后续flow变化。

**强竞争解释：** 后续LayerNorm、attention和残差更新即使连续计算，也可以产生显著非加性。BF16解释了局部误差，不自动解释最终联合收益。

**独特预测：** 固定连续方向和幅度，改变相对于舍入单元的位置，会产生台阶状响应和排序跳变；提高特定写回边界精度应改变这些跳变。要比较同一起始状态和每个数值配置自己的dense对照，避免把换模型的分布变化误判为机制消失。

**可能应用：**

1. 把残差写回精度、FFN压缩与校准联合设计，优化完整写回而非只有W2输出。
2. 将“保持相同实际写回状态”作为可验证的压缩目标。设未舍入和为z_i，当前输出格点的舍入单元为C_i；若候选z'_i仍在同一C_i中，且其他执行状态一致，则该坐标写回相同。全部坐标相同且后续确定时，完整后续轨迹相同。
3. 真正省算还需能在执行被省计算之前给出便宜的误差界/预测。用完整dense结果事后证明等价只是诊断；全部坐标的最小边界余量也可能很小。

这一数值原理与既有舍入分析、FP32残差累加有关：[Croci等的舍入误差分析](https://eprints.maths.manchester.ac.uk/2843/1/cfhm22.pdf)讨论小更新消失及最近舍入的条件性；[Megatron官方残差加法实现](https://raw.githubusercontent.com/NVIDIA/Megatron-LM/main/megatron/core/fusions/fused_bias_dropout.py)提供相关工程先例。本文的新研究对象是Wan固定动作的真实边界与下游效应，并不主张发明提高残差精度。

## 3. 竞争机制二：连续网络的有限响应压缩，或状态方向旋转

设同一输出边界：

    a = F_A − F_D
    b = F_B − F_D
    c = F_AB − F_D − a − b

严格有：

    E_AB − E_A − E_B = 2〈a,b〉 + 2〈a+b,c〉 + ||c||²

本批〈a,b〉均为正，故使联合能量变小的是非加性项。a、b是有限单臂差分，不是已经测得的Jacobian方向；c也不能仅凭名字认定为光滑Hessian曲率。

**解释：** 归一化、attention竞争或其他连续状态依赖，使联合扰动进入与单独扰动不同的响应区域，产生压缩/旋转。局部能量排序可能因下游各向异性的敏感方向发生翻转；排序翻转本身甚至不要求非线性，线性但各向异性的传播就能造成。

**新增定位：** 从原始JSON重读，六来源在step0的flow中已经出现联合次可加，比例为0.232–0.853。驱动在scheduler.step_post之前保存flow，所以首次出现这一现象不需要跨步累积或high→low专家切换。后续步骤仍可继续改变它。

**独特预测：** 在真正光滑的局部映射、起点固定且输入动作可加的条件下，按λ缩小两个扰动，应有c(λ)=O(λ²)，而a(λ)+b(λ)=O(λ)，故η=||c||²/||a+b||²=O(λ²)，前提是一阶和非零。量化阈值主导时可出现台阶与不满足该缩放律的区段。

**可能应用：** 把计算单元从独立通道组推广为少量预校准的组合；在残差/attention读取点上校准联合动作。需要与相同实际计算预算的固定组合竞争。当前AB删两个组而A/B各删一个组，四臂用于机制分解，不能直接构成等预算优胜结论。

## 4. 新增强反解释：共同参考与干预间误差去相关

这是对“系统自动纠错/学到了抵消”的必要竞争零模型。

假设四臂最终输出在某个二阶统计范围可写作：

    F_i = μ + e_i,   i∈{D,A,B,AB}

其中e_i零均值、不同臂的交叉矩为零，各臂误差能量相同，记为v。则：

    E||a||² = E||b||² = E||F_AB−F_D||² = 2v
    E〈a,b〉 = v > 0
    E||c||² = 4v
    E||a+b||² = 6v

因此，“期望能量之比”满足ρ=1/2、η=2/3，并呈正的单臂交叉项。这与此次部分统计的量级相近，完全不要求两个连续组方向相消，也不要求存在学到的联合修复。

**物理含义：** 确定性的BF16/HiF4阈值变化可能令不同干预轨迹的误差在大量坐标上去相关。跨节点逐位复现与这个统计解释相容，因为随机性是假设在坐标/样本分布上的描述，而非每次运行重新抽噪声。

**重要限定：** 共用参考本身不会让一个真实可加的系统变得非加性；这个零模型同时假设干预之间存在去相关的误差。实测c仍是真实有限非加性，只是它可能主要来自数值路径而非有益的语义修复。

用现有末步标量核对：

| 来源 | ρ（联合/单臂能量和） | η（定义见上文） | 单臂响应cosine |
|---|---:|---:|---:|
| 0 | 0.378 | 0.622 | 0.750 |
| 4 | 0.447 | 0.670 | 0.497 |
| 8 | 0.336 | 0.662 | 0.807 |
| 12 | 0.533 | 0.748 | 0.381 |
| 16 | 0.601 | 0.403 | 0.731 |
| 20 | 0.739 | 0.889 | 0.541 |

即便放松为各臂不同误差能量、仍要求交叉矩为零，也有必要的矩关系：

    v_D = 〈a,b〉
    v_AB = E_AB − 〈a,b〉 ≥ 0
    ||c||² = E_AB + E_A + E_B − 2〈a,b〉

source8按观测标量精确配矩会得到v_AB≈−13,444；后一个关系的归一化残差在六来源为−0.173至0.662。因此简单独立噪声矩模型无法完整拟合当前描述统计。这里不是以六个来源作严格显著性检验；它说明“仅凭ρ≈1/2就认定噪声”也站不住。

**下一步判别：** 完整使用四臂之间六个两两距离与分空间/分层交叉矩，检查是否存在稳定的共同方向和结构相关性；再用实际写回匹配、数值精度受控的对照区分连续响应与数值去相关。当前只用归档标量做了上述代数核对，完整张量交叉分解尚未执行。

**可能应用：** 组合压缩的选择准则加入跨数值微扰/来源的稳定性；寻找保持功能而不依赖某一条dense数值轨迹的组合。参考轨迹忠实度与感知质量分别评估。

[Widrow等的量化统计理论](https://isl.stanford.edu/~widrow/papers/j1996statisticaltheory.pdf)给出了加性去相关噪声近似的适用条件；不能默认其在当前低比特神经网络中成立。[Q-Drift，2026预印本](https://arxiv.org/html/2603.18095v1)也显式建模输出与量化误差的相关性，使用条件高斯/协方差近似；它是相邻机制先例，不提供本次四臂零模型或Wan稀疏收益的验证。

## 5. 首层径向对齐：逐token功能联系，还是共享方向造成的各向异性？

现有写回前与leave-one-group-out对照削弱了“仅因该组被加进残差才对齐”的解释，但没有区分：

- **逐token功能联系：** FFN组根据当前token状态产生定向更新，径向比例包含输入依赖的功能信息。
- **共享方向/低维结构：** 不同行的residual与组输出都含同一个较强方向，即使打乱token配对也会显示较大径向对齐；逐token动态选择的必要性较低。
- **步/专家/门控结构：** 第0层的门控与输入分布形成位置特异的对齐，未必来自蒸馏学到的通用冗余。当前同一蒸馏模型不足以归因“由蒸馏导致”。

**最便宜的区分观察：** 在相同source/step/block/group内，比较真实行配对、行间置换、减去跨行5120维共同均值后的对齐，匹配向量幅度，并保留时间/空间邻域分层。跨行均值不同于LN消除的每行通道常量。

若置换后对齐大体保留，共同模式优先解释；若真实配对明显胜出，token条件关系更值得研究。该检验设计可利用保存操作数，本文未运行。

**为什么径向分量仍有功能：** 理想ε=0、c>0且归一化输入非常量时，B(x)=x+f(LN(x))，有B(cx)−B(x)=(c−1)x。LN当下看不见的尺度差仍沿identity传递。若u=f(LN(x))、z=x+u，则J_LN(z)x=−J_LN(z)u：后续分支改变方向后，旧径向差可以重新可见。因此更有价值的对象可能是“径向信号什么时候重新影响计算”。

**可能应用：**

- 共享模式胜出：静态共同基底/共享分量压缩，减少逐token路由开销。
- token关系胜出：条件稀疏或小型状态相关近似。
- 延迟可见性胜出：基于下一次重要读取的预算分配，在真正敏感的位置保留精度/计算。

LN/角度关系已有文献和[ShortGPT的BI公式](https://arxiv.org/html/2403.03853v3)。本项目后续贡献应是可迁移的因果预测和真实省算，不能仅将角度重新命名为重要性。

## 6. 末层跨步结构：方向可复用，幅度与共同模式需要更新

当前gate加权的Block39 cosine≈0.963，而直接复用相对SSE≈0.373、事后标量修正≈0.072。对A=g_t⊙Y_{t−1}、B=g_t⊙Y_t，严格有：

    ||A−B||²/||B||² = r²+1−2r cos(A,B),  r=||A||/||B||

**机制A：** 主方向慢变，随去噪步的增益变化较快，适合“旧方向+便宜新系数”。

**机制B：** 高相似主要来自跨token共同分量；真正承载局部细节的中心化成分仍变化较大。原被动观察中Block39约79.28%跨步内积来自共同均值，去b2影响小，因而不能仅用显式输出偏置解释。

**区分观察：** 在未参与拟合的来源上，分别预测当前gate加权的幅度、5120维共同分量与中心化残差；比较它们对实际写回和后续结果的贡献。当前0.072是使用目标求出的事后最优值，尚不是在线可实现误差。

**可能应用：** 单历史、专家内的低维增益/共同分量更新；静态step校准；将算力留给难以预测的token差异。四步每个专家仅调用两次，严格依赖两个同专家历史增量的在线规则没有可跳过的新调用。中间层的事后标量残差仍高，应分层研究。

[AutoTarget，2026-10-02预印本](https://arxiv.org/html/2610.03577v1)强调缓存对象与solver变换共同决定误差，并证明某些Euler缓存表示等价。本文讨论的是内部FFN方向/增益结构；更换缓存表示之前应先检查是否真的改变了执行与输出。

## 7. 建议的研究顺序与应用优先级

1. **优先解释第一步内部的非加性。** 从已保存四臂数据核对完整交叉矩和方向，先判断共同参考零模型能解释多少。它不需要先假定长轨迹累积或专家切换。
2. **再切开数值边界与连续传播。** 若安排新原生诊断，使用同一起点、实际写回幅度匹配的方向，少量幅度级别，分开控制残差舍入与后续激活QDQ；每种配置带自己的dense对照。观察c随幅度/层深的变化，而不仅比较最终一个MSE。
3. **并行保留两条应用种子。** 首层真实配对vs置换决定静态共享压缩/动态路由；末层增益可预测性决定单历史更新的价值。这两条可能比继续微调独立通道能量排名更有信息量。

近期最具体的应用是**压缩校准目标包含真实残差写回**。潜在省算应用是**有稳定交互的组组合、共享分量压缩、专家内单历史增益更新**。它们需要分别通过便宜前置信息、实际计算消除、独立来源四步视频质量与完整延迟验证；本次结果尚未提供收益数值。
