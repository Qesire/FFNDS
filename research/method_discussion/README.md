# 方法讨论与版本登记

[当前接手说明](../agent_protocol/CURRENT_CONTEXT_PACKET.md)给出固定 64 点锚点基线及下一轮有判别力的对照。本目录保存不同阶段研究者提出了什么、同行检验了哪个精确版本，以及争议依赖哪些证据。按问题定位原始测量时使用[实验证据索引](../EXPERIMENT_EVIDENCE_INDEX.md)。

| 要查找的记录 | 位置 |
