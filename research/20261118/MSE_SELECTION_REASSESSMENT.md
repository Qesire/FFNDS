# 局部 MSE 的适用范围与实验筛选修正

日期：2026-11-18。修正基点：a2a3f7e2d802f26dee04652c2f328dc6cd8a2b6c。身份：已有结果重读、代数推导与实验设计修正；没有新增模型、CAL、回放、视频或性能实验。

## 1. 结论与需要修正的决定

局部 FFN MSE 可以保留为重构目标、数值诊断和表示/辨识误差的度量；目前不能给它“决定一个机制是否值得进入完整视频实验”的硬筛选权。

原方案以 online 相对 static 的 MSE 改善至少2%、至少8/11来源获胜、任一来源退化不超过10%、均值不差于共同A作为视频准入。这些阈值没有经过最终视频功能的预测验证。把它们称为预算分配规则，并不能消除错排候选的风险。本次撤回这些准入及“两类均不通过就不生成视频”的规则。

两类新构造各保留完整80位置、static/online、DEV3的匹配比较，共12条开发视频。原总上限15不增加，余下最多3条用于0392的六位置范围诊断，不再让六位置质量或局部误差阻止全80比较。[修订方案](OBSERVED_SECANT_EXPERIMENT_PLAN.md)与[机器规格](observed_secant_experiment_spec.json)给出实际队列和预算。

这次修正没有证明新算子中已经存在“MSE更差而视频更好”的候选。新算子仍未运行；现有反例证明的是旧代理指标没有资格预先排除这种可能。

## 3. 用算子和张量语义说明缺失的信息

### 3.1 局部误差的轴与真实目标的轴

记来源为s、去噪步为k、层为l，latent token坐标为(\(\tau,h,w\))，输出通道为c。本配方的latent时间轴\(\tau\)长度21、解码视频帧轴t长度81、去噪步轴k长度4，三者不同。当前输入是norm2/AdaLN后的U；pre-gate误差为

\[
E_{s,k,l,\tau,h,w,c}
=\widehat F_{k,l}(U,S)_{\tau,h,w,c}-F_{k,l}(U)_{\tau,h,w,c}.
\]

S包含本方法在自身轨迹上生成的缓存/锚点。残差写回误差是当前gate作用后的
\[
e_{s,k,l}=\operatorname{vec}(E_{s,k,l}G_{s,k,l}).
\]

当前局部目标本质为这些向量平方范数的归一化平均。它区分不了同能量误差位于不同物体、帧、通道方向和层的后续影响。

MSE并非完全不看方向。对非零目标y和非零预测p，
\[
\frac{\|p-y\|^2}{\|y\|^2}
=(r-1)^2+2r(1-\cos\theta),\quad r=\|p\|/\|y\|.
\]

它已经同时惩罚幅度和夹角。p为零时直接使用原平方误差，不计算余弦；y为零时也不计算上述相对归一化。缺失的是“朝哪个具体方向偏移会影响哪些最终功能”，不是在MSE旁再加一个余弦就自动补齐。

### 3.2 任务度量是下游算子的拉回

将隐状态、去噪状态、缓存一起纳入展开的执行系统。固定输入、初噪和离散分支，在连续参考轨迹附近，最终视频特征q对各位置注入误差的一阶变化为

\[
\delta q\approx\sum_i J_i e_i,
\]

i合并k/l等实际注入位置，J_i包括后续层、去噪推进、解码与选定的视频特征映射。对固定PSD特征度量W，

\[
\|\delta q\|_W^2
\approx\sum_{i,j}e_i^\top J_i^\top WJ_j e_j.
\]

由此出现两类局部MSE没有保留的量：

- 对角块J_i^T WJ_i：各方向及各token对目标的敏感性；
- 非对角块J_i^T WJ_j：跨层、跨步及跨缓存窗口的误差累积或抵消。

将目标换为逐位置局部MSE，相当于使用一个简单块对角度量；只有相关项和敏感性具有合适结构时，它才近似真实目标。实际J随来源和轨迹变化，不能未经验证把它从联合期望中分离。

以上是连续局部推导。BF16舍入、选择分支和有限幅度改动需要实际端点验证；本次不把Jacobian近似称为原生全局保证。若最终评价是一般非平方的视频质量函数，首先应保留其一阶梯度项，而不是假设存在PSD二次损失。

在static已经偏离Dense时，online效果还要与原始误差方向一起评估。令r=q_static-q_Dense、d=q_online-q_static，则固定W下精确有

\[
\|r+d\|_W^2-\|r\|_W^2
=2r^\top Wd+d^\top Wd.
\]

仅报告修正d的大小，不能判断它修复还是强化原始偏差。

### 3.3 三个直接代数反例

**敏感方向。** J=diag(100,1)，e_A=(0.02,0)、e_B=(0,0.1)。局部平方误差分别0.0004和0.01，A更小；输出平方误差分别4和0.01，排序反转。所有误差可以再同比缩小，反转仍存在。

**时间结构。** 两个时间位置的抽象误差[a,a]与[a,-a]有相同能量2a²。施加相邻时间差分D后，能量分别0和4a²。这说明应分析“相对目标的时间变化误差”，不能把最小化生成视频本身的运动当作保真；这个二位置反例不把21个latent时间token当成81个解码视频帧。

**跨位置相关。** 两位置J_1=J_2=I时，误差(v,-v)与(v,v)有相同局部能量总和2||v||²，最终能量却分别0和4||v||²。逐层各自的风险均值不保存这一关系。

这些是数学反例，不是已在Wan实测的机制。

### 3.4 教师状态与自身学生状态仍须区分

同一FFN边界有精确分解

\[
\widehat F(\widehat U,S)-F(U^D)
=[\widehat F(\widehat U,S)-F(\widehat U)]
+[F(\widehat U)-F(U^D)].
\]

教师端点上的CAL/DEV只约束其对应输入分布。当前学生输入上的query能够观察第一项，却不能独自恢复完整前缀漂移和后续传播。各臂student query的输入不同；它们是各自自由轨迹的诊断，不是严格同输入的局部算子排序。

新计划继续保存64行student query，视频后才运行绑定的64行Dense评分。它不是免费全-M teacher，不用来回拟合本轮参数。见实验方案的独立观测成本。

## 4. 还要审查MSE在构造内部的作用

新读出的通道池、greedy16、静态V与lambda，以及原生模式的作用Gram/POD，都受到局部平方误差偏好影响。撤掉最后一道视频门槛，并未使这些表示自动对齐视频功能。

本轮保留既有选择器作为明确的“局部欧氏目标构造”，让static/online的差别保持可解释，不临时加入多种loss、rank、probe和来源网格。如果两类失败，结论只涉及这套欧氏选择的传感器/模式及当前推断器；不能排除低维状态条件化本身。

### 4.1 对全输出读出，简单输出加权可能完全不改变解

X:[N,r]、R:[N,d]、自由V:[r,d]，公共M:[d,d]为SPD。考虑

\[
\mathcal L(V)=\operatorname{tr}[(XV-R)M(XV-R)^\top]
+\lambda\operatorname{tr}[(V-V_0)^\top H(V-V_0)M].
\]

正规方程为

\[
[X^\top(XV-R)+\lambda H(V-V_0)]M=0.
\]

M可逆时从右侧消去，得到与普通目标相同的解。无正则时同样成立。这也解释了固定当前gate对自由全输出OLS为什么可能不改变最优读出。

若只给data term加M、正则仍用原Euclidean形式，解会改变，但一部分效果只是改变各方向的有效正则强度。跨来源不同gate、受限V、共享theta、token依赖度量、非可分的下游拉回则一般不会消去。不能只在代码里乘一份通道权重，就宣称已实现视频任务感知学习。

### 4.2 真正有意义的后续表示目标

后续若发现局部误差与功能系统性错配，应让结构选择面向目标敏感方向：

\[
\min_\theta\mathbb E_s
\left\|\sum_i J_{s,i} e_{s,i}(\theta)\right\|_{W_s}^2,
\]

或在真实有限幅度输出上直接比较功能特征。平方损失仍可以存在；关键变化是保留哪些结构、在哪个空间比较、怎样共享参数和保留哪些交叉项。

可计算方法包括任务方向的VJP/JVP、冻结的少量下游读出、针对有限参数的整段响应，但必须支付真实下游计算并验证代理与功能的一致性。当前P512文件不能凭空提供整网J。四个模式是“每位置四个”，全80独立系数共320；逐坐标中央有限差分并非只需8条视频。每个全局方向、每来源的中央差分需2条额外完整D4，另有基线和评测成本。

本轮已有static/online两端点提供真实有限改动，先利用这些匹配结果，不另加JVP/SPSA/新loss搜索队列。

## 5. 怎样做判断而不换成另一项未经验证的单指标

| 使用位置 | 本轮角色 |
|---|---|
| 同一表示的最小二乘拟合 | 保留为可解释局部控制，记录其欧氏目标偏好 |
| FP64/BF16同程序核验 | 验证实现，区分数值误差与近似误差 |
| 局部MSE、风险、余弦、幅度 | 分别报告，解释拟合及分布变化 |
| query oracle | 仅给该query/该连续类/该局部度量下的表达下界 |
| 候选视频准入 | 不由MSE排名或2%/8of11/10%门槛决定 |
| 最终开发判断 | 完整视频的预定功能、连续人审、逐维质量与真实成本 |

“oracle没有MSE空间”只限制局部欧氏重构；它不是视频功能不可能改善的下界。已有负结果名称据此增加EUCLIDEAN限定，或直接报告连续差距而不下机制生死判断。

VBench本身将质量拆成多个维度，原论文明确指出静态视频在其他时间一致性维度中可能获得优势：[VBench原论文](https://openaccess.thecvf.com/content/CVPR2024/papers/Huang_VBench_Comprehensive_Benchmark_Suite_for_Video_Generative_Models_CVPR_2024_paper.pdf)。因此subject consistency、smoothness、RAFT幅度或一个人工加权总分也不能自动接管硬筛选权。

0392的预定功能是保留Dense的晕眩重影，同时减少额外破碎；另外两源检查主体、动作、背景和画质的新增严重退化。完整视频先盲评，再看方法标签与各指标。旧+0.01等视频分数阈值降为历史参照，不把功能改善否决成“未过某一个分数门槛”。人审与指标冲突时保留冲突与具体时间位置；没有人审时保持待审，不用自动指标代填。

这仍是暴露DEV3上的开发研究，不能据此证明泛化、统计非劣或所有来源上的视频优势。后续冻结确认集应检验新代理的排序和漏判能力，而不是先赋予其淘汰权再只看被它保留的候选。
