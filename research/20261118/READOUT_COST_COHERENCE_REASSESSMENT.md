# 全 80 条件读出的完整成本、割线价值与关系保持修正

日期：2026-11-18。源码基点：`3e4f7ba806644f5aaaafce1c3c78df8eebc3f035`；本轮开始时仓库为 `c625ee174a4104bd98918c0d6b37e8f89b9feb33`，中间只有结果分析和文档更新，算子源码没有改变。本报告使用 operator-tensor-analysis，完成独立成本、割线结构和关系建模审阅。工作仅包括源码检查、数学推导、静态计数和确定性采样代码重建，未进行模型回放、CAL 拟合或新视频对比。

**判断：全 80 在线读出是 Q1 割线法有价值的质量升级路线。它保留紧凑 anchor 状态，主要矩阵运算量仅比 Q1 增加约 0.3164%，已经获得更好的视频保留；当前原生程序仍混有大量研究 I/O，尚无清洁部署速度结论。下一步应保留它的锚定非线性割线与当前全输出观测，修正所拟合的关系、所选择的输入方向和求解数据流。**

## 1. 用户的新观察改变了需要解释的现象

用户补充：总体运动幅度相近；非 Dense 的结果存在本应保持一体的色块在同步运动中抖动、解离；0392 的全画面交叠运动尤其暴露空间关系损坏；P64 和全 80 读出的损坏较小，但仍明显。原话已追加到[人审补充](../../reports/20261118/observed_secant_ffn_operator/analysis/HUMAN_REVIEW_ADDENDUM.json)。这次分析使用用户的连续视频观察，没有声称独立重新观看视频。

因此，先前 RAFT 幅值比继续保留为该评分协议的数值事实，但不再承担“总体运动不足”或“运动功能恢复比例”的解释。当前研究对象应为**相关区域运动及外观变化的协调性**。空间损坏、总体运动幅度、时间上的抖动和原本希望保留的重影需要分别表达。

一个精确例子说明幅度与协调可以分离：若两块原本共同沿 v 运动，近似向量分别为 R_theta v 与 R_{−theta}v，则两者长度都等于 |v|，相对位移却为 `2|v||sin(theta)|`。偏转随时间改变时，就能出现幅度相近而局部解离的现象。这是数学例子，不是对实际视频光流的重新测量。

用户明确要求先重审成本与构造。本轮不执行前次报告提出的六处更新或 high/low 对比，也不展开新参数网格。

## 2. 当前算子到底是什么

固定专家、层、权重与 gate，使用行存 token：

\[
F(U)=\phi(UW_1^\top+b_1)W_2^\top+b_2,
\quad U:[N,d],\ W_1:[m,d],\ W_2:[d,m].
\]

当前 `N=31668=21×29×52`、`d=5120`、`m=13824`。21 是 latent 时间轴，29、52 是空间轴；解码帧数为 81，去噪步数为 4。全 80 指 high/low 两专家各 40 个层位置，不是 80 个去噪步，也不表示额外运行 80 次全 token Dense。

每位置在 HHLL 的 0→1 或 2→3 窗口内有一次 Dense anchor 和一次近似 hit。当前读出连续形式为：

\[
\widehat Y_1=Y_0+(U_1-U_0)A+
[\Phi(U_1)-\Phi(U_0)]V_s.
\]

生产缓存使用 `C0=BF16(Y0−BF16(U0@A))` 与 FP32 Phi0；hit 通过 `U1@A+C0` 加 BF16 特征读出执行。A 在原六处使用冻结 L64，其余 74 处为严格 Q1；相同尺寸的 A 对下面的成本结论没有影响。

令

\[
f_s(u)=uA+\Phi(u)V_s,
\]

就有

\[
\boxed{\widehat F(u_1)=F(u_0)+f_s(u_1)-f_s(u_0).}
\]

同一次当前 V_s 同时作用两端。它保持连续算术中的锚点一致性，没有遗漏 anchor 的动态减项；原生 BF16 舍入误差另计。固定当前条件后，所有 token 使用同一映射，这种共享并不自动制造空间不一致。

来源：[native_readout.py](../../tools/ffnds_observed_operator/native_readout.py)、[observed_local.py](../../tools/ffnds_observed_operator/observed_local.py)、[原设计](OBSERVED_SECANT_OPERATOR_DESIGN.md)。

## 3. 完整算术成本：它与 Q1 基本处于同一档位

\[
C_{Dense}=4Ndm,
\]

\[
C_{Q1}=2Ndm+2Nd^2,
\]

\[
C_{P64}=2Ndm+2NdK+pdm,
\]

\[
C_{readout}=2Ndm+2Nd^2+2Ndk+Nrd+2pdm.
\]

读出各项分别是 Dense anchor、anchor/hit 两次 A 乘法、两个端点的窄 W1、全 token 读出、64 行完整 FFN。P64 的 observer 只有 W1，GELU不计入主要 MAC。

当前完整输出读出不是主要算术瓶颈。它有 `32×5120=163840` 个系数，但求解结构是**同一个 32×32 系统、5120 个右端**，不是一个 16 万维耦合优化。每个输出列对应 64 行观测；正的 CAL 正则底保证连续问题有唯一解。

## 4. 真正可能昂贵的部分：完整权重访问、数据流与状态

### 4.1 少量 token 不意味着少量权重

64 行约为全部 token 的 0.2021%，但完整 W1/W2 的 BF16 payload 是 **270 MiB/位置**。Q1 的数学 hit 只需 A 与 C0；A 为 50 MiB/位置。在线 observer 要重新使用原始完整 FFN 权重。

- 权重已在设备驻留时，主要区别是完整权重读取、小 batch GEMM 利用率与启动成本。
- 若权重 offload，observer 可能要求在 hit 取回 W1/W2。
- 当前宿主是否本来就预加载了 Q1 不使用的权重，需要按宿主数据流判断；不能只凭 hook 声称 Q1 已经避免全部传输。

因此，observer 的真实预算应包括权重可用时点和数据流。它在运算量上很小，运行时间仍可能重要。

### 4.2 缓存和参数要与 Q1、P64同时比较

| 对象 | payload |
|---|---:|
| 单位置 BF16 V | 320 KiB |
| 80 位置 V | 25 MiB |
| 80 位置 BF16 A | 3.90625 GiB |
| Q1：40 层 C0 | 12.080383 GiB |
| 读出：40 层 C0/Phi0 | 12.231388 GiB |
| P64：40 层 H0/Y0 | 44.697418 GiB |

读出相对 Q1 只增加约 **1.25%** 的 anchor 状态；相对 P64 使用约 **27.36%** 的状态。这是按形状计算的 payload，未包含模型权重、A、临时输出、allocator 等，不能称为 GPU 总峰值。

### 4.3 当前发布的是带完整记录的研究执行路径

源码显示 C0/Phi0 经 GPU→CPU、保存、fsync、文件 hash；hit 又验证文件 hash、mmap 载入、传回 GPU。两个专家各保存和读取 40 层状态，缓存 payload 搬运为 **48.925552 GiB/视频**。额外完整 hash 的逻辑读取也是约 48.925552 GiB；合计文件内容逻辑访问约 97.851105 GiB，不含 query。OS 页缓存影响实际物理磁盘流量。

此外，每位置还存在参数加载、A 搬运、算子构造、首次完整权重见证、finite 检查，以及每 hit query/V/probe 残差的 CPU 保存与 fsync。代码中的 `timing_includes_query_capture=True` 明确了这类计时范围。它们服务于证据采集，不是定义函数值所必需的运算。

本轮没有发现清洁部署 latency 数据。可以判断算法预算节制，也能定位应当移出热路径的操作；当前还不能给出实测加速比。

## 5. 割线结构的新认识：单 token 修正的输入方向只有 16 条

把 CAL 缩放、有效基与 beta 吸收到读出系数，写成

\[
\Phi(u)V_s=z_K(u)C_s+h_K(u)B_s,
\quad C_s,B_s:[16,d].
\]

于是

\[
\widehat F_n-F(u_{0,n})
=\Delta u_n A+\Delta z_{K,n}C_s+\Delta h_{K,n}B_s.
\]

对每个选定 GELU 通道定义真实有限割线斜率 bar_beta，使 `delta_h=delta_z*bar_beta`。得到

\[
\boxed{
\widehat F_n-F(u_{0,n})
=\Delta u_n\mathcal A_{s,n},\qquad
\mathcal A_{s,n}=A+W_{1,K}^{\top}
\left(C_s+\operatorname{diag}(\bar\beta_n)B_s\right).
}
\]

因此：

- 跨 token 修正数组 `X V_s:[N,d]` 的连续秩至多 32；
- **单 token 割线矩阵的修正 `A_s,n−A:[d,d]` 的秩至多 16**；
- 给定当前 V_s，各 token 的直接特征路径只包含所选 16 条 W1 输入方向。完整 observer 可以通过 V_s 提供额外的全局条件信息，但不能消除下述非 probe token 的零空间边界。

若某输入位移满足

\[
\Delta u W_{1,K}^{\top}=0,
\]

则两端特征相同、X=0，读出如何更新都只能给出 `F(u0)+delta_u A`。真实 FFN 的其余通道仍可能有非线性响应。这个零空间至少有 d−16 维，但数据在其中是否有重要变化需要另行判断；不能把维数直接解释成实际功能损失比例。

更强的局部结论：固定 anchor、probe ID、权重、gate 和 CAL 参数，在 W1 前输入面板上选择一个非 probe token，仅沿上述零空间扰动该行。连续算术中全部 Phi 和 Gram 不变，probe 标签与基线也不变，因而当前 V 的估计保持不变。该 token 的输出只沿 A 线性变化，其他行保持不变。故此处的输入曲率缺口并不因在线估计依赖全部 token 而自动消失。该命题不把原始 latent 扰动经 attention 后影响多个 token 的情况包含进来，也不宣称 BF16 逐位恒等。

固定当前 V 时，二阶作用为

\[
D^2f_s(u)[a,b]
=\sum_{h\in K}\phi''(z_h)
(aW_{1,h}^{\top})(bW_{1,h}^{\top})B_{s,h,:}.
\]

相比真实 FFN 的全部 m 个通道求和，它只保留 16 个输入曲率方向，输出方向则可随状态变化。当前读出的价值正是恢复了一部分 Q1 没有的有限非线性响应；进一步改善应让这些有限输入方向承担真正重要的关系变化。

这些是连续结构的推导，不把 16 通道直接判为 0392 损坏的已证实根因，也不要求每个输入维度都单独建模。

## 6. 从画面解离到准确的数学目标：去噪差分与关系差分

令 i、j 表示两个有明确关系的 token，0、1 表示 anchor/hit 的去噪端点。定义

\[
\mathcal C_{ij}[F]
=F(u_{1,i})-F(u_{0,i})-F(u_{1,j})+F(u_{0,j}).
\]

这是去噪方向的有限变化，再沿 token 关系取差。它描述两处 FFN 写入之间的关系如何改变。

当前近似给出

\[
\mathcal C_{ij}[\widehat F]
=(\Delta u_i-\Delta u_j)A+(X_i-X_j)V_s.
\]

应该拟合两者的差，而不是要求它为零。图像上共同运动的区域，在 FFN 输入中仍可需要不同的写入。

### 6.1 一个简单极限揭示非线性割线的必要作用

假设用于说明的两个 token 具有共同输入增量 v，起点差为 a，则

\[
F(u+a+v)-F(u+a)-F(u+v)+F(u)
=\int_0^1\int_0^1 D^2F(u+sa+tv)[a,v]\,ds\,dt.
\]

共享线性 A 对这个混合差分给出零。非线性读出可以恢复其中一部分。例子 `F(u)=u²`、起点为 0 和 1、共同增量 epsilon，真实混合差分为 `2 epsilon`，线性 A 给出 0。该假设只是展示结构，未把真实视频的共同运动等同于 pre-W1 输入具有相同增量。

### 6.2 一般四端点的精确式

令 `v_j=u1j−u0j`、`delta_v=delta_ui−delta_uj`、`a=u0i−u0j`，构造

\[
u(t,s)=u_{0,j}+tv_j+s(a+t\delta v).
\]

在 F 二阶可微时：

\[
\mathcal C_{ij}[F]=\int_0^1\int_0^1
\left\{DF(u)[\delta v]+D^2F(u)[a+t\delta v,v_j+s\delta v]\right\}\,dt\,ds.
\]

它同时包含增量之差和混合曲率。Q1 提供前者的固定线性近似；当前读出增加部分混合曲率。新的关系目标应反过来决定哪些原生输入方向值得纳入 K。

### 6.3 关系约束的范围

把空间/对应差分表示为稀疏矩阵 B。对局部误差 E，`B E` 度量其关系缺陷；公共 gate G 满足 `B(EG)=(BE)G`。有限网格上它仍有 `||BE||≤||B||||E||` 的一般界，所以并不是独立于点值的神秘信息。当前困难来自有限观测、平均目标、方向权重和下游传播；它使关系误差可能在整体点值均方误差中被低估。

latent 关系误差只是与用户现象相联系的局部建模目标，尚不等价于终端视频的物体相对运动。空间邻近也不等于同一物体；遮挡/交叠边界上真实差分可以很大。严格的 token 置换与带插值的运动 warp 也应区分：非线性 FFN 一般不与混合插值算子交换，不能无依据地要求 `F(TU)=T F(U)`。

## 7. 建议的算子修正：保留完整输出，用关系几何拟合当前创新

保留当前 `Y_stat=Y_b+X V0` 与 64 行完整 FFN observer。定义

\[
D_P=F(U_P)-Y_{stat,P},\qquad V=V_0+\Delta V.
\]

令 `B_P:[E,p]` 表示具有真实坐标/对应依据的有符号关系边，W 为非负边权，定义

\[
M=I_p+\gamma B_P^\top W B_P.
\]

拟合

\[
\boxed{
\min_{\Delta V}\frac1p\|M^{1/2}(X_P\Delta V-D_P)\|_F^2
+\lambda\operatorname{tr}(\Delta V^\top H\Delta V),
\quad H=X^\top X/N+\tau^2\Gamma_{CAL}.
}
\]

对应的小系统为

\[
\boxed{
\left(X_P^\top M X_P/p+\lambda H\right)\Delta V
=X_P^\top M D_P/p.
}
\]

实际计算解线性方程，不显式求逆。若仍保留现有当前谱截断，令 Z=X T_s，在 Z 支撑中求更新并 lift，原完整静态预测不变。正则底使全 CAL 特征空间上的系统也是 SPD。

这个目标同时匹配点值创新与 Dense 本身的关系创新：

\[
X_P\Delta V\approx D_P,
\qquad B_PX_P\Delta V\approx B_PD_P.
\]

**惩罚对象是关系误差 `B_P(X_P deltaV−D_P)`。** 单独惩罚 `B_P X_P V` 会把真实非零差分压小，容易误抹重影和相对运动。当前提案没有这种“相邻输出应一样”的要求。

### 7.1 它改变的是行轴度量

M 作用于 token 行轴，会同时改变 `X_P^T M X_P` 与 `X_P^T M D_P`。在近似残差不能完全表示时，它一般改变最优投影。相反，给每个输出列共同乘同一可逆 G，并把同一输出度量施加于数据项和参数项，可能从完整输出回归方程中消去。只换一个输出加权名称未必改变原方法；关系行几何提供了真实不同的约束。

如果点值已经可被无正则精确拟合，其线性组合也已正确；加入差分不会再增加信息。这里改进的是有限表示能力和正则条件下的拟合偏好，而非宣称必然提高所有样本质量。

### 7.2 观测布局必须真的能形成关系

在 p 行已有标签上构造差分不会增加独立信息：

\[
\operatorname{rank}\begin{bmatrix}X_P\\B_PX_P\end{bmatrix}
=\operatorname{rank}(X_P).
\]

任意随机点的全连接等权差分满足 `B^T B=pI−11^T`，仅加强中心化残差，没有定义空间相邻或运动对应。

本次按已发布 `native_full80.row_ids` 的代码重建 seed42 的 64 行，并按 `(21,29,52)` raster 展平解释坐标：同 latent 帧的 4 邻接边、8 邻接边以及相邻 latent 帧同空间坐标边均为 **0**。这是确定性选择代码的重建，未另取回学校运行 BINDINGS 的 ID 见证；具体版本与全部 ID 保存在[重建记录](../../reports/20261118/observed_secant_ffn_operator/analysis/PROBE_GEOMETRY_RECONSTRUCTION.json)。它说明直接在当前随机 64 行上添加“局部邻接损失”，很可能根本没有对应关系可用。

一个明确可实现的观察设计是分配 `p_global+2p_pair=64`：保留分散的全局点，并在选定中心添加真实 raster 邻点形成 p_pair 条边。固定总 observer 行数可以保持主要 FFN 成本，但邻点会替代部分独立覆盖中心，不能把关系分辨率视为免费信息。分配比例与边权是尚待确定的设计选择，本轮没有按视频调参。

同帧相邻边可以直接匹配 teacher 的非零差分，即使跨物体也不会在目标上强迫相等。跨帧“同一物体”对应必须有实际依据；没有对应资产时只称坐标方向差分，不将固定空间位置冒充运动跟踪。当前 B 在一次 anchor/hit 分析内固定；若两端使用不同关系算子，还必须保留关系变化带来的额外项。

### 7.3 这个修正的额外成本很小

用 E 条两点边计算 `B_PX_P` 与 `B_PD_P`，只需差分；再增加 `E r²` 的 Gram 与 `E r d` 的 RHS 收缩。以 E=32 为计数例，后者为 5,242,880 MAC/位置。相对主 `U@A` 的 830,157,619,200 MAC 很小。

全 token 的 X V、C0/Phi0 缓存、V 尺寸均保持；总 p=64 时没有新增完整 FFN observer 行。边的选择与对应获取若需要额外模型，其代价必须另计；本提案不暗中调用光流或分割模型。

## 8. CAL 特征选择也应对同一种关系负责

仅改变 V 无法修正 §5 中不存在的输入方向。因此，关系几何应贯穿候选筛选、16 通道选择、prior 与正则定参。

对 CAL 的真实残差 R 与一组候选特征 X_K，使用

\[
\widetilde X_K=\begin{bmatrix}X_K\\\sqrt\gamma W^{1/2}B X_K\end{bmatrix},
\qquad
\widetilde R=\begin{bmatrix}R\\\sqrt\gamma W^{1/2}B R\end{bmatrix}.
\]

在这个增广行空间计算通道投影作用和多通道拟合。必须连最初的候选池打分一起改变，不能先按旧点值筛掉关系重要的方向，再指望最后 16 个通道恢复它们。

这保留了原生通道与配对特征的可计算性，改变有限预算的分配依据。现存 P512 是否包含有效边要按真实 global ID 判断；未捕获的关系不得由行顺序伪造。若已有校准点没有足够的关系信息，就将它明确列为新构造所需的观测资产，而不把当前推导写成已完成拟合。

平方损失本身不是主要问题。这里从“独立点值的平均偏差”转向“点值与具体关系的联合偏差”；视频功能仍不由任何单一局部标量决定。该目标是否足够恢复画面协调尚未实测，但其输入、目标、求解与代价已可明确描述。

## 9. 执行层应先做的简化

### 9.1 有正则时，昂贵的当前 SVD 并非求解存在性的必要步骤

现有 `_support` 对全 N×r 的 FP64 白化特征作 thin SVD，返回随后丢弃的左奇异向量，再构造全量 coords。若保留全部当前方向，原岭回归可直接写为

\[
\left[X_P^\top X_P/p+
\lambda(X^\top X/N+\tau^2\Gamma_{CAL})\right]\Delta V
=X_P^\top D_P/p.
\]

只需当前小 Gram、RHS 与 SPD 求解。`lambda*tau²*Gamma_CAL` 已为正定，X 降秩也不会使问题失去唯一解。固定 CAL 分解可缓存，当前 Gram 可按 token 分块累计。

数学等价范围必须保留：全部方向保留，或只删除精确零空间时，可以消去 SVD 换基；现有程序截掉小但非零方向时，则含有真实谱截断，直接全 r 解是明确的数值定义变化。用 Gram 特征分解模拟极小奇异值阈值会平方条件数。保持生产 BF16 X_b 再变换，与提前白化 Phi 后重新量化也不同。

### 9.2 固定对象预绑定，状态访问与证据记录分开

每 expert/layer/device 预绑定 A、窄 W1、prior、CAL Gram 和分解；权重身份验证一次。将 query 落盘、完整 hash、fsync 和大数组审计扫描移到独立记录路径。容量允许时让 C0/Phi0 在设备驻留；否则用明确的 pinned 缓冲与预取，实际容量和依赖顺序仍需满足。

这些执行改写可保持数学算子，数值归约/融合改变时单列浮点差异。不能通过删掉必要的状态或用另一臂 anchor 实现所谓提速。

### 9.3 真正减少大 GEMM 的存储—计算备选

如果改存 U0、Y0、Phi0，在 hit 计算

\[
\widehat Y_1=Y_0+(U_1-U_0)A+X V_s,
\]

则可省 anchor 的 U0A。计入相同 k16/r32/p64 主要项后，pair 比例由 68.7353% 降为 **59.4760%**；40 层状态由 12.2314 GiB 增至 **24.3118 GiB**。若不保存 Phi0、在 hit 从 U0 重新计算它，pair 的两端窄特征投影次数不变，状态可降至 U0/Y0 的约 24.1608 GiB，但工作移到 hit。

这是明确的容量换计算。落盘/PCIe 受限时可能反而更慢；BF16 的 delta/cache 程序也发生变化，因此作为设计备选，不默认取代 C0 形式。

把线性特征直接编入动态大 A 也不自动省事：仍需保留 anchor 对应减项，并付出每 hit 大矩阵形成与读取。当前小因子直接执行已经避免了这部分不必要成本。

## 10. 当前不应优先做什么

| 直接改动 | 为什么优先级低 |
|---|---|
| 把 V 限制为 M_s V0 | 将输出行空间锁回 prior；X V 也只占双 Dense pair MAC 约 0.0579%，不是主成本 |
| 统一降低运动幅度或在线增益 | 用户指出总体幅度相近；整体收缩可能削弱已经恢复的目标响应 |
| 对修正/画面直接空间平滑 | 真实重影、交叠与边界可有大差分；应该匹配真实差分而非趋零 |
| 立即增加区域独立 V | 增加区域边界不一致和状态；现有共享映射本身并非已证实问题 |
| 只增加 rank 或更多 probe | 没有先明确新增输入方向与观测关系；也不能把更多输出自由度当成新增曲率方向 |
| 立即重开视频比较 | 用户本轮优先要求完成成本和构造分析；本报告不创建新的执行范围 |

本轮建议保留完整输出 V，先把“关系保持”变成明确的观测与拟合对象，同时实现可等价简化的数据流。若今后仍要压缩 V，可在当前创新决定的方向中压缩；不默认回到已经限制过的固定输出空间。

## 11. 数学联系与结论范围

“同时匹配函数值与变化关系”与 [Sobolev Training for Neural Networks，NeurIPS 2017](https://proceedings.neurips.cc/paper/2017/file/758a06618c69880a6cee5314ee42d52f-Paper.pdf) 的值/导数联合逼近有联系；[Relational Knowledge Distillation，CVPR 2019](https://openaccess.thecvf.com/content_CVPR_2019/papers/Park_Relational_Knowledge_Distillation_CVPR_2019_paper.pdf) 则使用样本间距离和角度关系传递结构。这里采用的是实际 FFN anchor/hit 之间的有符号混合差分与小系统回归，不等同于上述任务或损失，也不把关系损失本身当作文献新颖性。

文献支持的是数学研究方向，不提供本方法视频效果的证据。成本、单 token rank16、输入零空间、混合割线与正规方程均由当前模型定义和实际源码直接推导。

最终判断按对象分开：

- **割线结构：值得保留。** 它通过当前完整响应选择非线性有限割线，保持原有 anchor 和输出自由度。
- **算法预算：适合继续。** 相对 Q1 主要 MAC 增量约 0.3164%、anchor 状态增量约 1.25%。
- **实际部署：尚未完成。** 完整权重访问、研究 I/O、重复支撑与同步需要整理，clean latency 未测。
- **质量修正：关系与输入方向优先。** 当前重要现象是同步结构解离，合理目标是保留真实关系变化，并让有限曲率方向对这些变化负责。

这轮完成的是可推导、可核算的重新设计；原模型实现、旧参数和已发布视频保持原身份，没有把新的关系目标写成已验证质量收益。
