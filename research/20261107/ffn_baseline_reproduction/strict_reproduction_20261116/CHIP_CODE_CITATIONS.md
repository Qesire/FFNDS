## 3. 合并为有限的验收工作

这些代码边界不需要各配一轮全视频实验。合并后的实现验收为：

1. **CPU 身份与接口检查**：入口配置、固定源码/权重 SHA、真实 patch grid、voxel 逆变换、显式 scheduler/counter。复用已有纯 Python counter 轨迹。
2. **作者模块同输入检查**：一组捕获的 BF16 FFN 输入，官方 Triton 算术加官方 selector；dense neutral 与同 inds/counts 的逐段数值对照一起完成。
3. **单条状态轨迹**：覆盖首两层、refresh、多 hit、step≥10 的 mask reuse、expert/invocation 隔离及 cache 写回。它是模块序列，不是完整视频扫描。
4. **两个局部边界检查**：一个真实 52-token 尾块和 U06 的一个 selector padding 例。selector 的索引排列可能受 atomic 顺序影响，不把两次索引 SHA 相等设为唯一通过条件。
5. **单条部署生命周期检查**：活动 W2 转置与 offload/cache 槽在 expert/layer 切换时保持身份及数值；仅在部署接入确实改变这些状态时执行。

完整视频与消融数量由总方案统一预算；本表没有增设原系统视频复现、所有特性的全视频扫描或新质量结论。
