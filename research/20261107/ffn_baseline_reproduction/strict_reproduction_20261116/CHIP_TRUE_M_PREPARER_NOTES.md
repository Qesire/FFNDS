# Offline true-M scope preparation

`chip_true_m_scope_prepare.py RECIPE RECIPE_SHA256 SCOPE_OUTPUT AUDIT_OUTPUT` only reads inputs and creates new local files; it does not stage, approve, or execute a job. The recipe contains `template`, `grid`, `factor_producers`, and optionally `q1` and `selected_icc`.

* `template` has the fields in `CHIP_TRUE_M_SCOPE_CANDIDATE.md`, with actual bound code, runtime, provider, module/selector receipts and DEV pair/capture manifests. Grid run/exit/scores, grid scope, canonical cache manifest, fixed64 and `decomposition_norm_floor` are injected from verified completed grid/capture, not guessed. The grid must freeze that norm floor.
* `grid` and each `factor_producers` entry are `{stage,scope_sha256,job_id}`. The stage must contain `scope.json`, `REVIEW.json`, `receipt/RUN.json`, `receipt/EXIT.json`, and the corresponding `output` payload. All three factor families across the six actual sites must be present exactly once, with sidecars, file hashes, checkpoint and clean-CAL ancestry matching the 792 grid rows and factor specs. The output `SUMMARY.json`, `scores.json`, `selection.json` and `cache_manifest.json` must agree. All 66 native endpoint cache files must still be present and hash correctly.
* Optional `q1` is a successful producer entry with `output/Q1_MANIFEST.json`; optional `selected_icc` is `{path,sha256}` for the frozen 80-site ICC manifest. Their 80 tensor artifact hashes are audited when supplied. Missing optional proofs are recorded as `NOT_BOUND`; the true-M calculation itself only requires the grid, 18 site factors and cache. The later five-arm generation freeze independently requires both full-depth parameter sets and the remaining completed prerequisites.
* `SCOPE_OUTPUT` is directly usable as a candidate `scope.json`; `AUDIT_OUTPUT` contains producer/receipt identities, selected family, optional readiness, and the scope SHA. Review remains mandatory; this tool does not create REVIEW or ACTIVE entries. Creation is exclusive and existing files are never overwritten.

The CPU fixture in `test_chip_true_m_scope_prepare.py` constructs 18 small factor stand-ins, 792 grid cells and 66 small cache stand-ins. It checks acceptance and tamper rejection, but mocks template validation and does not establish GPU, author-kernel, scientific or production-file correctness.
