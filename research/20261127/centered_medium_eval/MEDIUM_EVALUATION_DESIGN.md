# Centered + wide8192：固定规模确认性评测

状态：设计与准备资产；尚未生成本轮视频。研究版本为 `4ca6b1b14b90965269a7b480f4fd5bfc75f64f37`，方法细节以 `FROZEN_METHOD_BINDING.json` 为准，学校执行环境还须核实该文件要求的运行代码与权重身份。

## 1. 本轮要作出的判断

检验已经收敛的完整方法在更多独立输入上，能否保持终端视频质量并实现完整请求加速；同时用一个 FFN 对照分开 FFN 与注意力的增量收益。已有局部机制实验、六源比较及 centered DEV 结果支持进入这一步。完整矩阵输运、SparsePR RCP 的后续开发均可独立进行。

本轮只有三个固定臂。三臂使用相同四步蒸馏模型、HHLL 调度、图像、prompt、初始噪声、BF16、832×464、81 帧、16 fps。

| 臂 | 自注意力 | FFN | 解释 |
|---|---|---|---|
| D | 四步 native | 四步 native | 同一四步模型的 Dense 分母 |
| W | 四步 native | native / wide8192 / native / wide8192 | FFN 单独收益 |
| M | native / high OUT-ABS / native / low centered OUT-D | 同 W | 完整方法 |

`wide8192` 表示 FFN 执行 tile 行数；所选通道数仍是 2560。P64、锚点、当前统计量、路由、缓存和 probe 修正均进入真实在线推理。跨注意力保持既定实现。主比较为 M−D；W−D 和 M−W 提供组件贡献。局部 MSE 与 Dense 轨迹距离只解释近似误差，不承担画质判决。

## 2. 一个固定样本设计

主集采用 **100 个独立 image/source cluster × seed42 × 三臂 = 300 段原片**。从同一 VBench I2V 图像池中，预先选择 场景组 structured 33、自然组 natural 33、主体与活动组 subject 34 个簇。场景组覆盖 indoor / architecture / abstract，自然组覆盖 scenery / plant，主体与活动组覆盖 single-human / multiple-human / animal / transportation / food / other，候选范围纳入官方 11 类别。三组固定配额，每类别实际 n（含零）另报，不增加每类别最低数门槛。这是近均衡三层 CUSTOM_PAIRED 子集；结论适用于这些覆盖范围。既有快照含 1118 条 prompt、355 图像簇；历史快照的 299 个未曝光簇说明规模可行，最终数量以学校现行候选表和曝光登记为准。

每簇只选一个规范 source/prompt，重复 prompt、裁剪、seed 和帧均不增加独立样本量。先按 source_cluster_id 与 image_sha256 合并别名，再冻结规范代表。CAL3 与 current DEV 硬排除；旧曝光仅登记，优先从未曝光簇选取，不启动无止境的历史审查。原六源确认集及后续 DEV 应写入现行曝光登记。若采用旧曝光补足，须在结果中明示数量和用途。若三层不足 100，准备脚本明确失败，由数据管理员更新候选元数据，不自动改变配额或在看结果后补选。

选择顺序为预先固定 salt 的 SHA256；不读取任何模型输出。`prepare_cohort.py` 在选源后校验真实图像字节和原始 UTF-8 prompt 的 SHA256，生成私有运行清单及去除 prompt/locator 的公开清单。输入原文不得被隐式 strip 或改写。

同一清单预先选定每层 4 源作为计时集（共 12），每层 8 源作为盲审集（共 24）。全部 100 源原片均可访问。运动或指标尾部样本可追加诊断展示，但须与预先选定的盲审样本分开列出。

本轮默认一个 seed。100 个独立来源优先回答输入泛化；额外 seed 主要测同源随机性。本轮不会因置信区间跨界自动增加 seed 或样本。

## 3. 七项官方函数与统计判据

复用现有 pinned VBench I2V 环境和七个官方 `compute_*` 函数：subject_consistency、background_consistency、aesthetic_quality、motion_smoothness、imaging_quality、i2v_subject、i2v_background。

**主表将全部 100 段真实视频输入每个维度，每臂每维计划 n=100。** 官方 custom_input 支持把请求维度赋给全部输入；I2V subject/background 的公式不要求额外主体 mask 或 prompt 类别。保留 `original_dimension_tags`，另给官方原标签子集的附表和实际 n，原标签不作为 CUSTOM_PAIRED 主表门槛。此处七项由五项通用维度和两项 I2V 维度组成，本轮每 source/arm 只有一个真实视频，报告名称必须标为 CUSTOM_PAIRED；不声称官方五视频完整协议或官方榜单总分，不复制文件冒充五个样本。

主要 estimand 是每维在 100 个独立簇上的配对平均差：

\[
\widehat\Delta_d=\frac1{100}\sum_{i=1}^{100}\left(s_{M,i,d}-s_{D,i,d}\right).
\]

维度原值统一确认在 0–1、越高越好后，显示平均差的百分点。范围校验容忍 1e−6 的数值误差但保留原值，不截断分数；实质越界记 ERROR 并保留实际 min/max 与 n。保留原始单位和转换，禁止把分母或分数方向隐去。来源级分层配对 bootstrap 10,000 次，固定 seed20261127；分别在三个预定层内按原层大小有放回抽样，然后合并，保持 33/33/34 的设计权重。一次抽样同时重采样三臂及七个维度，以保留相关性。报告每臂均值、配对差、双侧 95% percentile CI 和实际有效 n。七个 CI 是逐维区间，不称为同时覆盖区间。

**预先选择的实际非劣界为 −0.005，即 −0.5 个百分点；这是本研究的容差，不是 VBench 社区标准。** 使用同一双侧 95% CI 作保守判定：

| 结果 | 预登记条件 | 可支持的结论 |
|---|---|---|
| PASS | 七维均完整，且每维配对差 CI 下界均大于 −0.005 | 本研究容差下，七个质量函数共同支持非劣 |
| FAIL | 至少一维 CI 上界小于 −0.005 | 对具体维度存在超出容差的下降证据；逐维报告 |
| INCONCLUSIVE | 其余情况，包括 CI 跨界或必要维度缺失 | 本规模无法排除容差外下降；不得把跨界直接称为质量下降 |

判界保留 1e−12 的数值误差带，数学上恰好等于容差的结果仍为 INCONCLUSIVE。配对均值为正或接近零、置信区间尚跨界，是可以同时成立的事实。100 源给定成本和覆盖，不保证通过预定容差：作为精度直觉，未分层近似的 95% 半宽约为 1.96×配对差标准差/10，实际报告以分层 bootstrap 为准。主判断不以加权总分抵消某一维下降。所有七维共同通过是交并检验逻辑；不把多次查看后的选优当作确认性结论。W−D、M−W 使用相同表格作贡献解释，M−D 是预登记主比较。缺少部分评分行记 INCOMPLETE，保留实际 n、缺失 source 与可用配对均值，不给该维 PASS。失败/缺失视频和 metric error 原样登记；修复基础设施后可重跑同一计算，不能按质量择优重试或把缺失填零。

## 4. 运动与成片解释

七维评分仍需结合既有连续运动诊断和盲审：复用 81 帧、最大边 320 的 Farnebäck 流量、已有时间窗口和 M/D motion ratio，同时保存帧间亮度变化与 temporal difference 距离。运动量大小本身不是质量方向，必须结合 prompt 的要求；不以流量增大作为成功。motion_smoothness 单项不能证明动作被保留。

固定 24 源以隐藏方法标签、哈希确定左右顺序的原片配对检查动作完成、运动幅度和连续性、布局细节及遮挡。记录每源 verdict 和理由。全部 100 源原片及评分均保留，指标尾部仅作为额外诊断。若出现可复现的要求动作丢失，结果必须描述受影响的条件，不能仅凭七维 PASS 宣称完整画质等价。盲审不再引入一种新模型指标，也不阻塞生成与评分准备。

## 5. 时间分母、预算与停止边界

固定 12 源各做 **3 轮 × 三臂 = 108 个正式计时请求**；加主集 300，共 **408 个核心推理请求**。每个正式请求均运行四步并包含该请求自身的原生锚点、路由/P64、缓存建立、decode 和保存；关闭 trajectory/audit/profile/route archive 等诊断 hook。首次权重加载、编译、离线拟合和预热分别记录。

quality 100 源按六种三臂排列循环。timing 的偶数 source index 使用 DWM→WMD→MDW，奇数使用 DMW→MWD→WDM，并由 `(index//2)%3` 旋转首轮。12 源共 36 个 block，六种排列各出现六次。每后端先预热，正式请求不得跨源复用模型语义之外的缓存。

先对每源每臂三轮的秒数取算术均值，再计算该源 `mean(T_D)/mean(T_M)`；跨来源取这些比值的几何平均，与既有计时口径保持一致。CI 在三个层内分别重采样 4 个 source cluster，三轮随来源整体保留；三轮不冒充 36 个独立来源。完整请求与四步 GPU 分别报告，同时给出原始秒数、峰值显存和 W 臂结果。两者差值只作为事件区间外总开销，包含编码、VAE、保存等流程；没有独立事件时，不把它拆称为已测 decode/save 分项。正式 timing 的原片与计时元数据可以保存，但不保存内部轨迹。不得用局部 kernel 提速代替完整请求速度。

可预登记工程推进目标：完整请求 speedup 点估计至少 1.10×，且来源级 95% CI 下界高于 1.00×；这是本研究的工程门槛，质量判据独立报告。若只有 GPU 加速而完整请求不足，结论应落在具体时间分项。

按既有单请求约 35–45 秒的工作量级估算，408 请求约 4.0–5.1 GPU 小时；建议为推理留 4–6 小时量级，预热、加载及评分单独核算。该预算是规划值，需用学校环境的三臂热运行校核，不是新实测性能。评分另作可恢复任务，避免把生成和全套 scoring 挤入一个硬时限。

本轮按固定 100 源完成一次判定。PASS 后进入跨配置或外部方法比较；FAIL 定位出现下降的对象和条件；INCONCLUSIVE 保留均值与区间，不自动扩样直到通过。任何方法修改另立版本，并把本次样本记为已曝光。没有无限追加的隐含阶段。
