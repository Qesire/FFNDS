# UB1 来源级泛化与竞争解释：冻结证据复核

**已有现象（VIDEO/OBS）**：formal20 的 UB1 成像 aggregate 下降1.345%，但7/20个来源的单源下降超过2%；disjoint20 aggregate 下降3.166%，其中10/20超过2%，最差来源下降16.78%。总体均值与源级尾部共同揭示两个不同问题：数据覆盖是否不足，以及固定预算、支持选择和时间分配是否在某些状态下产生更大的函数误差。当前历史对照能描述差异，不能将其唯一归因于其中之一。

## 证据与计量

[原样机器结果](UB1_SOURCE_GENERALIZATION_AUDIT_20261027.json)及[执行收据](UB1_SOURCE_GENERALIZATION_AUDIT_20261027_RUN.json)来自14项冻结历史输入，分析 RUN 协议 SHA256 `462ff85c58e542903c3ca6ad3c4cdec278e58eab3baa643fa658d9eb734e4d68`，原分析 JSON SHA256 `1a771269b0bf280a7aa02299dda729d219117eda3873c193431acc27c5144e41`。实际一次单 CPU 描述性分析退出0，未拟合、生成视频或运行模型/新评分。两批各20个 source_group，subject/background 各10，标识集合无交集；每批3个已存逐视频质量指标。两批均已在前期研究中暴露，不能作为未来未见确认集。各指标方向均为较高较好，单源降幅是 `(dense−candidate)/dense`；aggregate 是 `(sum dense−sum candidate)/sum dense`，不同于单源降幅均值。分位数为排序后 `(n−1)p` 线性插值。尾部是描述而非后续选样规则；2%只用于比较旧工程阈值，不是新科学发现的通过门槛。

Dense 自身的质量分布也不同：formal/disjoint 的 aesthetic 均值分别0.6292/0.6162、imaging均值0.7446/0.7263，imaging 的第10百分位分别0.6837/0.6420；motion smoothness 均值0.9839/0.9854。因而两批差异包含来源内容和基线难度的变化，不能解释为对同一总体独立抽样的精确因果效应。

## 时间轨迹与 OP3 的真正分歧

同源 UB1/UB2 的 dense suite 身份一致，两批 step0 各20/20来源记录的所有数值完全相同；step1–3 各20/20来源的相对 RMSE 不相同。formal 中 UB1→UB2 的四步均值依次为 `0.02119→0.02119, 0.05838→0.05982, 0.16278→0.16446, 0.41449→0.41532`；disjoint 依次为 `0.02064→0.02064, 0.05699→0.05933, 0.16198→0.16507, 0.42384→0.42645`。这支持相同起步后的不同有限轨迹与时间预算有联系；这些是自由轨迹描述，不能把误差差异直接归到某一步的单点干预，更不等于视频质量因果。

OP3 的8项 step×fold 原生 SSE 比较中，新学生状态拟合/同样本量旧状态拟合比值为0.9434–0.9998，均值0.9800；新拟合/冻结 UB1 为1.0115–1.1057，均值1.0606，原 native gate 未通过，视频未运行。前者提供状态匹配可能有局部价值的竞争证据；后者并不能证明覆盖或支持机制无效：冻结 UB1 使用24来源，而每折新旧拟合为12来源，训练行和目标状态同时不同，且只在 block20 的局部 SSE 检验。8个 step×fold 不是8个独立视频样本。

## 下一项最小判别（OPEN）

先冻结同一来源、seed、step/block 和相同实际输入状态，以相同校准来源数、行数、拟合预算与真实 HiF4 数值路径比较：原支持、只改变支持、只改变拟合状态；必要时加入同支持和同预算的更广来源覆盖。以 gate×W2 的有符号输出及 Q2 组内旁侧变化、实际后续 flow 为预定义观测，并保留 step0相同起点与不同后续状态的区分。H-Data 预测同操作和训练预算下仅提高独立来源覆盖可缩小未见来源尾部；H-Support 预测同校准数据改变合法组支持可针对相同状态改变误差；H-Temporal 预测相同预算和输入状态下改变步骤分配会改变后续有限映射。此处仅为将来授权的配对原生设计；确认来源须独立预先确定，不能依据本表挑选。最终完整视频质量、物理成本和速度仍需各自真实证据。
