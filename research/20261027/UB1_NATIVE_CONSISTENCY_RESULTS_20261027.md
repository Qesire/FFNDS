# UB1 原 M 数值路径一致性：16 个保存位置

**已测现象（NATIVE-OBS）**：在 source0/seed42 和 source12/seed54 的四步、block0/39，共16个已保存位置，原 M=31668 形状下，UB1 实际缩窄 W1 的选中输出、GELU 和 Q2 与 dense 对应通道逐 BF16 位模式一致；在同一 R256 支路及相同 gate 下，训练特征式 dense post-Q2 选列与部署缩窄路径的输出差为0。这个结果缩小了已测位置上的一个候选解释：同输入下，训练与部署 Q2 数值路径差异没有解释这里的 UB1 局部误差。它同时保留了支持选择、重构、来源覆盖和自由轨迹传播等竞争解释。

每个位置只保留160个已观测行，按原 row_id 置入31668行、其余填零；这是对行独立 FFN 算子的原形状测试，不是完整原始 latent 状态。两条来源此前均暴露于 UB1 校准，16位置并非16个独立来源；没有残差写回、后续网络、新视频或质量/速度验收。[紧凑逐位置结果](UB1_NATIVE_CONSISTENCY_RESULTS_20261027.json)保留每个条件、两种 M 形状、分组统计及跨形状比较，原始逐行统计以原 RUN 为准。

**证据身份**：冻结协议 SHA256 `eaca70a26f4cedfd3f76ac52c3ed7b4ee1a849f7a3738975cf023c32584421e6`；原 RUN SHA256 `2d61c00e3c7922b285d86a10e49e9b7aa867d79f460585f7f93966f0dd351f17`，4,275,562 字节；launcher 退出收据 SHA256 `c7ddb4653fc2e47d121756c0ad9f955646b98481c6e55880105d38bd4a5c9854`，退出0且不自动重试。独立只读复核协议快照及44个执行源码快照全部匹配、65个 HF 资产的大小和 SHA 全部匹配。另4个权重分片由执行前代码检查绑定身份；本次独立复核未重新读取其独立权重镜像。原生完成账本为192次 BF16 GEMM、48次 Q2、0全模型调用/拟合/视频，实际耗时50.556秒；23次 GPU 监测采样无冲突，记录物理使用峰值8976 MiB，采样不能证明连续隔离。

## 原形状结果与小形状对照

16/16位置的 dense W1、GELU、Q2、W2 基线通过严格 BF16 位模式检查。16/16的原 M 实际缩窄 W1/GELU/Q2 与 dense 选中通道位模式相同，缩窄和原选列两路使用相同 gain、bias、R256 与 gate，输出 gap 也逐位为零。该零只针对两种路径的比较，不代表候选等于 dense：原 M 的 gated 候选相对 dense 误差跨位置约2.46%–11.81%。gate 乘法是局部诊断，未执行 BF16 残差加法。

M160 控制在 step0 的四个位置未产生 W1/GELU/Q2 选列差；step1–3 的12个位置则出现差异，单位置 Q2 位模式不同元素为4,834–10,683，局部路径 gap 相对候选误差范数约5.26%–12.89%。原 M 对应位置的该 gap 均为零。因此，小 M 的路径差异在本对照中由执行形状改变所伴随，不能直接当作原 M 的训练/部署数值失配。比较仅覆盖本次 shape、设备和数值实现，不断言所有硬件和其他条件普遍相等。

## 独立审阅与下一判别

对冻结代码与结果的核对确认：每位置先验证 dense W1→GELU(tanh)→Smooth2/HiF4 Q2→W2 四个基线；相同选组下比较缩窄输入与保存的 dense Q2 选列，两个分支使用同一 R256 参数，随后分别乘同一 gate。按每位置 dense 2次 GEMM、原 M 和 M160 各5次 GEMM，以及各3次 Q2，16位置与192/48账本一致。所有观测位置原形状基线、选列及 gated gap 与完成状态吻合；独立复核没有重新运行算子。

下一步可在预先固定、独立于这些校准曝光来源的状态上，以同输入、同预算比较支持选择和 R256 重构，并保留原 M 的严格基线；若要判断真实视频后果，须进一步比较残差写回和下游完整轨迹。当前结果不决定哪一种支持或来源覆盖方案最佳，也不构成完整视频质量或真实性能结论。
