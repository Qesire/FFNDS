## 3. 真正的四步全路径数值：误差累计的方向是实测的

定义第k个去噪步后`e_k=z_k^S-z_k^D`，本步新增差`a_k=e_{k+1}-e_k`，有精确有符号关系：

```text
E_next = E_previous + I + C
E = ||e||², I = ||a||², C = 2 <e_previous, a>
```

时间维一阶差分 `D_time` 可线性穿过本恒等式，因此对 `D_time e` 也成立。此处时间差分是**latent视频时间轴**，不是去噪step自身的差分。

| 去噪Step结束 | 全latent误差能量E（20源均值） | latent视频时间差分误差能量 |
|---|---:|---:|
| 0 | 993.155 | 227.640 |
| 1 | 6114.845 | 1301.439 |
| 2 | 32350.276 | 8648.128 |
| 3 | **263834.513** | **100437.587** |

- 20/20来源的全latent及时间差分误差在四步间**每一步严格上升**；每source在step1/2/3的`C>0`，时间差分版本也有**20/20正交叉**。
- 最后一步20源等权分解：`32350.276 + 120777.566 + 110706.671 = 263834.513`。即末步新增误差能量`231484.237`，其中**47.82%是已有误差与新增差的同向交叉**，其余52.18%为本步增量平方。
- 同一末步时间差分误差分解：`8648.128 + 58491.476 + 33297.983 = 100437.587`，时间差分新增误差中**36.28%为正交叉**。
- 末步误差能量占最终总能量的新增份额为`(263834.513−32350.276)/263834.513=87.74%`，但这不是“最后一个Block承担87.74%误差”，且step3步长0.625与前面的0.0625/0.10417/0.20833不同。

**这建立了真实的跨step有符号共向累积机制观察**。并不要求误差是线性增益或局部层层放大；需要后续作用干预定位是哪一段FFN/Attention/轨迹消费者制造这种跨step行为。全20来源各4步真实轨迹覆盖全部160 site，不是在末层head计算一个代理。

## 4. 视频质量与误差的真正关联：Dense运动幅值是强混杂

把20来源`最终latent时间差分误差T_3`与**同源**的真实视频连续RAFT幅值连接，再计算Spearman来源级相关：

| 来源级相关的两变量 | rho |
|---|---:|
| T3 vs consumer/Dense RAFT幅值比 | −0.4241 |
| T3 vs **Dense原始RAFT幅值** | **+0.8586** |
| consumer/Dense RAFT幅值比 vs Dense原始RAFT幅值 | −0.6180 |
| T3 vs Imaging变化 | −0.1068 |
| T3 vs consumer原始RAFT幅值 | +0.5699 |

对 `rank(T3)` 与 `rank(consumer/Dense RAFT)` 分别回归去除 **Dense RAFT rank** 和 **主体/背景类别哑变量**，残差偏秩相关变为 **+0.0855**；20次逐一留一来源范围 **[−0.1376,+0.2904]**。仅控制Dense RAFT的偏秩相关也反转为 +0.2646。

在看见数据后提出的相关/置换结果均为**探索性**，不是预注册效应；20个开发来源还包含类别与prompt选择差异。关键是现有 `global latent SSE` 和 `temporal latent SSE` 不能再被拿来直接筛选“运动保持更好”的候选。其与视频运动幅值的观察联系主要承载了Dense本身运动幅度差异和ratio的分母效应。

这不妨碍设计下一步真正的方向性因果检验；但需要以**视频动作/运动、背景/光照、时间关系、感知与成本**为首要终端判据，并在source/seed全深度对应的同一候选上验证。

## 5. 与可见动作语义的交叉证据

同一20来源历史接触图记录（非盲、非人类完整播放）提供独立于RAFT分数的动作线索：

- `i2v_subject:23` 海豹游泳：Dense在帧30–53转正面并收拢鳍；UB1与consumer至末段保持偏侧面，consumer RAFT/Dense约**12.65%**，MUSIQ差**+0.572**。**更高画质分数没有恢复动作相位**。
- `i2v_subject:26` 飞鸟叼鱼：Dense帧0–45翅膀下拍再抬，consumer接近初始高举姿态，RAFT比约**6.88%**，MUSIQ差**+0.460**。
- `i2v_subject:24` 熊猫吃竹子：Dense帧9–35把竹竿从横向举到近竖向送入口，UB1/consumer保持相对水平，RAFT比**17.61%**。
- `i2v_background:35` 雪夜公交车：Dense公交车逐渐靠近镜头，consumer位置变化更小，RAFT比**1.97%**，Imaging差**−4.673**。

以上是**可指向具体帧段、物体及事件**的历史图像观察，而不是只用“并不等于”规避评价。后续要真正定量验证这些动作，需要对全部81帧做主体/相机ROI跟踪或明确人工逐帧事件审查，才能把动作相位/对象位移与模糊造成的光流失配分开。

## 6. 真实整段生成成本补算与偏差

20来源原始原生执行记录中，19/20组在被观测的generate墙钟上consumer较快。Dense平均**79.84 s**、consumer平均**60.25 s**，均值比`1.325×`。但**成对耗时差中位数仅5.44 s，而均值19.59 s**；三个极端差值含两项约102秒，去掉最大的3个，剩余17组均值仅**8.68 s**。这些原生运行的cold/warm、调度顺序、observer、保存、prefetch不平衡，**1.325×不能用于部署加速验收**。

因此已有实验可以证明真实执行过窄FFN并产生视频，且有可测耗时差，但要宣布方法有效必须新增平衡热态计时/原生Kernel检查，并且质量同时通过。画质和动作失败的UB1不能因观测速度数字被晋级为成功部署方法。

## 7. 下一次实验：直接让全深度干预回答视频因果

1. **必须配对的首轮完整生成**：预冻结至少20个不同image clusters（主体动作、背景、静态、camera各适用来源），相同prompt/seed、Dense及候选、同数值后端/四步全40层，优先覆盖每源首条而不是两个source多次测试；追加独立seed测波动。
2. **方法实现对象**：M-B应先形成能够作用于160个真实执行FFN位置的函数和价廉后缀响应，不再停留L39。结合当前签名，优先检验`step-wise signed error injection`的有限干预、重要层/时间窗口的方向控制与非线性QDQ/attention反馈；这些是**设计假说**，不预设哪项必成功。
3. **真正区分机制的对照**：在同一source/seed全160-site跟踪，固定一部分step/block区间改用Dense或候选，评估真实`z_{k+1}`、完整解码视频、动作ROI/事件、Imaging/I2V/时序和physical cost。适当采用factorial/分组混合干预，而不是为每个site生成160条视频。
4. **终端主判别**：按source报告与Dense的连续RAFT幅值、主体/相机位移与语义事件、视频背景稳定性/闪烁/小目标、VBench-I2V各适用轴、配对感知差，以及端到端真实wall。全局E/T、局部SSE和单末层q/σ仅用于事后解释干预作用。必要时按阶段冻结独立确认来源，遵循正式独立多seed采样。

**可交付资产（已生成）**：20行source对齐的逐来源质量/四步状态/成本/接触图注解JSON、预先写明复用条件的可复算脚本、相关性和混杂检验、该论文式方法判别文档。真实GPU/video任务仍按`research/ACTIVE_RESEARCH.json`登记；本轮未执行新模型作业或声称新方法视频质量通过。
