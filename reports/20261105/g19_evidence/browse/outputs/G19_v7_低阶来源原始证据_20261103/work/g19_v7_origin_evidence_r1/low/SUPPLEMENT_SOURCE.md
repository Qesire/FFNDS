G19v7 把 Wan2.2 FFN 压缩中的一个关键问题显露出来：在本次投影 Gaussian 参考输入下，完整二阶近似保留了大部分输出变化，当前共同正交表示却难以利用这一优势。要把这条线索转化为真实生成中的计算节省，需要解释低阶结构的来源，并找到适合表达它的计算形式。

**现阶段应保留 Gaussian 作为可解析、可复算的参照，把实际生成输入上的完整神经元函数作为比较基础。** GELU 本身已经能在 Gaussian 测度下产生很强的低阶集中；训练后的额外优势，要从读取方向、偏置、激活响应与写入方向的共同作用中寻找。G19 的结果因此把研究重点推向非正交一元函数和含交互的二次表示。

核对日期：2026年11月3日。

# 低阶结构与当前表示之间的距离

[G19v7 原始实验包](https://chatgpt.com/library?file_id=libfile_2c7299f55ddc8191adadd44d2ba73e82\&account_id=personal)提供了两组相互补充的证据。S12 描绘完整 FFN 在参考测度下的阶数结构和输入投影损失；S3 检验若干可压缩表示能恢复多少二阶信息。

S12 的 Oq 结果覆盖 80 个 expert×layer 单元，每单元使用 512 个 Gaussian 配对块：

| 指标 | 跨单元中位数 |
| - | -: |
| 完整二阶近似 MSE／原函数方差 | 1.724646% |
| 四阶近似 MSE／原函数方差 | 0.425381% |
| 所选 rank1024 输入投影的信息损失／原函数方差 | 32.088590% |
| 该投影的一阶谱尾／原函数方差 | 18.506473% |

完整二阶近似的误差很小，而所选 rank1024 投影丢失了约三分之一的输出信息。信息损失减去一阶谱尾，逐单元配对后的中位数为 14.427918 个百分点，说明这个输入子空间遗漏了大量非线性变化。

这两项结果并不矛盾。多项式次数描述函数怎样依赖输入；输入维数描述它依赖多少方向。一个满秩线性映射只有一阶，也可能需要全部输入方向。在该参考测度与已测单元中，低阶近似误差较小，紧凑表示仍需在方向及其交互上寻找结构；rank1024 的结果具体约束的是本次选定的投影。

S3 将问题进一步定位到表示形式。它覆盖 24 个 expert×layer 对，每对包含 Oq、Dq 两个 checkpoint arm，共 48 个评价单元，每单元使用 64 个 Gaussian 配对块。

这些共同正交候选均保留全输入仿射支路；512 和 5119 指二次平方特征的方向数。全部 5119 个平方特征覆盖该基底下的对角二次项，方向间的交叉项仍需另行表达：

| 候选表示 | MSE／原函数方差，中位数 |
| - | -: |
| 512 个共同正交方向 | 18.857831% |
| 全部 5119 个共同正交方向 | 18.844166% |
| 全维方向加 2559 条交互边 | 18.285943% |
| 完整二阶近似 | 1.670518% |

从 512 个方向增加到全部 5119 个方向，主乘加量由 31.457280M 增至 78.632960M，配对误差改善中位数只有 0.013874 个百分点，填补到完整二阶近似差距的比例仅为 0.082506%。增加同类方向的计算开销，几乎没有换来表达能力。

共同正交对角表示要求不同输出使用同一组平方特征，方向间的乘积需要由额外交互项表达。在相同 31.457280M 主乘加预算下，384 个方向加 256 条边，相对 512 个方向的点估计在 48/48 个单元上改善；配对改善中位数为 0.140659 个百分点，恢复的二阶差距比例为 0.816143%。交互项确有帮助，其当前覆盖范围仍然有限。这些比例均先逐单元计算再取中位数；48 个单元包含成对 checkpoint，反映的是这些局部评价上的一致性。

设计新的表示之前，还需分清：低阶集中中有多少来自激活与测度本身，又有多少来自训练后的权重耦合。

# GELU 与 Gaussian 如何形成低阶集中

Wan 使用的 tanh-GELU 具有一个直接的代数分解。按 [PyTorch 的定义](https://docs.pytorch.org/docs/2.15/generated/torch.nn.GELU.html)：

```math
\phi(z)=\frac z2\left[1+\tanh\!\left(\sqrt{\frac2\pi}(z+0.044715z^3)\right)\right]
=\frac z2+r(z),
\qquad r(-z)=r(z).
```

也就是说，GELU 包含一个精确的线性部分，剩余部分是偶函数；由此得到 φ(z)−φ(−z)=z。将它代入整个 FFN：

```math
F(u)=b_2+W_2\phi(W_1u+b_1)
=c_0+L_0u+R(u),
```

```math
c_0=b_2+\tfrac12W_2b_1,\qquad
L_0=\tfrac12W_2W_1,\qquad
R(u)=\sum_jv_jr(w_j^\top u+b_j).
```

这项恒等式对任意输入和固定权重成立。当第一层偏置 b1=0，且输入分布关于原点中心对称时，剩余函数关于输入为偶函数；Gaussian 情形下，这进一步限制了其 Hermite 阶数。以标准正态变量 Z 和正交 Hermite 多项式 hq 为例，φ(σZ) 的一阶系数为 σ/2，三阶及以上奇数阶系数全部为零。

标量求积显示，仅凭这一激活与 Gaussian 测度，就能产生接近 G19 的低阶误差。下表计算单个未经训练的函数 φ(σZ)，投影包含常数到指定阶数，分母为该函数的中心化方差：

| 预激活尺度 σ | 二阶残差／方差 | 四阶残差／方差 |
| - | -: | -: |
| 0.5 | 0.208144% | 0.005493% |
| 1 | 1.766356% | 0.270000% |
| 4 | 3.894911% | 1.692676% |
| 大尺度的 ReLU 极限 | 3.305779% | 1.360187% |

标准 Gaussian 下单个 GELU 的二阶残差为 1.766356%，与 G19 S12 的 1.724646% 处于同一量级。低阶集中因此有一个无需训练结构即可出现的解释。大尺度极限仍保持较小尾部，也说明这一现象不只依赖预激活集中在零附近。完整数值和复算方法见附录。

标量对照为整层分析提供了起点。对 Gaussian 输入，令 Zj 为第 j 个非退化预激活的标准化变量，ρij 为两个预激活的相关系数，ajq 为相应 GELU 响应的正交 Hermite 系数。利用 E[hq(Zi)hq(Zj)]=ρij^q，整层第 q≥1 阶能量为：

```math
\|F_q\|_{L^2(\gamma)}^2
=\sum_{i,j}(v_i^\top v_j)a_{iq}a_{jq}\rho_{ij}^{q}.
```

这个公式把完整权重连接起来：W1 与输入协方差决定读取方向之间的相关性，偏置和尺度决定激活系数，W2 决定各响应向哪些输出方向写入。交叉项可以抵消，也可以加强。因此，要判断训练形成了多少额外的可压缩结构，应在实际尺度与偏置匹配后，分析这些联合项；单个标准 GELU 的数字只负责揭示基础机制。

通道抵消还会改变压缩操作的含义。例如：

```math
v\phi(w^\top u+b)-v\phi(-w^\top u-b)=v(w^\top u+b).
```

两个非线性通道合起来恰好是仿射函数。合并它们可以利用这个结构，单独删除其中一个则会破坏原来的抵消关系。由此可见，原通道选择与函数重表示应分别评价：前者在既有原子中选择，后者可以重新组织共同承担的计算。

# 真实输入需要保留哪些统计结构

Gaussian 的价值在于它让上述阶数分解、条件投影和交叉项具有清晰的解析形式。要把这些结论用于生成过程，需要检验真实输入是否保留了候选表示所依赖的统计关系。

## 从归一化到条件调制

扩散模型的 Gaussian 加噪变量，与深层 FFN 接收的隐藏状态处在不同计算位置。[DDPM](https://arxiv.org/html/2006.11239v2) 给出的条件加噪分布，经过样本混合以及网络中的非线性、注意力和残差后，需要重新描述其统计。

[LayerNorm](https://arxiv.org/html/1607.06450v1) 约束了单个 token 的通道均值与长度。忽略 epsilon 和附加仿射参数，其形式为：

```math
\Pi=I-\frac1d\mathbf1\mathbf1^\top,\qquad
y=\sqrt d\,\frac{\Pi x}{\|\Pi x\|}.
```

这个变换把样本放到均值为零的球面上，方向分布仍由输入决定。例如，样本只取一个归一化向量及其相反数，归一化后仍然只有两个点。高维均匀球面的低维投影近似 Gaussian，依赖的正是均匀方向或旋转对称性；[Diaconis–Freedman 的结果](https://www.numdam.org/item/AIHPB_1987__23_S2_397_0.pdf)为合成球面参照提供依据，也指出了真实隐藏状态需要检验的角向条件。

Wan2.2 还会在 norm2 之后施加逐通道缩放和平移，并在 FFN 输出进入残差流时施加 gate：

```math
u=(1+s_c)\odot\operatorname{LN}(x)+\beta_c,
\qquad
\Delta x=g_c\odot F(u).
```

[官方实现](https://github.com/Wan-Video/Wan2.2/blob/main/wan/modules/model.py)说明，应当研究按 expert、layer、timestep 和生成条件组织的输入。固定调制条件、记 D=diag(1+s) 时，输入均值为 D E[y]+β，协方差为 D Cov(y)Dᵀ；gate 再对输出扰动赋予方向权重。这些变化会同时影响神经元预激活的尺度、偏置与相关性。

## 文献把关注点指向时间和通道结构

[ViDiT-Q](https://arxiv.org/html/2406.02540v3) 在线性层输入通道平衡分析中展示了 MLP fc1.A 随时间变化的通道结构，并将调制与这种变化联系起来。[Q-DiT](https://arxiv.org/html/2406.17343v2) 和 [PTQ4DiT](https://arxiv.org/html/2405.16005v3) 也报告了跨通道、层和去噪时间的统计差异。这些结果支持条件化采样与分析。

与目标模型更直接相关的 [Wan2.2 W4A4 研究](https://arxiv.org/html/2605.27003v1)，展示了 blocks.20.ffn.2 处的幅度统计。它记录的是该模块位置的时变通道结构；本研究需要的 pre-W1 输入则应在调制后、第一层线性映射前直接采集。

这些观察允许一种有用的中间模型：按条件匹配均值与协方差的 Gaussian。不同条件下的 Gaussian 本来就可以具有不同幅度和显著通道，因此时变统计与离群现象不能单独判定它是否失效。真正需要检验的是：条件化以后，候选函数的响应和选择是否能从参照分布迁移到真实输入。

## 用函数响应建立分布之间的联系

对当前通道选择任务，完整神经元函数是更直接的比较对象：

```math
h_j(u)=\phi(w_j^\top u+b_j),\qquad
\psi_j(u)=v_jh_j(u),\qquad
K_{\mu,ij}=\mathbb E_\mu[\psi_i^\top\psi_j].
```

Kμ 是实际输入测度下的函数 Gram。对固定删除掩码 d，删除误差为：

```math
R_\mu(d)=d^\top K_\mu d.
```

因此，两个输入分布即使形状不同，只要给出相同的 K，就会给出所有这类固定掩码相同的局部平方误差。坐标直方图是否近似正态，可以作为统计描述；候选风险与排序是否保持，直接决定 Gaussian 参照能否帮助选择。

允许动作集合 D 上的差异可以写成：

```math
\Delta_{\mathcal D}(\mu,\gamma)
=\sup_{d\in\mathcal D}\left|d^\top(K_\mu-K_\gamma)d\right|.
```

对有限候选库，若每个候选的真实风险与 Gaussian 风险差异均不超过 δ，则按 Gaussian 风险选出的最优候选，其真实风险至多比该库真实最优值高 2δ。这给出了可检验的迁移目标，无需先完成全维密度拟合。这里的风险是指定的局部损失，完整生成行为由后续视频评价检验。

评价残差更新时，样本相关的 gate 应并入函数原子；采用动态掩码时，则把 d(u) 保留在期望内部。这样，公式中的对象与实际执行的动作一致。

二次表示对统计的要求更高。两个二次函数的内积依赖四阶矩，二次项与线性项的相关性还依赖三阶矩。匹配均值和协方差以后，可以继续估计候选特征的 Gram，检查剩余差异；无需存储完整四阶张量。

[DSRAR](https://arxiv.org/html/1804.08609v4) 与 [dependent PCE](https://arxiv.org/html/1903.09682v1) 提供了针对相互依赖输入建立经验内积与多项式基底的方法。在有限特征字典上，这些工具有助于适配测度、选择系数并改善数值稳定性。同一函数空间内的换基保持其最佳逼近误差，真正的表达收益仍来自更合适的方向、交互或函数类。

# 把联合结构转成可执行的表示

函数空间描述了哪些响应可以相互替代，执行结构决定了替代后是否真的少算。研究应把两者连起来：每个候选既有明确的函数类，也有对应的点积、激活和写回操作。

## 从完整 GELU 通道建立基线

以 ψj 为原子，保留了 W1、偏置、激活和 W2 的共同作用。纯删除对应选择支持集 S；若允许保留通道再乘一个标量，固定 S 后的总体最优系数为：

```math
\alpha_S^*=K_{SS}^{\dagger}K_{S,:}\mathbf1.
```

这些系数可折叠进 W2。对 64 通道整块，可以把组内函数和作为原子。纯删除、标量重配、自由重拟合输出矩阵，对应逐步扩大的函数类，分别报告即可看清收益来自哪里。

[HOPE](https://arxiv.org/abs/2607.21366v1) 为完整神经元提供了 Hilbert 函数视角；它的 Gaussian 代理来自 BN 统计，部分缩放推导使用正一阶齐次激活。在 Wan 中，可借用完整神经元的函数视角，以 GELU 和 AdaLN 的实际响应重建内积，再判断相应的选择、合并和缩放规则是否成立。

[Model Preserving Compression for Neural Networks](https://papers.nips.cc/paper_files/paper/2022/file/f8928b073ccbec15d35f2a9d39430bfd-Paper-Conference.pdf) 则把可执行性问题说得很清楚：激活 SVD 的低秩方向通常是许多原神经元的线性组合，求出这个组合仍可能需要原有计算。论文采用实际激活列的插值分解保持网络结构。对当前任务，原通道或通道组选择因此是一条有明确实现含义的比较基线。

## 让读取方向与一元响应共同调整

更灵活的候选是：

```math
\widehat F(u)=c+Au+\sum_{r=1}^{R}v_r\,g_r(a_r^\top u+\beta_r).
```

方向 ar 可以非正交，一元函数 gr 可以取原 GELU，也可以用可学习 B-spline。A 是单独计入架构与成本的可选仿射项。这一形式允许用较少分支重新组织原通道共同承担的响应。

原函数的 Jacobian 展示了相应结构：

```math
J_F(u)
=W_2\operatorname{diag}(\phi'(W_1u+b_1))W_1
=\sum_jv_jw_j^\top\phi'(w_j^\top u+b_j).
```

函数值约束候选在已观察输入上的输出，方向导数约束附近状态变化时的响应。两者联合拟合，有机会区分只在若干采样点上接近的候选。Wan 尺度可用 JVP、VJP 或邻近状态差分提供这些信息，避免显式存储完整 Jacobian。

2026 年的 [Robust Basis Spline Decoupling for the Compression of Transformer Models](https://arxiv.org/html/2605.18794v1) 研究了函数值与 Jacobian 的联合分解及 FFN 替换。其主要 ViT/Swin 实验使用 embedding 64、FFN 256 的模型、真实训练样本，并在整网逐步替换时每步微调 5 epochs。这一证据支持把它作为函数重表示的先例；Wan 上的质量与执行收益，需要在对应规模和预算下评价。

## 为二次结构保留交互项

若真实输入继续支持低阶近似，可以采用非正交平方、双线性或共享投影的小块表示。例如，对中心化输入 ξ：

```math
\widehat F_2(\xi)
=\sum_{r=1}^{R}c_r
\left[(a_r^\top\xi)(b_r^\top\xi)-a_r^\top\Sigma b_r\right].
```

平方是 a=b 的特例，双线性项直接表达两个方向的交互。中心化消除了均值；真实测度中的线性相关可通过进一步残差化处理。

函数 (x²−y², 2xy) 是一个直观例子：它无法由同一个实正交方向族同时对角化，却可由一个二维块，或 x²、y²、(x+y)² 三个平方特征精确表示。共同正交表示的限制因此有明确的结构原因，也存在可比较的替代形式。

[Fang 等的共同合同块对角化研究](https://arxiv.org/html/2503.01166v2) 与 [Cai–Liu 的非正交共同块算法](https://arxiv.org/abs/1607.00716) 提供了研究整个输出切片族的工具。共同块需要由这一族矩阵的联合结构识别；非正交变换还需控制条件数，并在原坐标与实际测度上评价误差。单个矩阵对的谱现象只提供局部线索。

G19 的完整 Gaussian 二阶分量本来就能由原 W1 方向的非正交平方原子表达。这里的目标是进一步减少原子数量、共享投影或整理交互，使这些结构形成更经济的计算。

## 用实际计算形式约束候选

| 计算形式 | 主要 MAC 每 token |
| - | - |
| 原 FFN | 2dm |
| k 个原 GELU 通道 | 2dk |
| 全维仿射加 k 个一元分支 | d²+2dk，另计一元函数求值 |
| 全维仿射加 R 个独立双线性分支 | d²+3dR |

对 d=5120、m=13824，原 FFN 为 141.557760M MAC。若把 GELU 的线性项物化为全维矩阵，同时保留所有残差通道，成本变成 167.772160M，新增的稠密支路额外付出了 d² 次乘加。若残差确实压缩到 k=512，则相应候选为 31.457280M。是否采用仿射支路，应连同一元函数开销、内存和实际时延一起比较。

由此形成三类有意义的同预算对照：原 GELU 通道或通道组、非正交一元函数、含交互的二次表示。它们分别检验既有原子的可选择性、响应函数的可重组性，以及低阶交互的可压缩性。

# 让分布适配与表示选择各自接受检验

首先固定候选函数类，再改变系数拟合所用的分布。特征方向、支持集、允许的输出系数、checkpoint、数值路径和执行结构均保持一致，保留 Gaussian 系数 Bγ，并用真实校准来源拟合同一函数类的 Bμ：

| 系数来源 | 独立 Gaussian 测试 | 留出真实来源测试 |
| - | - | - |
| Gaussian 系数 Bγ | Rγ(Bγ) | Rμ(Bγ) |
| 真实校准系数 Bμ | Rγ(Bμ) | Rμ(Bμ) |

四格报告绝对 MSE；同一测试分布列中的候选使用共同分母，跨分布另给共同分母的归一化结果。这样，函数方差变化和候选误差变化可以分开解释。方向重选、增加交互边、放宽输出系数或改变激活，进入下一组函数类比较。

对闭线性函数空间，总体最优投影给出：

```math
R_\mu(B_\gamma)
=
R_\mu(B_\mu^*)
+
\mathbb E_\mu
\|\Psi(U)(B_\gamma-B_\mu^*)\|^2.
```

右侧第一项是固定函数空间的最佳逼近误差，第二项是沿用 Gaussian 系数的额外损失。有限样本拟合还包含估计、正则化和数值求解误差；留出来源上的稳定改善及其不确定性，可以用来估计系数适配带来的收益。

实际采集应放在调制后的 pre-W1 位置，并保留 gate 与条件信息。按 expert、layer、timestep 分层观察预激活尺度、有效偏置、GELU 工作区间及选定通道对的响应。校准、选择和确认按输入图像或 prompt 来源分组，使相关 token 与轨迹留在同一数据划分内。

参照输入可以逐步接近这一对象：原投影 Gaussian、归一化 Gaussian 球面、施加真实调制的球面、匹配均值协方差的条件 Gaussian，最后是留出真实输入。前几项分别检验半径、调制和二阶统计的影响；真实输入检验剩余高阶依赖与实际条件覆盖。分布比较的第一阶段沿用 v7 数值函数，原生 BF16 或 FP4 作为另一个数值因素评价。

## 让结果决定下一步表示

若条件化后候选风险与排序恢复，Gaussian 工具便可在相应条件下继续使用；若同一字典的真实系数显著改善留出误差，优先修正测度和系数；若校准拟合良好而留出来源退化，则应扩大条件覆盖并检查泛化。

稳定拟合后仍有较大误差，才进一步扩大候选字典。这里需要保留一个数学区别：G19 的 F≤2=F₀+F₁+F₂，在理想精确积分下是 Gaussian 全二次空间中的投影，其二阶部分恰好可由原 ridge 方向的中心化平方原子表示。换成真实测度后，最佳二次部分未必仍在这个有限字典中。固定特征重拟合失败，首先约束的是这个字典。

对 n=5119 维输入子空间，次数不超过二的标量多项式空间共有 13,109,760 维。实际研究只能选择有结构的子空间；比较非正交原子、双线性项和小块表示，正是为了确定哪些结构能以较小成本接近目标。

完整生成决定这些局部结构是否有用。候选先在原模型轨迹上诊断，再沿自己的生成轨迹评价，观察文本与动作关系、主体与背景、时序和光照稳定性、运动及相机行为。局部误差承担解释与筛选作用，视频行为检验整条生成过程。

当前优先推进实际测度上的原 GELU 通道或通道组基线，并以非正交一元函数作为主要重表示候选；真实输入若继续呈现良好的二阶可近似性，再比较含交互的二次结构。这个顺序既能利用 G19 已发现的结构，也能逐步识别训练后的联合权重究竟提供了多少可转化为计算节省的优势。

# 附录 实验口径与文献证据

S12 的 Oq 包含 80 个 expert×layer 单元，每单元 512 个 Gaussian 配对块；S3 包含 24 对 expert×layer、每对两个 checkpoint arm，每单元 64 个配对块。两组统计的覆盖范围不同。配对改善、相对改善和填补差距比例均先逐单元计算，再汇总中位数。

v7 的 Oq 数值路径为：原参数先按 BF16 舍入，再上转 FP32 前向。它刻画这个固定数值函数；原生 BF16 与 FP4 的执行误差需作为独立因素比较。GELU 恒等式对应实数函数，浮点运算重排与动态激活量化另有数值影响。

S3 的仿射残差方差／原函数方差中位数为 18.861382%。它使用方差口径；只有近似均值恰好等于被评价函数的参考均值时，才等于相应仿射替代器的直接 MSE。正文的候选表采用直接 MSE，保留了这一区别。

相同预算下，384 个方向加 256 条边相对 512 个方向，配对改善中位数为 0.140659 个百分点，相对候选误差下降中位数为 0.734078%，填补到完整二阶近似差距的比例中位数为 0.816143%。

checkpoint 差分还揭示了坐标选择的影响。对全维加边候选，分别拟合几何与使用共享几何时，二阶差分近似误差／目标二阶差分能量的中位数分别为 57.702217 和 0.908488；共享几何后仍有约 90.85% 的二阶差分能量落在误差中。若改用完整 FFN 差分能量作分母，两个值变为 0.906613 和 0.014685。

共享几何减少了大背景表示变化对小差分的污染，分母则决定了剩余误差的含义。Gaussian 下 checkpoint 差异中的均值占比，可用来描述参考函数的变化；固定 bias 补偿在实际生成中的效果，还取决于真实条件下的差分结构。

文献中的统计按采样位置解释。ViDiT-Q 的 fc1.A 图未独立注明 hook 定义或面板模型，提供的是调制与时变通道结构的线索；[SVDQuant](https://arxiv.org/html/2411.05007v3) 命题 4.2 的 Gaussian 特例用于残差权重 R。它们分别支持相应计算位置的分析，真实 pre-W1 输入的分布由该位置的样本检验。

# 附录 投影关系与标量复算

## 最佳仿射项怎样随测度改变

设 m=Eμ[U]、Σ=Covμ(U)。由 F=c₀+L₀U+R，实际测度下的最佳仿射投影可写为：

```math
P_{\mathrm{aff},\mu}F(u)
=
c_0+L_0u+\mathbb E_\mu R
+\operatorname{Cov}_\mu(R,U)\Sigma^\dagger(u-m),
\quad \mu\text{-a.s.}
```

当输入关于原点中心对称且 b1=0 时，R 关于输入为偶函数，与线性项的相关性消失，最佳斜率为 L₀；最佳截距仍包含 E[R]。输入关于 m 对称时，应检查有效偏置 b+wᵀm。非零有效偏置与分布不对称，都可能产生额外线性相关。

Gaussian 分部积分给出另一种表达：

```math
P_{\mathrm{aff},\gamma}F(u)
=
\mathbb E_\gamma F+
W_2\operatorname{diag}\!\left(
\mathbb E_\gamma\phi'(w_j^\top U+b_j)
\right)W_1(u-m).
```

因此，GELU 恒等式给出由激活固定的线性部分，正交投影再吸收剩余函数中与输入相关的部分。这个关系明确了代数分解、偏置和参考测度各自承担的作用。

## 二次内积与条件信息

对中心化输入 ξ、协方差 Σ 和对称矩阵 M，定义 qM(ξ)=ξᵀMξ−tr(MΣ)。四阶矩存在时：

```math
\mathbb E[q_Mq_N]
=
2\operatorname{tr}(M\Sigma N\Sigma)
+\sum_{a,b,c,d}\kappa_{abcd}M_{ab}N_{cd},
```

其中 κ 为四阶累积量。Gaussian 的 κ 为零；实际输入中的这一项改变二次特征的内积。三阶矩则影响二次项与线性项的相关性。

Gaussian pick-freeze 依赖保留坐标与正交补之间的独立性。真实输入白化后只消除了二阶相关，非线性依赖仍可能存在，因此条件信息损失应通过实际联合分布定义。记 mμ(T)=Eμ[F(U)∣T(U)]，则对 Gaussian 条件表示 mγ：

```math
\mathbb E_\mu\|F-m_\gamma(T)\|^2
=
\mathbb E_\mu\|F-m_\mu(T)\|^2
+
\mathbb E_\mu\|m_\mu(T)-m_\gamma(T)\|^2.
```

第一项是真实信息损失，第二项是条件均值失配。任何固定回归器的总体风险都不低于第一项；有限测试误差是总体风险的估计。回归效果较差时，需要结合拟合能力、估计误差和抽样波动判断统计量本身的充分性。

## Gaussian 与球面参照

G19 的投影 Gaussian 和由 Gaussian 归一化得到的均匀球面参照为：

```math
U_G=\sqrt{\frac d{d-1}}\Pi Z,\qquad
U_S=\sqrt d\,\frac{\Pi Z}{\|\Pi Z\|},
\qquad Z\sim N(0,I).
```

d=5120 时，Gaussian 半径的相对标准差渐近约为 0.99%。这一计算量化了两个合成参照的径向差别；真实激活的方向分布由实际输入检验。

## GELU 求积与解析极限

使用标准正态密度和正交 Hermite 多项式 hq=Heq/√q!，计算 aq=E[φ(σZ+b)hq(Z)]。残差同时通过直接误差积分，以及方差减去一至 q 阶系数平方和求得。

```math
h_0=1,\quad h_1=z,\quad h_2=\frac{z^2-1}{\sqrt2},\quad
h_3=\frac{z^3-3z}{\sqrt6},\quad
h_4=\frac{z^4-6z^2+3}{\sqrt{24}}.
```
