# Native FFN：条件投影、经验多项式与真实轨迹割线的文献审计

2026-11-03；只读文献及已存代码/回执审计，未重跑模型、未提交作业。问题是辨别真实分布上的 FFN 性质与潜在可执行表示；以下为数学对象及建议检验，并非发现结果、全局新颖性证明或质量/速度证明。

## 对象及既有数据约束

固定 expert e、layer l，连续 lift 对象写为 F(z)=W2 φ(W1z+b1)+b2，d=5120、m=13824；原生目标则是含实际 BF16 运算与多次舍入的程序输出。已存 z 是 AdaLN 后、W1 前；w2_output_before_gate 是 W2 输出且含 b2、尚未施 gate。gate/shift/scale、step、source、坐标和权重身份也已存。native_tap.py 表明每个 source/step 有 2048 个均匀 token，随机种子包含 step，因此不同 step 的数组**不是自然配对**；16 个固定空间位置×21 时间坐标的 tubelet 在同 source 各 step 相同，能按坐标配对。采样有时空聚集，源是统计簇；10 源不能当作大量独立视频，也不能把已有用途标记升格为真正新盲确认。

## 1. 条件期望投影：可见信息到底够不够？

对 Y=F(Z)、可在线获得的 C（如 step、expert、预先固定坐标信息）和 U=Pᵀ(Z−μ)；若 Y∈L²，所有基于(U,C)的平方损失最优预测器为 E[Y|U,C]。对任一候选 g：

E||Y−g(U,C)||² = E||Y−E[Y|U,C]||² + E||E[Y|U,C]−g(U,C)||²。

对嵌套观测 U⊂(U,V)，同理可将风险改进精确分成两个正交增量；这是 Hilbert 投影，不需要 U、V 独立。真正的问题是：在相同测量成本下，线性 g、多项式 g 和更灵活的受限回归之间的源外损失差距如何；同一P下若灵活类好、多项式差，说明值得找非多项式结构；若各种实用类都差，仅说明已试类与当前信息不够。**拟合器的 heldout 风险是其自身可实现风险，不是总体条件风险的下界或证书。** 更强的有限样本反例：在有限经验分布中，只要一维投影U对每个训练样本取值互不相同，就可查表使 E_emp[Y|U]=Y，经验条件残差严格为零，完全不能证明总体上一维足够；必须使用独立源外数据和受约束的可执行预测类。 维度与样本分离后稳定降低才有意义；严格下界需额外方法/假设。

条件表达不等于任意坐标组的正交 Sobol-ANOVA。现实 z 的组强依赖，直接拼接/交换边缘样本可能离开支持集；广义 Hoeffding 分解需要分布条件，通常只有层次正交且有交叉协方差。反例 Z2=Z1，Y=Z1²：两个特征组携带相同信息，若各自效果相加即双计；条件分布甚至可能退化，使常见密度下界不成立。来源 S 的条件解释应视为观察性：新源ID无训练参数可查，源专属调整需计入测试源可获得的warm-up及其代价；不得用目标源未来信息建基。应用验证按 source/整段划分、报告跨seed/层/专家误差分布；归一化按固定目标分母，不能以token数充独立样本。 另行报告已存 gate 权重后的局部误差 E||gate⊙(Y−Yhat)||²；已核实际 post_process 以 gate 乘 W2 输出再加残差。原生运算还有舍入，gated 局部误差仍不等于整段视频质量。

基础：[Gamboa 等，Hilbert 值输出与敏感性](https://arxiv.org/abs/1311.1797)；[Chastaing 等，依赖变量广义 Hoeffding 分解与条件](https://arxiv.org/abs/1112.1788)；[输入依赖下的交叉项说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC9292458/)。以上是数学与UQ基础，不是现成可执行加速器。

## 2. 经验多项式 + 输出算子：表示在真分布上是否可实现？

只在开发源拟合 μ、固定 P∈R^{d×k}，构造测度自适应 feature Ψ(U)=(1,U_i,U_iU_j)，对训练设计矩阵用稳定 QR/SVD 做有秩截断的经验正交化；建立多输出映射 Y≈BΨ(U)。训练正交只对经验测度成立，截断和正则化会改变投影；heldout源应重新报告完整输出误差及分位数，不得把经验正交解释成总体 Hermite 正交。可比较固定 Gaussian H1、源外线性映射、真分布 PCE，以及相同预算时的方向性基、学习型非多项式与 TARDIS 风格局部折叠。整个拟合/筛选/秩选择按源分离；不要从 heldout 检查后重新选基。

算术示例 k=32：二次基含截距 1+32+32×33/2=561 项，P 与 B 的矩阵乘主成本 (32+561)×5120≈3.04M MAC/token，BF16 参数约6.07 MB；现有 FFN 两主乘约2×5120×13824=141.56M MAC/token。这**不是实际加速结论**：还须 Ψ 构造、标定与读写、融合、偏置、gate、数值精度、实际矩阵大小与端到端生成，并检查 P/B 是否能跨源/step复用。当前单源单step只有2048行，k=64二次已2145 feature，训练设计必秩亏；即使跨源堆更多token，也不能用 token 数声称独立样本。输出仅在有限样本span低秩并不能推断总体算子低秩；常数预测、输入rank与输出rank、Gaussian H1要同预算比较。

[Liu–Choe, data-driven sparse PCE](https://arxiv.org/abs/2101.07997) 已用输出相关性、经验正交构造应对依赖输入；[Qian–Farcas–Willcox, reduced operator inference](https://arxiv.org/abs/2102.00083) 用投影、低维多项式算子与正则化，研究动态 PDE，不等同本静态 FFN 问题。新问题只能是：固定可执行预算、真实多源视频条件下，该 FFN **完整向量**是否存在跨源稳定的可复用算子，既优于输入加权低秩也优于已知 FFN 折叠；不能称“用PCE/残差建模”本身为新方法。

## 3. 真实轨迹平均 Jacobian / 分差：变化从何而来，能否少存状态？

同 expert 且连续 lift 下，a=W1z+b1、δ=W1(z′−z)，定义 s_i=(φ(a_i+δ_i)−φ(a_i))/δ_i（δ_i=0取 φ′(a_i)），则

F(z′)−F(z)=W2 diag(s) W1(z′−z)=∫₀¹ J_F(z+t(z′−z))(z′−z)dt。

这是标量分差与平均Jacobian的精确恒等式，不依赖小步近似；但真实输出是 BF16 程序，包含 matmul、activation、W2 与 bias 的舍入，因此应先测连续重算与 native ΔY 的差，不能把恒等式宣称机器精确。对于 step0→1（high）及 step2→3（low），对同坐标 tubelet 或严格索引交集求配对；计算可解释变化是否有少数可复用斜率模式、输出加权后的互相抵消、以及跨源稳定性。step1→2改变专家：

F_low(z2)−F_high(z1) = [F_low(z2)−F_low(z1)] + [F_low(z1)−F_high(z1)]，

其中反事实 F_low(z1) 未直接由对应原生步给出，必须用权重另算；不能把不同expert的差归为输入secant。已有 z、原生Y、同source tubelet足以观测真实Δz/ΔY；若要每神经元斜率及连续/舍入分离，必须读取对应权重并重算 W1、激活及W2，不能只从聚合Gram还原。

精确计算斜率本身仍需昂贵乘法；只有找到可低成本求得且跨源泛化的 s 压缩描述，才可考察 W2 diag(s)W1 的可执行表示。若用 K 个已折叠 d×d 矩阵，其主成本 Kd²、内存 Kd²×每元素字节；d²≈26.21M MAC，5个已接近原始两矩阵主成本，且在线选择α、状态搬运、缓存、gate也要计入。斜率变化幅度小却方向不稳、输出向量相互抵消、复用需大 H/Y cache 均是反例，必须与 dense、TARDIS、实际 Chipmunk 给出同硬件/同质量口径比较。[Gosea–Güttel 2021](https://epubs.siam.org/doi/10.1137/20M1324727) 比较矩阵值有理逼近及块 Loewner，并指出插值对噪声可敏感；[2022 quadratic-bilinear identification](https://doi.org/10.1016/j.ifacol.2022.09.064) 用多变量传递函数与状态空间拟合。上述 scalar 分差恒等式**不自动构成 Loewner pencil、动态系统辨识或稳定性结果**；把名称换成 Loewner 不产生新方法。

## 最相近 AI 工作及能否称新

[Chipmunk 2025](https://arxiv.org/abs/2506.03275) 已明确缓存 MLP 激活和输出，按 token 区块选变化神经元做稀疏增量，并提供专用GPU核；本工作已经重做的 packed P64 并非其原生CUDA。只说“跨步稀疏残差/缓存”高度重合。[TARDIS 2025](https://arxiv.org/abs/2501.10054) 已对每神经元常见区间做仿射拟合、折叠矩阵和outlier fallback；只说“真实激活上将FFN部分线性化”高度重合。[FastCache](https://arxiv.org/abs/2505.20353) 已研究跨步隐藏状态线性近似与缓存交互解释；只说“将变化分解成可预测线性分量”不够。[FLAT-LLM](https://arxiv.org/abs/2505.23966) 已按激活空间构造细粒度低秩变换；只说“按真实激活选低秩”也不够。以上均是最相近对手而非排他目录；跨架构、基准与精度不同，不能以论文报告数字代替本机比较。

真正待证的区别是：跨不同视频源、位置、step及expert，**平均Jacobians/可见特征的整体输出风险、分差漂移和缓存带宽是否共同受限于同一可复用的便宜对象**；如果没有，结果本身是有价值反证。当前样本属于探索/规划性质，无足够独立源支持广泛显著性；域外材料、冻结测试、真实精度与端到端质量/时间仍缺。检索于2026-11-03，优先查原论文与本地代码，未声称文献穷尽或全球原创。
