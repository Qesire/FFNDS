# 输入关系分析包：数据、代码与后续设计审阅

## 结论

包适合作为对既有 G19 数据的探索性再分析，不提供新的独立确认、在线路由效果或 GPU/视频性能证据。其结果中最有价值的线索是：同层跨来源的输入变化幅度与求积误差相关；低专家存在幅度相近但误差差别大的反例；隐藏坐标的割线斜率具有稳定层均值，同时存在大量坐标内部差异。后者尚不能区分静态通道差异和真正的输入依赖。报告基本披露了这些边界；“预测新来源”应理解为本次回归未拟合的既有来源，而不是从未观察的新盲样本。

## 来源与代码核验

独立以 SHA-256 核对 provenance 中全部 166 项：包内每项与登记一致，且与本工作区对应的原始 secant、odd、operator 证据及代码逐字节一致，166/166，无缺项或不匹配。secant `PAIR_ROWS.csv` 为 f14e69df82baf3a4f8b8e3884b8a8100c370e824782d652efc3e82004c545639。此检查建立本地副本身份，不独立重做原 GPU 计算，也不能仅据包内 `verification.json`、`cross_audit.json` 的 PASS 声称已重新执行其所有验证。

审阅 operator/analyze_operator_inputs.py、odd/analyze_secant_moments.py、secant/analyze_input_relations.py 和尾部分析脚本：主体使用已存标量，未执行外来脚本。后者将两表按 arm/expert/panel/source/layer 一对一合并、检查 3200 行与匹配数量；数量相同并不单独证明两次面板 token ID 完全相同，强配对还依赖上游冻结采样与原账本验证。ridge 是 CAL 内层中心化、CAL 特征缩放、每层不惩罚截距、标准化斜率统一 λ=1 的 log-log 线性拟合；变换与声明相符。指数还原是 log 标度点预测，未经残差修正不能直接当条件均值；log-MSE 改进不是原风险下降。使用 40 个层截距意味着必须已对该模型层有 CAL 数据，不能推断对新层或新模型外推。

CAL={02,04,07,09}、DEV={00,01}、HELD={03,05,06,08} 相互不交。报告承认 HELD 曾被其他分析查看，不能称独立盲确认；“事前固定”的可靠含义是本次脚本所写规则，缺少可核实先于所有相关结果观察的预注册。operator 原模型的 DEV 用于 ridge 候选选择；本次 secant 预测脚本不以 DEV/HELD 选择其斜率和 λ，两个阶段不能混为同一种无调参协议。160 个 layer×step 不是 160 个独立来源，十来源中的 token 和重复层也不可作为独立视频；给出每来源结果但没有可信独立总体置信区间是恰当的。

径向四阶矩从 CAL 白化特征 trace 的代数恢复在所述 1/n 白化与特征规范下成立；同样本白化、有限相关样本和 λ 随 trace 调整，使 Gaussian 参照、关联和正则效应不能解释为重尾检验或因果结论。PCA 方差比例的跨层相关不证明特征向量对齐或可共享的子空间。odd 的 Δa² 加权矩和 Cauchy 下界是能量权重，不是神经元数量；per-source-layer 内方差混合通道与 token 变化，不能证明需要动态路由。

low/layer16 来源08与06是看过极端结果后选出的对照；uniform 的巨大差异是可靠的具体诊断，但不估计总体尾部发生率，tubelet 排序变化还说明面板敏感。两者幅度接近不代表输入相同或方向相同，W2 增益变化也不表明 W2 参数变化。多个特征、目标和面板都经过观察，应防止只报告最显著关联。

## 可执行的后续研究设计（建议，未运行）

1. 先固定目标、源群和采样，再获取未用于此前探索的新来源，按图像簇分组设置训练、调参和最终盲测；不让多个层或 token 进入不同来源分割。明确来源为统计单位，逐来源报告风险与失效；使用来源簇重采样/层次模型时承认样本量不足，预注册主要终点与多重比较。当前资料只能做假设生成。
2. 先检验静态通道与输入动态的分界：按 source/expert/layer 和同一 token ID 的两个端点，在 CAL 流式积累每通道 A=ΣΔa²、B=ΣΔaΔφ、C=ΣΔφ²；固定 α=B/A 并对零 A 明确不可识别，在未见来源直接算隐藏 SSE，和共享标量、每对 oracle、静态通道模型对照。该三个量能精确评估隐藏空间，但不能恢复 W2 或 gate 的交叉通道二次型；必须在验证阶段直接使用隐藏残差向量乘冻结 W2，再按固定的相应 gate 度量累计输出 SSE。记录 native BF16 对平滑 F64 的偏差，不把 F64 身份当数值证书。
3. 对源08/06 提出的疑问，预先固定极端选择与不同面板的采样，测每来源中点、增量的符号、联合分位、跨零率和高阶尾，结合 Δa² 权重；采用统一冻结 CAL PCA 基/中心/尺度，测新来源投影和方向，不在每个测试来源重新白化。比较每源、每层误差与分母，做同层/来源控制，区分输入前可用的 Δz 特征与需先算 W1 才得到的 Δa、a_mid；后者不是免费在线元信息。
4. 如要声称可执行表示，固定成本模型并与共享层矩阵、静态逐通道折叠、已有缓存方法公平比较。必须计算真实 40 层矩阵内存、旧状态缓存、数据搬运、预测器开销和端到端质量；当前标量预测收益不等于误差下降或加速。独立新来源、多 seed 和 native 计算验证在新方案批准后另行进行。

所需原始资产为冻结权重 W1/W2/bias、原始预激活或可重算的真实端点 z0/z1、gate、配对 token IDs 与 source/step/layer 标识、native BF16 输出及浮点参考、原模型/权重身份。此包不含这些大数组；仅凭汇总不能恢复逐通道 A/B/C、方向耦合、实际输出误差向量或低成本路由性能。
