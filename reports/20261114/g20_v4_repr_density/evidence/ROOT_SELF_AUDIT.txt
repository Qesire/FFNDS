====================================================================
Primary: for source c, expert e, M(c,e,m) = equal-mean over predetermined layers
{4,19,34} of gatedSSE/(actual_rows*5120); r(c,e,m)=(M_m-M_CURRENT_Q1)/M_CURRENT_Q1;

Scoring = F64 gated PRE-GATE INCREMENT math lift: SSE = sum(((pred - Y) odot g)^2),
Y = y_hit - y_anchor (true dense pre-gate increment), g = hit-step per-channel gate
(c_gate_msa, shape (5120,)). This is the math lift, NOT the BF16 cache/gate replay;
the BF16 replay path is a SEPARATE V4D acceptance check (route 4.3 "实际BF16/缓存路径
另外验收"). Six primary sites (high/low x 4/19/34) is the primary table; all-80 is a
pre-registered SEPARATE later table. Secondary saved: absolute MSE, ratio_of_mean_risks,
per-source effects, leave-one-source-out, source_density_delta = r(512)-r(256).
Floor: CAL neutral numerical-error floor = mean BF16 cache/gate replay rounding MSE of
Q1 on CAL; a source's relative quantities are flagged when its Q1 denominator
M(c,e,Q1) < floor (small-denominator unmeasurable, route section 6). No post-hoc
main-summary switch.

====================================================================

  R2 old/new per-layer selection (there is no old new-bank solution).
- STABLE_FREE_LINEAR: free DxD correction D on Q1 residual R=Y-X@A_Q1, ridge toward 0
  rho=lambda/||A_Q1||^2 (lambda=1e-3); A_free=A_Q1+D. VERBATIM R1b stable_ridge_fit:
  F64 weighted thin-SVD sample-space DIRECT solve + F64 eigh cross-check (common gate,
  see 3c); certificates cross_check_f64_eigh_rel_l2<=1e-7, D_out_of_rowspace_rel_fro<=1e-10.
- L32: Phi=X@P32 (linear only, k=32, readout C_L 32x32).
- DELTA_N32: Phi=[X@P32, tanh(X@P32)] (k=64), X=u_t-u_s.
- ENDPOINT_N32: Phi=[u_t@P32-u_s@P32, tanh(u_t@P32)-tanh(u_s@P32)] (k=64). The
  per-endpoint tanh carries STATE info absent from delta-only.
- L64_Q32: Phi=X@P64 (linear only, k=64, readout C_L 64x32=2048). Capacity control:
  readout 2048 matches the N methods' C_L+C_N=32x32+32x32=2048, so "N beats L32" is
  tested against matched linear readout capacity before attributing gain to nonlinearity.
Odd symmetry: zero displacement (X=0 / u_t=u_s) -> Phi=0 -> pred=0; endpoint swap ->
Phi->-Phi -> pred->-pred. Holds by construction (no center offset, b=0).

3. FROZEN DESIGN DECISIONS (reviewer scrutiny invited)
====================================================================
(a) A0 prior — USER ADJUDICATED 2026-11-14: fresh per-config Q0. A0=A(alpha_Q0),
    alpha_Q0_j = E[dZ_j dH_j]/E[dZ_j^2] on the CAL training subset, dZ=X@W1^T,
    dH=tanhGELU(z1)-tanhGELU(z0). Common base shared by every representation within a
    config; anti-leakage clean (no old-CAL4 Dq reuse). This DEVIATES from G19's deployed
    Dq hash binding (old round) per route section 3 "each config refits its own
    init/normalization/ridge". The user chose this over deployed-Dq reuse and zero prior.
(b) P/Q selection rule — route names "CD-SVD or data-selected threshold" but gives no
    algorithm. AUTHOR FROZE: P = top-64 right singular vectors of weighted stacked CAL X;
    Q = top-32 right singular vectors of weighted stacked CAL gated residual (Y-XA0)odot g
    (F64 SVD, source-equal weights). Nested P32=P[:,:32]. CAL-only, deterministic. This is
    a defensible data-driven choice; reviewer should confirm it is fit-consistent and that
    Q spans the residual output directions.
(c) STABLE_FREE_LINEAR — VERBATIM reuse of R1b stable_ridge_fit (ridge_fit_core.py b22ac372):
    F64 weighted thin-SVD sample-space DIRECT solve + F64 eigh cross-check, ridge toward 0
    rho=lambda/||A_Q1||^2, A_free=A_Q1+D. The bank gate c_gate_msa is TIMESTEP MODULATION:
    per-channel and SHARED across sources at a site. VERIFIED empirically on the V2 bank
    (high04/low04/high19: gate identical across all 11 CAL sources, maxdiff=0.0), mirroring
    the R1b runner_recheck.py assertion. common_gate() asserts this invariant and fails if
    any source differs. Certificates enforced: cross_check_f64_eigh_rel_l2<=1e-7 and
    D_out_of_rowspace_rel_fro<=1e-10. (Author note: an initial per-source-gate CG variant was
    tried under a wrong assumption that the gate varied per source; it converged poorly and
    was REPLACED by the verbatim direct solver once gate-sharing was verified. No CG remains.)
(d) Readout solve — convex gated least squares. Normal matrix K = sum_c kron(GPhi_c, GQ_c),
    GPhi_c=w_c Phi_c^T Phi_c, GQ_c=Q^T diag(g_c^2) Q (UNWEIGHTED). The source weight w_c
    appears ONCE, on GPhi_c only (F1 fix: weighting BOTH Kronecker factors scales K by w_c^2
    and inflates C by 1/w_c=S*n=2816). Because the gate is COMMON across sources (3c),
    GQ_c=GQ_common and K reduces to kron(sum_c GPhi_c, GQ_common); the sum form is kept
    (general and correct). F64, relative Tikhonov floor eps=1e-6 on the normal diagonal for
    invertibility. C = reshape(solve(K, vec(T))), T=sum_c w_c Phi_c^T((R_c odot g_c^2) Q).
    Indexing verified by hand: K[(a,b),(a',b')]=GPhi[a,a']GQ[b,b'], row a*r_out+b.
    Smoke readout normal relative residuals ~1e-16; gradient at solved C rel ~1e-14.
(e) lambda_main=1e-3 (G19/R1b reference), readout eps=1e-6, Q1 maxiter 240 tol 1e-5 (R2
    fit_config.json). STABLE_FREE_LINEAR uses the direct SVD solve (no iteration count).
    All frozen in scope.fit_contract.
