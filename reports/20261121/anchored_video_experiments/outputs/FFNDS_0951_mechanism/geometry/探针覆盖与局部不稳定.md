# 0951 的 64 个 FFN 探针与熊身的时空覆盖

左摇时，保留锚点版的熊身纹理跨帧相关性从原提示的 0.620 降至 0.141；两者在所测熊身核心均直接落入 4 个探针，左摇的边界相交格还多 1 个。右摇有 5 个核心和 6 个边界命中，纹理相关性仍只有 0.229。观察削弱了「失败来自落在前景的探针总数下降」这一解释。像素层命中数对 FFN 状态中缺失的方向及下游放大没有直接鉴别力。[前景纹理与位移实测](../../FFNDS_anchor_scale24/camera7/diagnosis/0951主体不稳定分析.md)

## 同一组探针在八条视频上的几何投影

前处理先对补丁嵌入张量的时间、高、宽三轴按次序展平。实际网格为 21×29×52，行号为 (t×29+y)×52+x。VAE 步幅为 4×8×8，补丁为 1×2×2。按 16×16 像素划格，主分析取视频帧 4t。每个时空格有一行，去噪步为另一独立轴。一个格靠近可见轮廓只表示几何邻近。解码器的时空感受野、网络中的注意力与遮挡都会影响对应。

原提示、固定、左摇、右摇各取配对两臂，每条原片均与生成回执的 SHA-256 相符。依据原有 Lab 暖色色区抽取熊身，白口鼻、黑鼻和阴影可能缺失。核心要求方格过半面积属于向内腐蚀后的色区，边界要求方格内部同时有暖区与外部，较窄边界要求暖区面积占 20%–80%。三项分别计数，核心与边界可能重合。栅栏参照取右侧背景纹理格。

|---|---|---:|---:|---:|---:|---:|---:|

点集仅占 31,668 行的 0.2021%；各潜帧直接观测数为 4, 5, 1, 3, 3, 2, 3, 0, 4, 4, 5, 6, 5, 3, 5, 0, 1, 1, 4, 1, 4。以 0 起数的第 7、15 个潜帧零直接观测。读出可以从其他时空位置按特征相似性借用校正。Dense 列用相同坐标投影到 Dense 输出的暖色区域，以便判断轨迹几何差异；Dense 本身逐行求真值。

左摇候选的核心、边界分别命中 4、6。保持各潜帧点数与同帧布局，对整套探针做全部 1,508 种空间环移，核心命中的参考均值 3.19、10%–90% 区间 1–6；边界均值 3.37、区间 1–6。右摇候选的实际核心命中 5，环移均值 6.66、区间 4–9。环移是几何参照，不能解释为不同生成样本的置信区间。

将名义帧 4t 改为 4t−3、4t−1、4t+2 并截到 0–80，左摇候选核心命中范围 4–5、边界 6–8；右摇候选分别 5–7、3–7。按较窄边界，四个候选依次命中 3、2、3、3。各对应方式均保留了采样稀疏这一事实。

## 命中的时刻是否仍然失稳

将已测的 79 个视频中心帧按最近的名义潜帧 4t 分成 21 组，等距时归到较晚组。每组先求熊身纹理跨帧相关性的「锚点版减 Dense」中位数，再按同潜帧在候选熊身上是否有直接命中分别汇总。计量单位是整片时刻组，两个区域中命中的位置未必相同。

| 条件 | 核心直接命中 / 未命中时的纹理相关差 | 边界直接命中 / 未命中时的纹理相关差 |
|---|---:|---:|
| 原提示 | -0.178 / -0.083 | -0.096 / -0.083 |
| 要求固定 | -0.100 / -0.070 | -0.122 / -0.069 |
| 左摇 | -0.402 / -0.328 | -0.328 / -0.330 |
| 右摇 | -0.379 / -0.389 | -0.411 / -0.388 |

个别位置被真值回填时，同一潜帧的大多数熊身和边带位置仍依赖近似。上述统计只能检查时间上是否重合，不能把某个探针对一个像素的作用单独识别出来。

## 同预算对照

第一种对照在 21 个潜帧各置 3 个点，中间潜帧多置 1 个，空间位置取确定性的二维 Halton 点。第二种维持同样的潜帧点数，每帧一个点落在原始条件图的暖色核心，一个落在原图边界的过渡格，余点取上述 Halton 序列；两个目标区内按固定种子和最远点规则排序。两种对照都只用 64 行，均不使用生成片决定点位。首图色区规则服务于这一张泰迪熊图，未做跨来源验证。

首图分层在四个候选上都增加了核心与边界的直接命中，左右摇上同时损失了大量栅栏探针。各点预算相同，更换点位会改变线性系统条件、探针间协方差和跨区迁移。此处没有用替换点重新运行 FFN，因而只能判断关键区域几何覆盖尚可改善，视频质量与执行时间仍待干预检验。

## 有哪些局部方向可直接观测

考虑单个输出方向在网格上的未知标量残差向量 e，真值观测为 Sₚe。若没有施加 e 的结构先验，边差 eᵢ−eⱼ 可由 Sₚe 唯一确定，当且仅当相应的差分行属于 Sₚ 的行空间，即端点 i、j 均在 P 中。只要一端未观测，改变那一端的残差即可保持所有探针数值而改变边差。受限特征模型或跨层先验可以预测这条边，其效果需用未见真值检验。

实际 GLS 只在同潜帧内，将每个探针连向空间欧氏距离最近的另一个探针，再去除重复边。下表对 64 点的所有 2,016 个无序点对穷举。另设一个同预算探针组：在两个相邻潜帧的同一组空间坐标各放一对四邻接点，每两潜帧换一次边，从首帧暖色边界选择位置，余点承担全局观测。这样对已配对的两个时刻可分别观察局部共同模式、空间差、时间差和空间差的时间变化。显著运动会将主体移出这组坐标；实际沿轨迹的边还需要运动预测或特征匹配。

| 64 点设计 | 同潜帧四邻接边数 | 相邻潜帧同坐标边数 | 相邻潜帧允许最多一格移动的点对 | GLS 同潜帧边数 | GLS 边长中位数（格） |
|---|---:|---:|---:|---:|---:|
| 当前 | 0 | 0 | 1 | 42 | 14.71 |
| 仅时空分层 | 0 | 0 | 0 | 42 | 22.02 |
| 首图分层 | 7 | 0 | 3 | 43 | 8.25 |
| 首图时空成对 | 21 | 20 | 41 | 43 | 3.16 |

这给出一个严格而狭义的结论：在「以 64 个真值直接观测局部邻边」的目标下，现有点集未达最优。成对设计能观测更多指定的边，但它牺牲独立空间覆盖，解出的校正对全图和最终视频是否更优仍需实测。当前部署代码的 GLS 图只含同帧边，即使端点观测已提供时间边，也需相应的跨时刻观测度量才能在拟合中显式加权这些差分。[原生探针度量](../../../work/video_joint_impl/native_joint.py)

固定当前输入，区分几何空缺和创新方向缺失，还需在未观测熊身、边界及背景位置补算真实 FFN。可在相同的几何距离下比较真实残差和已探测创新子空间的正交分量，并分离采样外推误差与后续去噪传播。这要求在估计阶段屏蔽留出位置的真实输出。
