# 左摇四臂的主体尺度与匹配支持

同一张 0951 首帧和种子。原生前缀配对比较 Dense 与只在晚步近似的 low_only；早步近似前缀配对比较 high_only 与两步均近似的 candidate。每对进入晚步的潜变量相同。每条视频 79 个中心帧，统计单位为帧时刻；同片相邻帧存在相关性。纹理差值均为「晚步近似减晚步原生」。

| 臂 | 暖色熊身面积（占画面 %），P10 / 中位 / P90 | 熊身有效跟踪率 %，P10 / 中位 / P90 |
|---|---:|---:|
| dense | 5.5 / 14.9 / 17.5 | 77.8 / 91.0 / 100.0 |
| low_only | 5.3 / 13.6 / 16.4 | 70.7 / 88.7 / 100.0 |
| high_only | 5.3 / 8.0 / 9.2 | 59.3 / 75.0 / 99.9 |
| candidate | 4.9 / 7.1 / 8.3 | 39.2 / 69.9 / 99.2 |

二维面积、覆盖率以 2.5、10 个百分点分箱；各箱取两臂样本数较小值，相加后除以 79。原生前缀和早步近似前缀的分布重叠比例分别为 73.4%、46.8%。更细和更粗的分箱值均保留在 JSON。

匹配完全根据面积、有效跟踪率和时刻构建。每帧最多使用一次，先最大化满足卡钳的匹配数，再最小化标准化面积比、覆盖率差和时间错位之和。卡钳取较大与较小面积之比 ≤1.15 或 ≤1.30，对应覆盖率绝对差 ≤5 或 ≤10 个百分点。表列配对纹理相关差的中位数、差值为负的比例，以及匹配的实际差异。

宽卡钳（1.30、10 个百分点）、允许错位 ≤4 帧时，再将两个匹配帧同时限制在各自的早、中、晚时间窗。

| 前缀 | 1–26 帧 | 27–53 帧 | 54–79 帧 |
|---|---:|---:|---:|
| dense | 26 对，差 -0.043 | 26 对，差 -0.200 | 24 对，差 -0.298 |
| high_only | 24 对，差 -0.092 | 17 对，差 -0.206 | 16 对，差 -0.185 |

近似晚步时，纹理相关在两组有共同支持的画面中都较低。严格同帧、面积比 ≤1.15、覆盖率差 ≤5 个百分点时，原生前缀的 49 对里有 48 对下降；早步近似前缀的 23 对里有 22 对下降。放宽卡钳或允许有限的时间错位，这个方向依然保持。两组匹配支持不同，第二组尤为有限。

面积与覆盖率都是生成后的量；面积来自有遗漏的暖色色区，有效跟踪率来自 DIS 闭合阈值。匹配所保留的时刻可能集中于同一段姿态，不能从这里识别控制这两项之后的独立因果效应，也不能外推到没有共同支持的时段。
