# 0951 的镜头控制与主体不稳定

用户在已观看的新增 0951 对照中观察到，保留锚点版的熊持续闪烁、抖动，表面变平滑而轮廓不稳定。以下重点比较已交付的左右摇，再以同一图、同一种子的原提示和固定镜头作参照。七类镜头核查（本地归档） · 原提示核查（本地归档）

## 方法与边界

原片均为 832×464、16 fps、81 帧，逐条核对生成回执中的 SHA-256。每帧以平滑后的 Lab 色彩、最大连通区和内部腐蚀提取暖色熊身。该区域经抽帧检查，白口鼻、黑鼻尖以及部分脚掌或阴影常在选区之外。边带是暖色区边界的代理。不同生成轨迹中，熊的面积、转身和遮挡本身也不同。左摇锚点版选区（本地归档） · 左摇 Dense 选区（本地归档） · 右摇锚点版选区（本地归档） · 右摇 Dense 选区（本地归档）

以半分辨率 DIS 双向光流估计相邻帧对应，投回原分辨率，要求前后向闭合误差均小于 1 像素。亮度波动取当前亮度与前后帧对应位置均值的绝对差。纹理用当前亮度减去标准差 1.4 像素的高斯平滑，再与前后帧对齐后的同频响应均值算区域内 Pearson 相关。收严闭合阈值到 0.5 像素，左摇亮度波动仍为 12.99 / 8.66，右摇为 10.29 / 6.14。强形变、显露、遮挡与配准误差都会降低相关性。锚点版在摇镜下的有效覆盖率也更低，因此读数同时反映细节不稳定和追踪困难。

## 从运行回执到算子解释

三种提示的初始噪声哈希相同，实际运行配置指纹相同。固定一个提示，两版第 0 个去噪步的预测与步后潜变量相同；第 1 步首次启用近似，两版从这里分开。固定一种实现，只改变提示，三个提示的第 0 步原生预测已经不同。哈希可定位首次分岔，误差幅度须另行测量。各段视频各自建立锚点。[生成核验](../../../../work/vbench_scale24/audit_0951_pan.json)

四个去噪步按 0–3 编号，0 和 2 在当前轨迹逐位置计算原生 FFN 并留锚，1 和 3 在同一专家、同一层、同一时空索引复用锚点。低噪声专家的原生第 2 步接到的是候选自身的潜变量。一次原生 FFN 不会把模型拉回 Dense 的轨迹。这里的缓存跨去噪步；视频帧是另一个轴。

用 U 表示一层当前全部时空位置的 FFN 输入，F(U) 为真输出，B 为逐位置基底，包含锚点真输出、输入变化的线性项和所选通道的非线性增量。当前步还在固定的 64 个探针位置计算完整 FFN 并回填。在其余位置 N，校正写成 DₙR，Dₙ 有 16 个状态方向和 64 列探针核特征。扣除基底后的可表示校正秩最多为 80。若真正需要的联合残差 Eₙ=F(Uₙ)−Bₙ 含有垂直于 Dₙ 列空间的分量，则任何系数 R 都至少留下 ‖(I−Πᴅ)Eₙ‖ꜰ 的误差。Πᴅ 是到 Dₙ 列空间的正交投影。此式给出表示能力的限制；这几条视频尚未保存 Eₙ，无法直接给该下界赋值。[实际 FFN 与回填代码](../../../../work/anchored_scale/exact_port.py)

一个可检验的解释是，显著摇镜加上熊转身、局部遮挡与显露，使轮廓附近不同潜帧所需的残差不再由已有状态方向与 64 个探针充分代表。小缺口经过层间注意力、残差连接和后续去噪步放大，可以让全局摇镜正确而毛绒纹理逐帧重现失败。另一个可能是本层局部误差与原提示相当，但新增条件改变了后续网络对这种误差的增益。两种机制也可并存。颜色选区、局部光流和全片哈希均无法区分这两者。

能直接区分的检查是固定一条失败镜头的候选轨迹，在第 1、3 步对已选层少量留出的熊身、轮廓和栅栏位置，用完全相同的当前输入额外算一次原生 FFN。分别比较门控后的真实残差、沿轮廓相邻位置的残差差以及运动对齐后的跨帧差。如果留出轮廓的误差已显著增大，可定位到读出；如果同输入的误差很小，再用单步切回 Dense 的反事实定位误差放大。
