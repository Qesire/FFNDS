## 判读指标

光流复用三源的 OpenCV DIS 方法。81 帧先缩至 416×232 灰度，测量 40 对相隔两帧的光流，投回原分辨率，按每 8 个原像素采样。比较同一画布、同一时间的两个二维向量。运动位置已经分叉时，差异也会进入统计。单位为原分辨率像素／两帧。全片及五个连续 16 帧间隔分别计算。

投影增益为候选与 Dense 光流的内积总和除以 Dense 光流平方和。参考流 RMS <0.5 像素的来源／时间窗单独标记低运动，表中不报增益，原始 JSON 保留有限值及有效支撑。角差是两边模长均 ≥0.5 像素的格点上的逐点角度均值，有效格点为零时留空。过量和不足分别累加逐点流幅差的正部、负部。EPE 为两流向量差的平均长度。共同与差分误差分别沿水平和垂直相邻网格取向量和、差，再除以 √2，记录两轴合并的 RMS 及逐轴的有符号误差—目标二阶矩。

每个方法独立计算灰度帧用 σ=1、4 像素高斯平滑之差的标准差，除以原帧的标准差，再对各帧等权平均。纹理比是该均值的候选／Dense 比值。静区亮度偏离取奇数帧与前后帧线性插值之差的绝对值，在两边光流均 <0.5 像素的网格上统计，单位为 0–255 灰度级。这个时序量同时响应闪烁、短时运动与真实亮度变化。逐源 JSON 也保留各臂独立静区统计、共同静区覆盖率及 95 分位数，无静区时留空。

每个分组内以来源为单位计算各指标中位数及四分位范围，同时记录支持的来源数。帧或格点不会增加独立来源数。不同来源的生成质量由人工核查。这些统计描述对照差异。

## 已有盲审样例的指标表现

在三条已经人工判读的原片中，保留锚点版相对 Dense 的双边运动区角差均低于出现模糊的零跨步版，0392 为 21.0° / 29.2°，0800 为 15.5° / 26.9°，1013 为 32.1° / 73.1°。1013 的双边运动有效点仅占 7.4% / 6.6%。三源中频纹理比均以保留锚点版较高。0392 的共同／差分误差 RMS 反而在视觉更清晰的片中更高，2.63 / 0.33 对 2.34 / 0.27 像素。这些是三个已知样例的经验观察，未作为质量分数或筛选门槛。[冻结原片与复算记录](../../work/anchored_scale/metrics_controls.json)
