## 复算进程

在已绑定 Wan 模型、CAL3 参数和原始输入的学校环境中，使用两个独立的生成进程。每次作业单 A100、4 CPU，保留原任务封包中的环境变量、工作目录和编码约定。后续复算时，核心批的入口支持仅运行核心的选项；将此版入口纳入新的 manifest 后运行。

```sh
python -B run.py --core-only
```

该进程结束后，第二个作业在独立目录载入同一组配置与参照，运行下列入口。它会在小槽分配前同步 GPU，回收 Python 对象，并清空 CUDA 缓存分配器中的可回收块。新进程另外记录独立 Dense 待机、峰值，及小槽热身后的实测驻留。

```sh
python -B compact_only.py
```
